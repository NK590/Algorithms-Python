# 입출력과 시간 복잡도 (I/O and Complexity)

문제를 푸는 **도구**를 다룹니다. 입력을 빠르게 읽고 출력하는 법, 그리고 풀이가 시간 안에 돌아갈지 **미리 가늠하는** 법입니다. 알고리즘 자체는 아니지만, 이 둘을 모르면 맞는 풀이도 시간 초과가 납니다.

## 한눈에 비교

| 개념 | 해결하는 문제 | 핵심 |
|---|---|---|
| [빠른 입출력](fast-io/) | 입력·출력이 많아서 시간 초과 | `sys.stdin.readline`, 한 번에 모아 출력 |
| [시간 복잡도](time-complexity/) | 이 풀이가 시간 안에 돌까? | 입력 크기 → 허용되는 복잡도 |

## 읽는 순서

1. [시간 복잡도](time-complexity/): 문제를 읽고 N부터 보는 습관
