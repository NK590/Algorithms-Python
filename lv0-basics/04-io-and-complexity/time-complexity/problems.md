# 연습문제 — 시간 복잡도

쉬운 것부터 어려운 순서로 정리했습니다. **문제 지문은 옮기지 않고** 링크와 "배울 점"만 적었습니다. 난이도(solved.ac 티어)는 시간이 지나며 바뀔 수 있어서 표에 적지 않았으니 각 링크에서 확인하세요.

| # | 문제 | 유형 | 배울 점 |
|---|---|---|---|
| 1 | [백준 24262 알고리즘 수업 - 알고리즘의 수행 시간 1](https://www.acmicpc.net/problem/24262) | 상수 시간 | 주어진 의사 코드의 수행 횟수와 차수를 읽어 낸다 |
| 2 | [백준 24263 알고리즘 수업 - 알고리즘의 수행 시간 2](https://www.acmicpc.net/problem/24263) | 선형 | 단일 반복문의 횟수는 n이다 |
| 3 | [백준 24264 알고리즘 수업 - 알고리즘의 수행 시간 3](https://www.acmicpc.net/problem/24264) | 이차 | 이중 반복문의 횟수는 n²이다. 정수 오버플로가 없는 파이썬에서는 그대로 곱하면 된다 |

## 풀이 메모

- 이 문제들은 구현이 아니라 **반복 횟수를 식으로 세는 것**이 핵심입니다. `count_single_loop`, `count_nested_loops`의 결과를 먼저 손으로 확인해 보세요.
- 문제를 읽을 때마다 입력 크기로 허용 복잡도를 가늠하는 습관을 들이세요. ([복잡도 치트시트](../../../docs/complexity-cheatsheet.md))
