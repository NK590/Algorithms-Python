# Naive Prime Number Check (단순 소수 판별)

> **한 줄 요약**: 2부터 √n까지 나누어 떨어지는 수가 있는지 확인해서, 하나라도 있으면 소수가 아니라고 판정한다.

## 1. 언제 쓰나 (문제 신호)

- "소수인가?", "소수의 개수", "소수만 골라서 …" 처럼 **수 몇 개**를 판별할 때
- 수 하나가 10^12 정도까지 커도 √n = 10^6번이면 끝나니 충분합니다.
- 범위 안의 소수를 **한꺼번에** 구해야 한다면(수백만 개) [에라토스테네스의 체](../../../lv1-elementary/06-number-theory/sieve-of-eratosthenes/)가, n이 10^18까지 커지면 [밀러-라빈](../../../lv4-expert/01-number-theory/miller-rabin/)이 필요합니다.

**소수**는 1과 자기 자신 외에 약수가 없는 **2 이상**의 정수입니다. **1은 소수가 아닙니다.**

## 2. 핵심 아이디어

가장 단순한 방법은 2부터 n−1까지 모두 나눠 보는 것(O(n))입니다. 여기서 한 가지를 관찰합니다.

> n이 합성수라면 n = a × b (1 < a ≤ b)로 쓸 수 있고, 이때 **a ≤ √n**입니다. (둘 다 √n보다 크면 곱이 n보다 커진다)

즉 합성수는 **√n 이하의 약수를 반드시 하나** 가집니다. 그래서 2부터 √n까지만 확인하면 충분하고, 시간은 O(√n)입니다. √n 이하에서 약수가 하나도 없다면 소수입니다.

### 무엇을 저장하고 어떻게 움직이나

소수는 1과 자기 자신만 약수로 가지는 2 이상의 정수입니다. 판별하려는 수 하나의 작은 약수가 있는지 확인하는 방법과, 많은 수의 소수 여부를 한꺼번에 전처리하는 체를 구분하세요. 질문 수와 최댓값이 방법을 결정합니다.

### 왜 이 방법이 맞는가

합성수 n은 `n=a*b`로 쓸 수 있고 두 인수가 모두 sqrt(n)보다 클 수 없습니다. 따라서 2부터 제곱근까지 약수가 하나도 없으면 소수입니다. 1 이하를 먼저 제외하고, 짝수를 처리한 뒤 홀수 후보만 검사해도 누락이 없습니다.

### 작은 예제로 검산하기

49는 2, 3, 5로 나누어지지 않지만 7로 나누어지므로 합성수입니다. 반복 조건을 `d*d < n`으로 쓰면 7을 확인하지 않아 틀립니다. 여러 질문에서 같은 범위를 계속 검사한다면 체로 비용을 공유할 수 있습니다.

## 3. 손으로 따라가기

**97**: √97 ≈ 9.8이므로 2~9를 확인합니다.

| d | 97 % d | 나누어 떨어짐? |
|---|---|---|
| 2 | 1 | 아니오 |
| 3 | 1 | 아니오 |
| 4 | 1 | 아니오 |
| 5 | 2 | 아니오 |
| 6 | 1 | 아니오 |
| 7 | 6 | 아니오 |
| 8 | 1 | 아니오 |
| 9 | 7 | 아니오 |

약수가 없으므로 **97은 소수**입니다.

**91**: √91 ≈ 9.5. `d = 7`에서 `91 % 7 = 0`이므로 즉시 **합성수**(7 × 13)로 판정하고 멈춥니다. (13은 √91보다 크지만, 짝이 되는 7을 이미 찾았습니다)

## 4. 구현

전체 코드는 [solution.py](solution.py)에 있습니다.

```python
from math import isqrt

def is_prime(n):
    if n < 2:                                  # 0, 1, 음수는 소수가 아니다
        return False
    for d in range(2, isqrt(n) + 1):           # √n 이하까지, 같은 값(√n)도 포함
        if n % d == 0:
            return False
    return True
```

`isqrt`는 정수 제곱근(내림)입니다. 실수 `sqrt`는 아주 큰 수에서 오차가 생길 수 있어 정수 연산이 안전합니다.

## 5. 복잡도와 입력 크기 가이드

- 시간 **O(√n)**, 공간 O(1)입니다.
- n ≤ 10^12 정도의 수 몇 개는 이 방법으로 충분합니다. 수 N개를 판별해야 하면 O(N√n)이므로, N이 크면 체를 쓰세요. ([복잡도 치트시트](../../../docs/complexity-cheatsheet.md))

## 6. 자주 하는 실수

- **1을 소수로 취급**: `n < 2`를 먼저 걸러야 합니다.
- **상한을 `isqrt(n)`으로만 두기**: `range(2, isqrt(n))`는 √n을 빼먹어서 **소수의 제곱(4, 9, 25, …)을 소수로** 판정합니다. `+ 1`이 필요합니다.
- **`n`까지 반복**: 답은 맞지만 n이 크면 시간 초과입니다.
- **실수 `sqrt`**: 큰 수에서 `int(sqrt(n))`이 한 칸 틀릴 수 있습니다. `isqrt`를 쓰세요.
