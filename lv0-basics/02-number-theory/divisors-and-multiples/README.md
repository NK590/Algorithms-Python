# Divisors and Multiples (약수와 배수)

> **한 줄 요약**: `a % b == 0`이면 b는 a의 약수, a는 b의 배수다. 약수는 `(d, n/d)` 쌍으로 나오므로 √n까지만 찾으면 된다.

## 1. 언제 쓰나 (문제 신호)

- "약수", "배수", "나누어떨어진다", "완전수", "K번째 약수" 같은 표현
- 어떤 수의 약수를 **모두** 나열하거나 그 개수·합을 구해야 할 때
- 최대공약수·최소공배수([유클리드 호제법](../../../lv1-elementary/06-number-theory/euclidean-algorithm/)), 소인수분해로 이어지는 기초

## 2. 핵심 아이디어

- `n`의 약수 `d`가 있으면 `n // d`도 약수입니다. 약수는 **짝**으로 나옵니다. 36의 약수는 (1, 36), (2, 18), (3, 12), (4, 9), (6, 6)입니다.
- 짝 중 작은 쪽은 항상 **√n 이하**입니다. 그래서 `1`부터 `√n`까지만 나누어 보고, 나누어 떨어지면 `d`와 `n // d`를 함께 기록합니다. 시간 O(√n).
- `d == n // d`(n이 제곱수이고 d = √n)일 때는 **한 번만** 넣어야 합니다.
- **배수**는 `n, 2n, 3n, …`을 더해 가며 만듭니다. 한계(limit) 이하의 배수는 `limit // n`개입니다.

## 3. 손으로 따라가기

**36의 약수** (√36 = 6이므로 d = 1..6):

| d | 36 % d | 짝 `36 // d` | 기록 |
|---|---|---|---|
| 1 | 0 | 36 | 1, 36 |
| 2 | 0 | 18 | 2, 18 |
| 3 | 0 | 12 | 3, 12 |
| 4 | 0 | 9 | 4, 9 |
| 5 | 1 | - | - |
| 6 | 0 | 6 (같음) | 6 (한 번만) |

작은 쪽 `1, 2, 3, 4, 6`과 큰 쪽을 거꾸로 이은 `9, 12, 18, 36`을 합치면 `[1, 2, 3, 4, 6, 9, 12, 18, 36]`입니다. 약수는 모두 9개입니다.

## 4. 구현

전체 코드는 [solution.py](solution.py)에 있습니다.

```python
def divisors(n):
    small, large = [], []
    for d in range(1, isqrt(n) + 1):
        if n % d == 0:
            small.append(d)
            if d != n // d:                  # 제곱수일 때 √n 이 두 번 들어가면 안 된다
                large.append(n // d)
    return small + large[::-1]               # 큰 쪽은 거꾸로 이어 붙이면 오름차순
```

`is_perfect_number`(자기 자신을 뺀 약수의 합이 자기와 같은 수), `kth_divisor`, `multiples`도 있습니다. 10^4 이하의 완전수는 6, 28, 496, 8128입니다.

## 5. 복잡도와 입력 크기 가이드

- 약수 하나 구하기가 아니라 **전부 구하는** 데 O(√n)입니다. n = 10^12이면 10^6번 반복으로 충분합니다.
- 1부터 n까지 모든 수의 약수가 필요하면 하나씩 구하는 것보다 [체 방식](../../../lv1-elementary/06-number-theory/divisor-sieve/)이 빠릅니다. ([복잡도 치트시트](../../../docs/complexity-cheatsheet.md))

## 6. 자주 하는 실수

- **제곱수 중복**: 36에서 6이 두 번 들어가 약수가 10개로 세어집니다. `d != n // d` 검사가 필요합니다.
- **상한을 √n 미만으로**: `range(1, isqrt(n))`는 √n 자체를 놓칩니다. `+ 1`을 넣으세요.
- **정렬 순서**: 작은 쪽과 큰 쪽을 그냥 이어 붙이면 순서가 섞입니다. 큰 쪽을 뒤집어 붙이거나 마지막에 정렬하세요.
- **O(n) 풀이**: n이 10^9이면 시간 초과입니다.

## 7. 변형과 응용

- **약수의 개수 / 합**: 약수를 모두 모은 뒤 `len`, `sum`을 구합니다. 소인수분해를 쓰면 약수를 나열하지 않고도 구할 수 있습니다.
- **최대공약수 / 최소공배수**: [유클리드 호제법](../../../lv1-elementary/06-number-theory/euclidean-algorithm/)
- **완전수 / 소수 판별**: 약수가 1과 자기 자신뿐이면 소수입니다. ([단순 소수 판별](../naive-prime-check/))
