# Base Conversion (진법 변환)

> **한 줄 요약**: 같은 수를 10진수, 2진수, 16진수 등 다른 진법으로 적는 방법. 나머지를 모아 뒤집으면 b진법으로, 앞자리부터 `× b + 새 자리`를 반복하면 10진수로 바뀐다.

## 1. 언제 쓰나 (문제 신호)

- "2진수로 바꿔라", "16진수 출력", "B진법 수를 10진수로", "-2진수"
- 비트(2진수)를 다루는 문제: [비트 연산자](../../../lv1-elementary/09-bit-manipulation/bitwise-operators/), [비트마스크](../../../lv1-elementary/09-bit-manipulation/bitmask/)
- 숫자를 자릿수별로 처리해야 하는 문제 (자릿수의 합, 뒤집기)

## 2. 핵심 아이디어

b진법에서 `d_k … d_1 d_0`은 `d_k·b^k + … + d_1·b + d_0`입니다. 10 이상의 숫자는 `A=10, B=11, …, Z=35`로 적습니다.

- **10진수 → b진법**: n을 b로 나눈 **나머지**가 가장 낮은 자리(`d_0`), **몫**에 같은 일을 반복하면 다음 자리입니다. 몫이 0이 될 때까지 반복하고, 나온 나머지를 **뒤집으면** 결과입니다.
- **b진법 → 10진수**: 앞자리부터 읽으며 `값 = 값 × b + 현재 자리`를 반복합니다. (호너의 방법. 거듭제곱을 따로 계산하지 않아도 됩니다)
- **음수 진법**(예: -2진법)에서도 같은 방식인데, 나머지가 0 이상이 되도록 보정합니다. 나머지가 음수가 나오면 `나머지 - b`를 쓰고 몫을 1 올립니다. (`n = q·b + r`에서 `r`에 `-b`를 더하고 `q`에 1을 더하면 식이 그대로 성립합니다)

## 3. 손으로 따라가기

**37을 2진법으로**:

| n | n = 몫 × 2 + 나머지 | 나머지 |
|---|---|---|
| 37 | 37 = 18 × 2 + 1 | 1 |
| 18 | 18 = 9 × 2 + 0 | 0 |
| 9 | 9 = 4 × 2 + 1 | 1 |
| 4 | 4 = 2 × 2 + 0 | 0 |
| 2 | 2 = 1 × 2 + 0 | 0 |
| 1 | 1 = 0 × 2 + 1 | 1 |

나머지를 아래에서 위로 읽으면 `100101`입니다. 되돌리기: `1·32 + 0·16 + 0·8 + 1·4 + 0·2 + 1 = 37`.

**-13을 -2진법으로**: 나머지가 음수가 나오면 보정합니다.

| n | `divmod(n, -2)` | 보정 후 (몫, 나머지) |
|---|---|---|
| -13 | (6, -1) | (7, 1) |
| 7 | (-4, -1) | (-3, 1) |
| -3 | (1, -1) | (2, 1) |
| 2 | (-1, 0) | (-1, 0) |
| -1 | (0, -1) | (1, 1) |
| 1 | (-1, -1) | (0, 1) |

나머지를 거꾸로 읽으면 `110111`이고, `1·(-32) + 1·16 + 0·(-8) + 1·4 + 1·(-2) + 1·1 = -13`입니다.

## 4. 구현

전체 코드는 [solution.py](solution.py)에 있습니다.

```python
DIGITS = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ"

def to_base(n, base):
    if n == 0:
        return "0"
    digits = []
    while n > 0:
        n, remainder = divmod(n, base)
        digits.append(DIGITS[remainder])         # 낮은 자리부터 나온다
    return "".join(reversed(digits))

def from_base(text, base):
    value = 0
    for ch in text.upper():
        value = value * base + DIGITS.index(ch)  # 앞자리부터 읽는다
    return value
```

파이썬 내장으로는 `bin(n)`, `oct(n)`, `hex(n)`, `format(n, "b")`, `int("ZZ", 36)`이 있습니다. 36진법까지는 `int(text, base)`로 읽을 수 있지만 **쓰는** 내장은 2·8·16진법뿐이라, 임의의 진법으로 출력할 때는 직접 만듭니다.

## 5. 복잡도와 입력 크기 가이드

- 자릿수가 `log_b(n)`개이므로 시간 O(log n)입니다. n이 10^18이어도 2진법으로 60자리 남짓입니다.
- 파이썬 정수는 크기 제한이 없어서 아주 큰 수도 그대로 변환됩니다. (다만 `int`와 `str` 변환 길이에 제한이 있는 환경이 있습니다)

## 6. 자주 하는 실수

- **나머지를 뒤집지 않기**: 나머지는 낮은 자리부터 나오므로 마지막에 뒤집어야 합니다.
- **0 처리**: `n == 0`이면 반복문이 한 번도 돌지 않아 빈 문자열이 됩니다. 따로 `"0"`을 돌려주세요.
- **음수 처리**: 파이썬의 `%`와 `divmod`는 C++과 부호 규칙이 다릅니다. 음수 진법에서는 나머지 보정이 필요합니다.
- **대소문자**: 16진수 출력에서 `A-F`와 `a-f` 중 문제가 정한 쪽을 쓰세요.
- **진법을 넘는 숫자**: `"12"`를 2진법으로 읽으면 `2`는 올 수 없는 숫자입니다. 입력 검증이 필요한 문제도 있습니다.

## 7. 변형과 응용

- **2진수 ↔ 8진수/16진수**: 2진수를 3자리(8진수) 또는 4자리(16진수)씩 끊어 변환하면 됩니다.
- **비트마스크**: 정수를 2진수 비트의 집합으로 보는 기법. ([비트마스크](../../../lv1-elementary/09-bit-manipulation/bitmask/))
- **진법에서의 덧셈/곱셈**: 자릿수 배열로 직접 올림을 처리합니다.
