# Modular Arithmetic (나머지 연산)

> **한 줄 요약**: 큰 수를 직접 다루지 않고 **나머지만 가지고** 더하고 빼고 곱한다. 중간마다 나머지를 취해도 최종 나머지가 같다.

## 1. 언제 쓰나 (문제 신호)

- "**1,000,000,007로 나눈 나머지를 출력**" — 답이 너무 커서 나머지로 묻는 거의 모든 경우의 수·DP 문제
- 값이 매우 큰 팩토리얼, 피보나치, 거듭제곱
- 주기가 있는 문제(요일, 시계, 원형 인덱스 `(i + 1) % n`)

## 2. 핵심 아이디어

나머지는 덧셈·뺄셈·곱셈과 **자유롭게 섞일 수 있습니다.**

```
(a + b) % m == ((a % m) + (b % m)) % m
(a - b) % m == ((a % m) - (b % m) + m) % m
(a * b) % m == ((a % m) * (b % m)) % m
```

그래서 계산 도중 값이 커질 때마다 `% m`을 해서 값을 `m` 미만으로 유지할 수 있습니다. 예를 들어 20!처럼 큰 수를 만들지 않고 `result = result * i % m`만 반복해도 끝에 `20! % m`이 됩니다.

**나눗셈은 안 됩니다.** `(a / b) % m`은 `((a % m) / (b % m)) % m`이 아닙니다. 나누려면 **모듈러 역원**을 곱해야 하고, 이는 [Lv2](../../../lv2-intermediate/06-number-theory/modular-inverse/)에서 다룹니다.

**음수에 주의**: 파이썬의 `%`는 항상 0 이상(`m`이 양수일 때)을 돌려주지만, C/C++/Java에서는 `-7 % 3 == -1`처럼 음수가 나옵니다. 다른 언어로 옮길 때를 위해 뺄셈에서는 `+ m`으로 보정하는 습관을 들이세요.

## 3. 손으로 따라가기

**(7 × 5) % 4**: 직접 계산하면 35 % 4 = 3. 나머지끼리 계산하면 (7 % 4) × (5 % 4) = 3 × 1 = 3 → 3 % 4 = 3. 같습니다.

**20! % 1000** (`factorial_mod(20, 1000)`): 중간 값이 항상 1000 미만입니다.

| i | `result × i % 1000` |
|---|---|
| 2 | 2 |
| 3 | 6 |
| 4 | 24 |
| 5 | 120 |
| 6 | 720 |
| 7 | 5040 % 1000 = 40 |
| 8 | 320 |
| 9 | 2880 % 1000 = 880 |
| 10 | 8800 % 1000 = 800 |
| 11 | 8800 % 1000 = 800 |
| 12 | 9600 % 1000 = 600 |
| 13 | 7800 % 1000 = 800 |
| 14 | 11200 % 1000 = 200 |
| 15 | 3000 % 1000 = 0 |
| 16 ~ 20 | 0 |

20! = 2432902008176640000이고, 끝이 `000`이라 나머지가 0인 것과 일치합니다.

## 4. 구현

전체 코드는 [solution.py](solution.py)에 있습니다.

```python
def factorial_mod(n, m):
    result = 1 % m                       # m = 1 이면 결과는 항상 0 이다
    for i in range(2, n + 1):
        result = result * i % m          # 매번 나머지를 취해 값을 작게 유지한다
    return result

def fibonacci_mod(n, m):
    a, b = 0, 1 % m
    for _ in range(n):
        a, b = b, (a + b) % m
    return a
```

`pow(a, b, m)`은 `a^b % m`을 빠르게 구하는 내장 함수입니다. 이 문서의 `power_mod_slow`는 b번 곱하는 O(b) 방식이라 b가 크면 쓸 수 없고, 빠른 방법은 [빠른 거듭제곱](../../../lv2-intermediate/05-divide-and-conquer/fast-exponentiation/)입니다.

## 5. 복잡도와 입력 크기 가이드

- 나머지를 취하면 값이 항상 `m` 미만이라 연산 하나가 O(1)입니다. (취하지 않으면 값의 자릿수만큼 느려집니다)
- n이 10^6~10^7인 팩토리얼·피보나치 반복은 CPython에서 1초 안팎입니다. ([복잡도 치트시트](../../../docs/complexity-cheatsheet.md))
- `m = 10^9 + 7`처럼 소수를 쓰는 이유는 나눗셈(역원)이 가능해서입니다.

## 6. 자주 하는 실수

- **마지막에만 `% m`**: 곱셈이 반복되는 중간에 취하지 않으면 값이 폭발해서 느려지거나(파이썬) 오버플로(C++)가 납니다.
- **뺄셈 후 음수**: 다른 언어로 옮길 때 `% m` 결과가 음수일 수 있습니다. `(a - b + m) % m`으로 보정하세요.
- **나눗셈에 적용**: `a / b % m`은 틀립니다. 역원을 곱해야 합니다.
- **`m = 1` 경계**: 초기값을 `1`로 두면 `1 % 1 = 0`이어야 하는데 1이 남습니다. `1 % m`으로 시작하세요.

## 7. 변형과 응용

- [빠른 거듭제곱](../../../lv2-intermediate/05-divide-and-conquer/fast-exponentiation/): `a^b % m`을 O(log b)로

- **DP에서의 나머지**: 경우의 수를 세는 점화식에서 값을 더할 때마다 나머지를 취합니다.
