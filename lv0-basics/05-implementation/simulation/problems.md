# 연습문제 — 구현·시뮬레이션

쉬운 것부터 어려운 순서로 정리했습니다. **문제 지문은 옮기지 않고** 링크와 "배울 점"만 적었습니다. 난이도(solved.ac 티어)는 시간이 지나며 바뀔 수 있어서 표에 적지 않았으니 각 링크에서 확인하세요.

| # | 문제 | 유형 | 배울 점 |
|---|---|---|---|
| 1 | [백준 2884 알람 시계](https://www.acmicpc.net/problem/2884) | 시계 계산 | 시각에서 분을 빼고, 0시 이전이 되면 전날로 넘어가는 처리 (`add_minutes`) |
| 2 | [백준 2525 오븐 시계](https://www.acmicpc.net/problem/2525) | 시계 계산 | 시각에 분을 더하는 같은 연산. 하루 1440분으로 나눈 나머지를 쓴다 |
| 3 | [백준 1100 하얀 칸](https://www.acmicpc.net/problem/1100) | 격자 규칙 | 체스판에서 `(행 + 열)`이 짝수인 칸이 흰색이다. 규칙을 식으로 바꾼다 |
| 4 | [백준 1158 요세푸스 문제](https://www.acmicpc.net/problem/1158) | 원형 제거 | [solution.py](solution.py)의 `josephus_order`와 `main()`이 이 문제의 출력 형식(`<3, 6, 2, …>`)을 만든다 |
| 5 | [백준 14503 로봇 청소기](https://www.acmicpc.net/problem/14503) | 방향 전환 시뮬레이션 | 방향 배열과 회전, 방문 표시를 함께 다루는 전형적인 구현 문제. 규칙을 하나도 빠뜨리지 않는 것이 관건이다 |

## 풀이 메모

- 5번은 조건이 길어서, 먼저 규칙을 번호를 붙여 적고 예제를 손으로 따라간 뒤 코드를 짜세요.
- 4번은 N, K가 작아서 덱 시뮬레이션이 충분하고, 마지막 생존자만 묻는 변형은 `josephus_last`로 풀립니다.
