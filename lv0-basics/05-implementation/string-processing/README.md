# String Processing (문자열 처리)

> **한 줄 요약**: 문자열을 한 글자씩 훑으며 쪼개고, 세고, 압축하고, 규칙에 따라 바꾼다.

## 1. 언제 쓰나 (문제 신호)

- "단어의 개수", "문자열 압축", "특정 문자를 바꿔라", "알파벳 규칙에 따라 변환", "공통 접두사"
- 입력이 문장·단어 목록이고, 정렬이나 탐색 알고리즘이 아니라 **문자열 규칙을 구현**해야 할 때
- 내장 메서드(`split`, `replace`, `join`, `startswith`)로 풀리는지 먼저 살펴보고, 안 되는 규칙은 직접 훑습니다.

## 2. 핵심 아이디어

- **한 번 훑으면서 상태를 유지**합니다. 예를 들어 단어 수 세기는 "지금 단어 안에 있는가"만 기억하고, 단어가 **시작하는 순간**(공백 → 글자)에 1을 더합니다.
- **구간 경계를 조심**합니다. 연속된 같은 글자를 압축할 때 마지막 구간은 반복문 안에서 닫히지 않으므로, 반복이 끝난 뒤 따로 기록해야 합니다.
- **긴 패턴을 먼저 맞춰 봅니다.** 크로아티아 알파벳에서 `dz=`는 `z=`를 포함하므로, `dz=`를 먼저 검사하지 않으면 `d`와 `z=`로 잘못 셉니다.
- 결과 문자열은 `+=` 대신 **리스트에 모아 `"".join`** 합니다.

## 3. 손으로 따라가기

**런렝스 인코딩** `aaabcc`: 연속된 같은 글자를 `글자 + 개수`로 줄입니다.

| i | `s[i]` | 앞 글자와 같은가 | count | 하는 일 |
|---|---|---|---|---|
| 1 | a | 같음 | 2 | - |
| 2 | a | 같음 | 3 | - |
| 3 | b | 다름 | 1 | `a3` 기록 |
| 4 | c | 다름 | 1 | `b1` 기록 |
| 5 | c | 같음 | 2 | - |
| 끝 | | | | 마지막 구간 `c2` 기록 |

결과는 `a3b1c2`입니다. **크로아티아 알파벳** `ljes=njak`: `lj`(1) `e`(1) `s=`(1) `nj`(1) `a`(1) `k`(1) → 6글자입니다.

## 4. 구현

전체 코드는 [solution.py](solution.py)에 있습니다.

```python
def count_words(s):
    count = 0
    in_word = False
    for ch in s:
        if ch != " " and not in_word:      # 단어가 시작하는 순간
            count += 1
        in_word = ch != " "
    return count
```

함께 있는 함수: `run_length_encode` / `run_length_decode`, `longest_common_prefix`, `split_by`(내장 `split`을 직접 구현), `count_croatian`.

## 5. 복잡도와 입력 크기 가이드

- 대부분 문자열을 한 번 훑는 **O(n)** 입니다. 길이 10^6도 문제없습니다.
- 반복문 안에서 `s[:i] + s[i+1:]`처럼 문자열을 자르고 이어 붙이면 O(n²)이 됩니다. ([복잡도 치트시트](../../../docs/complexity-cheatsheet.md))

## 6. 자주 하는 실수

- **마지막 구간 누락**: 반복문 안에서 "다음 글자가 다를 때" 기록하는 방식은 마지막 구간을 놓칩니다.
- **패턴 순서**: 긴 패턴(`dz=`)을 짧은 패턴보다 먼저 확인하세요.
- **연속 공백, 앞뒤 공백**: 내장 `split()`은 공백을 알아서 정리하지만, `split(" ")`은 빈 문자열이 섞입니다.
- **줄바꿈 포함**: 입력에서 `rstrip()`을 하지 않으면 마지막 글자가 `"\n"`입니다.
- **개수가 두 자리 이상**: 압축을 풀 때 `a12`의 개수를 한 자리만 읽으면 틀립니다.
