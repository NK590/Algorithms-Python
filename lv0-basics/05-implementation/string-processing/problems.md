# 연습문제 — 문자열 처리

쉬운 것부터 어려운 순서로 정리했습니다. **문제 지문은 옮기지 않고** 링크와 "배울 점"만 적었습니다. 난이도(solved.ac 티어)는 시간이 지나며 바뀔 수 있어서 표에 적지 않았으니 각 링크에서 확인하세요.

| # | 문제 | 유형 | 배울 점 |
|---|---|---|---|
| 1 | [백준 1152 단어의 개수](https://www.acmicpc.net/problem/1152) | 단어 세기 | 앞뒤·연속 공백이 있어도 단어 수를 센다. `count_words`나 내장 `split()` |
| 2 | [백준 2941 크로아티아 알파벳](https://www.acmicpc.net/problem/2941) | 패턴 규칙 | 여러 글자가 한 글자로 취급된다. [solution.py](solution.py)의 `count_croatian`/`main()`이 그대로 풀이다 |
| 3 | [백준 1316 그룹 단어 체커](https://www.acmicpc.net/problem/1316) | 연속 구간 | 같은 글자가 떨어져서 다시 나오면 그룹 단어가 아니다. 이미 본 글자를 기록한다 |
| 4 | [백준 11655 ROT13](https://www.acmicpc.net/problem/11655) | 글자 변환 | 알파벳을 13칸 민다. 대소문자와 알파벳이 아닌 문자를 그대로 둔다 ([문자열 기초](../../01-data-structures/string-basics/)의 `caesar_shift`) |

## 풀이 메모

- 3번은 `set`으로 이미 나온 글자를 기록하되, 바로 앞 글자와 같을 때는 새 구간이 아니라는 점을 처리합니다.
- 압축과 해제(`run_length_encode`/`decode`)는 위 문제와 직접 대응하지는 않지만, "구간 경계를 닫는 법"을 연습하기 좋습니다.
