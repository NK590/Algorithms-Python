## 개요 (기존 주석에서 옮김)

- 원소들을 순서대로 나열한 연속적인 형태의 자료 구조
- 이 때, 각 원소에 붙은 순서(번호)를 인덱스라고 하며, 이 인덱스를 통해 해당 원소에 바로 접근이 가능
- 주어진 위치의 원소를 참조하거나 교환하는 데에는 O(1)의 시간 복잡도
- 주어진 위치의 원소를 삭제하거나 주어진 위치에 원소를 끼워넣을 떄는 일반적으로 O(n)의 시간 복잡도
- 대부분의 프로그래밍 언어에서 자체 지원하는 자료구조이고, Python에서는 일반적으로 리스트로 구현
