# 연습문제 — 문자열 기초

쉬운 것부터 어려운 순서로 정리했습니다. **문제 지문은 옮기지 않고** 링크와 "배울 점"만 적었습니다. 난이도(solved.ac 티어)는 시간이 지나며 바뀔 수 있어서 표에 적지 않았으니 각 링크에서 확인하세요.

| # | 문제 | 유형 | 배울 점 |
|---|---|---|---|
| 1 | [백준 2743 단어 길이 재기](https://www.acmicpc.net/problem/2743) | 기본형 | 문자열을 입력받아 길이를 구한다. 줄바꿈 처리에 주의한다 |
| 2 | [백준 2675 문자열 반복](https://www.acmicpc.net/problem/2675) | 글자 단위 | 문자열을 한 글자씩 훑으며 새 문자열을 만든다 |
| 3 | [백준 10809 알파벳 찾기](https://www.acmicpc.net/problem/10809) | 글자 ↔ 번호 | `ord(ch) - ord("a")`로 알파벳을 0~25 번호로 바꿔 배열에 기록한다 |
| 4 | [백준 10988 팰린드롬인지 확인하기](https://www.acmicpc.net/problem/10988) | 회문 | [solution.py](solution.py)의 `is_palindrome`이 그대로 풀이다 |
| 5 | [백준 1157 단어 공부](https://www.acmicpc.net/problem/1157) | 글자 세기 | 대소문자를 구분하지 않고 가장 많이 나온 글자를 찾는다. 최빈값이 여럿이면 어떻게 하는지 확인하자 |

## 풀이 메모

- 4번은 문자열을 입력받아 `main()`처럼 판별하되, 출력이 `1`/`0`인지 확인하세요.
- 5번은 `char_counts`로 센 뒤 최댓값이 하나뿐인지 검사합니다.
