# String Basics (문자열 기초)

> **한 줄 요약**: 문자를 나란히 늘어놓은 값. 배열처럼 번호로 읽고 자를 수 있지만, **한 번 만든 문자열은 바꿀 수 없다.**

## 1. 언제 쓰나 (문제 신호)

- 입력이 "단어", "문장", "문자열", "암호", "회문"처럼 글자로 주어질 때
- 글자 수를 세거나, 뒤집거나, 위치를 바꾸거나, 두 문자열을 비교해야 할 때
- 문자열 알고리즘([KMP](../../../lv2-intermediate/07-strings/kmp/) 등)의 바탕이 되는 연산을 익힐 때

## 2. 핵심 아이디어

문자열은 **글자의 배열**처럼 다룹니다. `s[i]`로 한 글자를 읽고, `s[a:b]`로 자르고, `for ch in s`로 훑습니다.

- **바꿀 수 없다(immutable)**: `s[0] = "x"`는 에러입니다. 일부를 바꾸려면 새 문자열을 만듭니다. `s += t`를 반복하면 매번 전체를 복사해서 느려질 수 있으니, 조각을 리스트에 모아 `"".join(...)`으로 한 번에 합치세요.
- **글자 ↔ 숫자**: `ord("a")`는 97, `chr(97)`은 `"a"`입니다. 알파벳은 연속된 번호이므로 `ord(ch) - ord("a")`가 0~25의 순번이 됩니다.
- **비교**는 앞에서부터 글자 코드를 비교한 **사전 순서**입니다. 대문자(65~90)가 소문자(97~122)보다 앞입니다.
- 글자 수 세기는 딕셔너리(`counts[ch] += 1`)로 하면 O(n)입니다.

### 무엇을 저장하고 어떻게 움직이나

문자열은 순서가 있는 문자들의 불변 수열입니다. 문자 하나를 바꾸려면 새 문자열을 만들거나 먼저 문자 리스트로 바꿔야 합니다. 순서가 중요한 회문·부분 문자열과 순서가 중요하지 않은 애너그램·빈도 문제를 먼저 구분하면 필요한 상태가 분명해집니다.

### 왜 이 방법이 맞는가

회문은 양 끝 문자가 같고 그 사이도 회문이어야 합니다. 바깥 한 쌍을 확인한 뒤 양쪽 인덱스를 좁히면 이미 확인한 쌍은 다시 볼 필요가 없습니다. 애너그램은 각 문자의 등장 횟수가 모두 같은 것이 필요충분조건이므로 정렬이나 빈도표로 판정합니다.

### 작은 예제로 검산하기

`level`은 `l=l`, `e=e`, 가운데 `v` 순으로 확인합니다. `listen`과 `silent`는 순서는 다르지만 빈도표가 같아 애너그램입니다. 빈 문자열도 회문인지, 대소문자와 공백을 그대로 비교하는지 먼저 정해야 합니다.

## 3. 손으로 따라가기

**회문 판별** `"level"`: 양 끝에서 안쪽으로 한 쌍씩 비교합니다.

| left | right | `s[left]` | `s[right]` | 결과 |
|---|---|---|---|---|
| 0 | 4 | `l` | `l` | 같다 → 계속 |
| 1 | 3 | `e` | `e` | 같다 → 계속 |
| 2 | 2 | - | - | `left < right`가 거짓 → 끝, **회문** |

**카이사르 암호** `caesar_shift("abc xyz", 3)`: 알파벳은 3칸씩 밀고(`z` 다음은 `a`로 돌아온다) 공백은 그대로 둡니다. `a→d, b→e, c→f`, `x→a, y→b, z→c`이므로 `"def abc"`입니다. 돌아오는 부분은 `(ord(ch) - ord("a") + k) % 26`으로 처리합니다.

## 4. 구현

전체 코드는 [solution.py](solution.py)에 있습니다.

```python
def is_palindrome(s):
    left, right = 0, len(s) - 1
    while left < right:                 # 가운데에서 만나면 끝
        if s[left] != s[right]:
            return False
        left += 1
        right -= 1
    return True
```

| 하고 싶은 일 | 파이썬 |
|---|---|
| 길이 / 한 글자 / 구간 | `len(s)`, `s[i]`, `s[a:b]` |
| 뒤집기 | `s[::-1]` |
| 단어로 쪼개기 / 합치기 | `s.split()`, `" ".join(words)` |
| 포함 여부 / 위치 | `"ab" in s`, `s.find("ab")` |
| 대소문자 | `s.lower()`, `s.upper()` |
| 글자 ↔ 번호 | `ord(ch)`, `chr(n)` |

## 5. 복잡도와 입력 크기 가이드

- 한 글자 읽기 O(1), 자르기·복사·비교·`in` 검사는 O(n)입니다.
- 길이가 10^5~10^6인 문자열을 한 번 훑는 것은 문제없지만, 반복문 안에서 `s += ch`나 `s[:i] + s[i+1:]`를 하면 O(n²)이 됩니다. ([복잡도 치트시트](../../../docs/complexity-cheatsheet.md))

## 6. 자주 하는 실수

- **입력 끝의 줄바꿈**: `sys.stdin.readline()`은 `\n`을 포함합니다. `.rstrip()`이나 `.strip()`을 잊으면 길이가 하나 늘어납니다.
- **문자열을 수정하려 하기**: `s[i] = ch`는 에러입니다. `list(s)`로 바꿔 수정한 뒤 `"".join(...)`으로 되돌립니다.
- **`s += ch` 반복**: 긴 문자열에서 느려집니다. 리스트에 모아 한 번에 합칩니다.
- **대소문자 구분**: `"A" != "a"`입니다. 문제가 구분하는지 확인하세요.
