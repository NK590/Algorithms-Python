# 자료구조 기초 (Data Structures)

데이터를 담고 꺼내는 가장 기본적인 구조인 **배열**, 격자 모양의 **2차원 배열**, 글자를 나열한 **문자열**을 다룹니다. 이후 모든 알고리즘의 바탕입니다.

## 한눈에 비교

| 개념 | 한 줄 설명 | 번호로 읽기 | 중간 삽입·삭제 | 바꿀 수 있나 |
|---|---|---|---|---|
| [배열](array/) | 값을 순서대로 늘어놓은 것 (`list`) | O(1) | O(n) | O |
| [2차원 배열](two-dimensional-array/) | 배열의 배열, 행과 열이 있는 격자 | O(1) | - | O |
| [문자열](string-basics/) | 글자를 나열한 값 (`str`) | O(1) | 새로 만들어야 함 O(n) | **X** (immutable) |

## 읽는 순서

1. [배열](array/): 인덱스, 삽입·삭제의 비용, 복사의 함정
2. [2차원 배열](two-dimensional-array/): `grid[행][열]`, 방향 배열, `[[0]*m]*n` 함정
3. [문자열 기초](string-basics/): 글자 ↔ 숫자, 바꿀 수 없다는 점, 자르기와 이어 붙이기

문자열 다루기의 다음 단계는 [문자열 처리](../05-implementation/string-processing/)입니다.
