# Two-dimensional Array (2차원 배열)

> **한 줄 요약**: 배열을 배열에 담아 행과 열이 있는 격자(표, 행렬, 지도)를 표현한다. `grid[행][열]`로 읽는다.

## 1. 언제 쓰나 (문제 신호)

- "N × M 표", "지도", "체스판", "행렬", "격자" → 거의 항상 2차원 배열입니다.
- 칸마다 상하좌우로 **이웃한 칸**을 살펴야 한다면, 방향 배열(`DIRECTIONS`)을 쓰는 이 형태가 기본입니다. (이후 [그래프 탐색](../../../lv1-elementary/05-graph-basics/bfs/)의 격자 문제로 이어집니다)
- 회전, 전치, 나선처럼 **칸의 좌표를 바꾸는** 구현 문제

## 2. 핵심 아이디어

`grid[r][c]`에서 `r`은 **행**(위→아래), `c`는 **열**(왼쪽→오른쪽)입니다. 수학의 (x, y)와 순서가 다르다는 점에 주의하세요. `x`는 열, `y`는 행에 해당합니다.

- **상하좌우 이동**은 `(dr, dc)` 쌍의 배열로 표현합니다. 위 `(-1, 0)`, 오른쪽 `(0, 1)`, 아래 `(1, 0)`, 왼쪽 `(0, -1)`. 새 좌표가 격자 안인지 **항상 검사**합니다.
- **전치**: `(r, c)` 칸이 `(c, r)`로 갑니다. **시계 방향 90도 회전**: `(r, c)` 칸이 `(c, 행수-1-r)`로 갑니다.
- **행마다 새 리스트**를 만들어야 합니다. `[[0] * m] * n`은 같은 행을 n번 가리켜서 한 칸을 바꾸면 같은 열이 전부 바뀝니다. (`[[0] * m for _ in range(n)]`이 맞습니다)

## 3. 손으로 따라가기

**시계 방향 회전**: `[[1, 2, 3], [4, 5, 6]]`(2행 3열)을 돌리면 3행 2열이 됩니다. `(r, c) → (c, 행수-1-r)`이므로

| 원래 칸 | 값 | 새 위치 |
|---|---|---|
| `(0, 0)` | 1 | `(0, 1)` |
| `(0, 1)` | 2 | `(1, 1)` |
| `(0, 2)` | 3 | `(2, 1)` |
| `(1, 0)` | 4 | `(0, 0)` |
| `(1, 1)` | 5 | `(1, 0)` |
| `(1, 2)` | 6 | `(2, 0)` |

결과는 `[[4, 1], [5, 2], [6, 3]]`입니다.

**나선 채우기**: 3 × 3에 1부터 시계 방향으로 채우면 앞 칸이 막힐 때마다 방향을 오른쪽으로 꺾습니다.

```
 1  2  3
 8  9  4
 7  6  5
```

## 4. 구현

전체 코드는 [solution.py](solution.py)에 있습니다.

```python
DIRECTIONS = [(-1, 0), (0, 1), (1, 0), (0, -1)]       # 상, 우, 하, 좌

def neighbors(r, c, rows, cols):
    result = []
    for dr, dc in DIRECTIONS:
        nr, nc = r + dr, c + dc
        if 0 <= nr < rows and 0 <= nc < cols:          # 격자 밖이면 버린다
            result.append((nr, nc))
    return result
```

`make_grid`, `transpose`, `rotate_clockwise`, `spiral_grid`, `row_and_column_sums`도 있고, 흔한 실수를 보여 주는 `make_grid_wrong`을 함께 두었습니다.

## 5. 복잡도와 입력 크기 가이드

- 한 칸 접근은 O(1)이고, 모든 칸을 한 번 훑는 데 O(행 × 열)입니다.
- 행 × 열이 10^6쯤까지는 리스트의 리스트로 충분합니다. 1000 × 1000 격자를 이중 반복문으로 돌면 100만 번이고, 각 칸에서 4방향을 보면 400만 번입니다. ([복잡도 치트시트](../../../docs/complexity-cheatsheet.md))

## 6. 자주 하는 실수

- **`[[0] * m] * n`**: 모든 행이 같은 리스트입니다. 위 `make_grid_wrong`이 그 예입니다.
- **행과 열을 바꿔 쓰기**: 입력이 `N M`(행, 열)일 때 `grid[M][N]`처럼 쓰면 범위를 벗어납니다. 정사각형이 아닌 격자로 꼭 시험해 보세요.
- **범위 검사 누락**: `grid[-1]`은 에러가 아니라 **마지막 행**을 읽습니다. 가장자리에서 조용히 틀립니다.
- **방향 순서**: 문제가 정한 방향 순서(북동남서 등)가 있다면 `DIRECTIONS`를 그 순서로 맞춰야 회전 연산이 맞습니다.

## 7. 변형과 응용

- **누적 합 2D**: 부분 격자의 합을 O(1)로 구하는 [2차원 누적 합](../../../lv1-elementary/04-range-techniques/two-dimensional-prefix-sum/)

- **대각선 이동**: `DIRECTIONS`에 8방향을 넣으면 됩니다.
