# 연습문제 사이트 이용 안내

연습문제는 한 플랫폼에 의존하지 않고 개념에 맞는 원문으로 연결합니다. 문제 이름과 학습 포인트를 함께 확인한 뒤 적용 조건, 입력·출력, 시간·메모리 제한을 읽으세요. 같은 알고리즘 문제라도 저장소의 `main()`과 입력 형식이 같다고 가정하지 않습니다.

## 사이트별 특징

| 사이트 | 적합한 연습 | 읽을 때 확인할 점 |
|---|---|---|
| [CSES](https://cses.fi/problemset/) | 기본 자료구조, DP, 그래프, 트리의 단계별 연습 | 영어 지문, 정점 번호와 큰 입력 제한 |
| [AtCoder](https://atcoder.jp/) | 명확한 조건의 응용 문제와 Educational DP | 영어·일본어 전환, 해당 문제의 Python/PyPy 실행 조건 |
| [Aizu Online Judge](https://judge.u-aizu.ac.jp/onlinejudge/) | 정렬·큐·스택·트리 등 직접 구현 연습 | 정렬 과정이나 비교 횟수까지 요구하는 출력 형식 |
| [LeetCode](https://leetcode.com/problemset/) | 함수 단위 문제, 경계 조건과 자료구조 API | 제출용 클래스·메서드와 인자 형식. 일부 문제는 접근 제한이 있음 |
| [Library Checker](https://judge.yosupo.jp/) | 고급 알고리즘의 기본 연산과 구현 검증 | 0 기반 인덱스, 반열린 구간, 큰 제약 조건 |
| [Codeforces](https://codeforces.com/problemset/) | 여러 개념을 결합하는 응용 | 테스트 케이스 수, 추가 제약과 시간 제한 |
| [SPOJ](https://www.spoj.com/problems/classical/) | 고전적인 자료구조·문자열 문제 | 오래된 지문의 입력·출력 관례 |
| [Luogu](https://www.luogu.com.cn/) | 동적 트리 등 전문적인 구현 문제 | 중국어 지문, 계정·접근 조건 |
| [Project Euler](https://projecteuler.net/archives) | 수학 모델링과 결과 계산 | 일반적인 표준 입력 채점 문제와 다른 방식 |

OEIS 등 수열 자료는 값의 교차 검산을 위한 참고 자료입니다. 제출 문제가 아닌 항목은 이름과 학습 포인트에서 구분합니다.

## 문제 목록의 유형

- **핵심 연습**: 해당 개념의 대표 연산을 직접 사용하는 문제입니다.
- **선행 연습**: 필요한 표현·기본 연산부터 익히는 문제입니다. 해당 고급 알고리즘이 반드시 필요한 것은 아닙니다.
- **심화·응용**: 다른 상태나 자료구조를 추가하거나 제약에 맞게 구현을 개선해야 합니다.
- 기존 목록의 세부 유형은 원래 학습 포인트를 보존합니다. 예를 들어 “비트 트라이”와 “문자 트라이”는 구현을 공유할 수 있지만 상태 표현은 다릅니다.

정렬처럼 알고리즘 자체를 익히는 문제는 구현 과정을 요구하는 AOJ 문제부터 시작하면 좋습니다. 큰 수열의 정렬 결과만 요구하는 문제에서는 O(n²) 교육용 구현을 그대로 제출하지 말고 내장 정렬이나 O(n log n) 방법을 선택합니다.

## 참고 구현을 제출 코드로 바꾸기

1. 문제 조건이 구현의 적용 범위와 같은지 확인합니다. 정적 탑 트리는 간선 삽입·삭제를 지원하지 않고, 비가중 블로섬은 가중 일반 매칭을 해결하지 않습니다.
2. 원문의 번호 기준과 구간 정의를 내부 표현으로 변환합니다.
3. 필요한 함수·클래스만 가져오고 원문의 입력을 읽는 호출부를 작성합니다.
4. 문제의 예제와 작은 반례를 검산합니다. 여러 정답이 가능한 문제에서는 값·유효성을 비교합니다.
5. 최댓값 입력의 계산량과 메모리를 추정하고 채점기가 허용하는 언어를 확인합니다.

Library Checker의 Minimum Cost b-flow처럼 더 일반적인 문제는 현재의 최단 증가 경로 구현에 없는 음의 순환·수요 제약 처리까지 필요할 수 있습니다. 이름이 비슷하다는 이유로 지원 범위를 동일하게 보지 마세요.

## 링크를 관리하는 방법

`python tools/gen_index.py --check`는 문서의 상대 경로·내부 앵커·문제 URL 형식과 필수 구성 요소를 검사합니다. 외부 페이지가 실제로 응답하는지는 별도의 네트워크 검사입니다.

```bash
python tools/check_external_links.py
```

이 명령은 원문 URL을 읽기 전용으로 확인합니다. 로그인 요구, 접근 제한, 요청 제한, 네트워크 차단은 페이지가 삭제됐다는 뜻이 아닙니다. 도구는 이런 미확인 결과를 404·410과 구분해 보고합니다. 외부 사이트 상태는 변할 수 있어 이 검사는 기본 CI의 필수 조건으로 넣지 않습니다.
