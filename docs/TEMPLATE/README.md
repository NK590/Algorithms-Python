## 1. 언제 쓰나 (문제 신호)

이 알고리즘을 떠올려야 하는 조건을 문제에서 보이는 표현으로 적습니다.

- 예: "가중치가 있는 그래프에서 한 점에서 모든 점까지의 최단 거리", "간선 가중치가 모두 0 이상", E ≤ 10^6

## 2. 핵심 아이디어

직관을 먼저, 그다음 왜 맞는지(정당성)를 짧게 설명합니다. 그림이 도움이 되면 mermaid나 ASCII 그림을 씁니다.

### 무엇을 저장하고 어떻게 움직이나

상태의 의미를 한 문장으로 정의하고 입력 표현, 초기화, 전이, 결과 읽기를 설명합니다.

### 왜 이 방법이 맞는가

불변식·귀납법·교환 논증 중 알맞은 근거를 설명하고 그 근거가 성립하는 적용 조건을 적습니다.

### 작은 예제로 검산하기

실제 숫자나 문자로 최소 세 단계의 상태 변화와 기대 답을 보여 줍니다. 경계 사례도 하나 포함합니다.

## 3. 손으로 따라가기

아주 작은 입력(정점 4~5개, 원소 6~8개)으로 단계마다 상태가 어떻게 바뀌는지 표로 보입니다.

| 단계 | 처리한 정점 | 거리 배열 | 큐 |

| 0 | - | `[0, ∞, ∞]` | `[(0, A)]` |
