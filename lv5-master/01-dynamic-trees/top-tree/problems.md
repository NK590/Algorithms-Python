# 연습문제 — 탑 트리 (정적)

쉬운 것부터 어려운 순서로 정리했습니다. **문제 지문은 옮기지 않고** 링크와 "배울 점"만 적었습니다. 난이도(solved.ac 티어)는 시간이 지나며 바뀔 수 있어서 표에 적지 않았으니 각 링크에서 확인하세요.

| # | 문제 | 유형 | 배울 점 |
|---|---|---|---|
| 1 | [Luogu P4719 【模板】"动态 DP"&动态树分治](https://www.luogu.com.cn/problem/P4719) | 정점 가중치 변경 + 최대 가중치 독립 집합 | [solution.py](solution.py)의 `main()`이 같은 형태. 최대-합 행렬 + 클러스터 트리 |
| 2 | [AtCoder ABC351 G - Hash on Tree](https://atcoder.jp/contests/abc351/tasks/abc351_g) | 정점 값을 바꾸며 루트의 값을 구하는 동적 트리 DP | 지문을 읽고 점화식이 "무거운 자식 값에 대한 아핀 함수" 로 쓰이는지 직접 확인하는 연습. 쓰이면 `LinearTreeDP`의 틀 (기울기·절편 한 쌍) 이 그대로 적용된다 |
| 3 | [Luogu P4751 【模板】"动态DP"(加强版)](https://www.luogu.com.cn/problem/P4751) | 1번과 같은 문제의 큰 입력 (`n, m ≤ 10⁶`) | 파이썬으로는 어렵다. 클러스터 값을 튜플 대신 평면 배열로 바꾸는 최적화가 필요한 규모 |
| 4 | [Library Checker - Vertex Set Path Composite](https://judge.yosupo.jp/problem/vertex_set_path_composite) | 정적 트리의 경로 위 일차 함수 합성, 정점의 함수 변경 | **경로 질의** 이므로 [HLD](../../../lv4-expert/02-tree-decomposition/heavy-light-decomposition/)가 자연스럽다. 탑 트리와 비교해 어느 도구가 어느 문제에 맞는지 느껴 보는 문제 |

## 풀이 메모

- 1번이 표준 연습입니다. 구현 후 [test_solution.py](test_solution.py)처럼 순진한 트리 DP(매번 `O(n)`)와 무작위로 비교하세요.
- 2번은 지문을 직접 읽고, 먼저 `n`이 작은 경우의 순진한 재귀 구현을 만든 뒤, 정점의 값 하나가 바뀔 때 *무엇이 변하는지* (그 정점에서 루트까지의 경로) 를 확인하세요. 점화식이 한 자식 값에 대해 아핀이라는 것이 확인되면 기울기·절편 표현으로 옮기면 됩니다. (이 저장소에서 지문을 확인하지 못했으므로 풀이 방향은 위의 일반 원칙입니다.)
- 3번의 큰 입력에서는 파이썬이 시간 안에 못 풉니다. 이 저장소의 목표는 구조의 이해와 정확성이므로 입력을 줄여 순진한 풀이와 비교하는 데 쓰세요.
- 4번은 *정점 값은 바뀌지만 질의가 경로* 인 문제입니다. 탑 트리는 "루트의 전체 값" 에 강하고, 임의의 경로 질의에는 HLD가 단순합니다.
