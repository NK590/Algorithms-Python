# 연습문제 — 탑 트리 (정적)

아래 순서는 개념의 기본 연산을 익힌 뒤 응용으로 넘어가기 위한 추천 순서입니다. 문제 지문은 원문 링크에서 확인하고, 표의 **배울 점**을 먼저 읽어 어떤 상태와 전이를 사용할지 정리하세요.

[문제 사이트 이용 안내](../../../docs/reference-guide.md)를 참고하세요. `solution.py`는 개념의 참고 구현입니다. 제출 전에는 원문의 입력·출력, 인덱스, 제약 조건에 맞게 호출부를 작성해야 합니다.

| # | 문제 | 유형 | 배울 점 |
|---|---|---|---|
| 1 | [AtCoder — Hash on Tree](https://atcoder.jp/contests/abc351/tasks/abc351_g) | 핵심 연습 | 곱셈형 트리 DP를 정점 갱신과 함께 유지한다 |
| 2 | [Library Checker — Vertex Set Path Composite](https://judge.yosupo.jp/problem/vertex_set_path_composite) | 선행 연습 | 선행으로 순서가 있는 함수 합성과 경로 집계를 연습한다 |
| 3 | [Luogu P4719 【模板】"动态 DP"&动态树分治](https://www.luogu.com.cn/problem/P4719) | 정점 가중치 변경 + 최대 가중치 독립 집합 | [solution.py](solution.py)의 `main()`이 같은 형태. 최대-합 행렬 + 클러스터 트리 |
| 4 | [Luogu P4751 【模板】"动态DP"(加强版)](https://www.luogu.com.cn/problem/P4751) | P4719의 최대 가중치 독립 집합을 큰 입력 (`n, m ≤ 10⁶`)에서 처리 | 파이썬으로는 어렵다. 클러스터 값을 튜플 대신 평면 배열로 바꾸는 최적화가 필요한 규모 |

## 연습 순서

1. 기본 연산을 작은 입력에서 손으로 실행하고, 코드의 중간 상태와 비교합니다.
2. 핵심 연습을 풀 때 적용 조건과 시간 복잡도를 먼저 확인합니다. 선행 연습은 해당 도구가 반드시 필요한 문제라는 뜻은 아닙니다.
3. 응용 문제에서는 추가 상태, 자료구조, 전처리가 필요한지 구분하고 작은 입력의 단순한 풀이로 답을 검산합니다.
