# 탑 트리 (Top Tree) — 정적 탑 트리

> **범위를 먼저 밝힙니다**: 간선이 추가·삭제되는 **완전한 동적 탑 트리**(Alstrup–Holm–de Lichtenberg–Thorup, 자기 조정 탑 트리)는 이 저장소에서 구현하지 않았습니다. 여기서 구현한 것은 **트리 모양이 고정**이고 **정점의 값만 바뀌는 "정적 탑 트리"** 입니다. 대회에서 "동적 트리 DP"를 푸는 표준 도구이고, 클러스터·`rake`·`compress`라는 탑 트리의 핵심 개념을 그대로 보여 줍니다. 모양이 바뀌는 트리는 [링크-컷 트리](../link-cut-tree/)의 몫입니다.

> **한 줄 요약**: 트리를 **클러스터**(트리의 연결된 조각)들의 이진 트리로 쪼갠다. 경로는 `compress`(이어 붙이기), 같은 정점에 매달린 가벼운 서브트리들은 `rake`(합치기)로 묶는다. 클러스터 트리의 깊이가 `O(log n)`이라서, 정점 하나의 값을 바꾸면 그 정점에서 루트까지 `O(log n)`개의 클러스터만 다시 계산해 **전체 트리 DP의 값**을 얻는다.

## 1. 언제 쓰나 (문제 신호)

- "트리 DP인데 **정점의 값이 계속 바뀌고**, 바뀔 때마다 DP의 최종 답을 묻는다" (**동적 DP**) — 질의 `q`개, 정점 `n`개가 `10⁵`
- 트리 DP의 점화식이 **결합 법칙을 만족하는 합성**으로 쓰인다: 최대 가중치 독립 집합(최대-합 행렬), 아핀 함수의 합성, 해시, 개수 세기 등
- 위상(간선)은 **바뀌지 않는다.** 간선이 바뀌면 [링크-컷 트리](../link-cut-tree/)
- 경로 질의만 있으면 [HLD](../../../lv4-expert/02-tree-decomposition/heavy-light-decomposition/)가 더 간단하다. 서브트리까지 얽힌 DP가 핵심일 때 탑 트리
- 질의마다 `O(n)` 재계산이 불가능하고 (`n, q ≈ 10⁵`), HLD + 경로마다 구간 트리(`O(log² n)`)로도 풀리지만 더 빠른 `O(log n)`이 필요할 때

## 2. 핵심 아이디어

**무거운 경로로 쪼개기**: 서브트리가 가장 큰 자식을 "무거운 자식"으로 두면 트리가 **무거운 경로**(위에서 아래로 내려가는 직선)들로 나뉜다. 어떤 정점에서 루트까지 가는 길에 가벼운 간선은 `O(log n)`개.

**두 가지 클러스터**:
- **경로 클러스터 `P`**: 무거운 경로의 한 구간. 그 경로 위 정점들에 매달린 가벼운 서브트리들까지 포함한다. 아래쪽 끝이 열려 있다 (그 아래 무거운 자식의 정보를 입력으로 받는 **함수**처럼 쓴다).
- **점 클러스터 `Q`**: 가벼운 자식 하나가 이끄는 서브트리 전체를, 부모에서 필요한 요약으로 줄인 것.

**사용자가 주는 네 연산**:
| 연산 | 의미 |
|---|---|
| `add_vertex(v, q)` → `P` | 정점 하나 `v`와 그 가벼운 자식들의 요약 `q`(없으면 `None`)로 이루어진 경로 클러스터 |
| `compress(upper, lower)` → `P` | 위쪽 경로와 아래쪽 경로를 이어 붙임 (결합 법칙 필요) |
| `add_edge(p)` → `Q` | 가벼운 자식의 무거운 경로 전체(`p`)를 부모가 쓰는 요약으로 바꿈 |
| `rake(q1, q2)` → `Q` | 같은 정점에 매달린 두 요약을 합침 (교환·결합 법칙 필요) |

**구성**: 무거운 경로의 정점 클러스터들을 `compress`로 묶는 **이진 트리**를 만든다. 이때 정점 `i`의 가중치 `1 + (가벼운 서브트리들의 크기 합)`으로 **가중치 균형**을 맞춰 가운데에서 쪼갠다 (큰 가벼운 서브트리가 매달린 정점은 위쪽에 둔다). 가벼운 자식들은 크기로 균형을 맞춘 `rake` 이진 트리로 묶는다. 이 가중치 균형 덕분에 정점 하나에서 루트까지 올라가는 클러스터 수가 전체 `O(log n)` (가벼운 간선을 하나 지날 때마다 서브트리 크기가 절반 이하로 줄고, 한 경로 안에서는 가중치 균형으로 `log(전체 / 자기 몫)`만큼만 깊다).

**갱신**: 정점 `v`의 값이 바뀌면 `v`의 클러스터 노드부터 부모 쪽으로 올라가며 각 노드의 값을 `add_vertex` / `compress` / `add_edge` / `rake`로 다시 계산한다. 올라가는 길이 곧 클러스터 트리의 깊이.

**예: 최대 가중치 독립 집합**. 정점의 상태 `(dp0, dp1)` = (고르지 않음, 고름)의 최댓값. 무거운 자식 `h`의 상태를 입력으로 받는 정점 `v`의 변환은 **최대-합(max-plus) 행렬**
```
dp0(v) = s0 + max(dp0(h), dp1(h))       s0 = 가벼운 자식 각각의 max(dp0, dp1) 의 합
dp1(v) = w_v + s1 + dp0(h)              s1 = 가벼운 자식 각각의 dp0 의 합
M_v = [[s0, s0], [w_v + s1, -inf]]
```
경로의 `compress`는 행렬의 최대-합 곱, 맨 아래 정점은 입력 `(0, -inf)`(자식 없음)로 평가한다. 가벼운 자식 요약 `Q = (max(dp0, dp1), dp0)`은 `rake`에서 성분별로 더해진다.

## 3. 손으로 따라가기

트리 `0–1, 0–2, 1–3, 1–4` (루트 `0`), 정점 가중치 `[4, 1, 3, 5, 2]`.

크기: `size = [5, 3, 1, 1, 1]`. `0`의 무거운 자식은 `1`(크기 3), 가벼운 자식 `2`. `1`의 자식 `3`, `4`는 크기가 같으니 `3`이 무거운 자식, `4`는 가벼운 자식. 루트 경로는 `0 – 1 – 3`.

클러스터 트리 (이 구현이 만든 것):

| 노드 | 종류 | 구성 | 값 |
|---|---|---|---|
| 0 | 정점 `2` | 자식 없음 | `M = [[0,0],[3,-∞]]` |
| 1 | `add_edge` | 노드 0 | `Q = (3, 0)` (정점 2 서브트리: `max(0, 3) = 3`, `dp0 = 0`) |
| 2 | 정점 `0` | 가벼운 자식 요약 = 노드 1 | `M = [[3,3],[4,-∞]]` (`s0 = 3`, `s1 = 0`, `w = 4`) |
| 3 | 정점 `4` | 자식 없음 | `M = [[0,0],[2,-∞]]` |
| 4 | `add_edge` | 노드 3 | `Q = (2, 0)` |
| 5 | 정점 `1` | 가벼운 자식 요약 = 노드 4 | `M = [[2,2],[1,-∞]]` |
| 6 | 정점 `3` | 자식 없음 | `M = [[0,0],[5,-∞]]` |
| 7 | `compress` | 노드 2 (위) + 노드 5 (아래) | `[[5,5],[6,6]]` |
| 8 | `compress` (루트) | 노드 7 (위) + 노드 6 (아래) | `[[10,5],[11,6]]` |

- 가중치 균형: 경로 정점 `0, 1, 3`의 가중치는 `1 + (가벼운 서브트리 크기)` = `2, 2, 1` (합 5). 가운데 근처에서 쪼개 `compress(compress(0, 1), 3)`.
- 루트 행렬을 입력 `(0, -∞)`에 적용하면 `(dp0, dp1) = (10, 11)`이므로 답 = `max = 11` (`{0, 3, 4}` = 4 + 5 + 2).
- **갱신**: 정점 0의 가중치를 `0`으로 바꾸면 노드 2부터 루트(노드 8)까지, 즉 `2 → 7 → 8`만 다시 계산 → 새 답 `10` (`{2, 3, 4}` = 3 + 5 + 2).
- 정점 4의 클러스터에서 루트까지: `3 → 4 → 5 → 7 → 8` (노드 5개 = 깊이 5).

**선형 DP 예**: `val(v) = A_v + B_v · Σ val(자식)`에서 `A = [1,2,3,4,5]`, `B = [1,1,1,1,1]`: `val(3) = 4`, `val(4) = 5`, `val(1) = 2 + (4 + 5) = 11`, `val(2) = 3`, `val(0) = 1 + (11 + 3) = 15`. 이 구현의 `LinearTreeDP.root_val()`도 15를 준다. 경로 클러스터는 **아핀 함수** `x → 기울기·x + 절편`, 합성은 `(a₁x + b₁)` 안에 `(a₂x + b₂)`를 넣는 것.

## 4. 구현

전체 코드는 [solution.py](solution.py)에 있습니다.

```python
class StaticTopTree:
    def __init__(self, n, edges, add_vertex, compress, add_edge, rake, root=0):
        # 1) 루트를 정해 크기·무거운 자식·가벼운 자식 목록을 구한다 (반복문 BFS)
        # 2) _build_path(top): 무거운 경로를 따라 정점마다
        #       rake_root = 가벼운 자식들의 add_edge(_build_path(자식)) 를 크기로 균형 맞춘 rake 트리로 묶은 것
        #       정점 노드 = add_vertex(v, rake_root)  가중치 = 1 + 가벼운 서브트리 크기 합
        #    정점 노드들을 가중치 균형 compress 트리로 묶는다
        ...

    def update(self, v):          # v 의 데이터가 바뀐 뒤
        node = self.vertex_node[v]
        while node != -1:         # 정점 노드에서 루트까지
            self.value[node] = self._compute(node, ...); node = self.node_parent[node]
```

- `StaticTopTree(n, edges, add_vertex, compress, add_edge, rake, root)`: `update(v)`, `root_value()`, `depth_of(v)`(갱신 비용). 노드는 배열에 저장되고 자식이 항상 부모보다 먼저 만들어집니다. 트리가 아니면(`n − 1`개의 간선이 아님, 사이클, 비연결) `ValueError`.
- `TreeMaxIndependentSet(n, edges, weights)`: `set_weight(v, w)`, `best()`. 가중치는 음수가 있어도 되고 빈 집합이 허용됩니다.
- `LinearTreeDP(n, edges, a, b, mod)`: `set_values(v, a=…, b=…)`, `root_val()`.
- 직접 실행하면 Luogu P4719 "动态 DP" 형식 — `n m`, 정점 가중치, 간선 `n − 1`개, 질의 `x y`(`a_x = y`로 바꾸고) — 마다 최대 가중치 독립 집합의 값을 출력합니다.

## 5. 복잡도와 입력 크기 가이드

- 구성 `O(n)`(가중치 균형 분할이 선형), 갱신 `O(log n)`(클러스터 트리의 깊이). ([복잡도 치트시트](../../../docs/complexity-cheatsheet.md))

## 6. 자주 하는 실수

- **`compress`가 결합 법칙을 만족하지 않음**: 경로를 어떤 괄호로 묶어도 같은 결과여야 합니다 (가중치 균형 트리가 임의의 모양이므로). 함수 합성·행렬 곱은 OK.
- **`rake`가 교환·결합 법칙을 만족하지 않음**: 가벼운 자식들을 묶는 순서가 임의이므로 합/최대처럼 교환 가능해야 합니다.
- **가중치 균형을 안 맞춤**: 경로를 반으로만 쪼개면 가벼운 서브트리가 큰 정점이 깊이 묻혀 깊이가 `O(log² n)`로 늘어납니다. `1 + (가벼운 서브트리 크기 합)`으로 균형.
- **아래쪽 끝의 입력**: 무거운 자식이 없는 정점(경로의 맨 아래)은 입력이 "없음" 입니다. 행렬 방식에서는 항등 상태 `(0, -inf)`로 평가합니다 (자식이 없으면 `dp0 = 0`, 선택하지 않은 상태만 허용).
- **갱신 뒤 `update`를 안 부름**: 사용자 데이터(`weights[v]`)를 바꾸고 `update(v)`를 호출하지 않으면 클러스터 값이 낡습니다.
- **값을 제자리에서 바꿈**: 클러스터 값이 리스트처럼 가변이면 `add_vertex`가 이전 값을 덮어써 다른 노드의 입력이 오염될 수 있습니다. 튜플 같은 불변 값으로 쓰세요.
- **간선 목록으로 위상을 바꾸려 함**: 이 구현은 정적입니다. 모양이 바뀌는 문제는 링크-컷 트리나 오일러 투어 트리.
- **루트 선택**: 루트가 다르면 경로와 가벼운 자식의 구분이 달라지지만 답은 같아야 합니다. 방향이 있는 DP(부모 → 자식)는 루트를 문제의 루트와 맞추세요.
- **재귀 깊이**: 구성의 재귀는 가벼운 간선의 개수(`≤ log n`)와 균형 분할 깊이뿐이라 사슬 모양에서도 한도에 걸리지 않습니다.

## 7. 변형과 응용

- **다른 DP**: 최소 정점 덮개·지배 집합·트리 색칠 수·경로 길이 최댓값(지름)·합성 함수의 합 — 상태가 작은 행렬/함수로 표현되면 같은 틀입니다.
- **서브트리 질의**: 클러스터에 "서브트리의 합" 도 함께 저장하면 서브트리 합이 `O(log n)`입니다.
- **완전한 동적 탑 트리**: 간선 삽입·삭제까지 하려면 클러스터 트리를 스플레이나 균형 트리로 유지하며 `rake`/`compress`를 분할·병합합니다 (자기 조정 탑 트리). 구현이 매우 어렵습니다.
- **링크-컷 트리의 가상 서브트리**: LCT에서 가상 서브트리(경로 부모로 매달린 서브트리)의 집계를 함께 유지하면 비슷한 질의를 모양이 바뀌는 트리에서도 풉니다.
- **HLD + 구간 트리 (동적 DP)**: 같은 문제를 무거운 경로마다 구간 트리를 두는 `O(log² n)` 풀이. 이 구현은 그 두 겹의 `log`를 하나로 합친 것입니다.
- **정적 → 오프라인 동적**: 질의를 먼저 알면 시간 구간 트리 + 롤백 같은 오프라인 방법(오프라인 동적 연결성 (Lv5))도 있습니다.
