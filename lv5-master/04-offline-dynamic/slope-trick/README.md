# 기울기 트릭 (Slope Trick)

> **한 줄 요약**: DP 값이 **볼록한 구간선형 함수** `f(x)`로 표현되는 문제에서, 함수를 배열로 들지 않고 **기울기가 바뀌는 점들** 을 두 개의 힙(왼쪽 `L`, 오른쪽 `R`)에 담아 `|x − a|` 더하기, 접두 최솟값, 구간 최솟값 같은 *함수 전체의 갱신* 을 `O(log n)`의 힙 연산으로 처리한다. 값 범위가 `10⁹`이어도 항 개수만큼만 일한다.

## 1. 언제 쓰나 (문제 신호)

- "수열을 **비감소(순증가)** 로 만드는 최소 비용 (값을 ±1 하는 연산 횟수 = `Σ|aᵢ − bᵢ|`)", 값의 범위가 커서 값에 대한 DP가 불가능
- "`bᵢ`를 정하되 이웃과의 차가 `d` 이하" 처럼 **이전 값에 대한 구간 최솟값** 을 취하는 전이: `fᵢ(x) = |x − aᵢ| + min_{|y − x| ≤ d} fᵢ₋₁(y)`
- 전이가 `f(x) ← min(f(x), …)`, `f ← f + |x − a|`, `f(x) ← f(x − d)` 의 반복이고 `f`가 볼록인 DP (볼록 함수에 볼록 함수를 더하고, 평행 이동하고, 구간 최솟값을 취해도 볼록)
- "사고팔기" 류의 그리디: 이후에 더 비싼 날이 있으면 팔고, 되돌릴 수 있게 힙에 남기는 문제 (`max_profit_buy_sell`)
- 최적값만이 아니라 *최적해의 경계* (`argmin` 구간)도 필요한 경우: `argmin()`이 `[L의 최댓값, R의 최솟값]`
- `f`가 볼록이 아니면 쓸 수 없다. 전이에 `max`나 비볼록 항이 있으면 [볼록 껍질 트릭](../../../lv3-advanced/07-dp-advanced/convex-hull-trick/)이나 [에일리언 트릭](../../../lv4-expert/06-misc/aliens-trick/) 같은 다른 도구를 본다

## 2. 핵심 아이디어

**볼록 구간선형 함수의 표현**: 기울기가 정수이고 `1`씩만 변하는 볼록 함수는 *최솟값* 과 *기울기가 바뀌는 점들(변화점)의 목록* 으로 정해진다. 최솟값이 되는 구간 `[l, r]`을 경계로 왼쪽(기울기 `≤ −1`)의 변화점을 `L`(최대 힙), 오른쪽(기울기 `≥ 1`)의 변화점을 `R`(최소 힙)에 둔다. 같은 위치에 변화점이 여러 번 있으면 기울기가 그만큼 변한다.

```
f(x) = min_value + Σ_{l ∈ L} max(0, l − x) + Σ_{r ∈ R} max(0, x − r),    max(L) ≤ min(R)
```

**연산** (모두 `O(log n)`):

- `f += max(0, x − a)`: `L`의 최댓값이 `a`보다 크면 새 함수의 최솟값이 `max(L) − a`만큼 올라간다. `a`를 `L`에 넣고, `L`의 최댓값을 꺼내 `R`로 옮긴다.
- `f += max(0, a − x)`: 대칭. `min_value += max(0, a − min(R))`, `a`를 `R`에 넣고 `R`의 최솟값을 `L`로 옮긴다.
- `f += |x − a|`: 위 둘을 차례로.
- `f(x) ← min_{y ≤ x} f(y)` (접두 최솟값): 오른쪽의 증가하는 부분이 평평해진다 → `R`을 비운다. (접미 최솟값은 `L`을 비운다.)
- `f(x) ← min_{x+lo ≤ y ≤ x+hi} f(y)` (구간 최솟값, `lo ≤ hi`): 평평한 구간이 넓어진다. `g(x) = f(x + hi)`가 왼쪽 부분을, `f(x + lo)`가 오른쪽 부분을 이으므로 `L`의 모든 원소를 `−hi`만큼, `R`의 모든 원소를 `−lo`만큼 옮긴다. 힙을 건드리지 않고 **지연 오프셋 두 개** (`_add_left -= hi`, `_add_right -= lo`)만 바꾼다.
- `f(x) ← f(x − d)`: 둘을 모두 `+d`.

**수열 비감소 만들기**: `fᵢ(x)`를 *`bᵢ = x`로 정했을 때 앞 `i`개의 최소 비용* 이라 하면 `fᵢ(x) = |aᵢ − x| + min_{y ≤ x} fᵢ₋₁(y)`. 접두 최솟값과 `|x − a|` 더하기의 반복이므로 `min_cost_non_decreasing`은 각 `a`마다 `add_abs(a); prefix_min()`이고 답은 `min_value`. 순증가는 `bᵢ − i`가 비감소인 문제로 바꾸면 된다 (`aᵢ − i`).

**왜 볼록이 유지되는가**: 볼록 함수의 합, 접두/구간 최솟값(`inf`-컨볼루션 with 구간의 지시 함수), 평행 이동은 모두 볼록을 보존한다. 변화점의 개수는 `add_abs`마다 2씩 늘기만 한다.

## 3. 손으로 따라가기

수열 `5, 3, 4, 2, 6`을 비감소로 만드는 최소 ±1 횟수. 각 원소에서 `add_abs(a)` → `prefix_min()`. 아래는 실행으로 확인한 `L`, `R`, `min_value`입니다 (`L`, `R`은 정렬해서 표시).

| `a` | `add_abs(a)` 직후 `L` | `R` | `min_value` | `prefix_min()` 후 `L` / `R` |
|---|---|---|---|---|
| 5 | `{5}` | `{5}` | 0 | `{5}` / `{}` |
| 3 | `{3, 3}` | `{5}` | 2 | `{3, 3}` / `{}` |
| 4 | `{3, 3, 4}` | `{4}` | 2 | `{3, 3, 4}` / `{}` |
| 2 | `{2, 2, 3, 3}` | `{4}` | 4 | `{2, 2, 3, 3}` / `{}` |
| 6 | `{2, 2, 3, 3, 6}` | `{6}` | 4 | `{2, 2, 3, 3, 6}` / `{}` |

답은 **4**. 두 번째 행을 읽어 보면: `f₁(x) = 비감소 접두 최소` 에 `|x − 3|`을 더한 뒤, `L`의 최댓값 `5`가 `3`보다 크므로 최솟값이 `5 − 3 = 2` 올라간다 — 앞의 `5, 3`을 비감소로 만들려면 최소 2번 (예: 둘 다 `4`로, 또는 둘 다 `3`으로). `R`은 매번 비워지므로 사실상 `L`만 힙으로 남는다. 최종 `L`에 남은 변화점들은 최적해의 "경계" 이기도 하다.

**구간 최솟값(이웃과의 차이 제한)**: `0, 10, 0`을 이웃과의 차가 `3` 이하가 되게 만드는 최소 `Σ|aᵢ − bᵢ|`: `0` 하나를 넣으면 `L = {0}, R = {0}`; `window_min(−3, 3)`으로 `L = {−3}`, `R = {3}`(평평한 구간이 `[−3, 3]`); `|x − 10|`을 더하면 `L = {−3, 3}`, `R = {10, 10}`, `min_value = 7`; 다시 `window_min(−3, 3)`으로 `L = {−6, 0}`, `R = {13, 13}`; `|x − 0|`을 더하면 `min_value`는 그대로 `7`. 답은 **7** (차이 한도 `d = 5`이면 `5`, `d = 10`이면 `0`: 실행으로 확인).

## 4. 구현

전체 코드는 [solution.py](solution.py)에 있습니다.

```python
class SlopeTrick:
    # _left: 최대 힙(부호 반전), _right: 최소 힙, 지연 오프셋 _add_left, _add_right, min_value
    def add_x_minus_a(self, a):                  # f += max(0, x - a)
        self.min_value += max(0, self.left_top() - a)
        self._push_left(a); self._push_right(self._pop_left())
    def add_a_minus_x(self, a):                  # f += max(0, a - x)
        self.min_value += max(0, a - self.right_top())
        self._push_right(a); self._push_left(self._pop_right())
    def add_abs(self, a): self.add_x_minus_a(a); self.add_a_minus_x(a)
    def prefix_min(self): self._right.clear()
    def window_min(self, lo, hi):                # f(x) <- min over [x+lo, x+hi]
        self._add_left -= hi; self._add_right -= lo
```

- `SlopeTrick`: `add_x_minus_a`, `add_a_minus_x`, `add_abs`, `prefix_min`, `suffix_min`, `window_min(lo, hi)`, `shift(d)`, `argmin()`, `evaluate(x)`(변화점 수에 비례), `min_value`.
- 응용: `min_cost_non_decreasing`, `min_cost_strictly_increasing`, `min_cost_bounded_difference(values, d)`, `narrow_rectangles(segments)`(층마다 구간이 이웃과 겹쳐야 할 때 총 이동 거리), `max_profit_buy_sell(prices)`.
- 직접 실행하면 Codeforces 713C 형식 — `n`, 이어서 `n`개의 정수 — 를 받아 수열을 순증가하게 만드는 최소 ±1 횟수를 출력합니다.

## 5. 복잡도와 입력 크기 가이드

- 연산 하나가 힙 연산 `O(log n)`이므로 `n`개의 원소는 `O(n log n)`. 구간 최솟값과 평행 이동은 `O(1)`. `evaluate(x)`만 변화점을 모두 보는 `O(n)`.
- 이 환경에서 측정한 값입니다.

| `n` | 비감소 | 순증가 | 이웃 차 제한 | 네로우 렉탱글즈 | 사고팔기 |
|---|---|---|---|---|---|
| `10⁴` | 0.01초 | 0.01초 | 0.02초 | 0.02초 | 0.00초 |
| `10⁵` | 0.15초 | 0.16초 | 0.27초 | 0.28초 | 0.04초 |
| `10⁶` | 1.65초 | 1.77초 | 2.63초 | 2.77초 | 0.46초 |

- 값이 `10⁹`까지 가는 입력에서 값에 대한 `O(n²)` DP(후보 값은 입력의 서로 다른 수)와 비교: `n = 1000`에서 0.109초 대 0.0013초, `n = 3000`에서 0.973초 대 0.0037초 (결과 일치). 기울기 트릭은 값의 범위가 아니라 항의 개수에만 의존합니다.
- 힙 연산 상수가 작아 `n = 10⁶`도 2초 안팎입니다. 이 단원의 다른 도구와 달리 대회 제한에 가까운 입력이 파이썬으로 현실적입니다.

## 6. 자주 하는 실수

- **볼록이 아닌 DP에 적용**: 전이에서 `min`과 `max`를 섞거나 비볼록 항을 더하면 변화점 표현이 깨집니다. 먼저 `f`가 볼록인지 확인하세요.
- **`prefix_min`의 순서**: 전이 `fᵢ(x) = |x − aᵢ| + min_{y ≤ x} fᵢ₋₁(y)`를 그대로 따르면 `prefix_min` 다음에 `add_abs`입니다. 이 구현처럼 `add_abs` 다음에 `prefix_min`을 호출해도 `min_value`는 같지만, 중간에 `evaluate`나 `argmin`으로 들여다보는 함수가 한 단계씩 어긋납니다.
- **순증가를 `aᵢ`로 그대로 풀기**: 순증가는 `aᵢ − i`로 바꿔 비감소로 풉니다. `+ i`로 바꾸면 `[5, 4, 3, 2, 1]`이 이미 비감소인 `[5, 5, 5, 5, 5]`가 되어 12가 아니라 0이 나옵니다.
- **구간 최솟값의 부호 혼동**: `window_min(lo, hi)`는 `f(x) ← min_{x+lo ≤ y ≤ x+hi} f(y)`이고 `L`이 `−hi`, `R`이 `−lo`만큼 옮겨집니다. 이웃과의 차 제한 `|bᵢ − bᵢ₋₁| ≤ d`는 `window_min(−d, d)`. 한쪽으로만 허용되는 문제(예: `bᵢ ∈ [bᵢ₋₁ − w', bᵢ₋₁ + w]`)는 두 인수의 부호와 순서를 식으로 다시 유도하세요 (`narrow_rectangles`는 `window_min(−이전 층의 너비, 현재 층의 너비)`).
- **지연 오프셋을 힙 원소에 반영 안 함**: `_add_left`, `_add_right`가 쌓인 뒤에 넣는 원소는 `value − 오프셋`으로 저장하고 꺼낼 때 `+ 오프셋`을 해야 합니다.
- **빈 힙의 처리**: 처음 `L`, `R`이 비어 있을 때 최댓값/최솟값을 `∓∞`로 보면 `max(0, ·)`가 자연스럽게 0이 됩니다.
- **정수가 아닌 값**: 이 구현은 변화점이 `int`든 `float`든 동작하지만, 문제에서 `bᵢ`가 정수여야 한다면 최적해에서 변화점이 정수인지(입력이 정수면 그렇다) 확인하세요.
- **`argmin`을 하나의 점으로 착각**: 최솟값이 되는 곳은 구간 `[left_top, right_top]`입니다.

## 7. 변형과 응용

- **사고팔기 (CF 865D)**: 하루 한 주씩 사고팔 수 있고 마지막에 주식이 없어야 할 때 최대 이익. 힙에 가격을 넣고 더 비싼 날이 오면 가장 싼 것을 팔되 판 값도 다시 넣는 그리디가 `L` 힙의 기울기 트릭과 같다.
- **네로우 렉탱글즈 (ARC070 E)**: 층마다 구간을 옮겨 이웃과 닿게 하는 최소 총 이동 거리 (`narrow_rectangles`).
- **슬라이딩 윈도 최소를 포함한 DP**: 이웃 값의 차 제한, "한 번에 `k` 이하로만 이동" 등 → `window_min`.
- **볼록 함수의 합성**: 두 볼록 함수의 최소-합성곱(min-plus convolution)은 기울기(변화점) 목록을 병합한 것과 같아서 힙의 작은-큰 병합으로 구현할 수 있다.
- **정수가 아닌 기울기 / 평행 이동하는 볼록 껍질**은 [볼록 껍질 트릭](../../../lv3-advanced/07-dp-advanced/convex-hull-trick/)이나 [에일리언 트릭](../../../lv4-expert/06-misc/aliens-trick/)과 비교해 볼 만하다.
