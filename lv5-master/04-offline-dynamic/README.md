# 오프라인과 동적 최적화 (Offline & Dynamic Optimization)

이 단원은 "**입력을 모두 알고 있다**" 거나 "**함수 전체를 한 번에 다룬다**" 는 점을 이용해서 온라인/단순 DP로는 어려운 문제를 푸는 두 기법입니다. 하나는 연산을 시간 축으로 펼쳐 *삭제를 없애는* [오프라인 동적 연결성](offline-dynamic-connectivity/), 다른 하나는 *볼록 함수의 모양* 을 힙 두 개로 들고 DP 전이를 힙 연산으로 옮기는 [기울기 트릭](slope-trick/)입니다.

## 한눈에 비교

| 개념 | 푸는 문제 | 핵심 | 시간 |
|---|---|---|---|
| [오프라인 동적 연결성](offline-dynamic-connectivity/) | 간선이 추가·삭제되는 그래프의 연결성·성분 수·이분성 질의 | 간선의 *시간 구간* 을 구간 트리에 흩고, DFS 하며 롤백 유니온 파인드 | O((T + E) log T · log n) |
| [기울기 트릭](slope-trick/) | 볼록 구간선형 함수로 표현되는 DP (수열 정렬 비용, 이웃 차 제한, 사고팔기) | 기울기가 바뀌는 점들을 두 힙에 담고 함수 전체를 갱신 | 연산당 O(log n) |

## 문제 신호로 고르기

| 문제의 신호 | 선택 |
|---|---|
| 간선 추가·삭제 + 연결 질의, 입력을 다 읽고 풀어도 된다 | [오프라인 동적 연결성](offline-dynamic-connectivity/) |
| 위에서 "지금 이분 그래프인가", 성분 수, 성분 합 | [오프라인 동적 연결성](offline-dynamic-connectivity/) (홀짝 유니온 파인드 / 집계 얹기) |
| 같은 문제인데 온라인이어야 한다 (숲) | [링크-컷 트리](../01-dynamic-trees/link-cut-tree/) |
| 수열을 비감소/순증가로 만드는 최소 ±1 비용 (값 범위가 크다) | [기울기 트릭](slope-trick/) |
| "`aᵢ`와의 차이의 절댓값을 더하고, 이전 `f`의 접두 최솟값 또는 구간 최솟값을 취한다" 꼴의 DP | [기울기 트릭](slope-trick/) |
| "더 비싼 날에 팔 걸" 처럼 번복 가능한 그리디 | [기울기 트릭](slope-trick/)의 힙 구조 |
| DP 전이가 직선의 최솟값 (`dp[i] = min(dp[j] + b[j]·a[i])`) | [볼록 껍질 트릭](../../lv3-advanced/07-dp-advanced/convex-hull-trick/) / [리 차오 트리](../../lv4-expert/03-advanced-data-structures/li-chao-tree/) |
| 비용 함수가 볼록이라는 성질로 "k개 선택"을 풀기 | [에일리언 트릭](../../lv4-expert/06-misc/aliens-trick/) |

## 개념 사이의 관계

- **둘 다 "문제를 다시 바라보기"**: 동적 연결성은 *연산의 시간 순서* 를 *간선의 시간 구간* 으로 바꾸고, 기울기 트릭은 *배열 DP* 를 *함수 하나의 변화* 로 바꿉니다. 계산 대상을 바꾸는 순간 어려운 연산(삭제 / 구간 최솟값)이 쉬운 연산(롤백 / 오프셋 두 개)으로 바뀝니다.
- **롤백 가능한 자료구조 + 시간 구간 트리**: 오프라인 동적 연결성의 틀은 유니온 파인드에만 한정되지 않습니다. [리 차오 트리](../../lv4-expert/03-advanced-data-structures/li-chao-tree/)의 롤백과 시간 구간으로 "일정 시간 동안만 살아 있는 직선들의 최솟값"을 풀 때도 같은 구성입니다.
- **볼록성**: 기울기 트릭은 함수의 볼록성이 연산(더하기, 접두/구간 최솟값, 평행 이동) 아래에서 보존되는 데 기댑니다. [볼록 껍질 트릭](../../lv3-advanced/07-dp-advanced/convex-hull-trick/)과 [에일리언 트릭](../../lv4-expert/06-misc/aliens-trick/)도 같은 볼록성에서 출발하지만 쓰는 지점이 다릅니다.

## 공통 원칙

- **느린 참조와 무작위 비교**: 동적 연결성은 질의마다 현재 간선 집합으로 처음부터 탐색하는 순진한 구현, 기울기 트릭은 정수 격자에 함수 값을 직접 들고 같은 연산을 적용하는 참조(와 정의 그대로의 DP)와 맞췄습니다.
- **구조의 불변식**: 롤백 후 모든 상태가 되돌아오는가(성분 수, 홀수 사이클 수, 크기), 크기로 합친 유니온 파인드의 깊이가 `log n` 이하인가, 힙 두 개가 `max(L) ≤ min(R)`을 유지하는가.
- **경계 조건**: 다중 간선, 자기 루프, 없는 간선의 삭제, 빈 힙(`±∞`), 지연 오프셋이 쌓인 뒤의 삽입.
- **측정**: 동적 연결성은 연산 `2·10⁵`개가 2초, 기울기 트릭은 `n = 10⁶`이 2~3초로, 이 레벨에서 대회 제한에 가까운 입력이 파이썬으로 돌아가는 편입니다 (각 개념의 5절).
