# 대수와 수열 (Algebra & Sequences)

수열과 급수, 정수론 함수를 **대수적으로** 다루는 도구들입니다. 이 단원의 셋은 서로 다른 문제를 풀지만 "무엇인가를 *직접 전개하지 않고* 구조로 줄인다" 는 점이 같습니다: 점화식을 *찾고* ([벌레캠프–매시](berlekamp-massey/)), 급수를 곱셈 한 번의 비용으로 *뒤집고 지수화하고* ([다항식 연산](polynomial-operations/)), 체로는 못 훑는 범위의 정수론 함수 합을 `√n`개의 값으로 *압축* 합니다 ([민-25 체](min-25-sieve/)).

## 한눈에 비교

| 개념 | 입력 → 출력 | 핵심 | 시간 |
|---|---|---|---|
| [벌레캠프–매시](berlekamp-massey/) | 수열의 앞부분 → 가장 짧은 선형 점화식 | 항을 보며 오차를 지우도록 연결 다항식을 고침 | O(n²) |
| [다항식 연산](polynomial-operations/) | 급수 `f` → `1/f`, `ln f`, `e^f`, `f^k`, `√f`, 나눗셈, 다점 계산·보간 | 곱셈 하나(크로네커 치환) + 뉴턴 방법으로 정밀도를 두 배씩 | 곱셈 M(n)이면 O(M(n)) ~ O(M(n) log n) |
| [민-25 체](min-25-sieve/) | `n` → 소수 개수·합, 곱셈적 함수의 누적합 | `n ÷ i` 꼴의 `2√n`개 값에 대한 표 + 가장 작은 소인수로 나눈 재귀 | O(n^{3/4}) 부근 |

## 문제 신호로 고르기

| 문제의 신호 | 선택 |
|---|---|
| "수열의 처음 몇 항만 줄 테니 `10¹⁸`번째를 구하라", 점화식을 세우기 어렵다 | [벌레캠프–매시](berlekamp-massey/) → [키타마사](../../lv4-expert/06-misc/kitamasa/) |
| 행렬의 거듭제곱에서 나온 수열인데 행렬을 모른다 / 희소 행렬의 행렬식 | [벌레캠프–매시](berlekamp-massey/) (Wiedemann) |
| 생성함수의 처음 `n`개 항 (분할수, 벨 수, 레이블 트리 수), 급수의 역수·로그·지수·거듭제곱·제곱근 | [다항식 연산](polynomial-operations/) |
| 다항식을 많은 점에서 계산 / 점들을 지나는 다항식 / `f(x + c)` | [다항식 연산](polynomial-operations/) |
| "연결 구조의 생성함수 → 전체 구조의 생성함수" (지수/로그 변환) | [다항식 연산](polynomial-operations/) |
| `n ≤ 10¹⁰`(`10¹¹`) 이하 소수의 개수·합 | [민-25 체](min-25-sieve/) (1단계) |
| `Σ_{m≤n} φ(m)`, `Σ σ(m)`, 메르텐스 함수 (`n ≥ 10⁹`) | [민-25 체](min-25-sieve/) (2단계) |
| 곱셈만 빠르게 (정수·다항식) | [FFT/NTT](../../lv4-expert/01-number-theory/fft-ntt/) |
| `n ≤ 10⁷`의 소수 / 약수 함수 | [에라토스테네스의 체](../../lv1-elementary/06-number-theory/sieve-of-eratosthenes/) |

## 개념 사이의 관계

- **점화식 ↔ 유리 생성함수**: 길이 `L`의 선형 점화식은 생성함수 `P(x)/Q(x)`(`deg Q = L`)와 같습니다. 벌레캠프–매시가 `Q`를 찾아 주고, 다항식 연산이 `1/Q`를 전개하고, 키타마사/보스탄–모리가 먼 항을 구합니다.
- **곱셈이 공통 기반**: 다항식 연산은 곱셈 하나가 `M(n)`이면 나머지가 모두 `O(M(n))`입니다. 그 곱셈은 [FFT/NTT](../../lv4-expert/01-number-theory/fft-ntt/)로도, 이 단원처럼 큰 정수 곱셈(크로네커 치환)으로도 만들 수 있습니다.
- **뉴턴 방법 ↔ 두 배씩 늘리는 구조**: 역수·지수·제곱근은 정밀도를 두 배씩 늘리는 같은 틀입니다. 민-25 체의 1단계도 "작은 소수부터 합성수를 지우며 표를 고쳐 간다" 는 점진적 정제입니다.
- **곱셈적 함수**: 민-25 체는 [오일러 피](../../lv2-intermediate/06-number-theory/euler-phi/)·[뫼비우스](../../lv4-expert/01-number-theory/mobius-inversion/)·약수 합 같은 곱셈적 함수의 *누적합* 을 다룹니다. 다항식 연산의 급수 도구는 이런 함수의 디리클레 급수/생성함수에서도 쓰입니다.

## 공통 원칙

- **정의에서 바로 만든 느린 참조와 비교**: 점화식은 모든 점화식을 나열하는 전수 탐색, 급수는 `O(n²)` 계수 점화식·이항 계수 같은 닫힌 식, 정수론 함수는 소인수 분해로 모든 `m`의 `f(m)`을 곱해 더한 접두사 합과 맞췄습니다.
- **알려진 값과 대조**: 소수 개수 `π(10⁹) = 50847534`, 메르텐스 `M(10¹⁰) = −33722`, `Σφ(10⁶)`, 벨 수·카탈란 수·분할수 등 널리 알려진 값이 실행 결과와 일치하는지 확인했습니다.
- **정의역과 경계 조건 명시**: `f₀ ≠ 0`/`= 1`/`= 0`, `mod`가 소수, `n < mod`, 항의 개수와 차수의 구분, 소수의 제곱 근처(`x = p²`, `p^{e+1}`)에서의 재귀 경계를 테스트에 넣었습니다.
- **파이썬의 한계를 숨기지 않기**: 급수는 `n ≈ 2¹⁵`, 점화식은 `n ≈ 4000`, 민-25 체는 `n = 10¹⁰`(소수 개수는 `10¹¹`)이 현실적인 상한입니다. 각 개념의 5절에 측정치가 있습니다.

## 읽는 순서

1. [벌레캠프–매시](berlekamp-massey/): 수열 → 점화식 (가장 짧고 자기완결적)
2. [다항식 연산](polynomial-operations/): 급수 대수 (점화식의 생성함수를 다루는 도구)
3. [민-25 체](min-25-sieve/): 정수론 함수의 큰 `n` 합
