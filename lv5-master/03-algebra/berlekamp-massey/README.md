# 벌레캠프–매시 (Berlekamp–Massey)

> **한 줄 요약**: 수열의 **앞부분만** 보고 그것을 만들어 내는 **가장 짧은 선형 점화식** `s[i] = c₁·s[i−1] + … + c_L·s[i−L]`을 `O(n²)`에 찾는다. 점화식 길이가 `L`이면 `2L`개의 항이면 충분하다. 점화식을 알면 [키타마사](../../../lv4-expert/06-misc/kitamasa/)로 `10¹⁸`번째 항도 구할 수 있어서, "작은 입력으로 항을 몇 개 구한 뒤 점화식을 *추정* 해 먼 항을 계산" 하는 대회 기법의 핵심이다.

## 1. 언제 쓰나 (문제 신호)

- "`n ≤ 10¹⁸`번째 항을 구하라" 인데 DP 전이가 선형 점화식으로 보이지만 **점화식을 직접 세우기 어렵다** (상태가 많은 DP, 타일링, 경로 세기 등)
  - 작은 `n`에 대해 브루트포스나 DP로 처음 `2L`개 정도의 항을 구하고 → 이 알고리즘으로 점화식을 얻고 → 키타마사나 [행렬 거듭제곱](../../../lv3-advanced/07-dp-advanced/matrix-exponentiation/)으로 먼 항
- 어떤 수열이 **고정된 행렬의 거듭제곱** 에서 나온다 (`aₖ = uᵀ Mᵏ v`, `M`은 `m × m`): 점화식 길이는 `m` 이하이고 앞의 `2m`항이면 충분하다. 행렬을 몰라도 항만으로 점화식을 얻는다
- **희소 행렬** 의 행렬식·랭크·선형 방정식 (Wiedemann 알고리즘): `uᵀ Mᵏ v` 수열의 점화식 = `M`의 최소 다항식의 약수
- 부호 이론: 유한체 위의 LFSR(선형 되먹임 이동 레지스터) 합성, BCH/리드–솔로몬 복호 (이 알고리즘의 원래 용도)
- 수열이 **선형 점화식을 따르는지 모를 때**: 이 알고리즘은 *항상* 점화식을 내놓지만, 점화식이 없는 수열이면 길이 `L ≈ n/2`인 의미 없는 점화식이 나온다 (6절). 길이가 항의 절반보다 충분히 작을 때만 믿을 수 있다
- 점화식의 계수가 `n`에 의존하는 다항식(P-재귀)이면 이 알고리즘으로는 안 된다 (예: `n!`, 카탈란 수는 상수 계수 점화식이 없다)

## 2. 핵심 아이디어

수열 `s₀, s₁, …, s_{n−1}`과 소수 `p`. 길이 `L`의 선형 점화식은 `L ≤ i`인 모든 `i`에서 `s[i] = Σⱼ₌₁ᴸ cⱼ s[i−j]` (mod `p`). 이를 **연결 다항식** `C(x) = 1 − c₁x − … − c_L x^L`로 쓰면 "`C`와 `S(x) = Σ sᵢ xⁱ`의 곱에서 `x^L` 이상의 계수가 0" 이다.

**알고리즘**: 항을 하나씩 보며 현재의 `C`(길이 `L`)로 `s[i]`를 예측하고 **오차** `d = s[i] − Σ cⱼ s[i−j]`를 구한다.

1. `d = 0`이면 `C`가 `s[i]`도 맞게 예측했으니 그대로 두고 `m`만 하나 늘린다.
2. `d ≠ 0`이면 *마지막으로 길이가 늘어났던 시점* 에 저장해 둔 다항식 `B`(그때의 오차 `b`; `m`은 저장 뒤 지난 항 수에 1을 더한 값으로, 길이가 늘어난 직후에는 1)를 이용해 `C ← C − (d/b)·x^m·B`로 고친다. `B`는 그때까지의 항 전부에서는 오차가 0이고 그때의 항에서만 오차 `b`를 냈으므로, `x^m B`는 이번 항 *전* 의 예측을 건드리지 않으면서 이번 항의 오차를 정확히 `d`만큼 바꾼다.
3. 길이도 늘려야 하는지: `2L ≤ i`이면 `L ← i + 1 − L`로 늘리고 방금 쓴 `C`(고치기 전의 것)를 새 `B`로 저장한다 (`b ← d`, `m ← 1`). 아니면 `m`만 하나 늘린다.

**왜 길이가 `i + 1 − L`로 최소인가**: 길이 `L₁`의 점화식이 `s₀ … s_{i−1}`을 맞게 만들고 `s_i`만 틀린다면, `s₀ … s_i`를 모두 만족하는 점화식의 길이는 `i + 1 − L₁` 이상이다. (두 점화식의 연결 다항식을 곱해 섞으면 모순이 생긴다.) 그래서 `L`은 항상 지금까지의 **최소** 길이를 유지하고, 마지막까지 돌린 결과가 `s` 전체에 대한 최단 점화식이다.

**몇 개의 항이 필요한가**: 진짜 점화식의 길이가 `L`이면 앞의 `2L`개로 유일하게 결정된다. `2L − 1`개 이하이면 *유효하지만 다른* 점화식이 나올 수 있다. 예: Lucas 모양 `1, 3, 4, 7, 11, 18, …`의 진짜 점화식은 `s[i] = s[i−1] + s[i−2]`인데, 앞의 3개 `1, 3, 4`만 주면 `s[i] = 3·s[i−1] − 5·s[i−2]` (`3·3 − 5·1 = 4`)도 조건을 만족한다. 4개 `1, 3, 4, 7`부터는 `[1, 1]`로 정해진다.

**`n`번째 항**: `x^k`를 특성 다항식 `x^L − c₁x^{L−1} − … − c_L`로 나눈 나머지 `r(x)`를 구하면 `s_k = Σ rᵢ sᵢ` ([키타마사](../../../lv4-expert/06-misc/kitamasa/)와 같은 방법, `O(L² log k)`).

## 3. 손으로 따라가기

수열 `1, 3, 4, 7, 11, 18` (mod 101, 값이 `p − 1`이면 `−1`로 읽는다). 시작: `C = 1`, `L = 0`, `B = 1`, `b = 1`, `m = 1`.

| `i` | `sᵢ` | 예측 | 오차 `d` | 일어나는 일 | `C(x)`, `L` |
|---|---|---|---|---|---|
| 0 | 1 | 0 | 1 | `2·0 ≤ 0` → 길이 증가 `L = 1`, `C ← 1 − (1/1)·x·1`, `B ← 1`, `b ← 1`, `m ← 1` | `1 − x`, `1` |
| 1 | 3 | `1·s₀ = 1` | 2 | `2·1 > 1` → 길이 유지, `C ← C − (2/1)·x·B` | `1 − 3x`, `1` |
| 2 | 4 | `3·s₁ = 9` | 4 − 9 = −5 | `2·1 ≤ 2` → 길이 증가 `L = 3 − 1 = 2`, `C ← C − (−5/1)·x²·1 = 1 − 3x + 5x²`, `B ← 1 − 3x`, `b ← −5`, `m ← 1` | `1 − 3x + 5x²`, `2` |
| 3 | 7 | `3·s₂ − 5·s₁ = 12 − 15 = −3` | 7 − (−3) = 10 | `2·2 > 3` → 길이 유지, `C ← C − (10/−5)·x·B = C + 2x(1 − 3x)` | `1 − x − x²`, `2` |
| 4 | 11 | `s₃ + s₂ = 11` | 0 | 그대로 | `1 − x − x²`, `2` |
| 5 | 18 | `s₄ + s₃ = 18` | 0 | 그대로 | `1 − x − x²`, `2` |

결과 `C = 1 − x − x²` → `c = [1, 1]`, 길이 `L = 2`, 즉 `s[i] = s[i−1] + s[i−2]`. 실행해서 확인한 값(`mod 101`에서 `C`의 계수 `[1, 100, 100]`)과 같다. 다른 예: `1, 2, 4, 8, 16` → `[2]` (길이 1), `3×2n` 타일 수 `1, 0, 3, 0, 11, 0, 41, 0, 153, 0, 571` → `[0, 4, 0, −1]` (`aₙ = 4aₙ₋₂ − aₙ₋₄`).

## 4. 구현

전체 코드는 [solution.py](solution.py)에 있습니다.

```python
def berlekamp_massey(seq, mod):
    n = len(seq)
    connection = [1] + [0] * n           # C(x) (부호는 s[i] + C[1]s[i-1] + ... = 0 꼴)
    previous = [1] + [0] * n             # B(x)
    length, gap, last_error = 0, 1, 1    # L, m, b
    for i in range(n):
        error = seq[i] % mod
        for j in range(1, length + 1):   # 현재 C 로 s[i] 를 예측한 오차 d
            error = (error + connection[j] * seq[i - j]) % mod
        if error == 0:
            gap += 1; continue
        saved = connection[:]
        coefficient = error * pow(last_error, mod - 2, mod) % mod   # d / b
        for j in range(gap, n + 1):      # C ← C − (d/b) x^m B
            connection[j] = (connection[j] - coefficient * previous[j - gap]) % mod
        if 2 * length <= i:              # 길이 증가
            length = i + 1 - length
            previous, last_error, gap = saved, error, 1
        else:
            gap += 1
    return [(-connection[j]) % mod for j in range(1, length + 1)]
```

- `berlekamp_massey(seq, mod=998244353)` → 계수 `[c₁, …, c_L]` (`mod`는 **소수**). 길이 `L = len(결과)`.
- `check_recurrence(seq, c, mod)`: 항 전체가 점화식을 만족하는지 정의대로 검사.
- `nth_term(c, init, k, mod)`: 점화식과 처음 `L`개 항에서 `k`번째(0부터) 항, `O(L² log k)`.
- `extend(seq, count, mod)`: 점화식을 찾아 항을 `count`개 더 이어 쓴다.
- 직접 실행하면 Library Checker "Find Linear Recurrence" 형식 — `N`, 이어서 `a₀ … a_{N−1}` — 을 받아 `L`과 `c₁ … c_L`을 출력합니다 (`mod = 998244353`).

## 5. 복잡도와 입력 크기 가이드

- 항 하나에 `O(L)`번의 곱셈 → 전체 `O(n·L) ⊆ O(n²)`. 메모리 `O(n)`. ([복잡도 치트시트](../../../docs/complexity-cheatsheet.md))
- 이 환경에서 측정한 값입니다.

| 입력 | 시간 |
|---|---|
| 무작위 수열 `n = 500` (`L = 250`) | 0.028초 |
| `n = 1000` (`L = 500`) | 0.105초 |
| `n = 2000` (`L = 1000`) | 0.47초 |
| `n = 4000` (`L = 2000`) | 1.65초 |
| 길이 20 점화식에서 나온 수열 `n = 2000` / `10000` / `40000` | 0.008초 / 0.043초 / 0.176초 (모두 `L = 20`을 정확히 복원) |
| `nth_term`, `k = 10¹⁸`, `L = 10 / 50 / 100 / 200` | 0.002초 / 0.037초 / 0.148초 / 0.64초 |

- 무작위(점화식이 없는) 수열은 `L ≈ n/2`라서 `O(n²)`가 그대로 드러납니다 (`n`이 두 배가 되면 시간이 약 네 배). 짧은 점화식에서 나온 수열은 `O(n·L)`이라 `n = 40000`도 0.18초입니다.
- `nth_term`은 `O(L² log k)`: `L`이 두 배가 되면 약 네 배. `L = 200`, `k = 10¹⁸`이 0.64초이므로 `L ≲ 500`까지가 파이썬으로 현실적입니다. 그 이상은 다항식 곱셈을 [NTT](../../../lv4-expert/01-number-theory/fft-ntt/)나 [다항식 연산](../polynomial-operations/)의 곱셈으로 바꾼 보스탄–모리가 필요합니다.

## 6. 자주 하는 실수

- **항이 부족함**: 진짜 길이가 `L`이면 `2L`개가 필요합니다. 부족하면 *맞아 보이는 다른 점화식* 이 나옵니다 (2절의 `1, 3, 4`). 여유 항을 따로 두고 찾은 점화식으로 예측해 맞춰 보세요 (`check_recurrence`).
- **점화식이 없는 수열에 사용**: 분할수 `p(n)`의 앞 21, 61, 121항에 돌리면 길이가 11, 31, 61로 항의 절반 정도이고, 소수 판별 함수(`1, 0, 1, 1, 0, …`)의 100항은 길이 50이 나옵니다. 항의 약 절반이 되는 길이는 "점화식이 없다" 는 신호이지 점화식이 아닙니다.
- **`mod`가 소수가 아님**: 오차 `d`를 `b`로 나누는 곱셈 역원이 필요합니다 (`pow(b, mod−2, mod)`). 합성수 모듈러에서는 역원이 없는 `b`에서 틀립니다 (정수 위에서 하려면 유리수 BM 또는 큰 소수 하나로 구한 뒤 복원).
- **정수 계수 점화식인데 `mod p`에서 구한 계수를 그대로 사용**: `mod p`의 값이므로 계수가 작은 정수라면 `[−p/2, p/2]` 범위로 해석해야 합니다 (`p − 1`은 `−1`). 계수가 유리수면 유리수 복원이 필요합니다.
- **인덱스 한 칸 밀림**: 반환값 `c[0]`은 `c₁`, 즉 `s[i−1]`의 계수입니다 (`c[j]` ↔ `s[i−1−j]`).
- **앞부분의 예외**: 점화식은 `i ≥ L`에서만 성립하면 됩니다. 처음 몇 항만 규칙에서 벗어나면 그만큼 `L`이 커집니다 (`0, 0, 0, 1` → 길이 4, `0, 0, 1, 2, 4, 8` → 길이 3).
- **모든 항이 0**: 점화식의 길이는 0이고 `c`는 빈 리스트입니다 (`nth_term`은 0).
- **`nth_term`의 초기값**: `init`에는 수열의 *처음* `L`개 항이 필요합니다 (점화식을 찾은 구간의 앞쪽).

## 7. 변형과 응용

- **DP 추정 → 먼 항**: 브루트포스로 작은 `n`의 답을 구해 이 알고리즘 → `nth_term`. 검증용으로 처음 `2L`개 이후의 항을 몇 개 더 구해 점화식을 확인합니다.
- **행렬의 최소 다항식 / 희소 행렬 계산**: 무작위 벡터 `u, v`로 `uᵀ Mᵏ v` (`k < 2m`)를 구하고 BM을 돌리면 높은 확률로 `M`의 최소 다항식. 행렬-벡터 곱이 `O(nnz)`이면 전체 `O(m·nnz + m²)` — 행렬식·선형 방정식 풀이 (Wiedemann).
- **다항식으로 주어지는 수열**: `d`차 다항식 `f(n)`의 수열은 길이 `d + 1`의 점화식(계수는 이항계수 `±C(d+1, j)`)을 따릅니다: `n² → [3, −3, 1]`, `n³ → [4, −6, 4, −1]` (실행해서 확인).
- **유리 생성함수**: 점화식은 `S(x) = P(x)/Q(x)`의 분모 `Q`입니다. [다항식 연산](../polynomial-operations/)의 나눗셈·역수와 짝을 이룹니다.
- **여러 수열**: 벡터 값 수열의 최소 점화식은 행렬 BM(블록 와이드만)이 필요하며 이 저장소 범위 밖입니다.
