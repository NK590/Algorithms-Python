# 매트로이드 교집합 (Matroid Intersection)

> **한 줄 요약**: 같은 원소 집합 위에 매트로이드가 둘 주어질 때, **두 매트로이드에서 동시에 독립인** 부분집합 중 가장 큰 것을 찾는다. 이분 매칭의 "증가 경로" 가 그대로 일반화된다 — 현재 답 `I`에 대해 *교환 그래프* 를 만들고 그 위의 **최단 경로** 를 따라 원소를 넣고 빼면 크기가 하나 늘어난다. 가중치가 있으면 최단 경로를 "무게 합이 가장 작고, 그중 정점이 가장 적은" 경로로 바꾸면 크기별 최대 가중치 해를 얻는다.

## 1. 언제 쓰나 (문제 신호)

- "원소를 골라야 하는데 **서로 독립인 두 가지 제약** 이 있다": 하나는 *사이클이 없어야 한다*(그래픽), 다른 하나는 *색마다 하나씩* (분할) 같은 식
  - 무지개 신장 트리/포레스트: 간선마다 색이 있고, 사이클 없이, 색은 모두 달라야 한다
  - **방향 그래프의 신장 arborescence**: 무방향으로 보아 사이클 없음(그래픽) + 각 정점으로 들어오는 간선은 하나(분할). 가중치 판이 최소 arborescence
  - 이분 매칭: 간선이 원소, 왼쪽 정점별로 하나(분할) + 오른쪽 정점별로 하나(분할) — 그래서 이분 매칭은 이 문제의 특수한 경우다
  - 벡터를 고르는데 일차 독립이어야 하고 그룹별 제한이 있다 (선형 + 분할)
- 한 제약만 있으면 **탐욕** 이 최적이다 (매트로이드의 성질). 제약이 둘이 되는 순간 탐욕은 틀리고 이 알고리즘이 필요하다
- 제약이 셋 이상이면 일반적으로 NP-난해이다 (3차원 매칭이 세 분할 매트로이드의 교집합)
- 일반 그래프의 매칭([블로섬](../blossom/))은 이 틀로 풀 수 없다. 교집합이 아니라 *매트로이드 패리티* 라는 더 어려운 문제의 특수한 경우이다

## 2. 핵심 아이디어

**매트로이드**: 원소 집합 `E`와 "독립 집합" 의 족 `𝓘`로, (1) 공집합이 독립, (2) 독립 집합의 부분집합도 독립, (3) **교환 성질**: `|J| > |I|`인 독립 집합 `I, J`에 대해 `J \ I`의 어떤 원소 `x`를 `I`에 더해도 독립이다. 예: 그래프의 포레스트(그래픽), 색마다 최대 `c`개(분할), 벡터의 일차 독립 집합(선형), 크기 `k` 이하(균등). 이 구현은 매트로이드를 **독립성 오라클** `independent(items)`로만 다룬다.

**교환 그래프** (현재 공통 독립 집합 `I`):

- 정점은 모든 원소. `y ∈ I`, `x ∉ I`일 때
  - `I − y + x`가 `M1`에서 독립이면 간선 **`y → x`**
  - `I − y + x`가 `M2`에서 독립이면 간선 **`x → y`**
- 출발점 `X1 = {x ∉ I : I + x ∈ M1}`, 도착점 `X2 = {x ∉ I : I + x ∈ M2}`

**알고리즘**: `X1`에서 `X2`로 가는 **정점 수가 최소인 경로**(BFS)를 찾아 그 경로 위 원소들의 소속을 뒤집는다 (`I`에 있던 것은 빼고, 없던 것은 넣는다). 그 결과는 여전히 두 매트로이드에서 독립이고 크기가 하나 커진다. 경로가 없으면 `I`가 최대이다.

직관: 경로 `x₀ → y₁ → x₁ → y₂ → … → xₖ`를 보면 `M1`에서는 `x₀`를 그냥 넣고(출발점이므로) `y₁`을 `x₁`으로, `y₂`를 `x₂`로, … 바꾸고, `M2`에서는 `x₀`를 `y₁`과 바꾸고, `x₁`을 `y₂`와 바꾸고, … `xₖ`를 그냥 넣는다. 이분 매칭의 "짝 없는 정점에서 시작해 번갈아 가며 짝 없는 정점에서 끝나는 경로" 와 같은 모양이다.

**왜 *최단* 경로여야 하나**: 경로가 짧지 않으면 중간에 지름길이 있어 바꾼 결과가 어느 한 매트로이드에서 *독립이 아닐 수 있다* (교환이 서로 간섭한다). 최단 경로에는 지름길이 없다는 사실이 정당성의 핵심이다. 실제로 이웃 순서를 무작위로 하는 DFS로 찾은 아무 경로를 뒤집으면 무작위 입력의 일부에서 중간에 독립이 깨진다 (3000개 중 210개, 아래 6절).

**최적성의 증명서**: 에드먼즈의 **최대-최소 정리** `max |I| = min_{A ⊆ E} ( r₁(A) + r₂(E \ A) )`(`rᵢ`는 `Mᵢ`의 랭크)가 성립한다. 경로가 없을 때 `X1`에서 교환 그래프로 닿을 수 있는 원소들에서 등호를 주는 `A`를 만들 수 있다. 이 구현은 증명서를 돌려주지 않고, 테스트가 이 정리를 모든 `A`에 대해 확인한다.

**가중치 판**: 원소에 가중치 `w`가 있고 크기 `k`마다 **무게 합이 최대인** 공통 독립 집합을 구하려면, 정점에 값을 준다: `x ∉ I`는 `−w[x]`(넣으면 이득), `y ∈ I`는 `+w[y]`(빼면 손해). `X1`에서 `X2`로 가는 경로 중 **(값의 합, 정점 수)가 사전순으로 가장 작은 것** 을 벨만–포드로 찾아 뒤집는다. `I`가 "크기 `|I|`의 최대 가중치 해" 이면 교환 그래프에 음수 사이클이 없고, 뒤집은 결과는 크기 `|I|+1`의 최대 가중치 해이다. 그래서 `weighted_matroid_intersection`은 크기 0, 1, 2, …에 대한 최적 해를 모두 돌려준다 (크기 `k`의 최적 해가 크기 `k−1`의 최적 해를 포함하지는 않는다 — 3절 끝의 예).

## 3. 손으로 따라가기

이분 그래프: 왼쪽 `a, b`, 오른쪽 `1, 2`. 간선(원소) `e0 = (a,1)`, `e1 = (a,2)`, `e2 = (b,1)`.

- `M1`: 왼쪽 정점마다 하나 (분할: 그룹 `a`에 `{e0, e1}`, 그룹 `b`에 `{e2}`)
- `M2`: 오른쪽 정점마다 하나 (그룹 `1`에 `{e0, e2}`, 그룹 `2`에 `{e1}`)

현재 `I = {e0}` (탐욕이 `e0`를 먼저 골랐다. 이대로는 더 넣을 수 없다 — `e1`은 왼쪽 `a`가 겹치고 `e2`는 오른쪽 `1`이 겹친다).

- 출발점 `X1`: `I + x`가 `M1`에서 독립인 `x ∉ I` → `e2` (`e1`은 왼쪽 `a`가 겹침). `X1 = {e2}`
- 도착점 `X2`: `I + x`가 `M2`에서 독립 → `e1` (`e2`는 오른쪽 `1`이 겹침). `X2 = {e1}`
- 간선 `y → x` (`I − y + x ∈ M1`): `e0 → e1` (`{e1}`은 독립), `e0 → e2`
- 간선 `x → y` (`I − y + x ∈ M2`): `e2 → e0` (`{e2}`는 독립), `e1 → e0`

실행으로 확인한 인접 리스트는 `e0: [e1, e2]`, `e1: [e0]`, `e2: [e0]` (코드의 `out_arcs`)이고 출발점 `[e2]`, 도착점 `[e1]`이다. 최단 경로: **`e2 → e0 → e1`** (정점 3개). 뒤집으면 `e2`와 `e1`이 들어오고 `e0`가 나간다: `I = {e1, e2}` = `{(a,2), (b,1)}` — 크기 2, 이분 매칭의 증가 경로와 똑같다.

**가중치 판**: 같은 그래프에서 `w = [5, 4, 4]`로 `weighted_matroid_intersection`을 실행하면 `[(0, []), (5, [0]), (8, [1, 2])]`를 돌려준다 — 크기 1의 최적은 `{e0}`(5)이고 크기 2의 최적은 `{e1, e2}`(8)이다. 크기 2의 최적 해가 크기 1의 최적 해 `e0`를 *포함하지 않는다*. 경로 `e2 → e0 → e1`의 값은 `−4 + 5 − 4 = −3`이고, 경로를 뒤집으면 무게가 `3` 늘어난다 (`5 → 8`). `w = [5, 1, 1]`이면 같은 경로의 값이 `−1 + 5 − 1 = 3`이라 무게가 `3` 줄어든다: `[(0, []), (5, [0]), (2, [1, 2])]`, 크기 2로 키우면 합이 *줄어든다* (5 → 2). 크기별로 최적을 보고하는 이유다 — 호출하는 쪽이 `max`를 취하거나 원하는 크기를 고르면 된다.

## 4. 구현

전체 코드는 [solution.py](solution.py)에 있습니다.

```python
def matroid_intersection(n, m1, m2, initial=()):
    in_set = [False] * n
    ...                                                    # initial 이 공통 독립 집합인지 확인
    while True:
        out_arcs, sources, sinks = _exchange_graph(n, m1, m2, in_set)
        sink_set = set(sinks)
        previous = [-2] * n                                # -2: 아직 못 감, -1: 출발점
        queue = deque(sources)
        for s in sources: previous[s] = -1
        end = -1
        while queue:                                       # BFS = 정점 수가 최소인 경로
            v = queue.popleft()
            if v in sink_set: end = v; break
            for to in out_arcs[v]:
                if previous[to] == -2: previous[to] = v; queue.append(to)
        if end == -1: break                                # 경로 없음: 최대
        path = []; v = end
        while v != -1: path.append(v); v = previous[v]
        for v in path: in_set[v] = not in_set[v]           # 소속 뒤집기
    return [e for e in range(n) if in_set[e]]
```

- 매트로이드는 `Matroid`를 상속해 `independent(items)`만 구현하면 된다. `exchangeable(current, x)`(`I − y + x`가 독립인 `y`의 목록)는 기본으로 오라클을 `|I|`번 부르고, 구조를 이용해 빠르게 덮어쓸 수 있다.
- 제공: `UniformMatroid(k)`, `PartitionMatroid(group_of, capacity)`, `GraphicMatroid(n, edges)`(포레스트, 교환 후보는 `I` 안의 `x`의 두 끝점 사이 경로), `LinearMatroid(vectors)`(GF(2) 위의 비트마스크 벡터).
- `matroid_intersection(n, m1, m2, initial=())` → 최대 크기 공통 독립 집합. `weighted_matroid_intersection(n, m1, m2, weight)` → 크기 `k`마다 `(최대 가중치, 집합)`.
- 직접 실행하면 무지개 신장 포레스트 형식 — `N M`, 이어서 `M`줄의 `a b color` — 을 받아 서로 다른 색의 간선만 쓰는 가장 큰 포레스트의 크기와 간선 번호를 출력합니다.

## 5. 복잡도와 입력 크기 가이드

- 교환 그래프 하나를 만드는 데 오라클 호출이 `O(r·n)`번(`r = |I|`, 빠른 `exchangeable`을 쓰면 원소마다 한 번), BFS는 간선 수 `O(r·n)`. 크기를 하나 늘릴 때마다 반복하므로 전체 `O(r²·n)` (오라클 호출 기준). 가중치 판은 벨만–포드로 `O(n · r·n)`이 더 든다.
- 이 환경에서 측정한 값입니다.

| 입력 | 답의 크기 | 시간 |
|---|---|---|
| 그래픽 ∩ 분할(색), 정점 30 / 간선 90 / 색 20 | 20 | 0.015초 (기본 오라클 교환: 0.054초) |
| 정점 60 / 간선 200 / 색 40 | 39 | 0.099초 (0.82초) |
| 정점 100 / 간선 400 / 색 70 | 69 | 0.59초 (8.7초) |
| 정점 200 / 간선 800 / 색 150 | 150 | 4.9초 |
| 이분 매칭 (분할 ∩ 분할), `L = R = 50`, 간선 127 | 42 | 0.033초 |
| `L = R = 100`, 간선 539 | 99 | 0.74초 |
| `L = R = 200`, 간선 1979 | 200 | 11.4초 |
| 가중치 판: 최소 arborescence (그래픽 ∩ 도착 정점별 1개), `n = 30`, 호 255 | 29 | 0.12초 |
| 선형(GF(2)) ∩ 분할, 원소 80, 24비트 | 24 | 0.17초 |

- "기본 오라클 교환" 열은 `exchangeable`을 덮어쓰지 않고 `independent`만으로 교환 후보를 구한 경우입니다. 구조를 이용한 `exchangeable`(그래픽: 포레스트의 경로)이 `V = 100`에서 약 15배 빠릅니다.
- 같은 이분 매칭(`L = 200`, 간선 약 2000)을 쿤 알고리즘으로 풀면 0.0024초입니다. 매트로이드 교집합은 **범용 도구** 이므로 전용 알고리즘이 있는 특수 경우(이분 매칭, 최소 arborescence)에서는 전용 알고리즘을 쓰고, 제약이 정말 두 매트로이드의 교집합인 문제(무지개 신장 트리 등)에 쓰세요. 원소 수 `n ≈ 10³` 이하가 파이썬의 현실적인 범위입니다.

## 6. 자주 하는 실수

- **최단이 아닌 경로를 뒤집음**: DFS로 찾은 아무 경로를 뒤집으면 결과가 독립이 아닐 수 있습니다. 이웃 순서를 무작위로 한 DFS로 실험하면 무작위 입력 3000개(분할·그래픽·선형 매트로이드 쌍, 원소 6~12개) 중 210개에서 과정 중 어느 시점에 두 매트로이드 중 하나에서 독립이 깨졌습니다. BFS(정점 수 최소)를 쓰세요.
- **간선 방향을 바꿔 씀**: `y → x`는 `M1`, `x → y`는 `M2`입니다. 출발점은 `M1`, 도착점은 `M2`에 대응합니다. 한쪽만 뒤집으면 경로가 의미를 잃습니다.
- **`I + x`가 독립이면 모든 `y`가 교환 가능**: `I − y + x`는 `I + x`의 부분집합이므로 독립입니다. `exchangeable`이 이 경우 `I` 전체를 돌려줘야 합니다 (그래픽에서 `x`가 두 트리를 이으면 경로가 없는 것이 아니라 전부).
- **가중치 판에서 정점 수 타이브레이크 누락**: 값의 합만 비교하면 같은 합의 더 긴 경로가 선택되어 정당성이 깨집니다. `(값, 정점 수)`의 사전순이어야 합니다.
- **가중치 판에서 크기 `k`의 최적이 크기 `k+1`의 최적에 포함된다고 가정**: 포함되지 않을 수 있습니다 (3절).
- **임의의 해에서 가중치 판을 시작함**: 가중치 판은 빈 집합에서 한 칸씩 키워야 각 단계가 그 크기의 최적 해임이 보장됩니다. 최대 크기만 구하는 `matroid_intersection`의 `initial`은 임의의 공통 독립 집합이어도 됩니다.
- **독립성 오라클이 느림**: `GraphicMatroid.independent`는 `O(n)`이라 교환 그래프를 순진하게 만들면 `O(r·n)`번 부르는 것만으로도 느립니다. `exchangeable`을 구조에 맞게 덮어쓰세요 (그래픽: 포레스트 경로, 분할: 같은 그룹).
- **세 번째 제약을 끼워 넣으려 함**: 매트로이드 셋의 교집합은 NP-난해입니다. 문제가 정말 두 제약인지 확인하세요.

## 7. 변형과 응용

- **이분 매칭, 이분 그래프의 가중치 매칭**: 분할 매트로이드 둘 (가중치 판이면 크기별 최대 가중치 매칭).
- **무지개 신장 트리**: 그래픽 ∩ 분할(색). 크기가 `V − 1`이면 존재.
- **최소 가중치 arborescence (Chu–Liu/Edmonds)**: 그래픽(무방향) ∩ 분할(도착 정점별 하나, 뿌리는 0개)의 가중치 판. 테스트가 작은 그래프에서 전수 탐색과 맞춰 봅니다. 전용 알고리즘이 더 빠르지만 제약이 더 붙은 변형(색 제한 등)은 이쪽이 쉽습니다.
- **두 개의 서로소인 신장 트리 / 매트로이드 합집합**: 매트로이드의 합(union)은 교집합으로 환원됩니다.
- **선형 매트로이드와의 교집합**: 벡터를 일차 독립으로 고르되 그룹 제한 (GF(2) 또는 소수체).
- **횡단 매트로이드, 행렬 매트로이드**: 마찬가지로 오라클만 구현하면 됩니다.
- **더 어려운 것**: 매트로이드 패리티(일반 그래프 매칭을 포함), 가중치 있는 매트로이드 패리티는 이 저장소 범위 밖입니다.
