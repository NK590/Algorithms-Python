# 매칭과 매트로이드 (Matching & Matroids)

Lv3의 [이분 매칭](../../lv3-advanced/03-graph-advanced/bipartite-matching/)과 Lv4의 [헝가리안](../../lv4-expert/04-flow-matching/hungarian-algorithm/)은 모두 **이분 그래프** 에서의 "짝짓기" 였습니다. 이 단원은 두 방향으로 한계를 넓힙니다. 하나는 그래프가 이분이 아니어도 되게 하는 것 ([블로섬](blossom/)), 다른 하나는 매칭의 *구조* 를 추상화해서 "두 가지 독립 제약" 이라는 훨씬 넓은 문제 집단을 한꺼번에 푸는 것 ([매트로이드 교집합](matroid-intersection/)) 입니다. 둘 다 "**증가 경로를 찾아 뒤집는다**" 는 같은 뼈대를 쓰지만, 경로가 놓이는 그래프가 다릅니다.

## 한눈에 비교

| 개념 | 푸는 문제 | 핵심 | 최적성의 증명서 | 시간 |
|---|---|---|---|---|
| [블로섬](blossom/) | 일반 그래프의 최대 매칭 | 교대 트리를 BFS로 키우다 홀수 사이클(꽃)을 만나면 한 정점으로 수축 | 투테–버지 공식, 갈라이–에드먼즈 분해 | O(V³) |
| [매트로이드 교집합](matroid-intersection/) | 두 매트로이드에서 동시에 독립인 최대(최대 가중치) 집합 | 교환 그래프의 *최단* 경로를 뒤집기 (가중치 판은 벨만–포드) | 에드먼즈의 최대-최소 정리 | 증가마다 O(r·n) 오라클 호출 |

같은 이분 매칭(`L = R = 200`, 간선 약 2000)을 두 방법으로 풀면 쿤 알고리즘이 0.0024초, 매트로이드 교집합이 11.4초입니다. 범용 도구일수록 전용 알고리즘이 있는 특수 경우에서는 느립니다 (매트로이드 교집합 개념 5절의 측정).

## 문제 신호로 고르기

| 문제의 신호 | 선택 |
|---|---|
| 같은 집합 안에서 서로 짝을 지어야 한다 (이분이라는 보장 없음), 최대 몇 쌍 | [블로섬](blossom/) |
| 완전 매칭 여부 / 모든 정점을 덮는 최소 간선 수 | [블로섬](blossom/) (`ν = V/2`인가, `V − ν`) |
| 어떤 정점이 모든 최대 매칭에 들어가는가 | [블로섬](blossom/)의 `gallai_edmonds` |
| 이분 그래프의 최대 매칭 | [이분 매칭](../../lv3-advanced/03-graph-advanced/bipartite-matching/) (더 빠르고 단순) |
| 이분 그래프의 최소(최대) 비용 완전 배정 | [헝가리안](../../lv4-expert/04-flow-matching/hungarian-algorithm/) |
| "사이클이 없어야 하고 동시에 색(그룹)마다 하나씩" 같은 *두 독립 제약* 을 만족하는 최대 부분집합 | [매트로이드 교집합](matroid-intersection/) |
| 위의 최대 *가중치* 판, 최소 가중치 arborescence | [매트로이드 교집합](matroid-intersection/)의 가중치 판 |
| 제약이 하나뿐 (사이클 없음만, 그룹별 개수만) | 그리디 (매트로이드의 성질) |
| 제약이 셋 이상 | 일반적으로 NP-난해 — 문제의 특수 구조를 찾아야 한다 |

## 개념 사이의 관계

- **같은 뼈대, 다른 그래프**: 베르주의 정리(증가 경로가 없으면 최대)가 두 알고리즘 모두의 정당성 근거입니다. 블로섬은 *교대 트리* 에서 사이클을 수축하며 경로를 찾고, 매트로이드 교집합은 원소를 정점으로 하는 *교환 그래프* 에서 최단 경로를 찾습니다. 둘 다 "찾은 경로가 정말 증가 경로인가" 를 보장하는 장치(수축 / 최단성)가 필요합니다.
- **이분 매칭 ⊂ 매트로이드 교집합**: 간선을 원소로 두고 왼쪽 정점별·오른쪽 정점별로 하나씩만 고르는 두 분할 매트로이드의 교집합이 이분 매칭입니다. 가중치 판은 이분 그래프의 (크기별) 최대 가중치 매칭을 줍니다. 헝가리안이 푸는 할당 문제와 같은 계열의 문제입니다.
- **일반 매칭 ⊄ 매트로이드 교집합**: 일반 그래프의 매칭은 두 매트로이드의 교집합으로 쓸 수 없습니다 (홀수 사이클이 방해). 그것은 *매트로이드 패리티* 라는 더 큰 문제의 특수한 경우이고, 블로섬이 그 경우를 직접 풉니다.
- **증명서**: 블로섬이 내놓는 갈라이–에드먼즈의 `A` 집합은 투테–버지 공식의 등호를, 매트로이드 교집합의 최대-최소 정리는 `r₁(A) + r₂(E∖A)`의 등호를 줍니다. 둘 다 "최적임을 알고리즘을 믿지 않고도 확인하는" 도구로 테스트에서 쓰였습니다.

## 공통 원칙

- **전수 탐색과 증명서로 이중 검증**: 작은 입력은 모든 부분집합/모든 매칭을 훑는 브루트포스, 큰 입력은 *유효한 해 + 같은 값을 주는 증명서* (투테–버지의 `A`, 최대-최소 정리) 로 최적성을 확인했습니다.
- **임의의 중간 상태에서 시작해도 맞아야 한다**: 알고리즘이 스스로 만든 상태뿐 아니라 임의의 (최대가 아닌) 매칭, 임의의 공통 독립 집합에서 시작해도 증가 경로 탐색이 맞는지 정의대로 만든 참조와 비교했습니다. 변이 검사에서 이 테스트가 없으면 놓치는 오류가 실제로 발견되었습니다.
- **구조적 불변식**: 교환 그래프의 경로는 *최단* 이어야 하고 (그 성질을 따로 검사), 블로섬의 수축은 서로 다른 꽃 둘을 합치므로 한 탐색에서 `V − 1`번을 넘지 않습니다.
- **파이썬의 한계를 숨기지 않기**: 블로섬은 정점 `10³`~`10⁴`, 매트로이드 교집합은 원소 `10³` 안팎이 현실적입니다.

## 읽는 순서

1. [블로섬](blossom/): 증가 경로 + 꽃 수축, 투테–버지 공식
2. [매트로이드 교집합](matroid-intersection/): 증가 경로를 교환 그래프로 일반화
