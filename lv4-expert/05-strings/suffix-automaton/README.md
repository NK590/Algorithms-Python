# 접미사 자동자 (Suffix Automaton)

> **한 줄 요약**: 문자열 `s`의 **모든 부분 문자열을 받아들이는 가장 작은 DFA**. 글자를 하나씩 붙이면서 `O(n)`에 만들고(온라인), 상태는 "끝나는 위치 집합이 같은 부분 문자열들의 묶음"이라 상태 수가 `2n` 이하다. 부분 문자열 포함 여부·출현 횟수·위치, 서로 다른 부분 문자열의 수, 사전순 `k`번째 부분 문자열, 여러 문자열의 최장 공통 부분 문자열이 모두 이 자동자 위의 단순한 계산이 된다.

## 1. 언제 쓰나 (문제 신호)

- "서로 다른 부분 문자열의 개수" — 글자를 붙일 때마다 **접두사별로** 답이 필요할 때 특히 (접미사 배열은 한 번에 하나)
- "패턴이 본문에 몇 번 나오나", "처음 나오는 위치", "나오는 모든 위치" — 패턴 질의가 **많고** 본문이 하나
- "두 문자열(또는 여러 문자열)의 가장 긴 공통 부분 문자열"
- "서로 다른 부분 문자열을 사전순으로 놓았을 때 `k`번째"
- "길이 `i`인 부분 문자열의 최대 출현 횟수" (모든 `i`에 대해)
- "가장 긴 반복 부분 문자열", "알파벳 위의 가장 짧은 **부분 문자열이 아닌** 문자열"
- 접미사 배열 + LCP([접미사 배열](../../../lv3-advanced/05-strings-advanced/suffix-array-lcp/))로도 풀리는 문제가 많지만, 자동자는 **온라인**이고 출현 횟수·위치를 트리 위의 계산으로 푸는 것이 자연스럽다
- 본문 하나에서 패턴 **여러 개**를 한꺼번에 찾으면 [아호-코라식](../../../lv3-advanced/05-strings-advanced/aho-corasick/)이 맞다 (방향이 반대)

## 2. 핵심 아이디어

**끝 위치 집합(endpos)**: 부분 문자열 `t`에 대해 `endpos(t)` = `t`가 `s`에서 끝나는 위치들의 집합. `endpos`가 같은 부분 문자열들을 한 묶음(**상태**)으로 보면, 한 묶음의 문자열들은 서로 접미사 관계이고 **길이가 연속**이다: 가장 긴 것의 길이를 `len[v]`, 가장 짧은 것보다 한 글자 더 짧은 문자열이 속한 묶음을 `link[v]`라 하면 상태 `v`의 문자열은 길이 `len[link[v]] + 1 .. len[v]` 전부다. 링크들은 빈 문자열(루트)을 뿌리로 하는 **접미사 링크 트리**를 이룬다. 글자 `c`를 붙이는 간선 `next[v][c]`는 "`v`의 문자열 뒤에 `c`를 붙인 문자열이 속한 상태"로 간다.

**글자를 붙이기 (`extend`)**: 새 글자 `c`를 붙이면 새 접두사가 생기고, 그 접두사의 모든 접미사가 `c`로 끝난다.

1. 새 상태 `cur`를 만든다 (`len[cur] = len[last] + 1`).
2. `last`에서 접미사 링크를 따라 올라가며 `c`로 가는 간선이 **없는** 상태 `p`마다 `next[p][c] = cur`를 단다.
3. 올라가다 `p = -1`이면 `link[cur] = 0` (루트).
4. 아니면 처음으로 `c` 간선이 있는 `p`를 만났다. `q = next[p][c]`.
   - `len[p] + 1 == len[q]`: `q`의 모든 문자열이 `p`의 문자열 뒤에 `c`를 붙인 것 → `link[cur] = q`.
   - 아니면 `q`에 `p + c`보다 긴 문자열이 섞여 있다. 새 글자가 붙으면서 `q` 안의 짧은 문자열과 긴 문자열의 `endpos`가 달라지므로 **`q`를 복제(clone)** 한다: `len[clone] = len[p] + 1`, `next[clone] = next[q]`의 복사, `link[clone] = link[q]`. `p`에서 올라가며 `q`를 가리키던 간선을 `clone`으로 돌리고, `link[q] = link[cur] = clone`.
5. `last = cur`.

전체 `O(n)`인 이유: 2번의 반복이 `last`의 접미사 링크 사슬을 따라가고, 3~4번의 복제 때마다 사슬이 짧아지는 분할 상환 논증이 성립한다. 상태는 글자마다 1개 + 복제 ≤ 1개라서 최대 `2n − 1`개, 간선은 `3n − 4`개 이하.

**서로 다른 부분 문자열의 수** = 상태마다 `len[v] − len[link[v]]`의 합. 한 글자를 붙일 때 `cur` 하나만 이 값을 더한다 (새로 생긴 접두사의 접미사 중 이전에 없던 것의 수).

**출현 횟수**: 복제가 아닌 상태(= 접두사에 대응)는 끝 위치가 하나이므로 `cnt = 1`, 복제 상태는 `0`. 링크 트리에서 **자식 상태의 `cnt`를 부모에 더하면** `cnt[v]` = `v`의 문자열이 나오는 횟수. `len` 내림차순으로 처리하면 자식이 항상 부모보다 먼저 나온다.

**사전순 `k`번째**: `paths[v] = 1 + Σ paths[next]` (상태 `v`에서 시작하는 서로 다른 경로의 수, 빈 경로 포함). 루트에서 글자를 사전순으로 훑으며 `k`와 비교해 내려간다.

**공통 부분 문자열**: 첫 문자열의 자동자 위에서 다른 문자열을 한 글자씩 읽으며 현재 상태와 맞춘 길이를 유지한다. 맞는 간선이 없으면 링크로 올라가 길이를 `len[v]`로 줄인다. 여러 문자열이면 문자열마다 상태별 최대 맞춘 길이를 구해 링크를 따라 위로 전파한 뒤, 상태별로 문자열 전체의 최솟값을 취한다.

## 3. 손으로 따라가기

`s = "abcbc"`. 상태는 `(번호: len, link, 간선)`.

| 붙인 글자 | 하는 일 | 결과 |
|---|---|---|
| `a` | 새 상태 1. `0 --a--> 1`, `link[1] = 0` | 서로 다른 부분 문자열 1 |
| `b` | 새 상태 2. 루트에서 올라가며 `1 --b--> 2`, `0 --b--> 2`. `link[2] = 0` | 3 |
| `c` | 새 상태 3. `2 --c--> 3`, `0 --c--> 3`. `link[3] = 0` | 6 |
| `b` | 새 상태 4(`len 4`). `3 --b--> 4`. `p = 0`에서 `b`가 이미 있음: `q = 2`, `len[0] + 1 = 1 ≠ len[2] = 2` → **복제** 상태 5 (`len 1`, `next = {c: 3}`, `link = 0`). `0 --b--> 5`로 돌림. `link[2] = link[4] = 5` | 9 |
| `c` | 새 상태 6(`len 5`). `4 --c--> 6`. `p = 5`에서 `c`가 이미 있음: `q = 3`, `len[5] + 1 = 2 ≠ len[3] = 3` → **복제** 상태 7 (`len 2`, `next = {b: 4}`, `link = 0`). `5 --c--> 7`, `0 --c--> 7`로 돌림. `link[3] = link[6] = 7` | 12 |

최종 자동자: 상태 8개 (`2n − 1 = 9` 이하), 간선 9개.

| 상태 | `len` | `link` | 간선 | 담긴 문자열 | 출현 횟수 |
|---|---|---|---|---|---|
| 0 | 0 | - | `a→1, b→5, c→7` | (빈 문자열) | - |
| 1 | 1 | 0 | `b→2` | a | 1 |
| 2 | 2 | 5 | `c→3` | ab | 1 |
| 3 | 3 | 7 | `b→4` | abc | 1 |
| 4 | 4 | 5 | `c→6` | abcb, bcb, cb | 1 |
| 5 (복제) | 1 | 0 | `c→7` | b | 2 |
| 6 | 5 | 7 | - | abcbc, bcbc, cbc | 1 |
| 7 (복제) | 2 | 0 | `b→4` | bc, c | 2 |

- **서로 다른 부분 문자열**: 상태 1~7의 `len − len[link]`는 `1, 1, 1, 3, 1, 3, 2` (담긴 문자열 개수와 같다), 합 **12**. 정의대로 세어도 `a, ab, abc, abcb, abcbc, b, bc, bcb, bcbc, c, cb, cbc` 12개.
- **출현 횟수**: 복제가 아닌 상태 1, 2, 3, 4, 6은 `cnt = 1`. 링크를 따라 올리면: 6→7 (`+1`), 4→5, 3→7, 2→5 이므로 `cnt[5] = 2` (b가 2번), `cnt[7] = 2` (bc, c가 각 2번).
- **질의**: `"bc"`는 `0 --b--> 5 --c--> 7`로 상태 7에 도착, `cnt = 2`. 모든 시작 위치는 링크 트리에서 상태 7의 서브트리(자식 3, 6)에 있는 복제가 아닌 상태의 끝 위치 `2`, `4`에서 `2 − 2 + 1 = 1`, `4 − 2 + 1 = 3`, 즉 `[1, 3]`. 처음 나오는 위치는 상태 7의 `first_end = 2`에서 `1`.
- **사전순 `k`번째**: `a, ab, abc, abcb, abcbc, b, bc, bcb, bcbc, c, cb, cbc`.
- **최장 공통 부분 문자열** (`"abcbc"` vs `"xbcby"`): `bcb`. 가장 짧은 부분 문자열이 아닌 문자열(알파벳 `abc`): `aa`.

## 4. 구현

전체 코드는 [solution.py](solution.py)에 있습니다.

```python
def extend(self, ch):
    cur = self._new_state(self.length[self.last] + 1, 0, {}, self.size, False)
    p = self.last
    while p != -1 and ch not in self.next[p]:
        self.next[p][ch] = cur
        p = self.link[p]
    if p == -1:
        self.link[cur] = 0
    else:
        q = self.next[p][ch]
        if self.length[p] + 1 == self.length[q]:
            self.link[cur] = q
        else:
            clone = self._new_state(self.length[p] + 1, self.link[q], dict(self.next[q]), self.first_end[q], True)
            while p != -1 and self.next[p].get(ch) == q:       # q 를 가리키던 간선을 clone 으로
                self.next[p][ch] = clone
                p = self.link[p]
            self.link[q] = self.link[cur] = clone
    self.last = cur
    self.size += 1
    self.distinct += self.length[cur] - self.length[self.link[cur]]
```

- `SuffixAutomaton(text)` (임의의 문자 시퀀스, 정수 리스트도 됨): `extend`, `contains`, `count_occurrences`, `first_occurrence`, `occurrence_positions`, `longest_repeated_substring_length`, `kth_distinct_substring`, `longest_common_substring_with(other)`, `shortest_absent_string(alphabet)`, `distinct`(서로 다른 부분 문자열 수), `state_count`, `transition_count()`.
- `longest_common_substring_of_many(strings)`: 여러 문자열의 최장 공통 부분 문자열.
- 간선은 상태마다 딕셔너리라 알파벳이 커도 되고 정수 리스트도 됩니다. 출현 횟수와 `len` 순서 같은 계산 결과는 캐시하고 `extend` 때 무효화합니다.
- 직접 실행하면 Library Checker "Number of Substrings" 형식 — 문자열 하나 — 를 받아 서로 다른 (비어 있지 않은) 부분 문자열의 수를 출력합니다.

## 5. 복잡도와 입력 크기 가이드

- 만들기 `O(n)` (알파벳 크기가 상수일 때, 딕셔너리 간선이면 기대 `O(n)`). 상태 `≤ 2n − 1`, 간선 `≤ 3n − 4`. 패턴 질의 `O(|패턴|)`. ([복잡도 치트시트](../../../docs/complexity-cheatsheet.md))
- 이 환경에서 측정한 값입니다.

| 입력 | 만들기 | 상태 | 간선 |
|---|---|---|---|
| 무작위 `ab`, `n = 10⁵` | 0.29초 | 199,967 | 275,282 |
| 무작위 소문자 26자, `n = 10⁵` | 0.24초 | 127,358 | 226,955 |
| 무작위 `ab`, `n = 2·10⁵` | 0.66초 | 399,966 | 550,956 |
| 무작위 소문자 26자, `n = 2·10⁵` | 0.58초 | 251,692 | 450,526 |
| `"a" × 2·10⁵` | 0.18초 | 200,001 | 200,000 |
| `"ab" × 10⁵` | 0.26초 | 200,001 | 200,001 |

- 무작위 `ab`는 상태 수가 `2n` 가까이 나옵니다 (복제가 많다). 이 환경에서 서로 다른 부분 문자열 수는 `n = 10⁵`에서 4,998,499,060으로 파이썬 정수가 그대로 담습니다.
- 질의 시간(`n = 10⁵`, 알파벳 `abcd`): `count_occurrences` `10⁴`번 0.10초(출현 횟수는 처음 한 번만 계산해 캐시), `kth_distinct_substring` 한 번 0.17초(`O(상태 수)`), 무작위 두 문자열의 최장 공통 부분 문자열 0.12초, 길이 `10⁵` 문자열 3개의 최장 공통 부분 문자열 0.82초.
- 메모리: 상태마다 딕셔너리 하나라 `n = 10⁶`이면 파이썬에서 무거울 수 있습니다. 알파벳이 작으면 리스트 배열(`next[v*26 + c]`)로 바꾸면 줄어듭니다.

## 6. 자주 하는 실수

- **복제할 때 간선을 복사하지 않음**: `next[clone]`은 `next[q]`의 *복사본* 이어야 합니다 (같은 딕셔너리를 공유하면 이후 한쪽의 수정이 다른 쪽을 망칩니다).
- **간선 돌리기를 빼먹음**: 복제 뒤에 `p`에서 올라가며 `q`를 가리키는 간선을 `clone`으로 바꿔야 합니다. 조건은 "간선이 *`q`를 가리키는 동안*" 입니다. `next[p].get(c) is not None`처럼 느슨하게 쓰면 다른 상태로 가는 간선까지 덮어씁니다.
- **링크 연결 순서**: `link[q] = link[cur] = clone`을 둘 다. 하나만 하면 사슬이 끊깁니다.
- **복제 상태의 `cnt`를 1로 시작**: 복제는 접두사에 대응하지 않으므로 `cnt = 0`으로 시작합니다. 아니면 출현 횟수가 부풀려집니다.
- **`cnt` 전파 순서**: 자식(더 긴 `len`)에서 부모로 `len` 내림차순으로. 상태 번호 순서로 전파하면 틀립니다 (복제가 나중 번호이면서 더 짧은 `len`을 가질 수 있습니다).
- **루트의 `cnt`를 세지 않기**: 빈 문자열은 모든 위치에 나옵니다 (`n + 1`번). 이 구현은 `count_occurrences("")`를 `size + 1`로 따로 처리합니다.
- **처음 나타나는 위치**: 복제는 원본 `q`의 `first_end`를 물려받아야 합니다. `first_end[v] − |패턴| + 1`이 시작 위치.
- **사전순 `k`번째에서 빈 문자열**: `paths[v]`는 빈 경로를 포함하므로, 한 글자를 고를 때마다 `k`에서 1을 빼서 "지금까지 만든 문자열 자체"를 소비해야 합니다.
- **여러 문자열의 공통 부분 문자열**: 문자열마다 맞춘 길이를 링크를 따라 위로 전파해야 합니다 (자식에서 맞으면 부모의 문자열 전체가 맞음). 전파를 빼면 짧은 공통 부분 문자열을 놓칩니다.
- **글자 사이에 구분자 없이 이어 붙임**: 두 문자열을 이어 한 자동자로 만들면 경계를 가로지르는 부분 문자열이 섞입니다. 하나의 자동자 + 다른 문자열 읽기로 풀거나, 구분자를 끼우세요.
- **같은 객체를 여러 문자열에 재사용**: 새 문자열은 새 자동자로 (또는 `last`를 루트로 되돌리는 일반화 자동자로).

## 7. 변형과 응용

- **일반화 접미사 자동자(트라이 위의 자동자)**: 여러 문자열을 한 자동자에 넣을 때 문자열마다 `last = 0`으로 시작하되, 이미 있는 전이를 만나면 새 상태를 만들지 않도록 `extend`를 조금 고칩니다. 여러 문자열의 모든 부분 문자열을 다룰 때.
- **접미사 트리**: *뒤집은 문자열* 의 접미사 자동자의 링크 트리가 원래 문자열의 접미사 트리입니다. 접미사 트리를 직접 만드는 대신 쓰는 경우가 많습니다.
- **오프라인 위치 질의**: 링크 트리에서 서브트리에 속한 끝 위치의 집합 — 병합 가능한 구간 트리나 작은 쪽을 큰 쪽에 합치기로 "구간 `[l, r]` 안에 시작하는 출현이 있는가" 같은 질의를 처리합니다.
- **길이별 최대 출현 횟수**: `best[len[v]] = max(cnt[v])`를 구한 뒤 길이를 줄여 가며 최댓값을 아래로 전파 (SPOJ NSUBSTR).
- **가중치 있는 문자열**: 상태마다 값을 가지고 링크 트리 위의 DP — 문자열의 길이 × 출현 횟수의 최댓값(`len[v] × cnt[v]`) 등.
- **접미사 배열과의 선택**: 접미사 배열은 사전순 순서와 `LCP`가 필요한 문제(`k`번째 접미사, 사전순 비교)에, 접미사 자동자는 온라인이거나 출현 횟수·위치를 트리 위에서 계산하는 문제에 맞습니다.
- **회문 트리(eertree)**: 회문 부분 문자열에 특화된 비슷한 구조(이 저장소에는 다루지 않습니다).
