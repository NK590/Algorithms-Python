# 에일리언 트릭 (Aliens trick, WQS 이분 탐색)

> **한 줄 요약**: "**정확히 `k`개**를 고르는" DP가 `O(nk)`로 느릴 때, 값이 `k`에 대해 **볼록/오목**이면 **개수 제한을 없애고 항목 하나당 벌점 `λ`를 매긴** 쉬운 문제를 `λ`에 대해 이분 탐색한다. 벌점을 올리면 최적해의 개수가 줄어드는 단조성 덕분에 정확히 `k`개가 되는 `λ`를 찾고, 그 `λ`에서 `F(k) = (완화 문제의 값) + λ·k`로 원래 답을 복원한다.

## 1. 언제 쓰나 (문제 신호)

- "**정확히 `k`개**(구간, 간선, 그룹, 물건)를 골라 합을 최대/최소로" 인데 `n, k`가 `10⁴~10⁵`라 `O(nk)` DP가 안 된다
- `k`개를 골랐을 때의 최적값 `F(k)`가 **볼록(최소화) 또는 오목(최대화)**: 개수가 늘수록 추가로 얻는 이득이 줄어든다 (한계 효용 체감)
- `k`를 제한하지 않은 "최소 비용 / 최대 이득" 버전은 `O(n)` 또는 `O(n log n)`에 풀린다 (고르는 개수에 벌점을 단 형태로)
- 전형적인 경우: `k`개의 서로 겹치지 않는 구간의 합, 수열을 `k`개 구간으로 나누기(구간 비용 `C(l, r)`이 사각 부등식을 만족), `k`개의 간선으로 이루어진 최소 가중치 구조, IOI 2016 *Aliens*
- 볼록성이 **안 되는** 경우: 개수가 늘수록 이득이 오히려 커지기도 하는 문제 — 이때 이 기법은 틀린 답을 낸다 (아래 확인법)
- 볼록성이 성립하는지 모르겠다면 작은 입력에서 모든 `k`의 `F(k)`를 느린 DP로 구해 2차 차분을 확인한다 (`convexity_violations`)

## 2. 핵심 아이디어

**벌점 `λ`를 매기기**: 최대화 문제 `F(k)`(오목)를 생각하자. 항목 하나당 `λ`를 빼는 완화 문제를 정의한다.

```
h(λ) = max over c ( F(c) − λ·c )          (개수 c 제한 없음)
c(λ) = 그 최댓값을 만드는 c  (여러 개면 가장 큰 것)
```

`λ`가 커질수록 개수가 손해라 `c(λ)`는 줄어든다 (**단조**). `F`가 오목이면 `F(c) − λc`의 최대는 "기울기 `F(c+1) − F(c)`가 `λ`를 처음으로 밑도는 곳" 이다. 즉 `λ`는 `F`의 **접선의 기울기**이다.

**원래 답 복원**: 개수가 `k` 이상인 **가장 큰** `λ`를 이분 탐색으로 찾는다. 그 `λ`에서 `k`는 최적 개수 구간 `[c_min(λ), c_max(λ)]` 안에 있으므로 (`c_max(λ) ≥ k`이고, `λ`가 한 칸 더 크면 `c_max < k`), `h(λ) = F(k) − λk` → **`F(k) = h(λ) + λ·k`**. `F`가 정수값이면 기울기도 정수이므로 정수 `λ`만 탐색하면 된다.

**동점 처리가 가장 중요**: 같은 `λ`에서 개수가 다른 최적해가 여럿일 수 있다 (예: 기울기가 `λ`와 같은 구간). 완화 문제를 풀 때 **최적값이 같으면 개수가 많은 쪽**을 고르도록 DP를 짠다. 그래야 "개수가 `k` 이상인 가장 큰 `λ`" 라는 이분 탐색의 조건이 일관된다 (이 파일의 모든 완화 DP가 `(값, 개수)` 쌍을 사전순으로 비교하거나 값에 큰 수를 곱하고 개수를 빼는 방법으로 이를 지킨다).

**벌점이 있는 완화 문제 짜기**: 원래 DP에서 "`k`번째로 고르는 항목" 에 대한 차원을 없애고, 항목을 새로 고를 때마다 `−λ`(최대화) 또는 `+λ`(최소화)를 더한다. 상태는 보통 `(값, 개수)` 쌍 하나.

**볼록성 확인**: 느린 DP로 `F(1), F(2), …`를 구해 `F(c−1) + F(c+1) ≤ 2F(c)`(오목)가 모든 `c`에서 성립하는지 본다. 증명이 어려운 문제는 이렇게 실험으로 확인하고, 안전하게는 최소 비용 흐름의 볼록성(유량에 대한 최소 비용은 볼록)이나 모노이드 구조로 정당화한다.

## 3. 손으로 따라가기

수열 `a = [5, −3, 4, −6, 2, 7, −1, 3]`에서 **서로 인접하지 않은** `k`개의 연속 구간의 합의 최댓값 `F(k)`:

| `k` | `F(k)` | 한 가지 최적 선택 |
|---|---|---|
| 1 | 11 | 전체 `[5, −3, 4, −6, 2, 7, −1, 3]` |
| 2 | 17 | `[5, −3, 4]` + `[2, 7, −1, 3]` |
| 3 | 20 | `[5]` + `[4]` + `[2, 7, −1, 3]` |
| 4 | 21 | `[5]` + `[4]` + `[2, 7]` + `[3]` |

기울기 `F(k+1) − F(k)`: `6, 3, 1` — 줄어든다 (오목). 이제 `k = 3`을 이분 탐색으로 구한다. 벌점 `λ`마다 `max_c (F(c) − λc)`와 그때의 최대 개수:

| `λ` | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|---|
| 값 `h(λ)` | 21 | 17 | 14 | 11 | 9 | 7 | 5 | 4 | 3 |
| 개수 `c(λ)` | 4 | 4 | 3 | 3 | 2 | 2 | 2 | 1 | 1 |

- `λ = 3`에서 `F(2) − 3·2 = 11`과 `F(3) − 3·3 = 11`이 **동점**이다 (기울기 `F(3) − F(2) = 3`). 개수가 많은 쪽을 고르므로 `c(3) = 3`.
- 개수 `≥ 3`인 가장 큰 `λ`는 3 (`λ = 4`에서는 개수 2).
- `F(3) = h(3) + 3·3 = 11 + 9 = 20`. ✓

**이분 탐색 과정** (탐색 범위 `[−63, 63]`): `mid = 0`: 개수 4 ≥ 3 → `lo = 0`; `mid = 32`: 개수 0 → `hi = 31`; `16`: 0 → `hi = 15`; `8`: 1 → `hi = 7`; `4`: 2 → `hi = 3`; `2`: 3 ≥ 3 → `lo = 2`; `3`: 3 ≥ 3 → `lo = 3`. 끝, `λ = 3`. 이분 탐색 루프에서 완화 문제를 7번 풀었다 (`O(n)`씩).

### 구간 나누기: 제곱합 최소화

`b = [3, 1, 4, 1, 5, 9, 2, 6]`을 `k`개의 연속 구간으로 나눠 (구간 합)²의 합을 최소화. `F(k)`는 `k = 1..8`에서 `961, 485, 341, 245, 211, 187, 179, 173` (볼록: 기울기 `−476, −144, −96, −34, −24, −8, −6`이 증가). 에일리언 트릭 + [볼록 껍질 트릭](../../../lv3-advanced/07-dp-advanced/convex-hull-trick/)으로 `λ`마다 `O(n)`에 완화 문제를 풀어 같은 값을 얻는다.

## 4. 구현

전체 코드는 [solution.py](solution.py)에 있습니다.

```python
def aliens_trick(evaluate, k, low, high, maximize=True):
    # evaluate(lam) -> (완화 문제의 최적값, 최적해들 중 가장 많은 개수)
    if evaluate(low)[1] < k: raise ValueError("k 개를 고를 수 없습니다")
    lo, hi = low, high                       # 불변: 개수(lo) >= k
    while lo < hi:
        mid = (lo + hi + 1) // 2             # 가장 큰 lam 을 찾으므로 올림
        if evaluate(mid)[1] >= k: lo = mid
        else:                     hi = mid - 1
    value, _ = evaluate(lo)
    return value + lo * k if maximize else value - lo * k

def _penalized_subarrays(a, lam, allow_adjacent):      # max over c ( 합 - lam·c ), 동점이면 c 가 큰 쪽
    outside, inside = (0, 0), (NEG, 0)                 # (값, 개수): 직전 원소가 구간 밖 / 구간 안(열림)
    for x in a:
        start_from = max(outside, inside) if allow_adjacent else outside
        new_inside = max((inside[0] + x, inside[1]),              # 구간을 이어 간다
                         (start_from[0] + x - lam, start_from[1] + 1))   # 새 구간을 시작 (벌점 lam)
        outside, inside = max(outside, inside), new_inside
    return max(outside, inside)
```

- `aliens_trick(evaluate, k, low, high, maximize)`: 일반형. 탐색 범위 `[low, high]`는 `F`의 기울기를 모두 담는 정수 범위.
- `max_sum_k_subarrays(a, k, allow_adjacent=False)`: 겹치지 않는 `k`개 구간의 합의 최댓값. 느린 `O(nk)` DP는 `max_sum_k_subarrays_dp`.
- `partition_min_cost(n, cost, k)`: 수열을 `k`개 연속 구간으로 나눠 구간 비용의 합을 최소화 (`O(n²)` 완화 DP, 느린 `O(n²k)` DP는 `partition_min_cost_dp`).
- `partition_sum_of_squares(a, k)`: 제곱합 최소화. 완화 DP를 볼록 껍질 트릭으로 `O(n)`에. 동점 처리를 "값에 `n + 1`을 곱하고 구간마다 1을 뺀다" 로 정수 안에서 해결.
- `convexity_violations(values)`: `F`가 볼록이 아닌 위치 목록 (비어 있어야 에일리언 트릭을 쓸 수 있다).
- 직접 실행하면 BOJ 2228 "구간 나누기"와 같은 형태 — `N M`, 이어서 `N`개의 정수 — 를 받아 서로 인접하지 않는 `M`개의 구간의 합의 최댓값을 출력합니다.

## 5. 복잡도와 입력 크기 가이드

- 완화 문제를 푸는 시간 `T`에 이분 탐색 횟수 `log₂(탐색 범위)`를 곱한 `O(T log C)`. 탐색 범위가 `10⁹`~`10¹⁸`이어도 30~60번. ([복잡도 치트시트](../../../docs/complexity-cheatsheet.md))
- 이 환경에서 측정한 값입니다 (무작위 수열, 값 `±10⁶`).

| 입력 | 에일리언 트릭 | 느린 `O(nk)` DP |
|---|---|---|
| `k` 개 구간, `n = 1000`, `k = 300` | 0.013초 | 0.08초 |
| `n = 3000`, `k = 1000` | 0.042초 | 0.50초 |
| `n = 10000`, `k = 3000` | 0.082초 | (생략) |
| 제곱합 구간 나누기 `n = 2000`, `k = 50` (볼록 껍질 트릭) | 0.097초 | `O(n²k)` DP 15.3초 |
| 제곱합 구간 나누기 `n = 50000`, `k = 200` | 3.36초 | (불가) |

- `k`가 클수록 격차가 커집니다. 느린 DP는 `n·k`에 비례하지만 에일리언 트릭은 `k`와 거의 무관합니다.

## 6. 자주 하는 실수

- **동점에서 개수 처리가 틀림**: 완화 문제가 동점일 때 개수가 *적은* 쪽을 돌려주면 중간 `k`에서 틀린 답이 나옵니다. 위의 표에서 `λ = 3`이 대표적입니다. [test_solution.py](test_solution.py)가 일부러 반대로 구현한 평가기로 틀린 값(`F(2) = 1`)이 나오는 것을 보여 줍니다.
- **`F(k) = 값 + λ·k`를 `값`만 반환**: 완화 문제의 최적값은 벌점이 이미 반영된 값입니다. 원래 답으로 되돌리려면 최대화면 `+ λk`, 최소화면 `− λk`.
- **볼록성(오목성) 가정 미확인**: 안 되면 조용히 틀립니다. 작은 입력에서 모든 `k`의 `F(k)`를 구해 2차 차분을 확인하세요.
- **이분 탐색 방향**: "개수 `≥ k`인 가장 큰 `λ`" 이므로 `mid`를 올림(`(lo + hi + 1) // 2`)으로 잡고 성공하면 `lo = mid`. 내림을 쓰면 무한 루프입니다.
- **탐색 범위가 좁음**: `[low, high]`가 `F`의 모든 기울기를 포함해야 합니다. `low`에서 개수가 `k` 미만이면 `k`개를 고를 수 없는 입력이거나 범위가 좁은 것입니다.
- **정수 아닌 `λ`**: 값이 정수이면 기울기도 정수라 정수 `λ`로 충분합니다. 실수 `F`에는 실수 이분 탐색과 오차 처리가 필요합니다.
- **`k`가 가능한 최대 개수를 넘음**: 인접 금지 구간은 최대 `⌈n/2⌉`개입니다. 이 구현은 오류를 냅니다.
- **완화 DP에서 `(값, 개수)`의 비교 순서**: 값을 먼저 비교하고 개수는 그다음. 반대면 개수만 많은 해를 고릅니다. 값에 큰 수를 곱해 한 정수로 합치는 방법이 CHT와 함께 쓸 때 편합니다.
- **볼록 껍질 트릭의 전제**: 제곱합 예제는 수열이 음이 아니어야 접두사 합이 단조라 단조 큐를 쓸 수 있습니다.

## 7. 변형과 응용

- **IOI 2016 *Aliens***: 점들을 `k`개의 정사각형으로 덮는 최소 면적. 구간 DP + 볼록 껍질 트릭 + 에일리언 트릭의 정석.
- **최소 비용 `k`개 간선**: 간선 `k`개로 이루어진 구조(예: `k`개의 비인접 간선, 최소 신장 트리에서 특정 색 간선 정확히 `k`개)의 최적값도 볼록이라 같은 방법.
- **두 개의 제약**: 서로 다른 종류의 항목을 각각 `k₁`, `k₂`개 고르는 문제는 `λ`를 두 개 쓴다 (중첩 이분 탐색, `O(T log² C)`).
- **복원(경로) 구하기**: `λ`에서 최적해는 여러 개일 수 있습니다. 개수가 `k`가 되도록 *동점인 다른 해*를 섞어야 하는 복원은 까다롭습니다 (값만 필요하면 이 방법이 가장 쉽습니다).
- **분할 정복 최적화와의 관계**: `k`개로 나누는 문제에서 `O(nk log n)`의 [분할 정복 최적화](../../../lv3-advanced/07-dp-advanced/divide-and-conquer-optimization/)보다 `k`가 큰 곳에서 이 기법이 훨씬 빠릅니다 (단, 에일리언 트릭은 `F`가 볼록이어야 함).
- **볼록 함수의 (최소·최대) 합성**: 두 볼록 함수의 *민코프스키 합*(기울기를 정렬해 합침)을 구할 때 같은 성질이 쓰입니다.
