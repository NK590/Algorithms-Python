# 키타마사 (Kitamasa) — 선형 점화식의 n 번째 항

> **한 줄 요약**: `a_n = c₁a_{n−1} + … + c_k a_{n−k}` 같은 **선형 점화식**의 `n`번째 항(`n`이 `10¹⁸`이어도)을 `O(k² log n)`에 구한다. `xⁿ`을 특성 다항식으로 나눈 **나머지 다항식**의 계수가 곧 "`a_n`을 처음 `k`개 항의 선형 결합으로 쓴 계수"라는 사실을 이용한다. 같은 일을 하는 행렬 거듭제곱(`O(k³ log n)`)보다 `k`배 빠르다.

## 1. 언제 쓰나 (문제 신호)

- "`a_n`이 이전 `k`개 항의 선형 결합이고 `n ≤ 10¹⁸`" — 피보나치, 펠 수, 트리보나치, 타일 채우기, 격자 경로 수 같은 개수 세기
- 점화식의 차수 `k`가 크다 (`k = 20 ~ 2000`): 행렬 `k × k`의 거듭제곱은 `k³`이라 느리다
- 부분합 `a₀ + … + a_n`을 구해야 한다 (점화식에 합 항을 붙여 차수 `k + 1`로)
- 같은 점화식의 항을 여러 번 묻는다: 특성 다항식은 같고 `n`만 바뀐다
- 점화식을 *모를 때* (수열의 앞부분만 있을 때)는 먼저 [베를캠프-매시](../../../lv5-master/)(Lv5)로 점화식을 찾는다
- `n`이 작으면(`≤ 10⁷`) 그냥 한 항씩 계산해도 된다 (아래 측정표: `10⁷`번에 1.3초)

## 2. 핵심 아이디어

**다항식으로 바꾸기**: 점화식 `a_i = c₁a_{i−1} + … + c_k a_{i−k}`를 만족하는 수열 `a`와 다항식 `x^i`를 짝지어, "다항식 `r(x) = Σ r_j x^j`의 값" 을 `Σ r_j a_j`로 정의하자 (선형 범함수 `L`). 그러면
`L(x^i) = a_i` 이고, 점화식은 `L(x^{i} − c₁x^{i−1} − … − c_k x^{i−k}) = 0`, 즉 **`x^{i−k}·f(x)`의 값이 0**이다 (`f(x) = x^k − c₁x^{k−1} − … − c_k` = **특성 다항식**). 따라서 `f`의 배수의 값은 항상 0이고,

```
x^n  =  q(x)·f(x) + r(x)      (r(x) = x^n mod f(x), 차수 < k)
a_n  =  L(x^n)  =  L(r(x))    =  r₀·a₀ + r₁·a₁ + … + r_{k−1}·a_{k−1}
```

`n`번째 항이 처음 `k`개 항의 선형 결합이고, 그 계수가 `x^n mod f`의 계수다.

**나머지를 빠르게**: `xⁿ mod f`는 일반 거듭제곱처럼 제곱하며 올라간다 (`x^n = (x^{n/2})²`). 곱은 `O(k²)`(차수 `< k`인 두 다항식의 곱은 차수 `< 2k − 1`), `f`로 나눈 나머지도 `O(k²)`(상위 계수부터 `x^k ≡ c₁x^{k−1} + … + c_k`로 낮춘다). `log₂ n`번 반복하니 `O(k² log n)`.

**행렬과의 관계**: 동반 행렬 `M`의 거듭제곱 `M^n`의 첫 행이 같은 계수 `(r₀, …, r_{k−1})`(순서 다름)을 준다. 행렬 곱은 `k³`, 다항식 곱+나머지는 `k²` — 같은 정보를 더 싸게 구한다. (케일리-해밀턴 정리: 행렬은 자신의 특성 다항식의 근이다.)

**보스탄-모리(Bostan–Mori)**: 같은 문제를 *생성 함수* `Σ aᵢxⁱ = P(x)/Q(x)` (`Q = 1 − c₁x − … − c_k x^k`, `P`는 차수 `< k`)의 `x^n` 계수로 본다. 분모와 분자에 `Q(−x)`를 곱하면 분모 `Q(x)Q(−x)`가 `x²`의 다항식이 되고, 분자에서 `n`의 홀짝에 맞는 차수만 남기면 **`n`이 절반으로 줄어든 같은 문제**가 된다. 코드가 더 짧고, 다항식 곱을 [NTT](../../01-number-theory/fft-ntt/)로 바꾸면 `O(k log k log n)`이 된다. 이 구현은 둘 다 제공한다.

## 3. 손으로 따라가기

### 피보나치 `F₁₀`: `x¹⁰ mod (x² − x − 1)`

`k = 2`, `c = [1, 1]`, `a₀ = 0`, `a₁ = 1`. `x² ≡ x + 1`로 낮춘다. `n = 10 = 1010₂`이므로 `x¹, x², x⁴, x⁸`을 차례로 구해 `x²`와 `x⁸`을 곱한다.

| 거듭제곱 | 계산 | `x^m mod f` (`r₀ + r₁x`) |
|---|---|---|
| `x¹` | | `0 + 1x` |
| `x²` | `x² ≡ x + 1` | `1 + 1x` |
| `x⁴` | `(1 + x)² = 1 + 2x + x² = 1 + 2x + (x + 1)` | `2 + 3x` |
| `x⁸` | `(2 + 3x)² = 4 + 12x + 9x² = 4 + 12x + 9(x + 1)` | `13 + 21x` |
| `x¹⁰` | `x² · x⁸ = (1 + x)(13 + 21x) = 13 + 34x + 21x² = 13 + 34x + 21(x + 1)` | `34 + 55x` |

`a₁₀ = 34·a₀ + 55·a₁ = 34·0 + 55·1 = 55`. ✓ (계수 `13, 21, 34, 55`가 피보나치 수로 나온다.)

### 보스탄-모리: `F₅`

`Q = 1 − x − x²`, `A = a₀ + a₁x = x`, `P = A·Q` 의 앞 `k = 2`항 `= x`. `n = 5`.

| 단계 | `n` | `P` | `Q` | 하는 일 |
|---|---|---|---|---|
| 0 | 5 | `x` | `1 − x − x²` | `Q(−x) = 1 + x − x²` |
| 1 | 5 → 2 | `P·Q(−x) = x + x² − x³`, 홀수 차수만: `x − x³` → 변수 `x²`을 `y`로 `1 − y` | `Q·Q(−x) = 1 − 3x² + x⁴` → `1 − 3y + y²` | `n`이 홀수라 홀수 차수 |
| 2 | 2 → 1 | `(1 − y)(1 + 3y + y²) = 1 + 2y − 2y² − y³`, 짝수 차수: `1 − 2z` | `(1 − 3y + y²)(1 + 3y + y²) = 1 − 7y² + y⁴` → `1 − 7z + z²` | `n`이 짝수라 짝수 차수 |
| 3 | 1 → 0 | `(1 − 2z)(1 + 7z + z²) = 1 + 5z − 13z² − 2z³`, 홀수 차수: `5 − 2w` | `1 − 47w + w²` | `n`이 홀수 |
| 끝 | 0 | `5 − 2w` | | `Q(0) = 1`이므로 답은 `P(0) = 5` |

`F₅ = 5`. ✓ `n = 5 → 2 → 1 → 0`으로 `log₂ n`번에 끝난다.

## 4. 구현

전체 코드는 [solution.py](solution.py)에 있습니다.

```python
def kitamasa(coeffs, initial, n, mod=None):
    k = len(coeffs)
    if n < k: return initial[n]
    result = [1] + [0] * (k - 1)                         # x^0
    base = [0, 1] + [0] * (k - 2)                        # x^1
    while n:
        if n & 1: result = reduce(poly_mul(result, base), coeffs)
        base = reduce(poly_mul(base, base), coeffs)
        n >>= 1
    return sum(r * a for r, a in zip(result, initial))

def reduce(poly, coeffs):                                # x^k ≡ c_1 x^{k-1} + … + c_k 로 위 차수부터 낮춘다
    for i in range(len(poly) - 1, k - 1, -1):
        for j in range(1, k + 1): poly[i - j] += poly[i] * coeffs[j - 1]
        poly[i] = 0
    return poly[:k]
```

- `kitamasa(coeffs, initial, n, mod=None)`: `coeffs = [c₁, …, c_k]`, `initial = [a₀, …, a_{k−1}]`. `mod`가 없으면 파이썬 큰 정수로 정확한 값, 있으면 나머지.
- `bostan_mori(...)`: 같은 인터페이스, 생성 함수 방식.
- `matrix_power_term(...)`: 비교용 동반 행렬 거듭제곱.
- `sum_of_prefix(coeffs, initial, n, mod)`: `a₀ + … + a_n`. 부분합 `S_i`가 차수 `k + 1`의 점화식을 만족하는 것을 이용.
- `fibonacci(n, mod)`.
- 직접 실행하면 BOJ 13976 형식 — 정수 `N`(`≤ 10¹⁸`) — 을 받아 `3 × N` 판을 `2 × 1` 타일로 채우는 방법의 수를 `10⁹ + 7`로 나눈 나머지로 출력합니다 (`N`이 홀수면 0, 짝수면 `f_k = 4f_{k−1} − f_{k−2}`, `k = N/2`).

## 5. 복잡도와 입력 크기 가이드

- 다항식 곱+나머지가 `O(k²)`, `log₂ n`번 → `O(k² log n)`. 행렬 거듭제곱은 `O(k³ log n)`. ([복잡도 치트시트](../../../docs/complexity-cheatsheet.md))
- 이 환경에서 측정한 값입니다 (`n = 10¹⁸`, 모듈러 `10⁹ + 7`, 무작위 계수).

| 차수 `k` | 키타마사 | 보스탄-모리 | 행렬 거듭제곱 |
|---|---|---|---|
| 10 | 0.002초 | 0.002초 | 0.011초 |
| 30 | 0.018초 | 0.010초 | 0.223초 |
| 60 | 0.059초 | 0.035초 | 1.871초 |
| 100 | 0.153초 | 0.092초 | - |
| 200 | 0.625초 | 0.358초 | - |

- 한 항씩 계산하는 단순한 방법은 피보나치를 `10⁷`항 구하는 데 1.34초입니다. `n ≤ 10⁷` 정도면 그것으로 충분합니다.
- `k = 2000`이면 `k² log n ≈ 2.4·10⁸`이라 파이썬에서는 느립니다. 그때는 다항식 곱을 [NTT](../../01-number-theory/fft-ntt/)로 바꾼 보스탄-모리 (`O(k log k log n)`)가 필요합니다.

## 6. 자주 하는 실수

- **계수 순서**: `coeffs[0] = c₁`은 `a_{n−1}`의 계수입니다. `initial[i] = a_i`는 `a₀`부터. 두 배열을 같은 방향으로 쓰는 실수가 흔합니다.
- **`n < k`**: 처음 `k`개 항은 그대로 `initial`에서 읽습니다 (다항식 방식은 `n ≥ k`에서 의미가 있습니다).
- **`k = 1`의 `x¹`**: 차수 `< 1`인 다항식은 상수뿐이므로 `x`는 이미 한 번 낮춰야 합니다 (`x ≡ c₁`).
- **음수 계수와 나머지**: 점화식 `a_n = 4a_{n−1} − a_{n−2}`의 `−1`은 모듈러에서 `MOD − 1`로 넣습니다 (`kitamasa([4, MOD − 1], …, MOD)`). 파이썬은 `%`가 음수를 알아서 처리하지만 계수를 `mod` 범위로 맞춰 두는 것이 안전합니다.
- **모듈러를 곱할 때마다 하지 않음**: 정수 `10⁹`끼리 곱을 `k`번 더하면 `10¹⁸·k`이지만 파이썬 정수는 오버플로가 없으므로 줄이는 시점은 자유롭습니다. C++로 옮길 때만 조심합니다.
- **상수항이 있는 점화식**: `a_n = c·a_{n−1} + d`는 동차(homogeneous)가 아닙니다. 상수 항을 "항상 1인 수열" `b_n = b_{n−1}`로 보고 차수를 하나 올려 `(a, b)`의 동차 점화식으로 만듭니다.
- **다항식 항 (`n²`)**: `a_n = a_{n−1} + n²` 같은 점화식은 `n`의 다항식 항 때문에 차수를 올려야 합니다 (`n², n, 1`을 추가 상태로).
- **점화식이 필요 이상으로 긴 경우**: 처음 `k`개 항이 점화식과 맞지 않으면 틀린 값이 나옵니다. 점화식은 `i ≥ k`에서 성립해야 합니다.
- **보스탄-모리의 분자 자르기**: `P = A·Q`를 *앞 `k`항만* 남겨야 합니다. 더 남기면 틀립니다 (뒤 항은 점화식이 대신 만들어 줍니다).

## 7. 변형과 응용

- **부분합** (`sum_of_prefix`): 차수 `k + 1`로 올려 `n`번째 항을 구하는 방식.
- **베를캠프-매시와 짝**: 수열의 앞부분만 알 때 점화식을 찾는 [베를캠프-매시](../../../lv5-master/)(Lv5)로 `c`를 구한 뒤 이 알고리즘으로 `n`번째 항을 구하는 것이 표준 조합입니다.
- **격자·그래프 위 경로 수**: 정점이 `k`개인 고정 그래프에서 길이 `n`의 경로 수는 인접 행렬 거듭제곱의 성분이고, 특성 다항식의 차수 `k`짜리 선형 점화식이 됩니다 → 키타마사로 `O(k² log n)`.
- **타일링·조합 문제**: 폭이 고정된 판의 채우기 수 (BOJ 13976).
- **확장**: 다항식 모듈러 거듭제곱 `x^n mod f(x)`는 `n`번째 항뿐 아니라 "수열의 모든 선형 함수" 를 구하는 데도 쓰입니다.
- **행렬 거듭제곱과의 선택**: `k ≤ 5` 정도이거나 "상태 전이 행렬" 이 자연스러우면 [행렬 거듭제곱](../../../lv3-advanced/07-dp-advanced/matrix-exponentiation/)이 단순하고, `k`가 커지면 키타마사가 필요합니다.
