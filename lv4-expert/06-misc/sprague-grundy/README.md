# 스프라그-그런디 정리 (Sprague–Grundy Theorem)

> **한 줄 요약**: 두 사람이 번갈아 두고 **마지막에 둘 수 없는 사람이 지는** 공정 게임에서, 각 위치에 **그런디 수**(= 다음 위치들의 그런디 수에 없는 가장 작은 음이 아닌 정수, mex)를 매기면, 독립된 여러 게임을 동시에 두는 **합** 의 그런디 수는 각 그런디 수의 **XOR**이다. 그래서 복잡한 게임은 부분 게임으로 쪼개 각자의 그런디 수를 구하고 XOR가 `0`이 아니면 선공이 이긴다는 것만 보면 된다.

## 1. 언제 쓰나 (문제 신호)

- 두 사람이 번갈아 움직이고, **두 사람이 할 수 있는 수가 같다** (공정 게임). 더 이상 움직일 수 없는 사람이 진다
- 돌 더미 여러 개, 말 여러 개, 구간 여러 개처럼 **독립된 부분 게임** 들이 있고 한 번에 한 곳에서만 움직인다 (게임의 합)
- 한 번에 가져갈 수 있는 개수가 정해진 뺄셈 게임, 더미를 둘로 쪼개는 게임 (케일스, 박스 나누기), 격자 위의 말 이동
- "선공이 이기는가", "이기는 첫 수는 무엇인가", 같은 게임을 여러 번 묻는다
- 위치 수가 커서 DP 표를 못 만들 때는 그런디 수열의 **주기성** 을 찾는 문제도 많다 (케일스는 71개의 예외 뒤 주기 12)
- **적용 안 되는 경우**: 두 사람의 수가 다른 게임(체스, 하켄부시 일부), 사이클이 있는 게임, 마지막에 두는 사람이 지는 일반 규칙(**미제르**)

## 2. 핵심 아이디어

**P-위치와 N-위치**: 위치 `P`에서 움직일 차례인 사람이 이기면 N-위치, 지면 P-위치. 더 못 움직이면 P-위치. N-위치는 "P-위치로 갈 수 있는 곳", P-위치는 "갈 수 있는 모든 곳이 N-위치".

**그런디 수**: `g(P) = mex{ g(Q) : P에서 한 수로 Q로 간다 }`. `g(P) = 0` ⟺ `P`는 P-위치. 더 못 움직이면 `g = 0`. 그런디 수 `g`인 위치는 크기 `g`의 **님 더미와 같은 역할**을 한다: `0, 1, …, g − 1`에 해당하는 위치로 모두 갈 수 있고, `g` 자신으로는 못 간다 (mex의 정의).

**정리 (스프라그-그런디)**: 독립된 게임 `G₁, …, G_m`의 합의 그런디 수는 `g(G₁) ⊕ … ⊕ g(G_m)`. 증명의 뼈대(귀납법): 합 위치에서 한 성분만 움직이므로, XOR 값 `x`인 위치에서 `x`보다 작은 모든 값으로 갈 수 있고(그런디 수의 mex 성질 + 님의 성질) `x` 자신으로는 갈 수 없다 → 합의 그런디 수가 정확히 `x`.

**님(Nim)**: 크기 `n`인 더미의 그런디 수는 `n` 자신이라 합이 `0`이면 지고(**부톤의 정리**), `0`이 아니면 이기는 수가 있다: XOR `s ≠ 0`일 때 `pile ⊕ s < pile`인 더미를 `pile ⊕ s`로 줄이면 합이 `0`이 된다.

**더미를 쪼개는 게임**: 한 더미가 두 더미로 갈라지면 갈라진 두 더미는 독립이므로 그 위치의 그런디 수는 `g(왼쪽) ⊕ g(오른쪽)`이다 (케일스: 핀을 1~2개 쓰러뜨리면 줄이 둘로 갈라진다).

**8진 게임(octal games)**: `0.d₁d₂d₃…` 코드로 "더미에서 `k`개를 가져가면 (비면 가능: 1, 하나가 남으면: 2, 둘로 갈라지면: 4)" 를 `d_k`의 비트로 표현한다. 케일스 `0.77`, 도슨의 케일스 `0.07`, 님의 변형 대부분이 들어간다.

**미제르 님**: 마지막 돌을 가져가는 사람이 지는 님은 *크기 2 이상인 더미가 하나라도 있으면* 일반 님과 같은 규칙(XOR ≠ 0이면 선공 승), *모든 더미가 0 또는 1이면* 1인 더미의 수가 짝수일 때 선공이 이긴다.

## 3. 손으로 따라가기

### 뺄셈 게임 `{1, 3, 4}`

한 번에 1, 3, 4개를 가져갈 수 있다. 그런디 수 표 (`g(n) = mex{ g(n−t) : t ∈ {1,3,4}, t ≤ n }`):

| `n` | 갈 수 있는 곳 | 그 곳들의 `g` | `g(n)` |
|---|---|---|---|
| 0 | - | - | 0 |
| 1 | 0 | {0} | 1 |
| 2 | 1 | {1} | 0 |
| 3 | 2, 0 | {0, 0} | 1 |
| 4 | 3, 1, 0 | {1, 1, 0} | 2 |
| 5 | 4, 2, 1 | {2, 0, 1} | 3 |
| 6 | 5, 3, 2 | {3, 1, 0} | 2 |
| 7 | 6, 4, 3 | {2, 2, 1} | 0 |
| 8 | 7, 5, 4 | {0, 3, 2} | 1 |

`g(0..14) = 0, 1, 0, 1, 2, 3, 2, 0, 1, 0, 1, 2, 3, 2, 0` — 주기 7로 반복된다. `g(n) = 0`인 `n = 0, 2, 7, 9, 14`가 진다 (P-위치).

**합**: 더미 `(5, 7)`을 동시에 둔다. `g(5) ⊕ g(7) = 3 ⊕ 0 = 3 ≠ 0`이므로 선공이 이긴다. 이기는 수: 그런디 수가 `3 ⊕ 3 = 0`이 되도록 더미 5를 `g = 0`인 위치로 — `5 − 3 = 2` (`g(2) = 0`). 그러면 `(2, 7)`의 XOR는 `0 ⊕ 0 = 0`. ✓

### 님 `(3, 4, 5)`

`3 ⊕ 4 ⊕ 5 = 2 ≠ 0`. 앞에서부터 `pile ⊕ 2 < pile`인 더미: `3 ⊕ 2 = 1 < 3` → 첫 더미를 `1`로. `(1, 4, 5)`의 XOR는 `1 ⊕ 4 ⊕ 5 = 0`. ✓ 이 구현의 `nim_winning_move`가 `(0, 1)`을 돌려준다.

### 케일스 (핀 1~2개, 줄이 갈라짐)

핀 `n`개의 줄에서 인접한 핀 1개 또는 2개를 쓰러뜨리면 남는 핀이 두 줄로 갈라질 수 있다 (`0.77`). `g(n)`은 "쓰러뜨리고 남은 두 줄 `(a, b)`의 `g(a) ⊕ g(b)`" 의 mex.

| `n` | 가능한 `(a, b)` (1개 / 2개 제거) | 그 `g(a) ⊕ g(b)` | `g(n)` |
|---|---|---|---|
| 1 | `(0, 0)` | {0} | 1 |
| 2 | 1개: `(0, 1)`, 2개: `(0, 0)` | {1, 0} | 2 |
| 3 | 1개: `(0, 2), (1, 1)`, 2개: `(0, 1)` | {2, 0, 1} | 3 |
| 4 | 1개: `(0, 3), (1, 2)`, 2개: `(0, 2), (1, 1)` | {3, 3, 2, 0} | 1 |
| 5 | 1개: `(0, 4), (1, 3), (2, 2)`, 2개: `(0, 3), (1, 2)` | {1, 2, 0, 3, 3} | 4 |

(`g(0..5) = 0, 1, 2, 3, 1, 4`.) 케일스의 전체 수열은 `0, 1, 2, 3, 1, 4, 3, 2, 1, 4, 2, 6, 4, 1, 2, 7, 1, 4, 3, 2, 1, …`이고 `n ≥ 71`부터 주기 12로 반복된다 (이 환경에서 계산해 확인).

## 4. 구현

전체 코드는 [solution.py](solution.py)에 있습니다.

```python
def mex(values):
    present = set(values); result = 0
    while result in present: result += 1
    return result

def grundy_subtraction(n, moves):                  # 더미 크기 0..n 의 그런디 수
    grundy = [0] * (n + 1)
    for size in range(1, n + 1):
        grundy[size] = mex(grundy[size - m] for m in moves if m <= size)
    return grundy

def nim_winning_move(piles):                       # XOR != 0 이면 (더미 번호, 새 크기)
    total = nim_sum(piles)
    for index, pile in enumerate(piles):
        if (pile ^ total) < pile: return index, pile ^ total
```

- `mex`, `grundy_subtraction(n, moves)`, `grundy_of(start, next_positions)`(일반 게임: 위치에서 다음 위치들을 돌려주는 함수, 반복형 DFS + 메모), `nim_sum`, `nim_winning_move`, `misere_nim_first_player_wins`.
- `octal_game_grundy(code, n)`, `kayles_grundy(n)`, `dawsons_kayles_grundy(n)`: 8진 게임.
- `winning_move_in_sum(components, grundy, next_positions)`: 합 게임에서 이기는 수 (성분 번호, 새 위치). 그런디 수가 `(전체 XOR) ⊕ (그 성분의 그런디 수)`인 이웃 위치를 찾는다.
- 직접 실행하면 BOJ 11868 형식 — 더미 수 `N`과 각 더미의 크기 — 을 받아 선공이 이기면 `koosaga`, 지면 `cubelover`를 출력합니다.

## 5. 복잡도와 입력 크기 가이드

- 뺄셈 게임의 표는 `O(n · |moves|)`, 8진 게임은 갈라지는 경우 때문에 `O(n²)`, 합의 승패 판정은 그런디 수를 알면 `O(성분 수)`. ([복잡도 치트시트](../../../docs/complexity-cheatsheet.md))
- 이 환경에서 측정한 값입니다.

| 작업 | 시간 |
|---|---|
| 케일스 `n = 1000` | 0.03초 |
| 케일스 `n = 3000` | 0.27초 |
| 케일스 `n = 6000` | 1.06초 (제곱으로 증가) |
| 뺄셈 게임 `n = 10⁶`, 수 4개 | 0.59초 |

- 위치 수가 `10⁹` 이상이면 표를 만들 수 없다: 작은 `n`에서 표를 만들어 **주기**(예비 주기 + 반복 주기)를 찾고 주기로 환산합니다. 케일스는 예비 71개 이후 주기 12.
- 그런디 수 자체는 `O(위치에서 갈 수 있는 곳의 수)`로 모으고 `mex`는 그 크기 이하이므로, 값이 커도 `mex` 계산이 비싸지 않습니다.

## 6. 자주 하는 실수

- **합이 아닌 XOR**: 성분들의 그런디 수를 더하지 않고 XOR합니다. `3 + 1 = 4 ≠ 3 ⊕ 1 = 2`.
- **mex를 리스트의 최솟값으로 착각**: mex는 집합에 *없는* 가장 작은 음이 아닌 정수. `{1, 2}`의 mex는 0, `{0, 2}`의 mex는 1.
- **갈라지는 더미**: 더미가 둘로 갈라지면 두 부분의 그런디 수를 **XOR** 해서 그 수가 가져다주는 값으로 mex에 넣습니다 (각각을 따로 넣으면 틀립니다).
- **독립이 아닌 성분**: 한 수가 두 성분을 동시에 건드리는 게임이면 합 규칙을 쓸 수 없습니다. 그런디 수를 정의하려면 성분이 독립이어야 합니다.
- **미제르 규칙에 그대로 적용**: 마지막에 두는 사람이 지는 게임은 그런디 수가 안 맞습니다. 님만 따로 규칙이 있습니다 (크기 2 이상 더미가 있으면 같음).
- **사이클이 있는 게임**: 같은 위치로 돌아올 수 있으면 mex가 정의되지 않습니다 (루피 게임은 별도 이론).
- **0번 위치(더 못 움직임)를 빼먹음**: `g(0) = 0`이 모든 표의 기저입니다. 더미의 크기 0에서 시작.
- **이기는 수 고르기에서 `target < g`**: 합의 XOR `s`가 0이 아니면 `g_i ⊕ s < g_i`인 성분이 반드시 있습니다. 그 성분을 그런디 수 `g_i ⊕ s`인 이웃으로 옮깁니다 (`g_i ⊕ s > g_i`면 이웃이 없을 수 있음).
- **주기성 가정**: 작은 `n`에서 주기처럼 보여도 예비 주기가 길 수 있습니다. 케일스의 71처럼. 충분히 큰 범위에서 반복 여부를 확인하세요.

## 7. 변형과 응용

- **계단 님(Staircase Nim)**: 돌을 아래 계단으로 옮기는 게임은 *홀수 번째 계단* 의 님과 같습니다.
- **그린 하켄부시(Green Hackenbush, 트리)**: 정점 `v`의 그런디 수는 자식 `c`들의 `(g(c) + 1)`의 XOR. 나무 자르기 게임.
- **Moore's Nim**: 한 번에 최대 `k`개 더미에서 가져가는 님 → 각 비트 위치에서 `1`의 개수가 `(k + 1)`의 배수인지 확인.
- **구간 게임**: 구간을 쪼개는 게임 (`[l, r]`에서 중간 구간을 지우면 양쪽이 독립). 구간 `(l, r)`마다 그런디 수를 구하는 `O(n³)` 또는 `O(n²)`.
- **비트셋 최적화**: 한 번에 가져가는 수가 많은 뺄셈 게임은 (예: 소수 개수) 비트셋으로 `mex` 후보를 한꺼번에 처리 (CF 1091H).
- **위트호프 게임**: 두 더미에서 같은 개수를 동시에 가져갈 수도 있는 게임은 합이 아니라 별도의 황금비 공식이 있습니다.
- **합이 아닌 게임**: 규칙이 다르면(partisan) 초현실수(surreal numbers) 이론이 필요합니다.
