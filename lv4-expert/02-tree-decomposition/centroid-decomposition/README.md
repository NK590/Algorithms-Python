# 센트로이드 분해 (Centroid Decomposition)

> **한 줄 요약**: 트리의 **중심 정점(센트로이드)** 을 지워 조각들로 쪼개고, 각 조각에서 같은 일을 되풀이한다. 깊이가 `log₂ n` 이하인 "센트로이드 트리" 가 생기고, **두 정점을 잇는 모든 경로는 센트로이드 트리에서 두 정점의 공통 조상 하나를 지난다.** 그래서 "경로에 관한 문제" 가 "각 센트로이드를 지나는 경로만 세는 문제" 로 바뀌어 `O(n log n)` 근처에 풀린다.

## 1. 언제 쓰나 (문제 신호)

- "트리에서 거리가 정확히 `k`인(또는 `k` 이하인) **정점 쌍의 수**" — 쌍이 `O(n²)`개라 하나씩 볼 수 없다
- "경로 위 가중치 합이 `K`인 경로 중 간선이 가장 적은 것" (IOI 2011 *Race*)
- "경로 위 글자들을 재배열해서 회문이 되는 경로의 수" 처럼 경로의 *성질* 이 두 반쪽의 **합성** 으로 판정되는 문제
- "정점을 칠하고(갱신), 어떤 정점에서 **가장 가까운 칠한 정점까지의 거리**" 를 묻는다 (CF 342E)
- "정점 사이 거리" 를 LCA 없이 `O(log n)`에 — 거리 표를 정점마다 `O(log n)`개 들고 있다
- 경로의 *값을 갱신하며* 경로를 *질의* 하는 문제라면 센트로이드가 아니라 [HLD](../heavy-light-decomposition/)가 맞다. 센트로이드 분해는 "경로의 **끝점 쌍** 에 대한 조건" 에 강하다

## 2. 핵심 아이디어

**센트로이드**: 지우면 남는 모든 조각의 크기가 `n/2` 이하가 되는 정점. 모든 트리에 하나 이상(많아야 둘) 있다.

*찾는 법*: 아무 정점에서 시작해 `n/2`보다 큰 조각(자식 서브트리)이 있으면 그쪽으로 한 칸 내려간다. 내려갈 때마다 "위쪽 조각" 은 `n - size[c]` ≤ `n/2`로 이미 작아져 있으므로, 더 내려갈 곳이 없을 때 멈춘 정점이 센트로이드다.

**센트로이드 트리**: 센트로이드 `c`를 루트로 삼고, `c`를 지운 각 조각의 센트로이드를 `c`의 자식으로 삼는다. 조각이 매번 절반 이하가 되므로 **깊이는 `⌊log₂ n⌋` 이하**. 정점 `v`는 `O(log n)`개 조각에만 들어간다 (조상 센트로이드마다 하나).

**핵심 성질**: 정점 `u`, `v`를 잇는 경로를 생각하자. 처음으로 `u`와 `v`가 서로 다른 조각으로 갈라지거나 둘 중 하나가 센트로이드가 되는 순간의 센트로이드 `c`가 센트로이드 트리에서 `u`, `v`의 가장 가까운 공통 조상이고, **경로는 `c`를 지난다.** 그래서

```
dist(u, v) = dist(u, c) + dist(c, v)      (c = 센트로이드 트리에서 u, v 의 공통 조상 중 가장 깊은 것)
```

정점마다 `O(log n)`개의 조상 센트로이드까지의 거리를 미리 `dist[v][i]`(레벨 `i`의 조상까지)로 저장해 두면 위 식을 곧바로 쓸 수 있다. 공통 조상 *아무거나* 로 합친 값도 실제 거리 이상이므로, 모든 공통 조상에 대한 **최솟값** 도 같은 답이다.

**패턴 1 — 쌍 세기**: 센트로이드 `c`를 지나는 쌍 `(u, v)` 중 `dist(u, c) + dist(c, v)` 조건을 센다. `c`의 조각 전체의 거리 목록에서 조건을 만족하는 쌍을 센 뒤, **같은 자식 조각 안의 쌍**(경로가 `c`를 지나지 않는데 합만 조건을 만족하는 가짜)을 빼면 된다. 두 포인터(정렬)나 해시로 센다.

**패턴 2 — 가장 가까운 칠한 점**: `best[c]` = "`c`의 조각 안에서 칠한 정점까지의 `c`로부터의 최소 거리". 정점 `v`를 칠할 때 `v`의 조상 센트로이드 `O(log n)`개의 `best`를 `dist[v][i]`로 갱신하고, 질의는 조상 `a`마다 `best[a] + dist[v][i]`의 최솟값. 칠하기·질의 모두 `O(log n)`.

## 3. 손으로 따라가기

### 일직선 7개 정점

정점 `0–1–2–3–4–5–6`. 센트로이드는 가운데 `3`. `3`을 지우면 `{0,1,2}`, `{4,5,6}` 두 조각, 각각의 센트로이드는 `1`, `5`. 다시 지우면 `{0}`, `{2}`, `{4}`, `{6}`.

```
센트로이드 트리:        3
                    /     \
                   1       5
                  / \     / \
                 0   2   4   6
```

`dist[v]`는 "레벨 0 조상까지, 레벨 1 조상까지, …, 자기 자신까지(0)":

| 정점 | 센트로이드 조상 (루트 → 자기) | `dist[v]` |
|---|---|---|
| 0 | 3, 1, 0 | [3, 1, 0] |
| 1 | 3, 1 | [2, 0] |
| 2 | 3, 1, 2 | [1, 1, 0] |
| 3 | 3 | [0] |
| 4 | 3, 5, 4 | [1, 1, 0] |
| 5 | 3, 5 | [2, 0] |
| 6 | 3, 5, 6 | [3, 1, 0] |

- `dist(0, 6)`: 공통 조상은 `3`뿐 → `3 + 3 = 6`. ✓
- `dist(0, 2)`: 공통 조상 `3`, `1` → `min(3 + 1, 1 + 1) = 2`. ✓ (더 깊은 공통 조상 `1`이 경로 위에 있다.)

### 거리가 `k` 이하인 쌍 세기 — 10개 정점

```
0
├─ 1 ─ 4 ─ 7
│  └─ 5
├─ 2
└─ 3 ─ 6 ─ 8
        └─ 9
```

센트로이드 트리: `0`이 루트(지우면 조각 크기 4, 1, 4 ≤ 5). `0`의 자식 `1`(조각 `{1,4,5,7}`), `2`, `6`(조각 `{3,6,8,9}`). `1`의 자식 `4`(조각 `{4,7}`), `5`. `4`의 자식 `7`. `6`의 자식 `3`, `8`, `9`.

`k = 3`으로 "거리가 3 이하인 쌍" 을 센다. 각 센트로이드에서 `(조각 전체의 쌍) − (같은 자식 조각 안의 쌍)`:

| 센트로이드 `c` | 조각 전체의 거리 (자기 포함 0) | 합이 3 이하인 쌍 | 같은 자식 조각 안의 쌍 | `c`를 지나는 쌍 |
|---|---|---|---|---|
| 0 | 0, 1, 1, 1, 2, 2, 2, 3, 3, 3 | 21 | 3 | **18** |
| 1 | 0, 1, 1, 2 | 6 | 1 | **5** |
| 4 | 0, 1 | 1 | 0 | **1** |
| 6 | 0, 1, 1, 1 | 6 | 0 | **6** |
| 나머지 (2, 3, 5, 7, 8, 9) | 0 | 0 | 0 | 0 |

합계 `18 + 5 + 1 + 6 = 30`. 정의대로 모든 쌍(45개)의 거리를 구해 세어도 30개. ✓ 같은 방식으로 거리가 *정확히* 3인 쌍은 10개, 정확히 2인 쌍은 11개.

`c = 0`의 "같은 자식 조각 안의 쌍 3" 의 정체: 조각 `{1,4,5,7}`의 거리 `[1,2,2,3]`에서 합 ≤ 3인 쌍은 `(1,2)` 두 개(정점 `1`–`4`, `1`–`5`), 조각 `{3,6,8,9}`의 `[1,2,3,3]`에서 `(1,2)` 하나(`3`–`6`). 이 쌍들은 `0`을 지나지 않는 경로인데 `dist(·,0)` 합만 맞아서 *가짜로* 들어간 것이라 빼야 합니다.

### 가장 가까운 칠한 점

위 10개 정점 트리에서 `7`을 칠한다: `7`의 조상은 `[0, 1, 4, 7]`, `dist[7] = [3, 2, 1, 0]`이므로 `best[0] = 3`, `best[1] = 2`, `best[4] = 1`, `best[7] = 0`.

- `nearest(9)`: `9`의 조상 `[0, 6, 9]`, `dist[9] = [3, 1, 0]` → `min(best[0] + 3, best[6] + 1, best[9] + 0) = min(6, ∞, ∞) = 6`. 실제로 `9–6–3–0–1–4–7`로 6칸. ✓
- 이제 `5`를 칠한다: 조상 `[0, 1, 5]`, `dist[5] = [2, 1, 0]` → `best[0] = min(3, 2) = 2`, `best[1] = min(2, 1) = 1`, `best[5] = 0`.
- `nearest(9)`: `min(2 + 3, ∞, ∞) = 5` (`9–6–3–0–1–5`). `nearest(2)`: 조상 `[0, 2]`, `dist[2] = [1, 0]` → `2 + 1 = 3` (`2–0–1–5`). ✓

## 4. 구현

전체 코드는 [solution.py](solution.py)에 있습니다.

```python
def build(n, adj):
    removed = [False] * n
    work = [(0, -1, 0)]                              # (조각 안의 아무 정점, 센트로이드 트리의 부모, 레벨)
    while work:
        start, centroid_parent, level = work.pop()
        order = bfs_order_of_piece(start)            # 지워지지 않은 정점만
        size = subtree_sizes(order)                  # 이 조각 안에서의 크기!
        c = start
        while True:                                  # n/2 보다 큰 자식 조각이 있으면 그쪽으로
            heavy = next((w for w in children_of(c) if size[w] * 2 > len(order)), None)
            if heavy is None: break
            c = heavy
        parent[c], level_of[c] = centroid_parent, level
        for each vertex v in the piece:              # c 에서 BFS 로 거리를 구해 dist[v] 에 덧붙인다
            dist[v].append(distance_from_c[v])
        removed[c] = True
        for each neighbour w of c that is not removed:
            work.append((w, c, level + 1))           # 조각마다 되풀이
```

- `CentroidDecomposition(n, edges)`: `parent`(센트로이드 트리의 부모), `level`, `dist[v]`, `group_distances[c]`(센트로이드 `c`의 조각을 자식 조각별로 나눈 거리 목록), `root`. 재귀 없이 스택으로 조각을 처리해 사슬 모양 트리에서도 깊이 문제가 없습니다. 간선 수가 `n−1`이 아니면 `ValueError`.
- `ancestors(v)`, `distance(u, v)`: 센트로이드 조상 목록과 거리 (공통 조상 전체의 최솟값).
- `count_paths_at_most(k)`: 센트로이드마다 조각 전체의 쌍 − 같은 자식 조각 안의 쌍. 두 포인터라 정렬이 필요 → `O(n log² n)`.
- `count_paths_with_length(k)`: 자식 조각을 하나씩 처리하면서 지금까지 본 거리의 `Counter`에서 `k − d`를 조회 → `O(n log n)`.
- `NearestMarked(decomposition)`: `mark(v)`, `nearest(v)` (칠한 정점이 없으면 무한대).
- 직접 실행하면 CF 342E 형식 — 정점 `N`, 질의 `M`, 간선, 질의 `1 v`(빨강으로 칠하기), `2 v`(가장 가까운 빨간 정점까지 거리), 정점 1은 처음부터 빨강 — 을 처리합니다.

## 5. 복잡도와 입력 크기 가이드

- 분해 `O(n log n)` (각 정점이 `O(log n)`개 조각에 들어가고 조각마다 BFS 한 번). 공간 `O(n log n)` (정점당 `dist` 목록). 쌍 세기는 정렬이 들어가면 `O(n log² n)`. ([복잡도 치트시트](../../../docs/complexity-cheatsheet.md))
- 이 환경에서 측정한 값입니다.

| 작업 | 시간 |
|---|---|
| 무작위 트리 `n = 2·10⁵` 분해 (`dist` 항목 193만 개) | 3.96초 |
| 사슬 `n = 2·10⁵` 분해 (센트로이드 트리 깊이 17) | 3.8초 |
| `NearestMarked` 칠하기·질의 합쳐서 `10⁵`번 (분해 후) | 0.32초 |
| 무작위 트리 `n = 10⁵`에서 `count_paths_at_most(10)` (답 69,229,917) | 0.27초 |
| 같은 트리에서 `count_paths_with_length(10)` (답 29,727,898) | 0.34초 |

- 분해 자체가 파이썬에서 가장 무겁습니다 (`n = 2·10⁵`에 약 4초). 질의가 많은 문제는 분해를 한 번만 하고 `dist`를 재사용하세요.
- 센트로이드 트리의 깊이는 `⌊log₂ n⌋` 이하이고 실제로 거기까지 갑니다: 완전 이진 트리와 사슬 모두 `n = 131071`에서 16, 사슬 `n = 2·10⁵`에서 17.

## 6. 자주 하는 실수

- **같은 자식 조각 안의 쌍을 빼지 않음**: 센트로이드를 지나지 않는 경로가 거리 합만으로 조건을 통과해 *가짜로* 들어옵니다. "전체 − 자식별" 또는 "자식 조각을 하나씩 처리하며 이전 조각들과만 쌍을 짓기" 중 하나를 꼭 쓰세요.
- **센트로이드 자신을 빼먹음**: `c`도 거리 `0`인 하나의 끝점입니다. 거리 목록에 `0`을 넣지 않으면 `c`가 끝점인 경로를 놓칩니다.
- **크기를 조각 안이 아니라 원래 루트 기준으로 계산**: 크기는 *지금 조각 안* 에서, 이미 지워진 정점을 건너뛰고 다시 구해야 합니다.
- **지운 정점을 건너가는 탐색**: 다음 조각을 처리할 때 `removed`를 확인하지 않으면 이미 처리한 센트로이드를 지나 조각이 합쳐집니다.
- **`dist[v]`의 인덱스와 레벨이 어긋남**: `dist[v][i]`는 "레벨 `i`의 센트로이드 조상까지의 거리". 조상 목록과 길이가 같아야 합니다 (자기 자신 포함). 분해 순서에 따라 `append`로 자연스럽게 맞춰지지만 직접 고칠 때 깨지기 쉽습니다.
- **칠한 것을 되돌릴 수 없는 `min`**: `NearestMarked`의 `best[c] = min(…)`은 *칠하기만* 되고 *지우기* 는 안 됩니다. 지우는 연산이 있으면 센트로이드마다 힙(지연 삭제) 또는 다중집합이 필요합니다.
- **재귀 DFS**: 사슬 모양 트리에서 파이썬 재귀 한도에 걸립니다. 반복문 BFS/스택으로 쓰세요.
- **쌍의 순서**: "순서 없는 쌍" 인지 "순서 있는 쌍" 인지 문제마다 다릅니다 (두 배 차이).
- **두 포인터의 조건**: `ordered[low] + ordered[high] <= k`이면 `high − low`개의 쌍을 한꺼번에 더한 뒤 `low`를 올립니다. 등호를 빼먹거나 같은 원소끼리의 쌍(`low == high`)을 세면 틀립니다.

## 7. 변형과 응용

- **간선 가중치**: 거리를 가중치 합으로 바꾸고, 쌍 세기는 정렬 + 두 포인터 그대로. 정확히 `K`를 구하는 문제는 "합이 `K − d`인 이전 경로 중 *간선 수가 최소* 인 값" 을 배열이나 해시로 유지 (Race).
- **BIT와 함께**: "`a ≤ x` 이고 `b ≥ y`" 같은 두 조건의 쌍은 센트로이드마다 정렬 + 펜윅 트리로 `O(n log² n)`.
- **회문 경로 / 비트마스크**: 경로의 글자 홀짝을 비트마스크로 두고, 센트로이드마다 마스크별 개수를 세면 "두 반쪽의 마스크가 같거나 한 비트만 다른 쌍" 을 센다.
- **동적 갱신**: 칠하기·지우기, 정점 가중치 변경은 센트로이드 조상 `O(log n)`개에 통계(개수·합)를 저장하고 갱신합니다. "자식 센트로이드 쪽 기여를 따로 저장해 중복을 빼는" 기법이 필요합니다.
- **센트로이드 트리의 깊이로 라벨링**: 깊이가 `log₂ n ≤ 17`이라 알파벳 26자로 "같은 글자 사이에 더 높은 글자가 있어야 한다" 같은 조건을 만족시키는 배정이 가능 (CF 321C).
- **트리의 동형 판정**: 센트로이드 하나(또는 둘)를 루트로 삼아 표준형을 만듭니다.
- **높은 차수**: 센트로이드가 간선 수에 의존하는 연산은 차수가 큰 정점에서 느려질 수 있습니다. 필요하면 정점을 이진 트리 모양으로 쪼개 차수를 3 이하로 줄이고 가중치 0 간선을 넣습니다.
- 하나의 센트로이드를 *간선* 으로 고르는 "간선 분해" 도 있지만, 정점 센트로이드로 거의 모든 문제가 풀립니다.
