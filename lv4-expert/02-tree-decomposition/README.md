# 트리 분해 (Tree Decomposition)

트리 위의 경로 문제는 "경로" 가 배열의 구간처럼 생기지 않아서 어렵습니다. 이 단원의 두 도구는 **트리를 구조적으로 쪼개서 경로를 `O(log n)`개의 다루기 쉬운 조각으로 바꿉니다.** 쪼개는 방식이 다르고, 그래서 잘하는 문제가 다릅니다.

## 한눈에 비교

| 개념 | 무엇으로 쪼개나 | 경로가 어떻게 바뀌나 | 잘하는 문제 | 시간 |
|---|---|---|---|---|
| [헤비-라이트 분할](heavy-light-decomposition/) | 서브트리가 가장 큰 자식으로 가는 간선 (사슬) | 배열 위의 `O(log n)`개 구간 | 경로·서브트리에 **갱신하며 질의** (합, 최댓값) | 질의 O(log² n) |
| [센트로이드 분해](centroid-decomposition/) | 지우면 조각이 절반 이하가 되는 정점 | `O(log n)`개 센트로이드를 지나는 경로 | **쌍 세기**, 거리가 조건을 만족하는 쌍, 가장 가까운 칠한 점 | 분해 O(n log n) |

## 문제 신호로 고르기

| 문제의 신호 | 선택 |
|---|---|
| "경로 `u–v`의 합/최댓값", 값이 바뀐다 | [헤비-라이트 분할](heavy-light-decomposition/) |
| "경로의 모든 정점에 `x`를 더하고 경로 합 / 서브트리 합" | [헤비-라이트 분할](heavy-light-decomposition/) |
| "거리가 `k`인(`k` 이하인) 정점 쌍의 수" | [센트로이드 분해](centroid-decomposition/) |
| "경로 위 가중치 합이 `K`인 경로" | [센트로이드 분해](centroid-decomposition/) |
| "정점을 칠하고 가장 가까운 칠한 정점까지 거리" | [센트로이드 분해](centroid-decomposition/) |
| 값이 고정, 경로 합만 / 갱신 없는 경로 최댓값 | 둘 다 필요 없음: 누적 합 + [LCA](../../lv3-advanced/03-graph-advanced/lca/), 이진 올리기 |
| 서브트리 연산만 | 오일러 투어(전위 번호)면 충분 |
| 간선이 추가·삭제되는 트리 | 링크-컷 트리 (Lv5) |

핵심 구분: **경로 위 값에 대한 갱신·질의 → HLD, 경로의 끝점 *쌍* 에 대한 조건 → 센트로이드.**

## 개념 사이의 관계

- 둘 다 "크기가 절반 이하인 쪽으로 가면 `log n`번" 이라는 같은 사실에서 `log`가 나옵니다. HLD는 *가벼운 자식* 으로 내려갈 때마다 서브트리 크기가 절반 이하가 되고, 센트로이드 분해는 조각이 절반 이하가 됩니다.
- HLD는 루트가 정해진 트리의 *위로 올라가는 경로* 를 구간으로 바꾸고, 센트로이드 분해는 루트와 무관하게 *모든 경로* 가 지나는 한 점(센트로이드)을 이용합니다.
- 센트로이드 트리 위의 거리 계산(`dist[v][i]`)은 [LCA](../../lv3-advanced/03-graph-advanced/lca/) 없이 두 정점 사이 거리를 `O(log n)`에 줍니다.
- HLD의 구간 트리 부분은 [구간 트리](../../lv3-advanced/01-range-query-structures/segment-tree/)·[펜윅 트리](../../lv3-advanced/01-range-query-structures/fenwick-tree/)이므로 *트리 문제를 배열 문제로 환원하는* 전형적인 사례입니다.

## 공통 원칙

- **반복문으로 쓰기**: 사슬 모양 트리(깊이 `10⁵`)에서 파이썬 재귀는 한도에 걸립니다. 두 구현 모두 스택과 BFS만 씁니다.
- **느린 기준과 비교**: 이 단원의 모든 구현은 부모를 따라 올라가는 순진한 경로 질의, 모든 쌍의 BFS 거리와 맞춰 검증했습니다. 새 변형을 만들 때도 같은 방법으로 확인하세요.
- **무엇이 `log n`인지 확인**: HLD의 `log`는 *사슬 수*, 센트로이드의 `log`는 *깊이*. 질의 비용이 거기에 구간 트리·정렬의 `log`가 곱해지는지 따져 보세요.
- **간선 가중치는 아래쪽 정점에**: 두 도구 모두 간선 값을 `(parent, child)`의 `child` 정점에 두는 변환이 자주 쓰입니다.

## 읽는 순서

2. [센트로이드 분해](centroid-decomposition/): 분할 정복을 트리에 적용해 쌍 세기
