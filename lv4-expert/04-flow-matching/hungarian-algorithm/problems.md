# 연습문제 — 헝가리안 알고리즘

쉬운 것부터 어려운 순서로 정리했습니다. **문제 지문은 옮기지 않고** 링크와 "배울 점"만 적었습니다. 난이도(solved.ac 티어)는 시간이 지나며 바뀔 수 있어서 표에 적지 않았으니 각 링크에서 확인하세요.

| # | 문제 | 유형 | 배울 점 |
|---|---|---|---|
| 1 | [Project Euler 345 - Matrix Sum](https://projecteuler.net/problem=345) | `15 × 15` 행렬에서 서로 다른 행·열의 칸 15개를 골라 합 **최대** | `maximize=True`. 비트마스크 DP(`2¹⁵`)와 결과 비교 |
| 2 | [HDU 2255 奔小康赚大钱](https://acm.hdu.edu.cn/showproblem.php?pid=2255) | 집-사람 배정, 가격의 합 최대 (클래식 KM) | 최대화, 정수 입력. 다중 테스트 케이스라 매번 새로 계산 |
| 3 | [POJ 2195 Going Home](http://poj.org/problem?id=2195) | 격자의 사람 `m`명을 집 `m`채에 배정, 이동 거리 합 최소 | 맨해튼 거리로 비용 행렬을 만든 뒤 배정. [최소 비용 흐름](../min-cost-max-flow/)으로도 풀리니 비교 |
| 4 | [Library Checker - Assignment Problem](https://judge.yosupo.jp/problem/assignment) | `N ≤ 500` 정사각 행렬 최소 비용 배정 + 배정 출력 | [solution.py](solution.py)의 `main()`이 같은 형태. 큰 입력에서 파이썬 속도 가늠 |
| 5 | [POJ 3565 Ants](http://poj.org/problem?id=3565) | 개미 `n`마리를 사과 `n`개에 짝지어 선분이 교차하지 않게 | 거리(실수)의 합이 최소인 배정은 교차하지 않는다는 성질. 실수 비용으로 헝가리안 |
| 6 | [백준 11408 열혈강호 5](https://www.acmicpc.net/problem/11408) | 일부 칸이 배정 불가인 최대 매칭 + 최소 비용 | `None` 칸 지원과 "모두 배정 불가" 처리. 이 문제는 최대 *매칭* 이라 가능한 만큼만 배정하므로 가상 열/행을 두는 변형이 필요 |

## 풀이 메모

- 1번은 헝가리안과 비트마스크 DP 두 방법으로 같은 답이 나오는지 확인하는 좋은 연습입니다 (행렬 크기 `15`면 `2¹⁵ × 15`).
- 2번과 5번처럼 "최대" 와 "실수" 비용은 이 구현이 그대로 받습니다. 5번은 부동소수라 합의 비교에 오차를 감안하세요.
- 3번은 맨해튼 거리라 비용이 정수입니다. 집과 사람을 따로 BFS 없이 좌표 차이로 계산하면 충분합니다.
- 6번은 *완전 배정이 없을 수 있어서* 직접 쓰기엔 변형이 필요합니다. "배정하지 않는 비용을 큰 값으로 둔 가상 열을 추가해 항상 완전 배정이 존재하게 만든 뒤, 가상 열에 배정된 행은 배정 안 된 것으로 센다" 가 표준 방법이고, 같은 문제를 흐름([MCMF 문제 목록](../min-cost-max-flow/problems.md)의 2번)으로 풀어 결과를 비교하세요.
- 모든 문제에서 처음엔 [test_solution.py](test_solution.py)처럼 작은 크기에서 전수 탐색(순열)과 비교해 보고, 쌍대 해(`hungarian_duals`)로 최적성을 확인하는 습관을 들이세요.
