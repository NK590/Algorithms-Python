# 최소 비용 최대 유량 (Min-Cost Max-Flow, MCMF)

> **한 줄 요약**: 간선마다 용량 `c`와 **단위당 비용** `w`가 있는 네트워크에서, 유량을 보낼 때 **총 비용이 최소**가 되게 한다. 비결은 "지금 잔여 그래프에서 **비용이 가장 싼 증가 경로**를 하나씩 찾아 흘리는 것"(연속 최단 경로, SSP). 역간선의 비용을 `−w`로 두면 이미 흘린 유량을 싸게 다시 돌리는 것도 최단 경로가 알아서 한다.

## 1. 언제 쓰나 (문제 신호)

- "작업-사람 배정, 비용(월급)의 합을 최소로, **최대한 많이** 배정" (이분 그래프 최소 비용 최대 매칭)
- "**정확히 `k`만큼** 보내는 데 드는 최소 비용", "운송·재고: 공급지에서 수요지로 보내는 비용 최소"
- "서로 겹치지 않는 경로 `k`개로 가는 최단 총 길이" (간선 용량 1 + 비용 = 길이) — 왕복 경로
- "비용·이익이 있는 선택에서 이득이 나는 동안만 보내기" — 증가 경로의 비용이 단조 증가하는 성질(볼록)을 이용해 멈출 곳을 찾는다
- 최대화 문제: 비용을 음수로 바꿔 최소화 (이득 최대)
- 완전 이분 그래프에서 **모든 행을 배정**(행렬이 꽉 찬) 하는 문제는 [헝가리안 알고리즘](../hungarian-algorithm/)이 훨씬 빠르다 (아래 측정표)
- 비용이 없는 최대 유량이면 [디닉](../../../lv3-advanced/03-graph-advanced/dinic/), 최소 컷이 필요하면 최대 유량-최소 컷 정리

## 2. 핵심 아이디어

**잔여 그래프**: 간선 `e = (u → v, 용량 c, 비용 w)`마다 역간선 `e' = (v → u, 용량 0, 비용 −w)`를 함께 둔다 (번호 `e ^ 1`). 유량 `x`를 `e`로 보내면 `e`의 남은 용량이 `x` 줄고 `e'`의 용량이 `x` 는다. `e'`로 흘리면 `e`의 유량을 취소하고 비용 `w`를 돌려받는다.

**연속 최단 경로(SSP)**: 흘릴 수 있는 동안 반복한다.
1. 잔여 그래프에서 `s → t` **비용 최단 경로**를 찾는다.
2. 그 경로의 병목 용량만큼 흘린다.

**왜 최적인가**: 유량이 최소 비용이라는 것은 **잔여 그래프에 음의 사이클이 없다**는 것과 동치다 (음의 사이클이 있으면 그 사이클로 돌려 비용을 줄일 수 있다). 처음 유량 0에서 잔여 그래프에 음의 사이클이 없으면, 최단 경로로 증가시켜도 음의 사이클이 생기지 않는다. 그래서 매 단계에서 "지금까지 흘린 양 `f`를 보내는 최소 비용 유량" 이 유지된다.

**볼록성**: 증가 경로의 단위당 비용은 **줄어들지 않는다** (싼 경로부터 쓰므로). 유량 `f`를 보내는 최소 비용 `C(f)`는 `f`에 대한 **볼록 조각 직선**이다. 그러므로 `limit`을 바꿔 가며 `C(f)`를 구하거나, "추가 한 단위의 비용이 이득보다 커질 때" 멈추는 문제를 한 번의 실행에서 풀 수 있다 (`flow_curve()`).

**다익스트라를 쓰려면 퍼텐셜(존슨)**: 역간선이 음수 비용이라 그대로는 다익스트라를 못 쓴다. 처음 한 번 벨만-포드로 `h[v]` = (`s`에서의 최단 거리)를 구하고, 이후 `비용 + h[u] − h[v]`(**줄인 비용**)를 쓰면 모든 잔여 간선에서 0 이상이다. 최단 경로를 구할 때마다 `h[v] += dist[v]`로 갱신하면 새로 생긴 역간선도 줄인 비용이 0이라 계속 0 이상이 유지된다. SPFA(큐 기반 벨만-포드)는 퍼텐셜이 필요 없지만 최악 시간이 느리다.

**모델링 요령**:
- 정점 용량 → 정점을 `in → out` 간선으로 쪼갠다.
- 이분 매칭 → `s → 왼쪽(1, 0)`, `왼쪽 → 오른쪽(1, 비용)`, `오른쪽 → t(1, 0)`.
- 여러 출발·도착 → 가상 `s`, `t`.
- 최대화 → 비용 부호 반전.

## 3. 손으로 따라가기

작업자 2명(`W0`, `W1`)과 작업 2개(`T0`, `T1`). 비용: `W0→T0 = 1`, `W0→T1 = 2`, `W1→T0 = 2`, `W1→T1 = 10`. 모든 용량 1. 최소 비용 최대 유량은?

| 단계 | 최단 경로 | 경로 비용 | 효과 |
|---|---|---|---|
| 1 | `s → W0 → T0 → t` | 1 | `W0 → T0` 배정 |
| 2 | `s → W1 → T0 → W0 → T1 → t` | `0 + 2 + (−1) + 2 + 0 = 3` | `T0`는 이미 `W0`가 차지 → 역간선 `T0 → W0`(비용 `−1`)로 `W0`의 배정을 **취소**하고 `W0`를 `T1`으로 돌린다 |

- 2단계 경로 `W1 → T0 → W0 → T1`의 비용 `2 − 1 + 2 = 3`이 `W1 → T1`(10)보다 싸다. 그래서 `W1 → T0`, `W0 → T1`.
- 결과: 유량 **2**, 총 비용 `1 + 3 = 4` (= `W0→T1(2) + W1→T0(2)`). `flow_curve()`는 `(0,0), (1,1), (2,4)` — 기울기 `1, 3`은 늘기만 한다 (볼록).
- 다른 배정 `W0→T0 + W1→T1 = 11`은 훨씬 비싸다. 처음에 싼 `W0→T0`를 골랐지만 2단계에서 되돌리는 경로가 자동으로 찾아졌다.

### 퍼텐셜 (다익스트라)

처음 벨만-포드로 `s`에서의 최단 거리를 구하면 `h[W0] = h[W1] = 0`, `h[T0] = 1`, `h[T1] = 2`, `h[t] = 1`.

- **1단계**: 줄인 비용 `w + h[u] − h[v]`는 `W0→T0`가 `1 + 0 − 1 = 0`, `W0→T1`이 `2 + 0 − 2 = 0`, `W1→T0`이 `2 + 0 − 1 = 1`, `W1→T1`이 `10 + 0 − 2 = 8`, `T0→t`가 `0 + 1 − 1 = 0`. 줄인 거리 `dist[t] = 0`이므로 실제 경로 비용은 `dist[t] + h[t] − h[s] = 0 + 1 − 0 = 1`. `h += dist`는 모두 0을 더하므로 그대로.
- 흘린 뒤 새 역간선 `T0→W0`의 줄인 비용은 `−1 + h[T0] − h[W0] = 0` — 음수가 아니다.
- **2단계**: `W1→T0`(줄인 비용 1) → 역간선 `T0→W0`(0) → `W0→T1`(0) → `T1→t`(`0 + 2 − 1 = 1`). 줄인 거리 `dist[t] = 2`, 실제 경로 비용 `2 + 1 − 0 = 3`. 퍼텐셜 덕분에 다익스트라가 음수 간선 없이 같은 답을 구한다.

## 4. 구현

전체 코드는 [solution.py](solution.py)에 있습니다.

```python
def flow(self, source, sink, limit=INF, algorithm="dijkstra"):
    potential = [0 if d == INF else d for d in self._bellman_ford(source)]   # 음의 사이클 검사 + 시작 퍼텐셜
    total_flow = total_cost = 0
    while total_flow < limit:
        found = (self._shortest_dijkstra(source, sink, potential) if algorithm == "dijkstra"
                 else self._shortest_spfa(source, sink))
        if found is None: break                      # sink 에 닿을 수 없다
        _, parent_edge = found
        push = limit - total_flow                    # 경로의 병목 용량 (limit 도 넘지 않게)
        v = sink
        while v != source:
            push = min(push, self.capacity[parent_edge[v]]); v = self.to[parent_edge[v] ^ 1]
        v = sink
        while v != source:                           # 경로를 따라 흘리고 비용을 합산
            e = parent_edge[v]
            self.capacity[e] -= push; self.capacity[e ^ 1] += push; path_cost += self.cost[e]
            v = self.to[e ^ 1]
        total_flow += push; total_cost += push * path_cost
```

- `MinCostFlow(n)`: `add_edge(u, v, capacity, cost)`(간선 번호, 역간선은 `^ 1`), `flow(source, sink, limit=∞, algorithm='dijkstra'|'spfa')` → `(보낸 양, 총 비용)`, `flow_on(edge_id)`, `flow_curve()`(마지막 호출의 `(누적 유량, 누적 최소 비용)` 점들), `augmentations`(경로별 `(단위당 비용, 양)`).
- 처음 네트워크에 음의 사이클이 있으면 `ValueError`. 음수 비용 간선 자체는 괜찮습니다.
- `assignment_by_flow(cost)`: `n × m`(`n ≤ m`) 비용 행렬의 최소 비용 배정을 흐름으로.
- 직접 실행하면 BOJ 11408 형식 — `N M`, 이어서 직원마다 `k`와 `k`개의 `(일 번호, 월급)` — 을 받아 최대로 할 수 있는 일의 수와 월급의 최소 합을 출력합니다.

## 5. 복잡도와 입력 크기 가이드

- 증가 경로 횟수는 용량이 1인 이분 매칭이면 최대 매칭 크기 `F` 이하. 경로마다 다익스트라 `O(E log V)`라 `O(F · E log V)`. SPFA는 평균은 빠르지만 최악 `O(VE)`. ([복잡도 치트시트](../../../docs/complexity-cheatsheet.md))
- 이 환경에서 측정한 값입니다.

| 입력 | 다익스트라 + 퍼텐셜 | SPFA |
|---|---|---|
| 무작위 그래프 `V = 2000`, `E = 2·10⁴`, 용량 1~30, 비용 0~100 (유량 122) | 0.62초 | 1.58초 |
| 희소 이분 그래프 `1000 × 1000`, 왼쪽 정점당 간선 10개 (유량 1000) | 5.83초 | - |
| 완전 이분 `n × n` 배정 `n = 100` / `200` / `300` (흐름) | 0.25초 / 1.95초 / 6.77초 | - |
| 같은 완전 이분 배정을 [헝가리안](../hungarian-algorithm/)으로 | 0.01초 / 0.08초 / 0.28초 | - |

- 조밀한 완전 이분 배정은 헝가리안이 **20배 넘게** 빠릅니다 (`O(n³)` 대 `O(F · n² log n)`). 간선이 희소하거나 용량이 크거나 일반 네트워크이면 MCMF.
- 증가 경로가 `10⁵`번 넘게 필요한 입력(용량이 크고 경로가 얇음)은 파이썬에서 느립니다. 용량 크기에 따라 도는 횟수가 늘면 용량 스케일링이나 프라이멀-듀얼(디닉 식으로 한꺼번에 흘림)로 바꾸세요.

## 6. 자주 하는 실수

- **역간선 비용을 `−w`로 두지 않음**: 취소하는 경로가 비용을 돌려받지 못해 최적이 아닙니다. 역간선 용량 0, 비용 `−w`.
- **퍼텐셜 없이 다익스트라**: 잔여 그래프에는 음수 비용 간선(역간선)이 있어 다익스트라가 틀립니다. 퍼텐셜(줄인 비용)을 쓰거나 SPFA.
- **닿지 못한 정점의 퍼텐셜 갱신**: `dist = ∞`인 정점에 `h += ∞`를 하면 이후가 망가집니다. 닿은 정점만 갱신합니다 (닿지 못한 정점은 앞으로도 닿지 못합니다).
- **처음부터 음의 사이클**: SSP의 전제 위반. SPFA는 영원히 돌고 다익스트라는 틀립니다. 시작 때 벨만-포드로 검사합니다.
- **`limit`을 넘겨 흘림**: 병목 용량을 `limit − 지금까지 보낸 양`으로 제한하지 않으면 정확히 `k`만큼 보내는 문제에서 넘칩니다.
- **최대 유량과 최소 비용을 혼동**: `flow(s, t)`(제한 없음)는 "최대 유량 중 최소 비용"입니다. 이득이 나는 동안만 보내는 문제는 `flow_curve()`나 `limit`을 이용해 비용이 이득을 넘기 전에 멈춰야 합니다.
- **최대화 부호**: 비용을 음수로 바꿨으면 답도 부호를 되돌립니다. 모든 간선이 음수 비용이어도 음의 사이클이 없다면(DAG 등) 동작합니다.
- **네트워크 재사용**: `flow()`를 부른 뒤의 네트워크는 이미 유량이 흐른 상태입니다. 같은 입력을 다른 `limit`으로 다시 풀려면 새로 만드세요 (이어서 부르면 남은 용량으로 더 흘립니다).
- **정점 용량을 무시**: 정점에 용량이 있으면 `in → out` 간선으로 쪼개야 합니다.
- **SPFA 반례**: 격자 같은 입력에서 SPFA는 최악 `O(VE)`로 느려질 수 있습니다. 큰 입력에는 다익스트라.

## 7. 변형과 응용

- **최소 비용 순환(음의 사이클 취소)**: 처음 네트워크에 음의 사이클이 있으면 간선을 포화시킨 뒤(비용이 음수인 간선은 먼저 채우고) 균형을 맞추는 보조 간선으로 변환합니다.
- **하한이 있는 유량**: 간선마다 최소 유량이 있으면 가상 `s'`, `t'`를 써서 하한을 먼저 채웁니다.
- **용량 스케일링 / 비용 스케일링**: 증가 경로 횟수가 용량에 의존하는 약점을 줄이는 이론적 개선.
- **프라이멀-듀얼**: 퍼텐셜로 줄인 비용이 0인 간선만 모아 한 번에 최대 유량을 흘리는 방식(디닉). 증가 경로 횟수가 많을 때 빠릅니다.
- **볼록 비용 간선**: 한 간선을 비용이 다른 여러 평행 간선으로 쪼개면 "처음 몇 단위는 싸고 이후는 비싼" 볼록 비용도 표현합니다.
- **프로젝트 선택·최소 컷**: 비용이 아니라 "선택/비선택" 구조는 최소 컷으로. 가중치가 있는 경우는 둘이 연결되는 문제도 있습니다.
- **헝가리안 알고리즘**: 이분 그래프의 완전 배정은 쌍대 변수로 직접 풀어 더 빠릅니다([다음 개념](../hungarian-algorithm/)).
