# 번사이드 보조정리 (Burnside's Lemma)

> **한 줄 요약**: 회전·뒤집기 같은 변환으로 *서로 같아지는 배치를 한 가지로 센* 서로 다른 배치의 수는, 각 변환 `g`가 **그대로 두는 배치의 수**의 평균이다: `(1/|G|) Σ_{g∈G} |Fix(g)|`. 색칠 문제에서 `g`가 그대로 두는 색칠은 `g`의 각 순환(cycle)이 한 가지 색이어야 하므로 `k^(순환의 수)`다. 목걸이·팔찌·정육면체 색칠·정점 이름을 지운 그래프의 수를 모두 같은 틀로 센다.

## 1. 언제 쓰나 (문제 신호)

- "구슬 `n`개를 `k`색으로 꿴 **목걸이**(회전해서 같으면 같은 것)의 수", "뒤집어도 같으면" → 팔찌
- "정육면체의 면을 `k`색으로 칠하는 서로 다른 방법의 수 (돌려서 같으면 같은 것)"
- "정사각 보드를 색칠하는데 회전·대칭으로 같은 것은 하나로"
- "정점에 이름이 없는 그래프가 몇 개인가" (작은 `n`)
- 문제가 *"회전하여 같으면 같은 것으로 본다"*, *"대칭"*, *"서로 구별되지 않는"*이라는 표현을 쓸 때
- 모든 배치를 나열해 대표만 세는 방법(`kⁿ`가지)이 너무 클 때

## 2. 핵심 아이디어

**군의 작용과 궤도**: 변환들의 모임 `G`(항등 변환 포함, 합성과 역변환에 닫혀 있음 = *군*)가 배치들의 집합 `X`에 작용한다. 서로 변환으로 옮겨지는 배치끼리 묶은 한 묶음이 **궤도(orbit)**. 구하려는 "서로 다른 배치의 수"가 곧 궤도의 수다.

**번사이드 보조정리**:
```
궤도의 수 = (1 / |G|) · Σ_{g ∈ G} |Fix(g)|,        Fix(g) = { x ∈ X : g(x) = x }
```

*왜 맞는가*: `Σ_g |Fix(g)|`는 "`g`가 고정하는 `x`"인 쌍 `(g, x)`의 수이므로 `x`쪽으로 세면 `Σ_x |Stab(x)|`. 궤도-안정자 정리에서 `|Stab(x)| = |G| / |Orb(x)|`. 한 궤도 안의 `|Orb|`개의 `x`가 모두 같은 값 `|G|/|Orb|`를 더하므로 궤도 하나가 `|G|`를 기여한다. 따라서 합은 `|G| × (궤도의 수)`.

**색칠에서의 `|Fix(g)|`**: 자리 `n`개를 `k`색으로 칠하는 `kⁿ`가지가 `X`이고 `g`는 자리의 순열. 칠한 결과가 `g`로 변하지 않으려면 `g`의 **같은 순환 안의 자리들은 같은 색**이어야 한다. 순환이 `c(g)`개이면 `|Fix(g)| = k^{c(g)}`.

**원형 목걸이 (회전만)**: `n`개의 회전 `r⁰, r¹, …, r^{n−1}`에서 `r^j`의 순환 수는 `gcd(j, n)`. 합을 약수로 정리하면
```
necklaces(n, k) = (1/n) Σ_{d|n} φ(d) · k^{n/d}
```
(`j`의 `gcd(j, n) = n/d`가 되는 `j`가 `φ(d)`개).

**팔찌 (회전 + 뒤집기)**: 군은 `2n`개의 원소(이면체군). 뒤집기 `n`개의 순환 수는
- `n`이 홀수: 모든 뒤집기가 고정점 하나 + `(n−1)/2`쌍 → 순환 `(n+1)/2`개. 합 `n · k^{(n+1)/2}`.
- `n`이 짝수: 꼭짓점을 지나는 `n/2`개는 고정점 2개 + `(n−2)/2`쌍 → `n/2 + 1`, 변을 지나는 `n/2`개는 `n/2`. 합 `(n/2)(k^{n/2+1} + k^{n/2})`.
- `bracelets = (회전 합 + 뒤집기 합) / (2n)`.

**정육면체의 면 색칠**: 24개의 회전. 면 6개에 대한 순환 구조를 세면 (구현이 계산) 항등 1개(순환 6), 면 축 180° 3개(순환 4), 면 축 90°·270° 6개(순환 3), 변 축 180° 6개(순환 3), 꼭짓점 축 120°·240° 8개(순환 2):
`(k⁶ + 3k⁴ + 12k³ + 8k²) / 24`.

**정점 이름 없는 그래프**: 정점의 순열 `n!`개가 정점 쌍(간선 후보)에 작용하고 각 쌍은 "간선 있음/없음" 두 가지 색. 순열이 쌍에 일으키는 순열의 순환 수 `c`에 대해 `2^c`.

**큰 `n`의 모듈러**: `necklaces(n, k) mod p`는 약수 `d`마다 `φ(d)·k^{n/d} mod p`를 더하고 `n`의 모듈러 역원을 곱한다. `n`이 `p`의 배수가 아니어야 한다.

### 무엇을 저장하고 어떻게 움직이나

회전·반사를 같은 것으로 보는 문제에서 모든 색칠을 직접 대표 하나로 만들기보다 각 대칭 변환이 그대로 유지하는 색칠을 셉니다. 변환의 위치 순환 하나에서는 색이 모두 같아야 하므로 q색이면 순환 개수 c에 대해 q^c개가 고정됩니다.

### 왜 이 방법이 맞는가

색칠과 그것을 고정하는 변환의 쌍을 두 방향으로 세면 궤도의 수가 고정점 수의 평균과 같습니다. 포함할 변환 집합은 문제의 실제 대칭군이어야 합니다. 회전만 같은 것인지 반사도 같은 것인지에 따라 평균의 분모와 항이 달라집니다.

### 작은 예제로 검산하기

길이 3 목걸이를 2색으로 칠하고 회전만 동일하게 보면 고정 색칠은 항등 회전 8개, 두 비자명 회전 각각 2개입니다. 평균 `(8+2+2)/3=4`입니다. 모듈러에서 이 평균을 구할 때 군 크기의 역원이 있는지도 확인합니다.

## 3. 손으로 따라가기

### 목걸이: `n = 4`, `k = 2` (회전만)

| 회전 `r^j` | 자리 순열 | 순환 수 | 고정 색칠 `2^c` |
|---|---|---|---|
| `r⁰` | (0)(1)(2)(3) | 4 | 16 |
| `r¹` | (0 1 2 3) | 1 | 2 |
| `r²` | (0 2)(1 3) | 2 | 4 |
| `r³` | (0 3 2 1) | 1 | 2 |

합 `16 + 2 + 4 + 2 = 24`, `|G| = 4` → `24 / 4 = 6`. 직접 나열하면 `0000, 0001, 0011, 0101, 0111, 1111`로 6개입니다 (`0001, 0010, 0100, 1000`은 모두 같은 목걸이).

### 팔찌: `n = 4`, `k = 2` (이면체군 8개)

순환 수: 회전 `4, 1, 2, 1`, 뒤집기 `3, 3, 2, 2` (꼭짓점 축 2개 `3`, 변 축 2개 `2`). 고정 색칠 `16 + 2 + 4 + 2 + 8 + 8 + 4 + 4 = 48`, `48 / 8 = 6`. `n = 4`에서는 팔찌와 목걸이가 같고 `n = 6`부터 달라집니다.

### 목걸이와 팔찌의 수 (`k = 2`)

| `n` | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| 목걸이 | 2 | 3 | 4 | 6 | 8 | 14 | 20 | 36 |
| 팔찌 | 2 | 3 | 4 | 6 | 8 | 13 | 18 | 30 |

`n = 6`: 목걸이 14개 중 거울상이 서로 다른 한 쌍(`001011`과 `001101`)이 팔찌에서는 하나로 합쳐져 13개.

### 정육면체의 면 색칠

회전 24개의 순환 수 분포(구현이 군을 직접 만들어 확인): 순환 6개 1번, 4개 3번, 3개 12번, 2개 8번. 그러므로

`k = 2`: `(64 + 48 + 96 + 32) / 24 = 10`, `k = 3`: `(729 + 243 + 324 + 72) / 24 = 57`, `k = 4`: `240`, `k = 5`: `800`.

### 정점 3개의 그래프

`S₃`의 6개 순열이 3개의 쌍 `{01, 02, 12}`에 작용: 항등(순환 3), 호환 3개(두 쌍을 맞바꾸고 하나는 고정: 순환 2), 3-순환 2개(순환 1). `(2³ + 3·2² + 2·2¹) / 6 = (8 + 12 + 4) / 6 = 4`: 간선이 0, 1, 2, 3개인 그래프 4가지. `n = 4`는 11, `n = 5`는 34, `n = 6`은 156, `n = 7`은 1044, `n = 8`은 12346.

## 4. 구현

전체 코드는 [solution.py](solution.py)에 있습니다.

```python
def count_cycles(perm):
    seen, cycles = [False] * len(perm), 0
    for start in range(len(perm)):
        if not seen[start]:
            cycles += 1
            i = start
            while not seen[i]:
                seen[i] = True
                i = perm[i]
    return cycles


def burnside_count(group, colors):
    total = sum(colors ** count_cycles(g) for g in group)
    return total // len(group)                       # 군이 아니면 나누어떨어지지 않아 ValueError


def necklaces(n, k):
    return sum(phi * k ** (n // d) for d, phi in _divisors_with_phi(n)) // n
```

- `generate_group(generators)`: 생성원들의 곱을 닫아 군을 만듭니다. `cyclic_group(n)`, `dihedral_group(n)`.
- `bracelets(n, k)`, `necklaces_mod(n, k, mod)`: 큰 `n`의 나머지 (약수만큼의 거듭제곱).
- `cube_rotations()`: 두 개의 90° 회전으로 24개 회전을 생성. `cube_face_colorings(k)`.
- `count_unlabeled_graphs(n)`: `n!`개의 정점 순열이 쌍에 작용. `brute_force_orbits(group, n, colors)`: 모든 색칠의 대표를 직접 세는 기준 구현.
- 직접 실행하면 `n k`를 받아 구슬 `n`개를 `k`색으로 꿴 목걸이의 수(회전만)와 팔찌의 수(회전 + 뒤집기)를 두 줄로 출력합니다.

## 5. 복잡도와 입력 크기 가이드

- 일반 군: 시간 `O(|G| · n)` (각 원소의 순환 수 세기), 공간 `O(|G| · n)`. 목걸이·팔찌: 약수의 개수 `d(n)`번의 거듭제곱 (`n`을 소인수분해한 뒤). ([복잡도 치트시트](../../../docs/complexity-cheatsheet.md))
- 이 환경에서 측정한 값입니다.

| 작업 | 시간 |
|---|---|
| `count_unlabeled_graphs(7)` (`7! = 5040`개 순열) | 0.029초 |
| `count_unlabeled_graphs(8)` (`40320`개) | 0.3초 |
| `brute_force_orbits`, `n = 12`, `k = 2` (4096 가지 × 12 회전) | 0.039초 |
| `necklaces_mod(10¹², 5, 998244353)` | 0.0003초 |
| `necklaces(1000, 2)` (정확한 값, 299자리) | 즉시 |

- 군의 원소를 모두 나열하는 방법은 `|G|`가 수백만을 넘으면 어렵습니다 (`n ≥ 10`인 대칭군 `n!`). 그때는 순환 *유형*(분할)별로 원소의 수를 세는 공식(순환 지수)을 씁니다.
- 목걸이·팔찌는 약수만 훑으므로 `n`이 `10¹²`여도 순간입니다.

## 6. 자주 하는 실수

- **회전만인지 뒤집기도 포함인지**: 문제를 읽고 군을 정하세요. 목걸이 ≠ 팔찌.
- **`k^{순환 수}` 대신 `k^n`**: 항등 변환만 `k^n`입니다.
- **합이 `|G|`로 나누어떨어지지 않음**: 입력이 군이 아니라는 신호입니다 (구현은 `ValueError`). 생성원으로 군을 닫는 `generate_group`을 쓰세요.
- **뒤집기를 홀수·짝수로 구분하지 않음**: `n`이 짝수면 두 종류(정점 축, 변 축)가 있습니다.
- **모듈러에서 `n`의 역원**: `n`이 `p`의 배수면 역원이 없습니다 (구현은 `ValueError`). 이때는 약수 합을 정확한 정수(파이썬 큰 정수)로 계산한 뒤 나누세요.
- **나눗셈을 먼저**: 항마다 `//`하면 틀립니다. 합 전체를 더한 뒤 한 번에 나눕니다.
- **색의 사용량 제한을 무시**: "정확히 검은 구슬 3개" 같은 조건이면 `k^c`가 아니라 *순환마다 크기만큼의 가중치*를 가진 다항식 계수를 구해야 합니다 (폴리아).
- **큐브의 면/꼭짓점/변을 혼동**: 같은 회전군이라도 면을 칠하는지 꼭짓점을 칠하는지에 따라 작용하는 대상과 순환 수가 다릅니다.
- **궤도와 대칭 요소 혼동**: 번사이드가 세는 것은 *서로 다른 배치(궤도)의 수*이지 대칭인 배치의 수가 아닙니다.
- **완전 탐색 기준 구현과 비교하지 않음**: 작은 `n`에서 `brute_force_orbits`와 맞춰 보면 군 정의 실수를 바로 찾습니다.

## 7. 변형과 응용

- **폴리아 열거 정리**: 각 색에 변수를 붙이고 순환 지수 `Z_G`에 대입하면 *색의 사용량별* 서로 다른 배치의 수를 다항식의 계수로 얻습니다.
- **순환 지수로 큰 군 다루기**: 대칭군 `Sₙ`는 순환 유형(정수의 분할)별 원소의 수 `n! / Π (cᵢ! · iᶜⁱ)`를 쓰면 `n!`개를 나열하지 않고 계산됩니다.
- **정사각 격자 색칠**: `N × N` 보드의 회전·반사 8개 대칭 (이면체군 `D₄`)로 센 서로 다른 색칠.
- **화학·그래프**: 분자의 이성질체 수, 트리의 동형 개수는 폴리아의 고전적 응용.
- **가중 번사이드**: 변환마다 가중치가 있는 경우로의 확장.
- **다른 군 작용**: 순열 말고 행렬군 작용 등으로 일반화됩니다. 실전 문제의 대부분은 순열 군입니다.
