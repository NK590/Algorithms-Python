# 연습문제 — 번사이드 보조정리

쉬운 것부터 어려운 순서로 정리했습니다. **문제 지문은 옮기지 않고** 링크와 "배울 점"만 적었습니다. 난이도(solved.ac 티어)는 시간이 지나며 바뀔 수 있어서 표에 적지 않았으니 각 링크에서 확인하세요.

| # | 문제 | 유형 | 배울 점 |
|---|---|---|---|
| 1 | [OEIS A000031 - Necklaces](https://oeis.org/A000031) | 이진 목걸이의 수 | `necklaces(n, 2)`를 구해 수열과 비교. 이 문서의 표(2, 3, 4, 6, 8, 14, …)를 확인 |
| 2 | [OEIS A000029 - Bracelets](https://oeis.org/A000029) | 이진 팔찌의 수 | `bracelets(n, 2)`. 목걸이와 달라지는 첫 `n` |
| 3 | [POJ 1286 Necklace of Beads](http://poj.org/problem?id=1286) | 3색 구슬 `n ≤ 24`, 회전과 뒤집기 | 이면체군의 팔찌. `bracelets(n, 3)`: `n = 0`일 때의 출력 형식(0)에 주의 |
| 4 | [POJ 2409 Let it Bead](http://poj.org/problem?id=2409) | `k`색 `n`개 팔찌, `k, n ≤ 32` | 큰 정수가 필요. 파이썬은 문제없다 |
| 5 | [UVa 10294 Arif in Dhaka (First Love Part 2)](https://www.udebug.com/UVa/10294) | 목걸이와 팔찌를 한 번에 | 두 값을 한 쌍으로 출력. `n ≤ 50`, `t ≤ 50` |
| 6 | [POJ 2154 Color](http://poj.org/problem?id=2154) | 회전만, `n ≤ 10⁹`, 나머지 | 약수만 훑는 풀이. `necklaces_mod`와 같은 구조. `n`의 소인수분해는 시행 나눗셈으로 충분 |
| 7 | [OEIS A000088 - 비동형 그래프의 수](https://oeis.org/A000088) | 정점 이름이 없는 그래프 | `count_unlabeled_graphs(n)`으로 1, 2, 4, 11, 34, 156, 1044, 12346을 확인. `n ≥ 9`는 순환 지수가 필요 |

## 풀이 메모

- 1번과 2번은 이론의 검증입니다. 구현이 맞는지 `brute_force_orbits`와도 `n ≤ 12`에서 확인하세요.
- 3번과 5번은 같은 공식입니다. 팔찌는 `(회전 합 + 뒤집기 합) / (2n)`.
- 4번의 출력은 매우 커질 수 있습니다 (`32^32` 근처). 파이썬의 큰 정수로 정확히 계산됩니다.
- 6번은 [폴라드 로](../pollard-rho/)가 필요 없을 만큼 `n ≤ 10⁹`입니다. 약수마다 `φ(d)`를 구할 때는 `_divisors_with_phi`처럼 소인수분해에서 한 번에 만들면 `d(n)`에 비례합니다. 나머지는 `n`의 역원으로 나눠야 하므로 `n`이 모듈러의 배수가 아닌지 확인하세요.
- 7번은 `n = 8`까지 이 구현으로 계산됩니다(`0.3초`). `n = 9, 10`은 `9! = 362880`, `10! = 3628800`개의 순열이라 순환 유형별로 묶는 방법이 필요합니다.
