# 기댓값 DP (Expected Value DP)

> **한 줄 요약**: "앞으로 평균 몇 번 / 평균 얼마"를 `E[상태] = (한 번 움직이는 비용) + Σ (다음 상태로 갈 확률) × E[다음 상태]`라는 점화식으로 쓴다. 상태가 앞으로만 나아가면 *끝에서부터* 채우는 일반 DP이고, 제자리나 되돌아가기가 있으면 *연립방정식*을 푼다. 값은 **분수(`Fraction`)로 정확히** 구하거나, 문제가 "`p/q`를 `p·q⁻¹ mod P`로 출력"을 요구하면 **모듈러 역원**으로 구한다. 복잡한 양은 **기댓값의 선형성**으로 쪼갠다.

## 1. 언제 쓰나 (문제 신호)

- "목표에 도달할 때까지 **평균 몇 번** 굴리는가/뽑는가/움직이는가"
- "모든 종류를 한 번씩 모으려면 평균 몇 번" (쿠폰 수집가)
- 무작위 보행, 도박꾼의 파산, 흡수 상태가 있는 마르코프 연쇄에서 "평균 몇 단계 뒤에 끝나고 어디서 끝나는가"
- 출력이 "**기약분수 `p/q`에서 `p·q⁻¹ mod 998244353`**" 형태
- 확률이나 평균을 묻는데 *경우의 수가 지수적*이라 나열이 불가능하지만 상태는 적을 때
- "무작위 순열에서 ~의 평균" 같은 문제 — 선형성으로 `O(1)`에 풀리는 경우

## 2. 핵심 아이디어

**기댓값의 정의와 점화식**. 확률 변수 `X`의 기댓값은 `E[X] = Σ x·P(X = x)`. 어떤 과정의 *남은 비용의 기댓값*을 상태 `s`의 함수 `E[s]`로 보면,

```
E[s] = 1 + Σ_t  P(s → t) · E[t]        (한 번 움직이는 비용 1)
E[끝] = 0
```

**방향이 있으면(DAG) 일반 DP**: 상태가 항상 "더 끝에 가까운" 쪽으로만 간다면 끝 상태부터 거꾸로 `E`를 채운다. 주사위로 합이 목표 이상이 될 때까지 굴리는 횟수가 이 경우다: `E[s] = 1 + (1/d)·Σ_{k=1..d} E[s+k]`, `s ≥ 목표`이면 0. `d`개의 합을 *슬라이딩 윈도우*로 밀면 `O(목표)`.

**순환이 있으면 연립방정식**: 상태가 제자리로 돌아가거나 서로 오갈 수 있으면(`E[s]`가 자기 자신을 포함) 방정식이 서로 얽힌다. 일반 상태 `Q`(전이 확률 행렬)에 대해 `(I − Q)·E = 1` (모든 칸이 1인 벡터)을 가우스 소거로 푼다. 흡수 확률은 같은 행렬로 `(I − Q)·P = R`을 푼다 (`R`은 일반→흡수 전이).

**쿠폰 수집가**: `n`종류 중 `k`종류를 가지고 있을 때 새 종류를 만날 확률은 `(n−k)/n`이고 *처음 만나기까지의 횟수의 평균은 `n/(n−k)`* (기하 분포의 평균 `1/p`). 합치면 `E = Σ_{k=0}^{n−1} n/(n−k) = n·Hₙ`.

**기댓값의 선형성**: `E[X + Y] = E[X] + E[Y]`는 `X`, `Y`가 **독립이 아니어도** 성립한다. 복잡한 수를 *0/1 지표 변수의 합*으로 쪼개서 지표 하나의 기댓값(= 그 사건의 확률)을 구한다.
- 무작위 순열의 고정점(`a_i = i`) 개수: 위치 `i`마다 확률 `1/n` → `n·(1/n) = 1`.
- 무작위 순열의 역순 쌍 수: 쌍마다 확률 `1/2` → `C(n,2)/2 = n(n−1)/4`.

(반대로 **곱의 기댓값** `E[XY] = E[X]·E[Y]`는 독립일 때만 성립한다.)

**정확한 값 vs 모듈러 vs 실수**:
- `Fraction`: 정확하지만 분모가 `d^단계 수`처럼 커진다 (주사위 목표 1500에서 분모가 1167자리).
- 모듈러 역원: 값을 `p·q⁻¹ mod P`(P는 소수, `q`와 서로소)로 직접 계산. 분수를 만들지 않아 빠르고 크기가 일정하다.
- `float`: 빠르지만 오차가 쌓이고 `==`로 비교하면 안 된다.

### 무엇을 저장하고 어떻게 움직이나

상태에서 가능한 결과의 확률과 그 이후의 값을 가중 합합니다. 성공 확률을 구하는 DP와 남은 횟수의 기댓값을 구하는 DP는 저장값이 다릅니다. 기댓값에는 현재 행동의 비용을 더하고 다음 상태의 기대 비용을 합칩니다.

### 왜 이 방법이 맞는가

전체 확률의 합이 1이고 사건들이 가능한 결과를 모두 나누면 전확률·기댓값 법칙으로 전이가 성립합니다. 자기 상태로 돌아오는 확률 p가 있으면 E가 식 양변에 나타나므로 `(1-p)*E`로 정리해야 합니다. p=1이면 종료하지 않을 수 있습니다.

### 작은 예제로 검산하기

성공 확률 1/2로 끝나고 실패하면 같은 상태인 시행은 `E=1+(1/2)*E`, 따라서 E=2입니다. 실패 후 다른 상태로 간다면 그 상태의 E를 사용합니다. 부동소수점 결과는 절대·상대 오차로 비교합니다.

## 3. 손으로 따라가기

### 두 면(1 또는 2)의 주사위, 합이 4 이상이 될 때까지: `E[s]` (`s` = 현재 합)

`E[4] = E[5] = 0`.

| `s` | 식 | `E[s]` |
|---|---|---|
| 3 | `1 + (E[4] + E[5])/2` | `1` |
| 2 | `1 + (E[3] + E[4])/2` | `3/2` |
| 1 | `1 + (E[2] + E[3])/2` | `9/4` |
| 0 | `1 + (E[1] + E[2])/2` | `23/8` |

답은 `23/8 = 2.875`번. 6면 주사위로 합이 2 이상이 될 때까지는 `7/6`(첫 굴림에서 `5/6`이 끝, `1/6`이 한 번 더), 합이 10 이상이 될 때까지는 `33495175/10077696 ≈ 3.3237`번입니다.

### 쿠폰 수집가: `n = 3`

`E = 3/1 + 3/2 + 3/3 = 11/2 = 5.5`. `n = 1..6`의 값은 `1, 3, 11/2, 25/3, 137/12, 147/10`. `n = 50`이면 약 224.96, `n = 100`이면 약 518.74번.

### 주사위 두 개의 합의 분포

`P(합 = 7) = 1/6`이고 `P(합 ≥ 11) = 3/36 = 1/12`. 분포는 `s = 2..12`에서 `1/36, 1/18, 1/12, 1/9, 5/36, 1/6, 5/36, 1/9, 1/12, 1/18, 1/36`이고 평균은 `dice × (sides+1)/2 = 7`.

### 순환이 있는 경우: 대칭 무작위 보행 (정점 0, 1, 2, 3, 4, 0과 4에서 멈춤)

매 단계 왼쪽/오른쪽 이웃으로 확률 `1/2`씩 간다. 정점 `i`에서 멈출 때까지의 평균 단계 수 `tᵢ`:

```
t1 = 1 + (t0 + t2)/2 = 1 + t2/2       (t0 = 0)
t2 = 1 + (t1 + t3)/2
t3 = 1 + (t2 + t4)/2 = 1 + t2/2       (t4 = 0)
```

대입하면 `t1 = t3 = 1 + t2/2`, `t2 = 1 + t1 = 2 + t2/2` → `t2 = 4`, `t1 = t3 = 3`. 일반적으로 `tᵢ = i(n − i)`. 가우스 소거로 같은 값 `{1: 3, 2: 4, 3: 3}`을 얻고, 오른쪽 끝(4)에서 끝날 확률은 `1/4, 1/2, 3/4`(= `i/4`)입니다.

**도박꾼의 파산**: 한 판에 확률 `p`로 +1, `1−p`로 −1, 0원이 되기 전에 `N`원에 도달할 확률. `p = 1/2`면 `start/N`(예: `3/10`), `p = 9/20`이면 `r = (1−p)/p = 11/9`로 `(1 − r³)/(1 − r¹⁰) = 1439673669/11225320100 ≈ 0.128`.

### 선형성: 길이 3의 순열 6개

| 순열 | 고정점 | 역순 쌍 |
|---|---|---|
| 123 | 3 | 0 |
| 132 | 1 | 1 |
| 213 | 1 | 1 |
| 231 | 0 | 2 |
| 312 | 0 | 2 |
| 321 | 1 | 3 |

고정점의 평균 `(3+1+1+0+0+1)/6 = 1`, 역순 쌍의 평균 `(0+1+1+2+2+3)/6 = 3/2 = 3·2/4`. 순열을 나열하지 않고 식으로 바로 얻은 값과 같습니다.

## 4. 구현

전체 코드는 [solution.py](solution.py)에 있습니다.

```python
def expected_rolls_to_reach(target, sides=6):
    window = deque([Fraction(0)] * sides)       # window[0] = E[s+1], …, window[-1] = E[s+sides]
    window_sum = Fraction(0)
    value = Fraction(0)
    for _ in range(target):
        value = 1 + window_sum / sides          # E[s] = 1 + (1/d)·Σ E[s+k]
        window_sum += value - window.pop()      # 다음(s-1): 가장 먼 값을 빼고 방금 구한 값을 앞에 넣는다
        window.appendleft(value)
    return value


def fraction_mod(value, mod=998244353):
    return value.numerator % mod * pow(value.denominator, -1, mod) % mod


def coupon_collector(n):
    return sum(Fraction(n, n - k) for k in range(n))


def absorbing_chain(transitions, absorbing):
    ...                                          # (I - Q)·E = 1 과 (I - Q)·P = R 을 solve_linear 로
```

- `solve_linear(A, b)`: `Fraction`에 대한 가우스 소거. 해가 하나로 정해지지 않으면 `ValueError`.
- `expected_rolls_mod(target, sides, mod)`: 같은 값을 분수 없이 모듈러로.
- `sum_distribution(dice, sides)`, `probability_sum_at_least(dice, sides, threshold)`.
- `gamblers_ruin(start, goal, p)`: 흡수 연쇄를 풀어 구한 도달 확률.

- 직접 실행하면 `목표 면의 수`를 받아 합이 목표 이상이 될 때까지 굴리는 횟수의 기댓값을 기약분수 `p/q`와 `p·q⁻¹ mod 998244353`으로 두 줄에 출력합니다.

## 5. 복잡도와 입력 크기 가이드

- **주사위 기댓값: 시간 `O(목표)`**(슬라이딩 윈도우), 분수를 쓰면 분모 길이만큼 느려지고 모듈러면 `O(목표)` 정수 연산. **연립방정식(`Fraction`): `O(S³)`**, `S`는 일반 상태 수. ([복잡도 치트시트](../../../docs/complexity-cheatsheet.md))
- 이 환경에서 측정한 값입니다 (6면 주사위).

| 목표 | `Fraction` | 모듈러 | 분모의 자릿수 |
|---|---|---|---|
| 200 | 0.002초 | 0.0001초 미만 | 155 |
| 1500 | 0.064초 | 0.0003초 | 1167 |
| 10⁶ | - (분수는 비현실적) | 0.20초 | - |

- 두 방법이 같은 결과를 냈음을 목표 1500까지 확인했습니다(테스트).
- 연립방정식의 `Fraction` 가우스 소거는 상태 수가 수십 개까지는 즉시, 수백 개를 넘으면 분수가 커져 느립니다. 문제가 모듈러 출력을 요구하면 가우스 소거를 *모듈러 연산*으로 하세요 (`Fraction` 대신 `mod` 역원).

## 6. 자주 하는 실수

- **끝 상태의 값을 0으로 두지 않음**: `E[끝] = 0`이 *모든 비용 계산의 기준*입니다. 끝에 도착한 순간에 한 번 더 세지 않도록 하세요 (`s ≥ 목표`가 곧 끝).
- **한 번 움직이는 비용 `1`을 빼먹음**: `E[s] = Σ P·E[t]`만 쓰면 항상 0이 됩니다.
- **확률의 합이 1이 아님**: 같은 도착점으로 가는 전이를 합쳐야 합니다 (목표를 넘는 모든 눈은 같은 "끝" 상태).
- **분수를 만들지 않고 `float`로 `==` 비교**: 오차가 쌓입니다. 정확한 값이 필요하면 `Fraction`이나 모듈러.
- **모듈러에서 분모가 `P`의 배수**: 역원이 없습니다 (`fraction_mod`가 `ValueError`). 면의 수가 `P`보다 작으면 보통 문제없습니다.
- **모듈러에서 확률과 기댓값 혼동**: 확률의 곱은 모듈러 곱이지만 *분수의 합*은 역원을 곱한 뒤에 더해야 합니다 (분모를 맞추지 않고 `p/q + r/s`를 `(p+r)/(q+s)`로 쓰는 실수 방지).
- **선형성을 곱에 적용**: `E[XY] = E[X]E[Y]`는 독립일 때만.
- **연립방정식이 특이**: 어디서도 끝에 도달하지 못하는 상태가 있으면 기댓값이 무한대이고 `(I − Q)`가 특이 행렬입니다 (`ValueError`).
- **조건부 기댓값과 전체 기댓값**: "성공한 경우의 평균"을 묻는지 "전체 평균"을 묻는지 읽으세요.
- **상태 정의가 과거에 의존**: 마르코프 성질이 성립하도록 상태에 필요한 모든 정보(남은 횟수, 직전 결과 …)를 담아야 합니다.

## 7. 변형과 응용

- **a + b·x 트릭**: 방정식이 순환이라 막힐 때, 시작 값을 미지수 `x`로 두고 모든 `E[s]`를 `a_s + b_s·x`의 꼴로 계산해 마지막에 `x = a + b·x`를 풉니다 (AtCoder ABC189 F).
- **확률 DP(앞으로 나아가기)**: `E` 대신 `dp[t][상태] =` 확률을 앞으로 전파합니다. 정확히 `t`단계 뒤의 분포를 묻는 문제.
- **큰 단계 수**: 전이가 고정이고 `t`가 10¹⁸이면 확률 전이 행렬을 [거듭제곱](../matrix-exponentiation/)합니다.
- **최적 정지·게임**: 각 상태에서 선택지 중 `min`/`max`를 고르는 기댓값 DP (예: 지금 멈출지 한 번 더 굴릴지).
- **모듈러 가우스 소거**: `O(S³)`에 모듈러로 연립방정식을 풉니다. 상태가 수백 개인 흡수 연쇄.
- **상태 압축**: 쿠폰이 종류별로 다를 때 부분집합 비트마스크를 상태로 (확률이 다른 쿠폰 수집가).
- **정상 분포와 마르코프 연쇄 이론**: 흡수 상태가 없는 연쇄의 장기 평균은 `π P = π`의 해.
- **몬테카를로로 검증**: 식이 맞는지 의심될 때 무작위 시뮬레이션의 평균과 비교해 보면 오류를 잡기 쉽습니다.
