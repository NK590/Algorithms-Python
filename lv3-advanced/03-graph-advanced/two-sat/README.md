# 2-SAT

> **한 줄 요약**: 각 절이 리터럴 **두 개의 OR**인 논리식 `(a ∨ b) ∧ (c ∨ d) ∧ …`이 참이 되도록 변수 값을 정할 수 있는지, 있다면 한 가지를 찾는다. 절 `(a ∨ b)`를 함의 `¬a → b`와 `¬b → a` 두 간선으로 바꾼 **함의 그래프**를 [SCC](../scc/)로 나누면 `O(N + M)`에 풀린다. 변수 `x`와 `¬x`가 같은 SCC에 있으면 불가능이다. (절당 리터럴이 셋이면 NP-완전한 3-SAT)

## 1. 언제 쓰나 (문제 신호)

- "각 `i`에 대해 두 선택 중 하나를 고르는데, 두 항목의 선택이 **함께 일어날 수 없다**(또는 **적어도 하나는 해야 한다**)는 제약이 `M`개"
- **양자택일 + 쌍 제약**: 각 회의가 오전/오후 중 하나, 각 스위치가 켜짐/꺼짐, 각 손님이 A/B 메뉴 중 하나, 두 개의 후보 중 하나를 고르는 학급 대표 선출
- "`x`이면 `y`" 형태의 **조건부 제약**이 많다 (함의가 그대로 간선)
- 변수가 `10⁴~10⁶`개이고 제약이 `10⁵~10⁶`개 (완전탐색 `2ᴺ`은 불가능)
- 가능 여부만 묻거나 **해 하나**를 출력하라고 한다 (모든 해를 세는 것은 어렵다)

## 2. 핵심 아이디어

**절 하나는 함의 두 개**: `(a ∨ b)`는 "`a`가 거짓이면 `b`는 참"이라는 `¬a → b`, 그리고 대칭으로 "`b`가 거짓이면 `a`는 참"이라는 `¬b → a`와 같다. 변수 `x`마다 정점 두 개(`x`가 참, `x`가 거짓)를 두고 모든 절에서 두 간선을 만든다. 이 그래프는 **대칭**이다: `a → b`가 있으면 `¬b → ¬a`도 있다.

**판정**: 함의 그래프를 [SCC](../scc/)로 나눈다.

- 어떤 변수 `x`에 대해 `x`와 `¬x`가 **같은 SCC**에 있으면 `x ⇒ ¬x ⇒ x`이므로 모순 → **불가능**.
- 어느 변수도 그렇지 않으면 **가능**하다.

**해 구하기**: SCC로 줄인 DAG의 위상 순서에서 `x`가 `¬x`보다 **뒤**에 있으면 `x = 참`, 앞에 있으면 거짓으로 둔다. 왜 일관적인가: 리터럴 `a`가 참으로 정해졌고(`a`가 `¬a`보다 위상 순서에서 뒤) `a → b`라면, `a → b`이므로 `b`는 `a`보다 뒤이고, 대칭 간선 `¬b → ¬a`에서 `¬b`는 `¬a`보다 앞이다. 따라서 `b`는 `a`보다 뒤, `a`는 `¬a`보다 뒤, `¬a`는 `¬b`보다 뒤(또는 같음)이므로 `b`가 `¬b`보다 뒤 — `b`도 참이다. **참인 리터럴에서 출발한 함의는 참에서 끝난다**는 뜻이라 모든 절이 만족된다.

타잔의 SCC 번호는 위상 정렬의 역순으로 매겨지므로, **`comp[x] < comp[¬x]`이면 `x = 참`**이다.

**정점 번호 규칙**: 변수 `i`의 "참" 정점을 `2i`, "거짓" 정점을 `2i + 1`로 둔다.

**자주 쓰는 제약을 절로 바꾸기**

| 제약 | 절 |
|---|---|
| `x` 또는 `y` 중 적어도 하나 참 | `(x ∨ y)` |
| `x`이면 `y` | `(¬x ∨ y)` |
| `x`와 `y`가 동시에 참일 수 없다 | `(¬x ∨ ¬y)` |
| `x`는 참이어야 한다 (강제) | `(x ∨ x)` |
| `x`와 `y`의 값이 같다 | `(¬x ∨ y)`, `(x ∨ ¬y)` |
| `x`와 `y`의 값이 다르다 | `(x ∨ y)`, `(¬x ∨ ¬y)` |

## 3. 손으로 따라가기

### 식: `(x₀ ∨ x₁) ∧ (¬x₀ ∨ x₂) ∧ (¬x₁ ∨ ¬x₂) ∧ (x₀ ∨ x₂)`

정점: `0 = x₀`, `1 = ¬x₀`, `2 = x₁`, `3 = ¬x₁`, `4 = x₂`, `5 = ¬x₂`.

| 절 | 간선 (정점 번호) |
|---|---|
| `(x₀ ∨ x₁)` | `¬x₀ → x₁` (1→2), `¬x₁ → x₀` (3→0) |
| `(¬x₀ ∨ x₂)` | `x₀ → x₂` (0→4), `¬x₂ → ¬x₀` (5→1) |
| `(¬x₁ ∨ ¬x₂)` | `x₁ → ¬x₂` (2→5), `x₂ → ¬x₁` (4→3) |
| `(x₀ ∨ x₂)` | `¬x₀ → x₂` (1→4), `¬x₂ → x₀` (5→0) |

인접 리스트: `0:[4]`, `1:[2,4]`, `2:[5]`, `3:[0]`, `4:[3]`, `5:[1,0]`.

SCC (이 환경에서 확인): `{0, 3, 4}` = `{x₀, ¬x₁, x₂}`가 번호 0, `{1, 2, 5}` = `{¬x₀, x₁, ¬x₂}`가 번호 1. 어느 변수도 자신과 부정이 같은 SCC에 있지 않으므로 **가능**.

| 변수 | `comp[참]` | `comp[거짓]` | `comp[참] < comp[거짓]`? | 값 |
|---|---|---|---|---|
| `x₀` | 0 | 1 | 예 | **참** |
| `x₁` | 1 | 0 | 아니오 | **거짓** |
| `x₂` | 0 | 1 | 예 | **참** |

배정 `(참, 거짓, 참)`을 식에 넣으면 `(T∨F) ∧ (F∨T) ∧ (T∨F) ∧ (T∨T)` = 참.

### 불가능한 식: `(x₀ ∨ x₁) ∧ (x₀ ∨ ¬x₁) ∧ (¬x₀ ∨ x₁) ∧ (¬x₀ ∨ ¬x₁)`

네 절이 변수 두 개의 모든 조합을 금지한다. 정점 `0..3`(`x₀, ¬x₀, x₁, ¬x₁`)이 모두 한 SCC가 되고(예: `x₀ → x₁ → ¬x₀ → ...`), `x₀`와 `¬x₀`가 같은 SCC이므로 **불가능**. 처음 세 절만 있으면 `(참, 참)`이 해다.

## 4. 구현

전체 코드는 [solution.py](solution.py)에 있습니다. 변수는 0부터. 단독으로 실행되도록 반복문 타잔을 포함합니다.

```python
class TwoSat:
    def __init__(self, n):
        self.n = n
        self.adjacency = [[] for _ in range(2 * n)]

    @staticmethod
    def _node(variable, value):                 # 리터럴 "variable == value"
        return 2 * variable + (0 if value else 1)

    def add_clause(self, i, a, j, b):           # (x_i == a) ∨ (x_j == b)
        self.adjacency[self._node(i, not a)].append(self._node(j, b))   # ¬A → B
        self.adjacency[self._node(j, not b)].append(self._node(i, a))   # ¬B → A

    def solve(self):
        ids = _scc_ids(2 * self.n, self.adjacency)       # 타잔: 위상 정렬의 역순으로 번호
        assignment = []
        for i in range(self.n):
            if ids[2 * i] == ids[2 * i + 1]:
                return None                              # x 와 ¬x 가 같은 SCC
            assignment.append(ids[2 * i] < ids[2 * i + 1])
        return assignment
```

- 편의 메서드: `force(i, value)`, `add_implication(i, a, j, b)`, `add_equal(i, j)`, `add_not_equal(i, j)`.
- 직접 실행하면 `N M`과 `M`개의 절 `a b`(= `a ∨ b`, 변수는 1부터, 음수는 부정)를 받아 만족 가능하면 `1`과 각 변수의 값(0/1)을, 아니면 `0`을 출력합니다.

## 5. 복잡도와 입력 크기 가이드

- 정점 `2N`개, 간선 `2M`개에서 SCC 한 번이라 **시간 O(N + M)**, **공간 O(N + M)**. ([복잡도 치트시트](../../../docs/complexity-cheatsheet.md))
- 이 환경에서 측정한 값입니다(해가 있는 무작위 식, 두 번 중 최소).

| 입력 | 시간 (그래프 만들기 + 풀기) |
|---|---|
| 변수 10⁵개, 절 2·10⁵개 | 0.69초 |

- 변수 `N = 10⁶`, 절 `10⁶` 정도까지 파이썬에서 몇 초 안에 됩니다. 재귀 SCC는 사슬 모양의 함의에서 깊이 제한에 걸리므로 반복문 구현이 필수입니다 ([테스트](test_solution.py)의 사슬 입력).
- 절이 세 개의 리터럴을 가지면(3-SAT) 다항 시간 알고리즘이 알려져 있지 않습니다. 문제를 2-SAT으로 환원할 수 있는지가 핵심입니다.

## 6. 자주 하는 실수

- **함의를 한 방향만 추가**: 절 하나당 간선이 **두 개**여야 합니다 (`¬a → b`와 `¬b → a`). 하나만 넣으면 그래프가 대칭이 아니어서 틀립니다.
- **정점 번호 규칙을 일관되게 쓰지 않음**: 참/거짓 정점을 `2i`, `2i + 1`로 정했다면 부정은 항상 `^ 1`.
- **값 판정의 방향**: 타잔(위상 정렬의 역순 번호)이면 `comp[x] < comp[¬x]`일 때 참. 코사라주(위상 정렬 순서)면 부등호가 반대입니다.
- **같은 변수가 절 안에 두 번**: `(x ∨ x)`는 `x`를 참으로 강제하는 절입니다 (`force`). `(x ∨ ¬x)`는 항상 참이라 영향이 없습니다.
- **입력의 부호 처리**: 문제가 `-3`을 `¬x₃`으로 줄 때 `abs(a) − 1`을 변수 번호로, `a > 0`을 값으로.
- **"최대 하나만 선택" 제약**: 변수 `k`개 중 최대 하나만 참이어야 하면 쌍마다 `(¬xᵢ ∨ ¬xⱼ)`가 `O(k²)`개입니다. 접두사 변수(`pᵢ` = "앞 `i`개 중 참이 있다")를 도입하면 `O(k)`개의 절로 줄일 수 있습니다.
- **모든 해를 세려 함**: 2-SAT은 해의 존재와 해 하나를 `O(N + M)`에 구하지만, 해의 개수를 세는 것은 어렵습니다.
- **재귀 SCC**: 변수가 많으면 깊이 제한에 걸립니다.

## 7. 변형과 응용

- **이분 그래프 판정**: 각 정점을 "0/1" 변수로 두고 간선마다 `add_not_equal` → 2-SAT. (이분 그래프 자체는 BFS로 더 간단히 판정) → [이분 그래프](../../../lv2-intermediate/02-graph-algorithms/bipartite-graph/)
- **양자택일 + 충돌 쌍**: 각 항목이 두 선택지를 갖고, 두 선택지가 충돌하는 쌍이 주어질 때 고르기 (회의 시간 배정, 방송 순서 정하기).
- **해 하나만이 아니라 사전순 최소 해**: 변수를 순서대로 참/거짓을 시도하며 가능성을 `O(N + M)`씩 확인하면 `O(N(N + M))`.
- **강제된 값을 먼저 넣고 전파**: 일부 변수를 고정하고 풀기 (`force`).
- **SCC를 활용한 다른 문제**: [SCC](../scc/)의 도미노, 최소 간선 추가 등.
- **3-SAT, 일반 SAT**: NP-완전. 2-SAT처럼 특수 구조를 찾는 것이 핵심.
