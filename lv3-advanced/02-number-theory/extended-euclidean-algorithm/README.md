# Extended Euclidean Algorithm (확장 유클리드 호제법)

> **한 줄 요약**: 유클리드 호제법이 `gcd(a, b)`만 구한다면, 확장 유클리드 호제법은 **`a·x + b·y = gcd(a, b)`를 만족하는 정수 `x`, `y`(베주 계수)까지** 함께 구한다. 이것으로 소수가 아닌 모듈러의 **역원**, **일차 부정 방정식 `ax + by = c`**, **일차 합동식 `ax ≡ b (mod m)`**을 모두 `O(log)`에 푼다.

## 1. 언제 쓰나 (문제 신호)

- "`ax + by = c`를 만족하는 **정수** `x`, `y`를 구하라" (해가 없으면 -1)
- 모듈러가 **소수가 아닐 때의 역원** `a⁻¹ mod m` (`gcd(a, m) = 1`이면 존재)
- "`a`번 뛰어서 `m`칸 원형을 돌 때 `b`칸에 도착하는가", `k·S ≡ c (mod N)` 형태의 일차 합동식
- 동전 두 종류(`a`원, `b`원)로 `c`원을 만들 수 있는가, 만드는 방법의 수
- 두 합동식을 하나로 합치는 [중국인의 나머지 정리](../chinese-remainder-theorem/)의 내부 도구
- 유클리드 호제법의 **계수**가 필요하다는 신호: "어떤 정수 결합으로 gcd를 만든다"

## 2. 핵심 아이디어

**베주 항등식**: 임의의 정수 `a`, `b`에 대해 `a·x + b·y = gcd(a, b)`인 정수 `x`, `y`가 존재합니다. 확장 유클리드 호제법은 이를 실제로 계산합니다.

**재귀 관점**: `gcd(a, b) = gcd(b, a mod b)`에서 `b·x' + (a mod b)·y' = g`를 이미 알고 있다고 하자. `a mod b = a − ⌊a/b⌋·b`이므로

```
b·x' + (a − ⌊a/b⌋·b)·y' = g
a·y' + b·(x' − ⌊a/b⌋·y') = g          →   x = y',   y = x' − ⌊a/b⌋·y'
```

`b = 0`일 때 `gcd = a`, `x = 1`, `y = 0`이 바탕입니다.

**반복문 관점**: 유클리드 호제법의 각 나머지 `rᵢ`는 처음 두 수의 **정수 결합** `rᵢ = sᵢ·a + tᵢ·b`로 쓸 수 있습니다. 나머지 `rᵢ₊₁ = rᵢ₋₁ − q·rᵢ`를 계산할 때 `s`와 `t`도 같은 식(`sᵢ₊₁ = sᵢ₋₁ − q·sᵢ`)으로 갱신하면 됩니다. 시작은 `r₀ = a = 1·a + 0·b`, `r₁ = b = 0·a + 1·b`. 반복문 버전이 재귀 깊이 걱정 없이 안전하고, 계수가 작게 유지됩니다(`|x| ≤ b/g`, `|y| ≤ a/g`).

**응용 세 가지**

1. **역원**: `gcd(a, m) = 1`이면 `a·x + m·y = 1`에서 `mod m`으로 보면 `a·x ≡ 1`. 그 `x`가 역원입니다. `m`이 소수일 필요가 없습니다. (`x`가 음수일 수 있으니 `x % m`)
2. **일차 부정 방정식 `a·x + b·y = c`**: `g = gcd(a, b)`일 때 해가 있을 **필요충분조건은 `g | c`**. 있다면 `a·x₀ + b·y₀ = g`에 `c/g`를 곱한 `(x₀·c/g, y₀·c/g)`가 해 하나이고, **모든 해**는
   ```
   x = x₁ + (b/g)·t,    y = y₁ − (a/g)·t        (t 는 임의의 정수)
   ```
3. **일차 합동식 `a·x ≡ b (mod m)`**: `g = gcd(a, m)`일 때 `g | b`이어야 해가 있고, 양변을 `g`로 나눈 `a'x ≡ b' (mod m')`(`m' = m/g`)는 `a'`의 역원을 곱해 풉니다. 해는 `mod m'`에서 하나, 즉 `mod m`에서 `g`개입니다.

### 무엇을 저장하고 어떻게 움직이나

gcd와 함께 `a*x+b*y=gcd(a,b)`를 만족하는 계수 x,y를 구합니다. 유클리드 알고리즘의 나머지 관계를 되돌려 원래 a,b의 정수 결합으로 표현합니다. 모듈러 역원과 일차 디오판토스 방정식의 기본 도구입니다.

### 왜 이 방법이 맞는가

작은 문제 `b*x'+r*y'=g`에서 `r=a-q*b`를 대입하면 `a*y'+b*(x'-q*y')=g`입니다. 이 계수 변환을 거슬러 올리면 베주 항등식을 보존합니다. `a*x+b*y=c`의 해는 gcd가 c를 나눌 때만 존재합니다.

### 작은 예제로 검산하기

30과 18의 gcd는 6이고 `30*(-1)+18*2=6`입니다. 12를 만드는 해는 계수를 두 배로 늘려 얻지만 5를 만드는 정수 해는 없습니다. 계수가 음수인 것은 정상이며 모듈러 답은 마지막에 정규화합니다.

## 3. 손으로 따라가기

### `extended_gcd(240, 46)`

각 줄에서 `r = s·240 + t·46`이 성립하도록 `s`, `t`를 함께 갱신합니다.

| 단계 | 몫 `q` | 나머지 `r` | `s` | `t` | 확인 `s·240 + t·46` |
|---|---|---|---|---|---|
| 시작 | | 240 | 1 | 0 | 240 |
| 시작 | | 46 | 0 | 1 | 46 |
| 1 | 5 | 10 | 1 | −5 | 240 − 230 = 10 |
| 2 | 4 | 6 | −4 | 21 | −960 + 966 = 6 |
| 3 | 1 | 4 | 5 | −26 | 1200 − 1196 = 4 |
| 4 | 1 | 2 | −9 | 47 | −2160 + 2162 = **2** |
| 5 | 2 | 0 | 23 | −120 | (끝) |

나머지가 0이 되기 직전 줄이 답입니다: `gcd = 2`, `x = −9`, `y = 47`. `240 · (−9) + 46 · 47 = −2160 + 2162 = 2`. 재귀 버전도 같은 `(2, −9, 47)`을 줍니다.

### 모듈러 역원

- `3⁻¹ mod 7`: `extended_gcd(3, 7) = (1, −2, 1)` (`3·(−2) + 7·1 = 1`) → `−2 mod 7 = 5`. `3 · 5 = 15 ≡ 1`.
- `3⁻¹ mod 10 = 7` (소수가 아닌 모듈러), `3⁻¹ mod (10⁹+7) = 333333336`.
- RSA의 개인키: `17⁻¹ mod 3120 = 2753`. `17 · 2753 = 46801 = 15 · 3120 + 1`.
- `gcd(a, m) ≠ 1`이면 `ValueError`. 예: `mod_inverse(4, 10)`.

### 일차 부정 방정식 `3x + 5y = 7`

`extended_gcd(3, 5) = (1, 2, −1)` (`6 − 5 = 1`). `7/1 = 7`배: `(14, −7)`이 해 하나 (`42 − 35 = 7`). 모든 해는 `x = 14 + 5t`, `y = −7 − 3t`. `x ≥ 0`에서 가장 작은 해는 `t = −2`일 때 `(4, −1)`: `12 − 5 = 7`.

해가 없는 예: `6x + 9y = 7` (`gcd = 3`, `3 ∤ 7`). 해가 있는 예: `6x + 9y = 21` → 해 하나 `(−7, 7)`, 모든 해 `x = −7 + 3t`, `y = 7 − 2t`, 가장 작은 `x ≥ 0`은 `(2, 1)`.

### 동전 두 종류로 `c`원 만들기: `3x + 5y = 40` (`x, y ≥ 0`)

가장 작은 `x ≥ 0`은 `(0, 8)`. `x`가 `5`씩 늘 때 `y`가 `3`씩 줄어 `y ≥ 0`을 유지하는 횟수만큼이 해의 개수입니다: `8 // 3 + 1 = 3`가지, `(0,8), (5,5), (10,2)`. `count_nonnegative_solutions(3, 5, c) = 0`인 `c`는 `1, 2, 4, 7`뿐입니다 (3원과 5원으로 만들 수 없는 가장 큰 금액이 7).

### 일차 합동식

- `6x ≡ 4 (mod 10)`: `gcd(6, 10) = 2`, `2 | 4`. 양변을 2로 나눠 `3x ≡ 2 (mod 5)`, `3⁻¹ mod 5 = 2` → `x ≡ 4 (mod 5)`. `mod 10`에서는 `x = 4, 9`. `solve_linear_congruence(6, 4, 10) = (4, 5)`.
- `3x ≡ 1 (mod 6)`: `gcd = 3`, `3 ∤ 1` → 해 없음.
- `4x ≡ 2 (mod 7)`: `gcd = 1`, `x ≡ 4 (mod 7)` (`4·4 = 16 ≡ 2`).

## 4. 구현

전체 코드는 [solution.py](solution.py)에 있습니다.

```python
def extended_gcd(a, b):
    """(g, x, y): g = gcd(a, b), a·x + b·y = g"""
    old_r, r = a, b
    old_s, s = 1, 0          # old_r = old_s·a + old_t·b
    old_t, t = 0, 1
    while r:
        q = old_r // r
        old_r, r = r, old_r - q * r
        old_s, s = s, old_s - q * s
        old_t, t = t, old_t - q * t
    if old_r < 0:            # 음수 입력이면 부호를 맞춘다
        old_r, old_s, old_t = -old_r, -old_s, -old_t
    return old_r, old_s, old_t

def mod_inverse(a, m):
    g, x, _ = extended_gcd(a, m)
    if g != 1:
        raise ValueError("역원이 없습니다")
    return x % m
```

- `extended_gcd_recursive(a, b)`: 재귀 버전(`a, b ≥ 0`).
- `solve_diophantine(a, b, c)`: 해 하나 또는 `None`. `diophantine_family(a, b, c)`: 모든 해를 `(x₀, y₀, dx, dy)`로. `smallest_nonnegative_x_solution(a, b, c)`(`b ≠ 0`), `count_nonnegative_solutions(a, b, c)`(`a, b > 0`, `c ≥ 0`).
- `solve_linear_congruence(a, b, m)`: `(x₀, m')` 또는 `None` (모든 해가 `x ≡ x₀ (mod m')`).
- 직접 실행하면 `A B C`를 받아 `A·x + B·y = C`의 정수 해(`x`가 0 이상으로 가장 작은 것)를 출력합니다. 해가 없으면 `-1`.
- 파이썬 3.8 이상에서는 역원만 필요하면 `pow(a, -1, m)`이 간단하고 더 빠릅니다.

## 5. 복잡도와 입력 크기 가이드

- **시간 O(log min(a, b))**: 유클리드 호제법과 같은 횟수의 나눗셈. 최악은 인접한 피보나치 수입니다 (`354224848179261931`과 `218922995834555169`는 58단계). **공간 O(1)**. ([복잡도 치트시트](../../../docs/complexity-cheatsheet.md))
- 이 환경에서 측정한 값입니다(세 번 중 최소).

| 작업 | 시간 |
|---|---|
| `extended_gcd` (10¹⁸ 근처의 두 수) | 6.5μs |
| `math.gcd` (같은 두 수) | 0.43μs |
| `pow(3, -1, 10⁹+7)` | 0.42μs |
| `mod_inverse(3, 10⁹+7)` | 0.9μs |

- 계수 `x`, `y`는 `|x| ≤ b/g`, `|y| ≤ a/g`로 입력과 같은 크기입니다. 해 하나에 `c/g`를 곱하면 `c`만큼 커지니 크기가 문제의 제한(`10⁹` 이하 등)을 넘으면 `t`로 줄입니다.
- 파이썬은 큰 정수를 지원해 오버플로 걱정이 없지만 C++/Java에서는 `x · (c / g)`가 `long long`을 넘을 수 있습니다.

## 6. 자주 하는 실수

- **해가 있는지 먼저 확인하지 않음**: `c % gcd ≠ 0`이면 해가 없습니다. 이 확인 없이 나누면 틀린 `(x, y)`가 나옵니다.
- **`x`가 음수인 역원을 그대로 사용**: `mod_inverse`는 마지막에 `x % m`. 음수 나머지가 나오는 언어에서는 `(x % m + m) % m`.
- **`gcd(a, m) ≠ 1`에서 역원을 요구**: 존재하지 않습니다. 일차 합동식은 `gcd`로 먼저 나눈다.
- **일반해의 방향을 틀림**: `x`를 `b/g`만큼 늘리면 `y`는 `a/g`만큼 **줄어듭니다**(부호가 반대).
- **`a·x + b·y = c`에서 `a`, `b` 중 0**: `b = 0`이면 `x = c/a`이고 `y`는 임의입니다. `a = b = 0`이면 `c = 0`일 때만 해가 있고 모든 쌍이 해입니다.
- **음수 입력**: 파이썬의 `//`는 내림이라 이 구현은 음수에서도 맞게 동작하지만, C++/Java의 나눗셈은 0 방향으로 잘려 음수에서 부호 처리가 달라집니다.
- **`mod_inverse`의 모듈러가 1**: 모든 수가 `0`과 합동이라 역원은 `0`입니다 (`x % 1 = 0`).
- **재귀 깊이**: 반복문 구현을 쓰면 신경 쓸 필요가 없습니다. 재귀 버전도 깊이가 `log`라 작습니다.

## 7. 변형과 응용

- **중국인의 나머지 정리**: 서로소가 아닌 모듈러까지 합치려면 이 알고리즘으로 `gcd`와 역원 계수를 구합니다. → [중국인의 나머지 정리](../chinese-remainder-theorem/)
- **모듈러 역원**: 이 알고리즘이 가장 일반적인 방법입니다. → [모듈러 역원](../../../lv2-intermediate/06-number-theory/modular-inverse/)
- **동전 문제(프로베니우스)**: 서로소인 `a`, `b`로 만들 수 없는 가장 큰 금액은 `ab − a − b`. `3, 5`이면 7.
- **원형에서의 이동**: `N`명이 원으로 앉아 `k`칸씩 뛰는 문제는 `k·s ≡ d (mod N)`.
- **세 개 이상의 수**: `gcd(a, b, c)`의 계수는 `gcd`를 이어서 구하며 계수를 곱해 갱신합니다.
- **분수의 베주 계수/스턴-브로콧 트리**: 연분수와 확장 유클리드는 같은 몫의 열을 씁니다.
