# Chinese Remainder Theorem (중국인의 나머지 정리)

> **한 줄 요약**: 여러 개의 합동식 `x ≡ r₁ (mod m₁)`, `x ≡ r₂ (mod m₂)`, …을 **하나의 합동식 `x ≡ r (mod lcm)`**으로 합친다. 모듈러가 서로소이면 해가 항상 있고 `mod (m₁·m₂·…)`에서 유일하다. 서로소가 아니어도 두 식씩 합치면 되고(해가 없을 수도 있다), 합칠 때마다 [확장 유클리드 호제법](../extended-euclidean-algorithm/)이 쓰인다.

## 1. 언제 쓰나 (문제 신호)

- "`x`를 `3`으로 나누면 `2`, `5`로 나누면 `3`, `7`로 나누면 `2` 남는다. `x`는?" (손자산경의 문제)
- 서로 다른 **주기를 가진 사건**이 동시에 일어나는 때: 카잉 달력 `<x:y>`, 날짜 계산(15·28·19년 주기)
- 큰 합성수 `m`에 대한 연산을 `m`의 **서로소인 인수**(소수의 거듭제곱)로 쪼개 각각 계산한 뒤 합치기 (`nCr mod m`, 큰 수의 거듭제곱)
- 서로 다른 소수 모듈러(`998244353`, `10⁹ + 7`)에서 구한 결과를 합쳐 **큰 정수를 복원**하기 (다항식 곱셈의 NTT 결과)
- "처음으로 둘이 동시에 만나는 시각" 같은 주기의 최소공배수 문제

## 2. 핵심 아이디어

**서로소일 때 (정리)**: `m₁, …, m_k`가 쌍마다 서로소이면 연립합동식 `x ≡ rᵢ (mod mᵢ)`은 `mod M = m₁⋯m_k`에서 **유일한 해**를 가집니다.

**두 식 합치기**: `x ≡ r₁ (mod m₁)`, `x ≡ r₂ (mod m₂)`를 합칩니다.

1. 첫 식의 모든 해는 `x = r₁ + m₁·t`. 이를 둘째 식에 넣으면 `m₁·t ≡ r₂ − r₁ (mod m₂)`.
2. `g = gcd(m₁, m₂)`일 때, 이 일차 합동식은 **`g | (r₂ − r₁)`일 때만** 해가 있다. 아니면 연립합동식 전체가 해가 없다.
3. 양변을 `g`로 나눠 `(m₁/g)·t ≡ (r₂ − r₁)/g (mod m₂/g)`. `m₁/g`와 `m₂/g`는 서로소라 역원이 있고, 그것은 확장 유클리드가 준다: `m₁·p + m₂·q = g`이면 `p`가 `m₁/g`의 `mod m₂/g` 역원이다.
4. `t = (r₂ − r₁)/g · p mod (m₂/g)`, 합친 결과는 `x ≡ r₁ + m₁·t (mod lcm(m₁, m₂))`, `lcm = m₁/g · m₂`.

식이 여러 개이면 **앞에서부터 하나씩 합쳐 나갑니다**(`crt`). 합쳐진 모듈러는 `lcm`이 되어 커집니다.

**서로소일 때의 고전적 공식**: `M = Πmᵢ`, `Mᵢ = M/mᵢ`, `Mᵢ⁻¹`을 `mod mᵢ`의 역원이라 하면

```
x ≡ Σ rᵢ · Mᵢ · (Mᵢ⁻¹ mod mᵢ)    (mod M)
```

항 `rᵢ·Mᵢ·Mᵢ⁻¹`이 `mod mᵢ`에서는 `rᵢ`, `mod mⱼ`(`j ≠ i`)에서는 `Mᵢ`가 `mⱼ`의 배수라 0이기 때문입니다. 같은 값이 나옵니다 (`crt_coprime`).

**Garner 알고리즘**: 서로 다른 소수 모듈러 `p₀, p₁, …`에서의 나머지로 정해지는 수 `x`를 직접 만들면 매우 커집니다. 대신 `x`를 **혼합 기수** `x = c₀ + c₁·p₀ + c₂·p₀p₁ + …`로 쓰고 자릿수 `cᵢ`를 앞에서부터 하나씩 구하면, `x mod (임의의 수)`를 큰 정수 없이 계산할 수 있습니다 (`garner`). 각 자릿수는 `cᵢ = (rᵢ − (이미 정한 자릿수의 기여)) · (p₀⋯pᵢ₋₁)⁻¹ mod pᵢ`.

## 3. 손으로 따라가기

### 손자산경의 문제: `x ≡ 2 (3)`, `x ≡ 3 (5)`, `x ≡ 2 (7)`

**방법 1: 두 식씩 합치기**

| 단계 | 합치는 식 | 계산 | 결과 |
|---|---|---|---|
| 1 | `x ≡ 2 (3)`, `x ≡ 3 (5)` | `x = 2 + 3t`, `3t ≡ 1 (mod 5)` → `t ≡ 2` | `x ≡ 8 (mod 15)` |
| 2 | `x ≡ 8 (15)`, `x ≡ 2 (7)` | `x = 8 + 15t`, `15t ≡ −6 ≡ 1 (mod 7)`, `15 ≡ 1`이라 `t ≡ 1` | `x ≡ 23 (mod 105)` |

**방법 2: 고전적 공식** (`M = 105`)

| `i` | `mᵢ` | `rᵢ` | `Mᵢ = M/mᵢ` | `Mᵢ⁻¹ mod mᵢ` | 항 `rᵢ·Mᵢ·Mᵢ⁻¹` |
|---|---|---|---|---|---|
| 1 | 3 | 2 | 35 | 2 (`35 ≡ 2`, `2·2 = 4 ≡ 1`) | 140 |
| 2 | 5 | 3 | 21 | 1 | 63 |
| 3 | 7 | 2 | 15 | 1 | 30 |

합 `140 + 63 + 30 = 233`, `233 mod 105 = 23`. 두 방법 모두 **23** (`23 = 3·7 + 2 = 5·4 + 3 = 7·3 + 2`).

### 서로소가 아닌 모듈러: `x ≡ 2 (6)`, `x ≡ 5 (9)`

`g = gcd(6, 9) = 3`, `5 − 2 = 3`은 3의 배수 → 해가 있다. `extended_gcd(6, 9) = (3, −1, 1)` (`6·(−1) + 9·1 = 3`)이므로 `p = −1`.

- `t = (5 − 2)/3 · (−1) mod (9/3) = −1 mod 3 = 2`
- `x = 2 + 6·2 = 14`, `lcm = 6·9/3 = 18` → **`x ≡ 14 (mod 18)`**

확인: `14 mod 6 = 2`, `14 mod 9 = 5`. 한 주기 `0..17`에서 해를 직접 찾아도 `14` 하나뿐입니다.

해가 없는 예: `x ≡ 1 (4)`, `x ≡ 2 (6)` — `gcd = 2`, `2 − 1 = 1`은 2의 배수가 아니므로 `crt_pair`가 `None`을 돌려줍니다. 두 식 모두 `x`의 홀짝을 정해 버리는데 서로 어긋나기 때문입니다 (`x ≡ 1 (4)`는 홀수, `x ≡ 2 (6)`은 짝수).

### 카잉 달력

해마다 `<x:y>`가 `<x+1:y+1>`로 바뀌고 `x`가 `M`을 넘으면 1로, `y`가 `N`을 넘으면 1로 돌아간다. 첫 해는 `<1:1>`이고 마지막 해는 `<M:N>`이다. `<x:y>`가 몇 번째 해인가? 해를 `k`라 하면 `k ≡ x (mod M)`, `k ≡ y (mod N)`이고 `1 ≤ k ≤ lcm(M, N)`.

| 입력 `M N x y` | 풀이 | 답 |
|---|---|---|
| `10 12 3 9` | `k ≡ 3 (10)`, `k ≡ 9 (12)`, `gcd = 2`, `9 − 3 = 6` ✓ → `k ≡ 33 (mod 60)` | **33** |
| `10 12 7 2` | `gcd = 2`, `2 − 7 = −5`는 홀수 → 해 없음 | **−1** |
| `13 11 5 6` | 서로소 → `k ≡ 83 (mod 143)` | **83** |

합동식의 해가 `0`이면 한 주기의 끝이라 해는 `lcm` (예: `<M:N>` 자체의 해는 `lcm`). `M = 40000`, `N = 39999`, `<40000:39999>`는 `40000 · 39999 = 1,599,960,000`번째 해입니다. 해를 하나씩 세면 불가능한 크기입니다.

### Garner: 두 소수에서 큰 수 복원

`x = 123456789012345678`을 `p₀ = 998244353`, `p₁ = 10⁹ + 7`로 나눈 나머지는 `(751949330, 148148162)`. 혼합 기수 `x = c₀ + c₁·p₀`:

- `c₀ = r₀ = 751949330`
- `c₁ = (r₁ − c₀) · p₀⁻¹ mod p₁ = 123673916`

`751949330 + 123673916 · 998244353 = 123456789012345678` — 원래 수가 나옵니다(`x < p₀·p₁ ≈ 9.98·10¹⁷`이어야 복원됨). `garner`는 이 자릿수들로 `x`를 만들지 않고 임의의 `mod`로 바로 줄입니다: `x mod (10⁹ + 9) = 901234595`, `x mod 12345 = 8808`, `x mod 1000 = 678` (이 환경에서 확인).

## 4. 구현

전체 코드는 [solution.py](solution.py)에 있습니다. 단독으로 실행되도록 `extended_gcd`를 포함합니다.

```python
def crt_pair(r1, m1, r2, m2):
    """x ≡ r1 (mod m1), x ≡ r2 (mod m2) → (x, lcm) 또는 None"""
    g, p, _ = extended_gcd(m1, m2)          # m1·p + m2·q = g
    if (r2 - r1) % g:                       # 해가 있을 조건
        return None
    lcm = m1 // g * m2
    t = (r2 - r1) // g * p % (m2 // g)      # (m1/g)·t ≡ (r2 - r1)/g  (mod m2/g)
    return (r1 + m1 * t) % lcm, lcm

def crt(remainders, moduli):
    x, lcm = 0, 1                           # 식이 없으면 모든 수가 해
    for r, m in zip(remainders, moduli):
        merged = crt_pair(x, lcm, r % m, m)
        if merged is None:
            return None
        x, lcm = merged
    return x, lcm
```

- `crt_coprime(remainders, moduli)`: 서로소일 때의 고전적인 공식. 서로소가 아니면 `ValueError`.
- `garner(remainders, moduli, mod)`: 서로소인 모듈러로 정해지는 수를 `mod`로 나눈 나머지.
- `calendar_year(m, n, x, y)`: 카잉 달력. 직접 실행하면 `T`와 `T`개의 `M N x y`를 받아 `<x:y>`가 몇 번째 해인지(없으면 -1) 출력합니다.
- 반환하는 `x`는 `0 ≤ x < lcm`이고 모든 해는 `x + lcm·k`입니다.

## 5. 복잡도와 입력 크기 가이드

- 식 하나를 합치는 데 **O(log m)**(확장 유클리드), `k`개 식은 **O(k log m)**. 공간 `O(1)`. `crt_coprime`은 `M = Πmᵢ`의 역원을 `k`번 구해 `O(k log m)`. `garner`는 **O(k²)**. ([복잡도 치트시트](../../../docs/complexity-cheatsheet.md))
- 이 환경에서 측정한 값입니다.

| 작업 | 시간 |
|---|---|
| `calendar_year(40000, 39999, 12345, 6789)` | 약 1.3μs |
| `crt`로 식 100개 (모듈러 `2ⁱ + 1`) | 약 1.1ms |

- 합쳐진 모듈러(`lcm`)는 곱처럼 빠르게 커집니다. 파이썬은 큰 정수가 자동이지만 C++/Java에서는 `lcm`이 `long long`을 넘지 않는지 확인하고 `m₁ · t`에 `__int128`을 쓰세요.
- 해가 `mod lcm`에서 유일하다는 것은 `lcm`이 커도 같습니다. `lcm`이 10¹⁸을 넘는 문제는 "해가 `[0, L)` 안에 있는가" 같은 조건으로 바뀌어 나옵니다.

## 6. 자주 하는 실수

- **모듈러가 서로소라고 가정**: 서로소가 아니면 `Mᵢ`의 역원이 없고 해가 아예 없을 수도 있습니다. `gcd`로 먼저 확인하세요 (`crt_pair`).
- **해가 있는지 확인하지 않음**: `(r₂ − r₁) % gcd ≠ 0`이면 해가 없습니다.
- **역원을 `mod m₂`로 구함**: `(m₁/g)`의 역원은 `mod (m₂/g)`입니다. `g > 1`일 때 `m₂`로 잡으면 틀립니다 (결과를 `lcm`으로 줄이면 우연히 맞는 경우가 있어 더 위험).
- **나머지가 음수이거나 모듈러 이상**: `r % m`으로 정규화합니다 (`crt`가 이미 합니다).
- **합친 `x`가 `lcm` 이상**: 마지막에 `% lcm`으로 `0 ≤ x < lcm`을 보장합니다.
- **카잉 달력에서 해가 0**: 합동식의 해가 `0`이면 마지막 해인 `lcm`을 답으로 해야 합니다 (연도는 1부터).
- **오버플로(C++/Java)**: `m₁ · t`, `Mᵢ · rᵢ`가 크다. `__int128` 또는 곱셈 함수.
- **Garner에서 모듈러가 서로소가 아님**: 혼합 기수 방식은 서로소가 필요합니다 (`ValueError`).

## 7. 변형과 응용

- **합성수 모듈러의 조합**: `m`을 소수의 거듭제곱들로 분해해 각각에서 `nCr`을 구하고 CRT로 합칩니다. `m`의 소인수가 작으면 뤼카 정리(Lv4 예정)를 함께 씁니다. → [조합 nCr mod p](../../../lv2-intermediate/06-number-theory/ncr-mod/)
- **서로 다른 소수에서의 NTT 결과 합치기**: 정수 계수 다항식의 곱셈을 `998244353` 등 여러 소수의 NTT로 구하고 Garner로 복원합니다 (Lv4 FFT/NTT).
- **RSA 복호화 가속**: `m = p·q`에서 `mod p`, `mod q` 따로 거듭제곱 후 CRT로 합치면 대략 4배 빠르다고 알려져 있습니다.
- **주기 문제**: 서로 다른 주기의 사건이 동시에 일어나는 첫 시각.
- **GCD 테이블 문제**: 수열 `aᵢ = gcd(x, i)`가 주어진 값과 같도록 `x`를 CRT로 구한다.
