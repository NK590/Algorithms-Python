# Convex Hull (볼록 껍질)

> **한 줄 요약**: 평면 위의 점들을 모두 감싸는 **가장 작은 볼록 다각형**(고무줄을 점들 주위에 걸었을 때의 모양)의 꼭짓점을 구한다. 점을 x 순으로 정렬한 뒤 왼쪽→오른쪽으로 아래 껍질, 오른쪽→왼쪽으로 위 껍질을 스택으로 만든다(앤드류의 단조 체인). 새 점이 마지막 두 점에 대해 **왼쪽으로 꺾이지 않으면 마지막 점을 버린다**. `O(n log n)`. 껍질을 구하면 둘레, 넓이, 가장 먼 두 점(회전하는 캘리퍼스)이 쉬워진다.

## 1. 언제 쓰나 (문제 신호)

- "점들을 모두 포함하는 **가장 작은 볼록 다각형**의 꼭짓점 수/넓이/둘레", "고무줄/울타리로 모든 나무를 둘러싸기"
- "**가장 먼 두 점**(지름)", "점 집합을 감싸는 최소 직사각형" — 껍질 위에서 회전하는 캘리퍼스
- "두 점 집합을 직선으로 **분리**할 수 있는가" — 두 껍질이 겹치지 않는가
- 점을 껍질 위의 점부터 한 겹씩 벗겨 내는 문제 (감옥 건설)
- 좌표 정수 10⁴~10⁹, 점 10⁴~10⁶개 (모든 점 쌍을 보는 `O(n²)`이 느릴 때)

## 2. 핵심 아이디어

**단조 체인 (Andrew's monotone chain)**

1. 점을 `(x, y)` 순으로 **정렬**하고 중복을 없앤다.
2. **아래 껍질**: 왼쪽에서 오른쪽으로 점을 하나씩 스택에 넣는다. 새 점 `p`를 넣기 전에, 스택의 마지막 두 점 `o, a`와 `p`가 **왼쪽으로 꺾이지 않으면**(`cross(o, a, p) ≤ 0`) `a`는 껍질 위의 점이 아니므로 버린다. (`a`가 `o`와 `p`를 잇는 선분 아래 또는 선 위에 있다.)
3. **위 껍질**: 오른쪽에서 왼쪽으로 같은 방식으로.
4. 두 체인을 이어 붙인다 (각 체인의 마지막 점은 다른 체인의 첫 점이므로 하나씩 뺀다). 결과는 **가장 왼쪽 아래 점에서 시작하는 반시계 방향**.

핵심은 [CCW](../ccw/)의 외적 하나입니다. 정수 좌표이므로 오차가 없습니다.

**일직선 위의 점**: `cross ≤ 0`으로 버리면 껍질의 **변 위의 점**이 빠지고(꼭짓점만 남음), `cross < 0`으로 버리면 변 위의 점도 남습니다 (`keep_collinear=True`). 문제의 정의에 따라 고릅니다. 모든 점이 한 직선 위이면 따로 처리해야 합니다 (양 끝 점만, 또는 정렬된 모든 점).

**왜 `O(n log n)`인가**: 정렬이 `O(n log n)`, 각 체인은 점마다 한 번 넣고 많아야 한 번 버리므로 `O(n)`.

**회전하는 캘리퍼스 (rotating calipers)**: 볼록 다각형의 **가장 먼 두 점**을 `O(h)`에 찾는다 (`h` = 껍질의 꼭짓점 수). 변 `(a, b)`마다 그 변에서 가장 먼 꼭짓점 `j`는 다음 변으로 갈 때 **한 방향으로만** 전진한다 (오른쪽으로 도는 평행한 지지선 한 쌍). `j`를 `cross(a, b, hull[j+1]) > cross(a, b, hull[j])`인 동안 전진시키고 `a`, `b`와 `j` 사이 거리를 후보로 쓴다. 가장 먼 두 점은 반드시 껍질의 꼭짓점이다.

### 무엇을 저장하고 어떻게 움직이나

점들을 좌표순으로 정렬하고 아래쪽·위쪽 경계를 차례로 만듭니다. 새 점을 붙였을 때 볼록한 회전 방향이 아니면 직전 경계점을 제거합니다. 경계의 공선점을 모두 포함할지 꼭짓점만 남길지 먼저 정합니다.

### 왜 이 방법이 맞는가

제거되는 점은 새 경계 선분의 안쪽에 놓여 전체를 감싸는 꼭짓점이 될 수 없습니다. 각 점이 한 번 추가되고 한 번 제거돼 정렬 이후는 O(n)입니다. 중복점과 모든 점이 공선인 경우에 출력 정책을 일관되게 적용해야 합니다.

### 작은 예제로 검산하기

정사각형 네 꼭짓점과 중심점을 넣으면 중심은 껍질에서 제외됩니다. 한 변의 중간점은 공선점 포함 정책에 따라 남거나 빠집니다. `<0`과 `<=0`의 차이는 단순 구현 취향이 아니라 출력할 경계점의 정의입니다.

## 3. 손으로 따라가기

### 점 8개: `(0,3) (1,1) (2,2) (4,4) (0,0) (1,2) (3,1) (3,3)`

정렬: `(0,0) (0,3) (1,1) (1,2) (2,2) (3,1) (3,3) (4,4)`.

**아래 껍질** (스택):

| 새 점 | 마지막 두 점과 `cross` | 동작 | 스택 |
|---|---|---|---|
| `(0,0)` | | 넣음 | `(0,0)` |
| `(0,3)` | | 넣음 | `(0,0) (0,3)` |
| `(1,1)` | `cross((0,0),(0,3),(1,1)) = −3` | `(0,3)` 버림 → 넣음 | `(0,0) (1,1)` |
| `(1,2)` | | 넣음 | `(0,0) (1,1) (1,2)` |
| `(2,2)` | `cross((1,1),(1,2),(2,2)) = −1`, 이어서 `cross((0,0),(1,1),(2,2)) = 0` | `(1,2)`, `(1,1)` 버림 → 넣음 | `(0,0) (2,2)` |
| `(3,1)` | `cross((0,0),(2,2),(3,1)) = −4` | `(2,2)` 버림 → 넣음 | `(0,0) (3,1)` |
| `(3,3)` | | 넣음 | `(0,0) (3,1) (3,3)` |
| `(4,4)` | `cross((3,1),(3,3),(4,4)) = −2` | `(3,3)` 버림 → 넣음 | `(0,0) (3,1) (4,4)` |

아래 껍질 `(0,0) (3,1) (4,4)`.

**위 껍질** (정렬의 역순 `(4,4) (3,3) (3,1) (2,2) (1,2) (1,1) (0,3) (0,0)`):

| 새 점 | 동작 | 스택 |
|---|---|---|
| `(4,4)`, `(3,3)`, `(3,1)` | 넣음 | `(4,4) (3,3) (3,1)` |
| `(2,2)` | `cross = −2`로 `(3,1)` 버림, `cross = 0`으로 `(3,3)` 버림 | `(4,4) (2,2)` |
| `(1,2)` | `cross = −2`로 `(2,2)` 버림 | `(4,4) (1,2)` |
| `(1,1)` | 넣음 | `(4,4) (1,2) (1,1)` |
| `(0,3)` | `cross = −1`로 `(1,1)` 버림, `cross = −5`로 `(1,2)` 버림 | `(4,4) (0,3)` |
| `(0,0)` | 넣음 | `(4,4) (0,3) (0,0)` |

위 껍질 `(4,4) (0,3) (0,0)`.

**결합**: `아래[:-1] + 위[:-1] = (0,0) (3,1) + (4,4) (0,3)` → **`[(0,0), (3,1), (4,4), (0,3)]`**, 꼭짓점 4개. 이 환경에서 넓이의 2배 20 (넓이 10), 둘레 약 13.45.

### 변 위의 점

`(0,0) (2,0) (2,2) (0,2)`에 `(1,1)`(안), `(1,0)`(아래 변 위)를 더한 점들의 껍질은 기본적으로 `[(0,0), (2,0), (2,2), (0,2)]`. `keep_collinear=True`이면 `(1,0)`도 포함됩니다.

### 가장 먼 두 점

위의 껍질에서 `(0,0)`과 `(4,4)`가 가장 멀고 거리의 제곱은 `32`. `rotating_calipers_diameter`는 변마다 가장 먼 꼭짓점을 따라 포인터 하나를 전진시키며 이 값을 `O(h)`에 찾습니다.

## 4. 구현

전체 코드는 [solution.py](solution.py)에 있습니다. 점은 `(x, y)` 정수 튜플입니다.

```python
def convex_hull(points, keep_collinear=False):
    unique = sorted(set(points))
    if len(unique) <= 1:
        return unique
    if all(cross(unique[0], unique[1], p) == 0 for p in unique):   # 모두 일직선
        return unique if keep_collinear else [unique[0], unique[-1]]

    def turns_wrong(o, a, b):                                      # a 를 버려야 하는가
        c = cross(o, a, b)
        return c < 0 if keep_collinear else c <= 0

    lower = []
    for p in unique:
        while len(lower) >= 2 and turns_wrong(lower[-2], lower[-1], p):
            lower.pop()
        lower.append(p)
    upper = []
    for p in reversed(unique):
        while len(upper) >= 2 and turns_wrong(upper[-2], upper[-1], p):
            upper.pop()
        upper.append(p)
    return lower[:-1] + upper[:-1]
```

- 점이 하나면 그 점, 두 개면 정렬된 두 점, 모두 일직선이면 양 끝 두 점(`keep_collinear`이면 모든 점).
- `polygon_area2(polygon)`(넓이의 2배, 반시계면 양수), `hull_perimeter(hull)`, `squared_distance(a, b)`.
- `rotating_calipers_diameter(points)`: `(거리의 제곱, 점 p, 점 q)`.
- 직접 실행하면 `N`과 `N`개의 점 `x y`를 받아 볼록 껍질을 이루는 점의 수(변 위의 점 제외)를 출력합니다.

## 5. 복잡도와 입력 크기 가이드

- **시간 O(n log n)** (정렬이 지배적), **공간 O(n)**. 회전하는 캘리퍼스는 껍질이 이미 있으면 **O(h)**. ([복잡도 치트시트](../../../docs/complexity-cheatsheet.md))
- 이 환경에서 측정한 값입니다(두 번 중 최소).

| 입력 | 시간 |
|---|---|
| 무작위 점 10⁵개 (좌표 ±10⁶, 껍질 꼭짓점 25개) | 0.17초 |
| 포물선 위의 점 2·10⁴개 (모두 꼭짓점) | 0.02초 |
| 원 모양 점 5·10⁴개 (정수로 반올림해 8,652개가 꼭짓점) | 0.07초 |
| 무작위 점 10⁵개의 지름 (껍질 + 캘리퍼스) | 0.17초 |

- 무작위 점의 껍질 꼭짓점은 매우 적습니다(좌표를 고르게 뿌리면 `O(log n)`). 정렬이 대부분의 시간입니다.
- 모든 쌍을 비교하는 `O(n²)`는 점 수천 개까지, 껍질 알고리즘은 10⁶개까지 몇 초에 됩니다.

## 6. 자주 하는 실수

- **일직선 점 처리 부호**: 꼭짓점만 원하면 `cross ≤ 0`(같은 직선이면 버림), 변 위의 점도 원하면 `cross < 0`. 반대로 쓰면 결과 개수가 달라집니다.
- **모든 점이 한 직선 위**: 아래·위 껍질이 같은 점들을 가지므로 합치면 꼭짓점이 중복됩니다. 이 구현은 먼저 모두 일직선인지 확인합니다.
- **중복 점**: `set`으로 제거하지 않으면 같은 점이 여러 번 껍질에 들어갑니다.
- **점이 1~2개**: 스택 조건 `len(...) ≥ 2`가 있어도 결과 조합이 어긋나므로 먼저 처리합니다.
- **정렬 기준**: `(x, y)` 사전순. x가 같은 점을 y 순으로 정렬하지 않으면 틀립니다.
- **껍질을 이을 때 마지막 점**: `lower[:-1] + upper[:-1]` (각 체인의 마지막 점은 다른 체인의 첫 점).
- **방향**: 이 구현은 반시계. 문제가 시계 방향이나 특정 시작점을 요구하면 맞춰 줍니다.
- **캘리퍼스 포인터 초기화/조건**: `cross(a, b, hull[j+1]) > cross(a, b, hull[j])` (엄격한 부등호). 평행한 변이 있으면 후보가 둘일 수 있어 양쪽 끝점과의 거리를 모두 봅니다.
- **껍질의 꼭짓점이 1~2개인 입력에 캘리퍼스**: 점 하나(거리 0)와 일직선(두 끝점)을 별도로 다룹니다.
- **거리 계산을 `sqrt`로**: 비교는 제곱 거리로 정수로 하고, 마지막에만 제곱근.
- **`O(n²)` 선물 포장 알고리즘(gift wrapping)을 큰 입력에**: 꼭짓점 수 `h`에 대해 `O(nh)`. 최악 `O(n²)`.

## 7. 변형과 응용

- **둘레와 넓이**: `hull_perimeter`, `polygon_area2 / 2`. 둘레에 반지름 `L`인 원을 더해 감싸는 울타리(맹독 방벽): `둘레 + 2πL`.
- **가장 먼 두 점**: 회전하는 캘리퍼스. 껍질 위의 평행한 지지선 한 쌍을 한 바퀴 돌린다.
- **최소 넓이 직사각형/최소 폭**: 같은 캘리퍼스로 변마다 가장 먼 점, 가장 왼쪽/오른쪽 점을 함께 추적한다.
- **껍질 벗기기(onion peeling)**: 껍질을 구하고 그 점들을 제거하고 반복.
- **두 점 집합의 분리 가능성**: 두 껍질이 겹치지 않는가. → [선분 교차](../segment-intersection/)
- **점이 껍질 안에 있는가**: 한 꼭짓점에서 부채꼴로 나눠 이진 탐색 `O(log h)`.
- **그래함 스캔(Graham scan)**: 가장 아래 점을 기준으로 각도순 정렬 후 스택. 같은 `O(n log n)`이지만 각도 정렬 때문에 구현이 번거롭다. → [CCW](../ccw/)의 `sort_by_angle`
- **볼록 껍질 트릭(CHT)**: 이름이 비슷하지만 DP 최적화 기법. → [볼록 껍질 트릭](../../07-dp-advanced/convex-hull-trick/)
