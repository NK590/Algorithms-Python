# 기하 (Geometry)

점과 선분과 다각형을 다루는 알고리즘입니다. 좌표가 **정수**인 문제의 거의 모든 판정은 [CCW](ccw/)의 외적 한 줄로 환원되고, 이 단원은 그 한 줄이 어떻게 선분 교차와 볼록 껍질로 이어지는지를 보여 줍니다. 부동소수점을 쓰지 않아 답이 정확합니다.

## 한눈에 비교

| 개념 | 푸는 것 | 핵심 도구 | 시간 |
|---|---|---|---|
| [CCW와 외적](ccw/) | 세 점의 방향, 다각형 넓이, 점이 다각형 안에? | 외적의 부호 | O(1) / O(n) |
| [선분 교차](segment-intersection/) | 두 선분이 만나는가, 교점, 그룹 | CCW 네 번 + 일직선 구간 비교 | 한 쌍 O(1), 모든 쌍 O(n²) |
| [볼록 껍질](convex-hull/) | 점들을 감싸는 최소 볼록 다각형, 지름 | 정렬 + 스택 + CCW, 회전하는 캘리퍼스 | O(n log n) |

## 문제 신호로 고르기

| 문제의 신호 | 선택 |
|---|---|
| "세 점의 방향", "다각형의 넓이", "점이 다각형 안/밖/경계", "각도순 정렬" | [CCW](ccw/) |
| "두 선분이 교차하는가", "교점의 좌표", "닿는 선분끼리 묶기" | [선분 교차](segment-intersection/) |
| "점들을 감싸는 울타리", "가장 먼 두 점", "고무줄 둘레" | [볼록 껍질](convex-hull/) |
| "두 점 집합을 직선으로 분리", "최소 직사각형" | [볼록 껍질](convex-hull/) + [선분 교차](segment-intersection/) |

## 기하 문제의 공통 원칙

- **정수만 쓴다**: `atan2`, 기울기 나눗셈, `float` 교점은 일직선·거의 일직선인 경우를 틀리게 합니다. 외적(정수)과 필요하면 `Fraction`을 쓰세요.
- **퇴화 경우를 먼저 생각한다**: 점이 1~2개, 모두 일직선, 같은 점이 여러 개, 길이 0인 선분, 끝점이 닿는 선분.
- **경계의 정의를 문제에서 확인한다**: 끝점이 닿는 것을 교차로 칠지, 변 위의 점을 껍질에 넣을지, 경계 위의 점을 "안"으로 볼지.
- **외적의 크기를 가늠한다**: 파이썬은 문제없지만 C++/Java는 좌표 `10⁹`에서 외적이 `long long` 한계(약 `9.2·10¹⁸`)에 가깝습니다.
