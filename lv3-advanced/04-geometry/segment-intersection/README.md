# 선분 교차 (Segment Intersection)

> **한 줄 요약**: 두 선분이 만나는지를 [CCW](../ccw/) 네 번으로 판정한다. 선분 `ab`의 양 끝점 `c`, `d`가 `ab`의 **서로 반대편(또는 선 위)**에 있고, 동시에 `a`, `b`가 `cd`의 서로 반대편(또는 선 위)에 있으면 교차한다. 네 점이 모두 한 직선 위에 있는 특수한 경우만 따로 **구간이 겹치는지** 본다. 교점은 분수로 정확하게 계산한다.

## 1. 언제 쓰나 (문제 신호)

- "두 선분이 **교차하는가**" (끝점이 닿는 것도 교차로 치는지 확인)
- "교차한다면 **교점의 좌표**" (겹치면 그 구간)
- 선분 `n`개를 **서로 닿는 것끼리 그룹**으로 묶기 (그룹 수, 가장 큰 그룹)
- 다각형의 변끼리 교차하는가(단순 다각형인가), 두 도형이 겹치는가, 점 집합을 직선으로 분리할 수 있는가
- 좌표가 정수이고 **정확한 판정**이 필요한 기하 문제 (기울기 나눗셈이나 `float`는 쓰지 않는다)

## 2. 핵심 아이디어

**방향 판정 네 개**: 선분 `ab`와 `cd`에 대해

```
d₁ = ccw(a, b, c)    d₂ = ccw(a, b, d)    d₃ = ccw(c, d, a)    d₄ = ccw(c, d, b)
```

- **일반적인 교차**: `d₁ ≠ d₂`이고 `d₃ ≠ d₄` (각 선분의 양 끝점이 상대 선분의 직선 양쪽에 있다).
- **0을 허용**하면 끝점이 다른 선분 위에 있거나 닿는 경우도 교차로 잡힌다: 조건은 `d₁·d₂ ≤ 0` 이고 `d₃·d₄ ≤ 0`.
- **네 점이 모두 한 직선 위**(`d₁ = d₂ = d₃ = d₄ = 0`)이면 위 식이 항상 성립해 버리므로, 두 선분을 그 직선에 투영한 구간이 겹치는지(`x` 범위와 `y` 범위가 모두 겹치는지)를 따로 본다.
- 길이 0인 선분(점)도 같은 식으로 처리된다.

**엄격한 교차 (`segments_properly_intersect`)**: `d₁·d₂ < 0`이고 `d₃·d₄ < 0`. 끝점이 닿거나 겹치는 경우는 제외한다.

**교점 계산**: `ab`를 `a + t·r` (`r = b − a`), `cd`를 `c + u·s` (`s = d − c`)로 쓰면 교점에서 `a + t·r = c + u·s`. 양변에 `s`와 외적을 취하면

```
t = (c − a) × s / (r × s)          교점 = a + t·r
```

`r × s ≠ 0`(평행이 아님)이면 `t`가 유일하다. 좌표가 정수라도 교점은 분수라서 `fractions.Fraction`으로 정확히 계산한다. `r × s = 0`이고 교차한다면 두 선분이 한 직선 위에서 겹치는 것이고, 사전순으로 `max(시작점)`부터 `min(끝점)`까지가 겹치는 구간이다 (한 점이면 닿는 경우).

**그룹 묶기**: 모든 쌍을 검사해 교차하면 [유니온 파인드](../../../lv2-intermediate/02-graph-algorithms/union-find/)로 합친다. `O(n²)`.

## 3. 손으로 따라가기

### 네 방향 값으로 판정

| 경우 | 선분 | `d₁` | `d₂` | `d₃` | `d₄` | 결과 |
|---|---|---|---|---|---|---|
| X 자 | `(0,0)-(2,2)`, `(0,2)-(2,0)` | + | − | − | + | `d₁d₂ < 0`, `d₃d₄ < 0` → **교차** (엄격) |
| T 자 | `(0,0)-(4,0)`, `(2,0)-(2,3)` | 0 | + | + | − | `d₁d₂ = 0 ≤ 0`, `d₃d₄ < 0` → **교차** (끝점이 선분 위) |
| 끝점이 닿음 | `(0,0)-(2,0)`, `(2,0)-(3,5)` | 0 | + | + | 0 | `d₁d₂ = 0`, `d₃d₄ = 0` → **교차** |
| 직선은 만나지만 선분은 아님 | `(0,0)-(1,1)`, `(2,0)-(3,5)` | − | + | + | + | `d₁d₂ < 0`이지만 `d₃d₄ > 0` → **교차 안 함** |
| 평행 | `(0,0)-(4,0)`, `(0,1)-(4,1)` | + | + | | | `d₁d₂ > 0` → **교차 안 함** |
| 한 직선 위, 겹침 | `(0,0)-(4,0)`, `(2,0)-(6,0)` | 0 | 0 | 0 | 0 | `x` 범위 `[0,4]`와 `[2,6]`이 겹침 → **교차** |
| 한 직선 위, 떨어짐 | `(0,0)-(4,0)`, `(5,0)-(6,0)` | 0 | 0 | 0 | 0 | `[0,4]`와 `[5,6]`이 안 겹침 → **교차 안 함** |

(빈 칸은 부호를 따질 필요 없이 앞 두 값만으로 판정이 끝난 경우. 값은 모두 [CCW](../ccw/)의 부호이고 이 환경에서 `cross`를 계산해 확인했다.)

### 교점 계산: `(0,0)-(1,3)`과 `(0,1)-(3,0)`

`r = (1, 3)`, `s = (3, −1)`, `r × s = 1·(−1) − 3·3 = −10`. `c − a = (0, 1)`, `(c − a) × s = 0·(−1) − 1·3 = −3`. `t = −3 / −10 = 3/10`. 교점 `= (0,0) + 3/10·(1,3) = (3/10, 9/10)`. 정수가 아닌 교점이 분수로 정확히 나옵니다.

일직선 위에서 겹치는 `(0,0)-(4,0)`과 `(2,0)-(6,0)`은 겹치는 구간 `((2,0), (4,0))`을, 끝점만 닿는 `(0,0)-(4,0)`과 `(4,0)-(6,0)`은 점 `(4, 0)` 하나를 돌려줍니다.

### 선분 그룹

선분 5개: `A=(1,1)-(5,5)`, `B=(1,5)-(5,1)`, `C=(6,6)-(7,7)`, `D=(0,0)-(1,0)`, `E=(1,0)-(2,5)`.

- `A`와 `B`는 `(3,3)`에서 교차, `D`와 `E`는 끝점 `(1,0)`에서 닿음, `E`와 `A`는 `(1.25, 1.25)`에서 교차.
- `C`는 직선 `y = x` 위에 있지만 `A`의 끝 `(5,5)`와 떨어져 있어 아무와도 닿지 않음.

그룹은 `{A, B, D, E}`, `{C}`로 **2개**, 가장 큰 그룹의 크기 **4**.

## 4. 구현

전체 코드는 [solution.py](solution.py)에 있습니다. 점은 `(x, y)` 정수 튜플.

```python
def segments_intersect(a, b, c, d):
    d1 = sign(cross(a, b, c)); d2 = sign(cross(a, b, d))
    d3 = sign(cross(c, d, a)); d4 = sign(cross(c, d, b))
    if d1 == d2 == d3 == d4 == 0:               # 네 점이 일직선: 투영한 구간이 겹치는가
        return (max(min(a[0], b[0]), min(c[0], d[0])) <= min(max(a[0], b[0]), max(c[0], d[0]))
                and max(min(a[1], b[1]), min(c[1], d[1])) <= min(max(a[1], b[1]), max(c[1], d[1])))
    return d1 * d2 <= 0 and d3 * d4 <= 0

def intersection(a, b, c, d):
    if not segments_intersect(a, b, c, d):
        return None
    r = (b[0] - a[0], b[1] - a[1]); s = (d[0] - c[0], d[1] - c[1])
    denominator = r[0] * s[1] - r[1] * s[0]     # r × s
    if denominator != 0:                        # 평행하지 않다: 한 점
        t = Fraction((c[0] - a[0]) * s[1] - (c[1] - a[1]) * s[0], denominator)
        return "point", (a[0] + t * r[0], a[1] + t * r[1])
    first, second = sorted([a, b]), sorted([c, d])  # 한 직선 위: 겹치는 구간
    low, high = max(first[0], second[0]), min(first[1], second[1])
    return ("point", (Fraction(low[0]), Fraction(low[1]))) if low == high else ("segment", (low, high))
```

- `segments_properly_intersect(a, b, c, d)`: 엄격한 교차. `segment_groups(segments)`: `(그룹 수, 가장 큰 그룹 크기)`.
- 직접 실행하면 두 줄(선분 `x1 y1 x2 y2`)을 받아 교차하면 `1`, 아니면 `0`을 출력합니다.

## 5. 복잡도와 입력 크기 가이드

- 선분 한 쌍은 **O(1)**, 모든 쌍의 그룹 묶기는 **O(n²)**, 공간 `O(n)`(유니온 파인드). ([복잡도 치트시트](../../../docs/complexity-cheatsheet.md))
- 이 환경에서 측정한 값입니다: 선분 1000개(약 50만 쌍)의 `segment_groups`는 0.59초. 따라서 쌍 전체를 검사하는 풀이는 `n ≤ 2000~3000` 정도까지입니다.
- 선분이 수만 개이고 "교차하는 쌍이 **하나라도** 있는가"만 묻는다면 스위핑으로 `O(n log n)`에 풀 수 있습니다 (샤모스-호이: x 순으로 훑으며 y 순서로 정렬된 선분 집합을 관리). 정렬된 집합이 필요해 이 저장소의 파이썬 구현은 다루지 않았습니다. 교차 쌍을 모두 나열하는 벤틀리-오트만은 `O((n + k) log n)`.

## 6. 자주 하는 실수

- **일직선 경우 누락**: `d₁d₂ ≤ 0 && d₃d₄ ≤ 0`만 쓰면 네 점이 한 직선 위일 때 떨어진 두 선분도 교차로 판정됩니다. 구간이 겹치는지 따로 확인합니다.
- **끝점이 닿는 경우**: 문제에 따라 교차로 칠지가 다릅니다 ("끝점이 닿는 것도 교차" → `≤ 0`, "엄격한 교차" → `< 0`).
- **기울기와 직선의 방정식**: 수직선에서 0으로 나누게 되고 분수 비교에 오차가 생깁니다. 외적만 쓰세요.
- **`float`로 교점 계산**: 정확한 출력이 필요하면 `Fraction`이나 분자·분모를 정수로 따로 계산합니다. 부동소수점으로는 `3/10`이 정확히 표현되지 않습니다.
- **바운딩 박스 검사만 믿음**: 박스가 겹쳐도 교차하지 않을 수 있습니다 (대각선 모양의 두 선분). 박스 검사는 일직선 경우에만 필요합니다.
- **길이 0인 선분(점)**: 외적이 0이 되어 일직선 경우로 흘러가며, 바운딩 박스 검사가 "점이 선분 위에 있는가"를 올바르게 알려 줍니다. 이 구현은 점도 처리하지만 다른 구현이 그런지 확인하세요.
- **교점 표현**: 교점이 한 점인지(`"point"`) 겹치는 구간인지(`"segment"`) 구분하지 않고 하나만 출력하면 문제의 요구와 다를 수 있습니다.
- **오버플로(C++/Java)**: 외적이 `long long`을 넘을 수 있는 좌표 범위인지 확인하세요 ([CCW](../ccw/)).

## 7. 변형과 응용

- **그룹 묶기**: 닿은 선분끼리 같은 그룹 (유니온 파인드). 그룹 수와 최대 크기.
- **다각형이 단순한가(변이 서로 교차하지 않는가)**: 인접하지 않은 변의 모든 쌍을 검사 (`O(n²)`), 또는 스위핑.
- **점 집합의 분리 가능성**: 두 점 집합의 볼록 껍질이 서로 교차하지 않는가 (껍질의 변끼리 교차 + 점 포함 검사). → [볼록 껍질](../convex-hull/)
- **교점 개수 세기**: 선분이 수직/수평뿐이면 스위핑과 [펜윅 트리](../../01-range-query-structures/fenwick-tree/)로 `O(n log n)`.
- **점과 선분 사이의 거리, 두 선분 사이의 최소 거리**: 교차하면 0, 아니면 끝점과 선분 사이 거리의 최솟값.
- **반평면 교집합, 다각형 클리핑**: 직선과 선분의 교점을 반복해서 구한다.
