# CCW (반시계 판정)와 외적

> **한 줄 요약**: 세 점 `a → b → c`가 **왼쪽으로 꺾이는지(반시계), 오른쪽으로 꺾이는지(시계), 일직선인지**를 외적의 부호 하나로 판정한다. 좌표가 정수면 외적도 정수라서 **부동소수점 오차 없이** 정확하다. 선분 교차, 볼록 껍질, 다각형 넓이, 점이 다각형 안에 있는가 같은 기하 문제 대부분이 이 한 줄에서 출발한다.

## 1. 언제 쓰나 (문제 신호)

- "세 점이 **반시계/시계/일직선**인가" (CCW 판정 자체가 문제)
- **선분이 교차**하는가 → [선분 교차](../segment-intersection/)
- 점들을 감싸는 **볼록 껍질** → [볼록 껍질](../convex-hull/)
- **다각형의 넓이** (신발끈 공식), 다각형이 볼록인지, 점이 다각형 **안/밖/경계**인지
- 점들을 한 점 둘레의 **각도순**으로 정렬해야 할 때 (`atan2`를 쓰고 싶은 상황)
- 좌표가 10⁹ 이하 정수이고 **정확한 답**이 필요한 모든 기하 문제

## 2. 핵심 아이디어

**외적(cross product)**: 점 `o`에서 `a`로 가는 벡터와 `o`에서 `b`로 가는 벡터의 외적

```
cross(o, a, b) = (a − o) × (b − o) = (aₓ − oₓ)(b_y − o_y) − (a_y − o_y)(bₓ − oₓ)
```

- **양수**: `o → a → b`가 **반시계**(왼쪽으로 꺾임) — `b`가 직선 `oa`의 왼쪽에 있다
- **음수**: **시계**(오른쪽으로 꺾임)
- **0**: 세 점이 **한 직선 위**
- **절댓값 = 세 점이 이루는 삼각형 넓이의 2배** (넓이를 정수로 유지하려고 2배로 다룬다)

`ccw(a, b, c)`는 이 부호를 `1 / −1 / 0`으로 돌려줍니다. 성질: 점을 순환(`a→b→c→a`)해도 같고, 두 점을 바꾸면 부호가 바뀌며, 평행 이동에 불변이고 크기를 `k`배 하면 `k²`배.

**왜 `atan2`를 쓰지 않는가**: 실수 오차 때문에 일직선이거나 거의 일직선인 경우를 정확히 가릴 수 없다. 정수 외적은 오차가 없다.

**다각형의 넓이: 신발끈 공식**: 꼭짓점이 순서대로 주어질 때 `2·넓이 = Σ (xᵢ·yᵢ₊₁ − xᵢ₊₁·yᵢ)` (끝에서 첫 점으로 돌아간다). 반시계면 양수, 시계면 음수. 원점에서 각 변으로 만든 삼각형들의 부호 있는 넓이의 합이다.

**볼록 다각형 판정**: 모든 연속한 세 점이 **같은 방향**으로 꺾이면 볼록 (일직선인 세 점을 허용할지는 문제에 따라). 단, 변이 교차하지 않는 단순 다각형이어야 한다 (별 모양처럼 여러 번 감기는 도형은 같은 방향으로만 꺾여도 볼록이 아니다).

**점이 다각형 안에 있는가: 반직선 교차**: 점에서 `+x` 방향으로 반직선을 쏘아 다각형의 변과 만나는 횟수가 **홀수**면 안. 경계 위인지는 먼저 `on_segment`로 확인. 꼭짓점이 반직선 위에 걸리는 경우는 "변이 점의 높이를 가로지른다"를 `(a_y > p_y) != (b_y > p_y)`(한쪽 끝점만 포함)로 적어 꼭짓점을 두 번 세지 않는다.

**각도순 정렬**: 기준점을 중심으로 먼저 위쪽 반평면(+x 축 포함)과 아래쪽 반평면으로 나누고, 같은 반평면 안에서는 외적의 부호로 비교한다 (`cross > 0`이면 앞). 각도가 같으면 가까운 점이 먼저.

## 3. 손으로 따라가기

### CCW: `(1, 1) → (5, 5) → (7, 3)`

`a − o = (4, 4)`, `b − o = (6, 2)` → `4·2 − 4·6 = 8 − 24 = −16`. 음수이므로 **시계**(오른쪽으로 꺾임): `ccw = −1`. 위 대각선으로 올라갔다가 오른쪽 아래로 꺾이기 때문입니다. 그 반대 순서 `(1,1) → (7,3) → (5,5)`는 `+16`, `(0,0) → (1,1) → (3,3)`은 `0`(일직선).

### 신발끈 공식: 'ㄴ'자 다각형 `(0,0), (4,0), (4,1), (1,1), (1,3), (0,3)`

| `i` | 점 `i` → 점 `i+1` | `xᵢ·yᵢ₊₁ − xᵢ₊₁·yᵢ` |
|---|---|---|
| 0 | `(0,0) → (4,0)` | `0·0 − 4·0 = 0` |
| 1 | `(4,0) → (4,1)` | `4·1 − 4·0 = 4` |
| 2 | `(4,1) → (1,1)` | `4·1 − 1·1 = 3` |
| 3 | `(1,1) → (1,3)` | `1·3 − 1·1 = 2` |
| 4 | `(1,3) → (0,3)` | `1·3 − 0·3 = 3` |
| 5 | `(0,3) → (0,0)` | `0·0 − 0·3 = 0` |

합계 12 → 넓이 `12 / 2 = 6` (가로 4 × 세로 1 = 4, 세로 2 × 가로 1 = 2). 합이 양수이므로 점들이 반시계 순서. 이 다각형은 오목이라 `is_convex_polygon`은 `False`. 직사각형 `(0,0),(4,0),(4,3),(0,3)`은 넓이의 2배가 24이고 `True`.

### 점이 다각형 안에 있는가: 'ㄴ'자 `(0,0), (6,0), (6,2), (2,2), (2,6), (0,6)`

넓이 20. 점 `(1, 4)`에서 `+x` 방향으로 반직선을 쏘면 변 `(2,2)–(2,6)`과 한 번 만나 **홀수 → 안**. `(4, 1)`은 변 `(6,0)–(6,2)`와 한 번 → **안**. `(3, 3)`은 `x ≥ 3`에서 만나는 변이 없어 0번 → **밖**. `(2, 2)`(안쪽 모서리)와 `(3, 2)`는 변 위라 **경계**.

이 환경에서 모든 정수점을 세어 보면 안쪽 9개, 경계 24개입니다. 피크의 정리 `넓이 = I + B/2 − 1`에 넣으면 `9 + 12 − 1 = 20`으로 신발끈 공식의 결과와 일치합니다.

### 각도순 정렬

기준 `(0, 0)`에서 `[(1,1), (−1,1), (0,−2), (2,0), (−3,−3), (1,0), (0,3)]`를 반시계 방향(+x 축부터)으로 정렬하면 `[(1,0), (2,0), (1,1), (0,3), (−1,1), (−3,−3), (0,−2)]`. `(1,0)`과 `(2,0)`은 각도가 같아 가까운 `(1,0)`이 먼저입니다.

## 4. 구현

전체 코드는 [solution.py](solution.py)에 있습니다. 점은 `(x, y)` 정수 튜플입니다.

```python
def cross(o, a, b):
    return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])

def ccw(a, b, c):                      # 1: 반시계, -1: 시계, 0: 일직선
    value = cross(a, b, c)
    return (value > 0) - (value < 0)

def polygon_area2(points):             # 넓이의 2 배 (반시계면 양수)
    total = 0
    for i in range(len(points)):
        x1, y1 = points[i]
        x2, y2 = points[(i + 1) % len(points)]
        total += x1 * y2 - x2 * y1
    return total

def point_in_polygon(p, polygon):      # "inside" | "boundary" | "outside"
    inside = False
    for i in range(len(polygon)):
        a, b = polygon[i], polygon[(i + 1) % len(polygon)]
        if on_segment(p, a, b):
            return "boundary"
        if (a[1] > p[1]) != (b[1] > p[1]):                       # 변이 p 의 높이를 가로지른다
            if (b[1] > a[1]) == (cross(a, b, p) > 0):            # 교점이 p 의 오른쪽
                inside = not inside
    return "inside" if inside else "outside"
```

- `triangle_area2`, `is_convex_polygon(points, allow_collinear=False)`, `on_segment(p, a, b)`, `point_in_triangle(p, a, b, c)`, `sort_by_angle(points, origin=(0, 0))`.
- 직접 실행하면 세 점을 받아 반시계면 `1`, 시계면 `-1`, 일직선이면 `0`을 출력합니다.

## 5. 복잡도와 입력 크기 가이드

- `cross`, `ccw`, `on_segment`, `point_in_triangle`: **O(1)**. 다각형 넓이·볼록 판정·점의 위치: **O(n)**. 각도순 정렬: **O(n log n)**. 공간 `O(1)`. ([복잡도 치트시트](../../../docs/complexity-cheatsheet.md))
- 파이썬은 정수가 임의 정밀도라 외적이 커져도 오버플로가 없습니다. C++/Java에서는 좌표가 최대 `M`이면 외적이 `(2M)² · 2`까지 커지므로 `M = 10⁹`이면 `8·10¹⁸`로 `long long`(약 `9.2·10¹⁸`)의 한계에 가깝습니다. `M`이 더 크면 `__int128`을 쓰세요.
- 점이 10⁵~10⁶개인 문제에서는 각 판정이 파이썬 함수 호출 한 번이라 수십만 번까지는 문제없습니다.

## 6. 자주 하는 실수

- **부동소수점·`atan2` 사용**: 일직선이거나 거의 일직선인 경우를 틀립니다. 정수 외적만 쓰세요.
- **점의 순서**: `ccw(a, b, c)`와 `ccw(a, c, b)`는 부호가 반대입니다. `a → b → c` 순서를 문제의 정의와 맞추세요.
- **`y`축 방향**: 화면 좌표(아래로 증가)에서는 반시계/시계의 직관이 뒤집힙니다. 수식은 항상 수학 좌표계 기준입니다.
- **다각형의 방향**: 신발끈 공식의 부호가 음수이면 시계 방향입니다. 넓이는 `abs(...) / 2`로 구하고 방향이 필요하면 부호를 봅니다.
- **넓이 출력의 `.5`**: 정수 좌표 다각형의 넓이는 `.0` 또는 `.5`만 가능합니다. 2배 값(`area2`)을 정수로 구해 마지막에 `area2 // 2`와 `area2 % 2`로 출력하면 오차가 없습니다.
- **마지막 점 → 첫 점**: 신발끈 공식에서 `(i + 1) % n`을 빼먹으면 변 하나가 빠집니다.
- **볼록 판정에서 일직선**: "엄격한 볼록"이면 한 직선 위의 세 점을 거부하고, 아니면 허용합니다. 문제의 정의를 확인하세요.
- **각도 정렬에서 반평면 구분**: 외적만으로 비교하면 `(1, 0)`과 `(−1, 0)`처럼 반대 방향이 같다고 판정됩니다. 먼저 위/아래 반평면으로 나눕니다.
- **점이 다각형 안인지 판정에서 꼭짓점이 반직선에 걸림**: `(a_y > p_y) != (b_y > p_y)`처럼 한쪽 끝점만 포함하는 규칙을 일관되게 써야 합니다.
- **중복 점·길이 0인 선분**: `cross`가 0이 되어 일직선으로 판정됩니다. 문제에서 허용하는지 확인하세요.

## 7. 변형과 응용

- **선분 교차**: 두 선분의 끝점들에 대한 `ccw` 네 개로 판정. → [선분 교차](../segment-intersection/)
- **볼록 껍질**: 점들을 정렬한 뒤 `ccw`로 "왼쪽으로 꺾이지 않으면 버린다". → [볼록 껍질](../convex-hull/)
- **피크의 정리**: 격자점을 꼭짓점으로 하는 단순 다각형의 넓이 `A = I + B/2 − 1` (`I` = 내부 격자점, `B` = 경계 격자점). 경계점 수는 각 변의 `gcd(|dx|, |dy|)`의 합.
- **점과 직선/선분 사이의 거리**: 외적의 절댓값을 선분의 길이로 나눈다.
- **볼록 다각형 안의 점 판정을 `O(log n)`에**: 한 꼭짓점에서 부채꼴로 나눠 이진 탐색.
- **회전하는 캘리퍼스**: 볼록 다각형의 지름, 최소 폭. → [볼록 껍질](../convex-hull/)
- **반평면 교집합**: 각도순 정렬 + 덱 (Lv4).
