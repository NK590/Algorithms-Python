# 고급 문자열 (Advanced Strings)

[KMP](../../lv2-intermediate/07-strings/kmp/)와 [트라이](../../lv2-intermediate/07-strings/trie/)로 "한 패턴 찾기", "단어 사전 다루기"를 배운 다음 단계입니다. 이 단원은 **문자열 안의 구조 전체**를 한 번에 계산해 두는 도구들입니다: 접두사와의 일치 길이(Z), 모든 중심의 회문(매내처), 여러 패턴을 동시에(아호-코라식), 모든 접미사의 정렬 순서(접미사 배열).

## 한눈에 비교

| 개념 | 푸는 것 | 핵심 도구 | 시간 |
|---|---|---|---|
| [Z 알고리즘](z-algorithm/) | 각 위치와 전체 문자열의 최장 공통 접두사, 주기, 테두리, 패턴 찾기 | 가장 오른쪽 일치 구간 `[l, r)`의 재활용 | O(n) |
| [매내처](manacher/) | 모든 중심의 가장 긴 회문, 회문 개수, 구간 회문 질의 | 가장 오른쪽 회문의 거울 대칭 | O(n) |
| [아호-코라식](aho-corasick/) | 여러 패턴의 동시 검색, 등장 횟수, 금지 문자열 DP | 트라이 + 실패 링크 + 출력 링크 | 구축 O(패턴 길이 합), 탐색 O(본문 + 찾은 개수) |
| [접미사 배열과 LCP](suffix-array-lcp/) | 서로 다른 부분 문자열, 가장 긴 반복/공통 부분 문자열, 패턴 이진 탐색 | 접두사 배가법 + 카사이 | O(n log² n) (이 구현), LCP O(n) |

## 문제 신호로 고르기

| 문제의 신호 | 선택 |
|---|---|
| "본문에서 패턴 **하나**가 나오는 위치", "문자열이 **반복**인가/최소 주기", "접두사이면서 접미사" | [KMP](../../lv2-intermediate/07-strings/kmp/) 또는 [Z](z-algorithm/) |
| 위치마다 "접두사와 몇 글자 일치하나"가 필요 | [Z](z-algorithm/) |
| "**회문**인 부분 문자열", 구간이 회문인가 질의 | [매내처](manacher/) |
| "패턴이 **수천 개**, 본문은 길다", "금지 단어 포함 여부", "금지 문자열을 피하는 문자열 수" | [아호-코라식](aho-corasick/) |
| "서로 다른 부분 문자열의 수", "두 번 이상 나오는 가장 긴 부분 문자열", "두 문자열의 가장 긴 공통 부분 문자열" | [접미사 배열과 LCP](suffix-array-lcp/) |
| 본문이 고정이고 패턴이 계속 바뀐다 | [접미사 배열](suffix-array-lcp/) (`O(m log n)` 검색) |
| 단순히 "문자열 안에 부분 문자열이 있나" (파이썬) | 내장 `in` / `str.find` — 전부 C로 구현되어 위 방법들보다 훨씬 빠르다 |

## 개념 사이의 관계

- [Z 알고리즘](z-algorithm/)과 [KMP](../../lv2-intermediate/07-strings/kmp/)는 서로 변환할 수 있습니다. Z는 "이 위치의 접미사가 접두사와 얼마나 같은가", KMP의 `π`는 "이 위치까지의 접두사가 접미사와 얼마나 같은가"입니다.
- [아호-코라식](aho-corasick/)은 KMP를 트라이 위로 옮긴 것이고, 패턴이 하나면 KMP와 같습니다.
- [매내처](manacher/)와 [Z](z-algorithm/)는 모두 "가장 오른쪽까지 간 구간을 기억해 재활용"하는 같은 기법입니다. 비교를 성공할 때마다 오른쪽 끝이 밀린다는 점이 선형 시간의 근거입니다.
- [접미사 배열](suffix-array-lcp/)은 Z가 못 하는 "임의의 두 접미사"의 공통 길이를 줍니다. 대신 구축이 더 비싸고(`O(n log² n)`) 구현이 깁니다.

## 문자열 문제의 공통 원칙

- **입력을 정확히 읽는다**: 공백이 들어 있는 줄이면 `strip()`이 아니라 `rstrip("\n")`이 필요할 수 있습니다. 큰 입력은 `sys.stdin.buffer.read().split()` 하나로 읽습니다.
- **구분자(sentinel)는 입력에 나올 수 없는 값**: 패턴과 본문을 이어 붙이는 기법(Z, 접미사 배열)은 구분자가 곧 정확성입니다. 이 단원의 구현은 `None`이나 코드 0 같은 값을 쓰도록 되어 있습니다.
- **파이썬 내장이 이길 때를 안다**: 하나의 문자열을 찾는 것은 `str.find`가 가장 빠릅니다. 이 단원의 알고리즘은 **숫자 리스트**, **배열 자체가 필요한 문제**, **여러 패턴**, **부분 문자열 통계**에서 가치가 있습니다.
- **0부터 vs 1부터**: 위치를 출력하는 문제는 대부분 1부터입니다.
- **같은 글자 반복 입력을 시험한다**: `"aaaa…a"`가 대부분 알고리즘의 최악 입력입니다.
