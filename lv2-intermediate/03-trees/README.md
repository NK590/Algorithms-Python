# 트리 (Trees)

트리 구조를 이용하는 자료구조와 알고리즘을 다룹니다. 이진 탐색 트리는 **값을 정렬된 구조로 보관**하고, 트리 DP와 트리의 지름은 **트리라는 그래프의 성질**(사이클 없음, 경로가 하나뿐)을 이용합니다.

## 한눈에 비교

| 개념 | 하는 일 | 핵심 | 시간 |
|---|---|---|---|
| [이진 탐색 트리](binary-search-tree/) | 값을 넣고 빼며 검색, 순서 질의(k번째, 순위, 다음 값) | 왼쪽 < 키 < 오른쪽, 중위 순회 = 정렬 | 평균 O(log n), 최악 O(n) |
| [트리 DP](tree-dp/) | 서브트리의 답을 자식들의 답으로 계산 (독립 집합, 정점 덮개, 지배 집합) | 루트를 정하고 후위 순서로 `dp[v][상태]` | O(n) |
| [트리의 지름](tree-diameter/) | 가장 먼 두 정점 사이의 거리, 이심률, 중심 | 아무 정점에서 가장 먼 정점을 찾고 거기서 다시 | O(n) |

## 고르는 기준

| 문제 상황 | 선택 |
|---|---|
| 값을 동적으로 넣고 빼며 순서 질의 | [이진 탐색 트리](binary-search-tree/) (또는 정렬 리스트 + `bisect`) |
| 트리에서 정점/간선을 고르는데 인접 제약이 있다 | [트리 DP](tree-dp/) |
| 서브트리 단위로 답을 합친다 | [트리 DP](tree-dp/) |
| 트리에서 가장 먼 두 정점, 중심, 최소 높이 루트 | [트리의 지름](tree-diameter/) |
| 그래프에 사이클이 있다 | 트리가 아니다 → [그래프 알고리즘](../02-graph-algorithms/), [SCC](../../lv3-advanced/03-graph-advanced/scc/) |

## 파이썬에서의 주의

- **재귀를 피하세요.** 트리가 사슬 모양이면 깊이가 n이라 기본 재귀 한도(1000)를 넘습니다. 이 그룹의 구현은 모두 BFS 순서나 스택으로 반복문입니다.
- 트리는 **간선 n−1개의 연결 그래프**입니다. 입력이 무방향이면 부모 방향 간선을 자식으로 오해하지 않도록 방문 표시를 하세요.
