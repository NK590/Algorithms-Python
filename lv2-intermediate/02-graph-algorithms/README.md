# 그래프 알고리즘 (Graph Algorithms)

그래프 문제를 푸는 도구들입니다. 연결을 합치고 확인하는 **유니온 파인드**, 선후 관계를 한 줄로 세우는 **위상 정렬**, 모든 정점을 최소 비용으로 잇는 **최소 신장 트리**(크루스칼·프림), 정점을 두 집합으로 나누는 **이분 그래프** 판별을 다룹니다.

## 한눈에 비교

| 알고리즘 | 해결하는 문제 | 그래프 | 시간 복잡도 |
|---|---|---|---|
| [유니온 파인드](union-find/) | 같은 그룹인가, 그룹 합치기, 사이클 판별 | 무방향 (간선이 추가됨) | 연산당 거의 O(1) |
| [위상 정렬](topological-sort/) | 선후 관계를 지키는 순서, 사이클 판별, DAG DP | **방향 비순환** | O(V+E) |
| [크루스칼](kruskal/) | 최소 신장 트리 (간선을 가중치순으로) | 무방향 가중치 | O(E log E) |
| [프림](prim/) | 최소 신장 트리 (정점에서 뻗어 나가며) | 무방향 가중치 | O(E log V), 밀집은 O(V²) |
| [이분 그래프](bipartite-graph/) | 두 집합으로 나눌 수 있는가, 홀수 사이클 | 무방향 | O(V+E) |

## 고르는 기준

| 문제 상황 | 선택 |
|---|---|
| "같은 그룹인가?" 질의와 "합치기"가 번갈아 | **유니온 파인드** |
| 간선을 하나씩 추가할 때 처음 사이클이 생기는 순간 | **유니온 파인드** |
| 모든 정점을 최소 비용으로 잇기 | **크루스칼** (희소 그래프, 간선 목록) / **프림** (밀집 그래프) |
| 정점을 K개 그룹으로 나누는 최소 비용 | 크루스칼을 K개 남을 때까지 |
| "A를 하려면 B를 먼저" 선후 관계 | **위상 정렬** (사이클이면 불가능) |
| 선후 관계가 있는 작업의 최소 소요 시간 | 위상 정렬 + DP |
| 두 팀으로 나누기, 두 가지 색으로 칠하기 | **이분 그래프** (BFS 2-색칠) |

## 서로의 관계

- **크루스칼은 유니온 파인드 위에서 동작**합니다. 사이클 판별이 곧 "두 끝점이 이미 같은 집합인가"입니다.
- **프림은 다익스트라와 같은 힙 틀**입니다. 힙의 키만 "누적 거리"에서 "간선 하나의 가중치"로 바뀝니다. → [다익스트라](../01-shortest-path/dijkstra/)
- **이분 그래프는 유니온 파인드로도** 판별할 수 있습니다 (정점당 노드 두 개). 간선이 동적으로 추가되는 경우에 편리합니다.
- **위상 정렬은 [칸 알고리즘](topological-sort/)(BFS 스타일)과 DFS 후위 순서** 두 가지 구현이 있고, 둘 다 사이클을 판별합니다.

## 읽는 순서

1. [유니온 파인드](union-find/): 가장 기본이 되는 자료구조
2. [크루스칼](kruskal/) → [프림](prim/): 최소 신장 트리의 두 접근
3. [위상 정렬](topological-sort/): 방향 그래프의 순서
4. [이분 그래프](bipartite-graph/): 두 집합으로 나누기
