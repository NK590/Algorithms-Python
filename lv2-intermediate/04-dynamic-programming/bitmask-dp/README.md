# Bitmask DP (비트마스크 DP)

> **한 줄 요약**: "지금까지 **어떤 원소들을 썼는가**"가 상태일 때, 그 집합을 정수 하나(비트마스크)로 표현해 `dp[mask][...]`를 만든다. 원소 수 n이 20 이하일 때 외판원 순회, 할당 문제, 해밀턴 경로 문제를 O(2ⁿ·poly(n))에 푼다.

## 1. 언제 쓰나 (문제 신호)

- n ≤ 16~20이고 "**모든 원소를 정확히 한 번씩** 방문/배정/사용"해야 한다
- **방문한 집합**이 다음 선택에 영향을 준다 (이미 방문한 곳은 못 간다)
- n!을 줄이고 싶다: 순열을 모두 시도하면 20! ≈ 2.4×10¹⁸이지만 2²⁰ = 100만이다
- 외판원 순회(TSP), n명에게 n개의 일 배정(할당 문제), 해밀턴 경로/사이클의 수
- 격자의 한 줄을 비트로 표현해 줄 단위로 DP(프로파일 DP)하는 문제

## 2. 핵심 아이디어

[비트마스크](../../../lv1-elementary/09-bit-manipulation/bitmask/)로 집합을 정수로 바꾼 뒤, 그 정수를 DP의 인덱스로 씁니다.

> `dp[mask][last]` = 집합 `mask`의 원소를 한 번씩 거치고 마지막에 `last`에 있을 때의 최솟값(또는 경우의 수)

**순서가 아니라 집합**이 상태이므로 n!개의 순열이 `2ⁿ·n`개의 상태로 합쳐집니다. 같은 집합을 어떤 순서로 방문했든, 마지막 위치만 같다면 이후의 선택은 동일하기 때문입니다.

### 외판원 순회 (TSP)

0번 도시에서 출발해 모든 도시를 한 번씩 거치고 0번으로 돌아오는 최소 비용.

```
dp[1][0] = 0                                  # 0번만 방문, 지금 0번
dp[mask | (1<<k)][k] = min( dp[mask][j] + dist[j][k] )    (j in mask, k not in mask)
답 = min over j ( dp[full][j] + dist[j][0] )
```

### 할당 문제

n명에게 n개의 일을 하나씩. `dp[mask]` = "앞의 `popcount(mask)`명이 `mask`의 일을 맡았을 때의 최소 비용". 다음 사람(번호 = `popcount(mask)`)이 아직 안 맡은 일을 하나 고릅니다. 마지막 위치가 필요 없어 상태가 `2ⁿ`개뿐입니다.

### 해밀턴 경로의 수

`dp[mask][j]` = `mask`를 한 번씩 지나며 `j`에서 끝나는 경로의 수. 간선이 있는 이웃으로만 이동합니다. 답은 `Σ dp[full][j]`.

## 3. 손으로 따라가기

도시 4개, 비용 행렬 (비대칭):

```
        0   1   2   3
  0  [  0, 10, 15, 20 ]
  1  [  5,  0,  9, 10 ]
  2  [  6, 13,  0, 12 ]
  3  [  8,  8,  9,  0 ]
```

가능한 순회 6가지 중 최소는 **35**입니다. `0 → 1 → 3 → 2 → 0`: `10 + 10 + 9 + 6 = 35`.

DP로는 방문 집합이 커지는 순서로 채웁니다. (집합은 비트마스크, `{0,1}`은 `0011₂`)

| mask (집합) | 끝 `last` | `dp[mask][last]` | 유도 |
|---|---|---|---|
| `{0}` | 0 | 0 | 시작 |
| `{0,1}` | 1 | 10 | `0 → 1` |
| `{0,2}` | 2 | 15 | `0 → 2` |
| `{0,3}` | 3 | 20 | `0 → 3` |
| `{0,1,3}` | 3 | 20 | `{0,1}`에서 1 → 3 (10 + 10) |
| `{0,1,3,2}`(전체) | 2 | 29 | `{0,1,3}`에서 3 → 2 (20 + 9) |

마지막에 `last = 2`에서 0으로 돌아오는 비용 6을 더해 `29 + 6 = 35`. 다른 `last`로 끝나는 경우(예: 1에서 돌아오기 `5`)와 비교해 최솟값을 택합니다. `tsp_with_path`는 `came[mask][last]`(이전 도시)를 따라가 경로 `[0, 1, 3, 2, 0]`을 복원합니다.

## 4. 구현

전체 코드는 [solution.py](solution.py)에 있습니다.

```python
def tsp(dist):
    n = len(dist)
    full = (1 << n) - 1
    dp = [[INF] * n for _ in range(1 << n)]
    dp[1][0] = 0
    for mask in range(1, 1 << n, 2):             # 0 번이 포함된(홀수) 마스크만
        for j in range(n):
            cost = dp[mask][j]
            if cost == INF:
                continue
            for k in range(1, n):
                if mask >> k & 1:                # 이미 방문
                    continue
                new = cost + dist[j][k]
                if new < dp[mask | (1 << k)][k]:
                    dp[mask | (1 << k)][k] = new
    return min((dp[full][j] + dist[j][0] for j in range(1, n)), default=INF)
```

- `tsp_with_path`: 이전 도시를 기록해 경로를 복원합니다.
- `assignment_min_cost(cost)`: 할당 문제.
- `count_hamiltonian_paths(adj)`: 방향 그래프의 해밀턴 경로의 수.
- 길이 없는 곳(`dist[i][j] = INF`)이 있으면 그 경로는 자연스럽게 제외됩니다.
- 직접 실행하면 `N`과 N×N 비용 행렬(0은 길이 없음)을 받아 최소 순회 비용을 출력합니다.

## 5. 복잡도와 입력 크기 가이드

- 상태 `2ⁿ·n`개, 전이 `n`개 → **시간 O(2ⁿ·n²)**, **공간 O(2ⁿ·n)**. 할당 문제는 상태 `2ⁿ`, 전이 `n`개라서 O(2ⁿ·n).
- 이 환경에서 무작위 비용으로 측정했습니다. ([복잡도 치트시트](../../../docs/complexity-cheatsheet.md))

| n | TSP | 할당 문제 |
|---|---|---|
| 12 | 0.01초 | 0.01초 |
| 15 | 0.16초 | 0.05초 |
| 16 | 0.38초 | |
| 17 | 0.88초 | |
| 18 | 1.99초 | 0.48초 |

- 상태가 2ⁿ·n개라서 n = 20이면 약 2천만 개의 값을 저장해야 해서 파이썬의 리스트 메모리가 부담이 됩니다. n ≤ 16~18이 CPython에서 안전합니다.

## 6. 자주 하는 실수

- **0번이 없는 마스크까지 계산**: 시작 도시를 고정하면 0번이 포함되지 않은 마스크는 도달 불가능합니다. `range(1, 1 << n, 2)`로 홀수만 도세요.
- **돌아오는 간선 누락**: 순회(사이클)는 마지막 도시에서 출발 도시로 돌아오는 비용을 더해야 합니다. 경로(해밀턴 경로)는 돌아오지 않습니다.
- **길이 없음(0)을 비용 0으로 읽음**: 입력에서 0이 "길 없음"이면 `INF`로 바꿔야 합니다. ([테스트](test_solution.py)의 `test_main_treats_zero_as_no_road`)
- **`INF` 덧셈**: `INF + 비용`은 `INF`를 유지하지만, 정수 `INF`를 쓰면 비교가 어긋날 수 있습니다. 이 구현은 `float("inf")`를 씁니다.
- **그리디로 할당**: 각 사람이 가장 싼 일을 고르면 틀립니다. (`[[1, 2], [1, 100]]`의 최적은 3)
- **비트 순서 혼동**: `mask >> k & 1`이 k번 원소가 포함되었는지입니다.
- **메모리 폭발**: `[[INF] * n for _ in range(1 << n)]`는 n = 22에서 이미 큽니다. 필요하면 `array`나 1차원 배열로 쓰세요.

## 7. 변형과 응용

- **해밀턴 사이클의 수**: 시작 도시를 고정하고 마지막에 시작 도시로의 간선 확인
- **부분집합 DP**: `dp[mask]` = mask 집합을 처리한 최적값. 집합을 두 부분집합으로 나누는 전이(`submask` 열거)는 O(3ⁿ). → [비트마스크](../../../lv1-elementary/09-bit-manipulation/bitmask/)
- **프로파일 DP**: 격자를 줄 단위로, 줄의 채움 상태를 비트마스크로 (타일 채우기)
- **중간에서 만나기**와 비교: n이 40이면 2⁴⁰은 불가능하지만 2·2²⁰는 가능. → [중간에서 만나기](../../../lv3-advanced/06-query-techniques/meet-in-the-middle/)
- **TSP 근사/휴리스틱**: n이 크면 정확해는 포기하고 근사 알고리즘을 쓰는 문제가 많습니다.
