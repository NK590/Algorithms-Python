# KMP Algorithm (KMP 알고리즘)

> **한 줄 요약**: 본문 `T`에서 패턴 `P`를 찾을 때 불일치가 나도 **본문 위치를 되돌리지 않고**, 패턴을 이미 맞춘 부분의 "접두사이면서 접미사인 가장 긴 부분"(실패 함수)까지만 물러나서 이어 비교한다. 본문 `n`, 패턴 `m`이면 `O(n + m)`. 실패 함수 자체가 **반복 주기·테두리(border)** 문제의 열쇠다.

## 1. 언제 쓰나 (문제 신호)

- "문자열 `T`에서 `P`가 **몇 번, 어디에** 나오는가" (겹치는 등장 포함), 길이가 10⁶ 수준
- "문자열이 어떤 단위의 **반복**으로 이루어져 있는가", "가장 짧은 반복 단위" (예: `abcabcabc` → `abc`)
- "접두사이면서 접미사인 부분 문자열" (테두리/border) 관련 문제
- "광고판처럼 어떤 문자열이 계속 반복되어 흐를 때 한 장면만 보고 **가능한 가장 짧은 길이**"
- 원형(circular) 문자열 비교 → 본문을 두 번 이어 붙여 검색

## 2. 핵심 아이디어

**순진한 방법의 낭비**: 위치 `i`에서 비교하다 `j`번째에 틀리면, `i + 1`로 가서 처음부터 다시 비교합니다. 최악에 `O(nm)`입니다. 그런데 틀리기 직전까지 `T[i..i+j−1] = P[0..j−1]`이 맞았다는 사실이 있는데 버립니다.

**실패 함수** `failure[i]`: `P[0..i]`의 접두사이면서 접미사인 부분 문자열(자기 자신 제외) 중 **가장 긴 것의 길이**.

```
P = A B A B C A B A B
failure = [0, 0, 1, 2, 0, 1, 2, 3, 4]
```

예를 들어 `failure[8] = 4`는 `P[0..8] = ABABCABAB`의 접두사 `ABAB`가 접미사 `ABAB`와 같다는 뜻입니다.

**본문을 훑는 규칙**: `k` = 지금까지 맞춘 패턴의 길이(`T`에서 방금 끝난 부분이 `P[0..k−1]`과 같다).

1. 다음 글자 `ch`가 `P[k]`와 같으면 `k += 1`.
2. 다르면 **`k`를 `failure[k−1]`로 줄이고** 다시 비교. (맞춘 `P[0..k−1]`의 접미사 중 `P`의 접두사이기도 한 가장 긴 것이 `failure[k−1]`이라서, 그만큼은 이미 맞은 상태이기 때문)
3. `k = 0`에서도 다르면 그냥 다음 글자로.
4. `k == m`이면 등장 하나를 찾은 것이니 위치를 기록하고 `k = failure[m−1]`로 물러나 **겹치는 다음 등장**을 이어서 찾는다.

**왜 `O(n + m)`인가 (분할 상환)**: 본문의 한 글자마다 `k`는 최대 1 늘어납니다. 줄이는 일은 `k`가 늘어난 만큼만 할 수 있으므로 안쪽 `while`이 도는 횟수의 합은 `n`을 넘을 수 없습니다.

**실패 함수도 같은 방식으로 만든다**: 패턴 자신을 본문으로 삼아 `P[1..]`을 `P`와 맞춰 보면 됩니다. 그래서 두 함수의 구조가 거의 같습니다.

**실패 함수의 응용**

- **테두리 사슬**: `s` 전체의 테두리는 `failure[n−1]`, 그 테두리의 테두리는 `failure[failure[n−1]−1]`, …. `ABABCABAB`는 `ABAB`(4), `AB`(2).
- **최소 반복 단위**: 후보 `n − failure[n−1]`. 이 값이 `n`을 나누어떨어뜨리면 `s`는 그 단위의 반복이고, 아니면 반복 문자열이 아닙니다.

## 3. 손으로 따라가기

### 실패 함수 만들기: `P = ABABCABAB`

`k`는 지금까지 이어 온 테두리의 길이입니다.

| `i` | `P[i]` | 동작 | `k` | `failure[i]` |
|---|---|---|---|---|
| 0 | A | (시작) | 0 | 0 |
| 1 | B | `P[0]=A`와 다름, `k = 0` | 0 | 0 |
| 2 | A | `P[0]=A`와 같음 | 1 | 1 |
| 3 | B | `P[1]=B`와 같음 | 2 | 2 |
| 4 | C | `P[2]=A`와 다름 → `k = failure[1] = 0`, `P[0]=A`와도 다름 | 0 | 0 |
| 5 | A | `P[0]`과 같음 | 1 | 1 |
| 6 | B | `P[1]`과 같음 | 2 | 2 |
| 7 | A | `P[2]`와 같음 | 3 | 3 |
| 8 | B | `P[3]`과 같음 | 4 | 4 |

`failure = [0, 0, 1, 2, 0, 1, 2, 3, 4]`. 같은 방법으로 `AABAAAB → [0, 1, 0, 1, 2, 2, 3]`, `AAAA → [0, 1, 2, 3]`, `ABCD → [0, 0, 0, 0]`.

### 본문 훑기: `T = ABABABCABABABCABAB` (18글자), `P = ABABCABAB` (9글자)

| `i` | `T[i]` | 비교 전 `k` | 동작 | `k` |
|---|---|---|---|---|
| 0~3 | A B A B | 0→3 | 모두 같음 | 4 |
| 4 | A | 4 | `P[4]=C`와 다름 → `k = failure[3] = 2`, `P[2]=A`와 같음 | 3 |
| 5 | B | 3 | `P[3]=B`와 같음 | 4 |
| 6 | C | 4 | `P[4]=C`와 같음 | 5 |
| 7~10 | A B A B | 5→8 | 모두 같음 | 9 |
| 10 | (`k=9=m`) | | **등장 발견: 시작 위치 `10 − 9 + 1 = 2`**, `k = failure[8] = 4`로 물러남 | 4 |
| 11 | A | 4 | `P[4]=C`와 다름 → `k = 2`, `P[2]=A`와 같음 | 3 |
| 12 | B | 3 | 같음 | 4 |
| 13 | C | 4 | 같음 | 5 |
| 14~17 | A B A B | 5→8 | 모두 같음 | 9 |
| 17 | (`k=9=m`) | | **등장 발견: 시작 위치 `17 − 9 + 1 = 9`** | |

시작 위치는 `[2, 9]`입니다. 글자 비교 횟수는 **20번**(본문 18글자 + 불일치 후 다시 비교한 2번)이고, 같은 입력에서 위치마다 처음부터 비교하는 순진한 방법은 **36번**입니다. 첫 등장(위치 2)과 두 번째 등장(위치 9)이 `ABAB`를 겹친다는 점이 중요합니다. `k = failure[8] = 4`로 물러나서 앞의 `ABAB`를 다시 비교하지 않고 이어 갑니다.

겹치는 등장을 모두 찾으므로 `kmp_search("AAAAAA", "AAAA")`는 `[0, 1, 2]`, `kmp_search("abababa", "aba")`는 `[0, 2, 4]`입니다.

### 반복 단위

| 문자열 | `failure` 마지막 값 | 후보 `n − failure[n−1]` | `n`을 나누나 | 최소 단위 |
|---|---|---|---|---|
| `abcabcabc` | 6 | 3 | 9 % 3 = 0 | **3** (`abc`) |
| `aaaa` | 3 | 1 | 4 % 1 = 0 | **1** |
| `abab` | 2 | 2 | 4 % 2 = 0 | **2** |
| `abcab` | 2 | 3 | 5 % 3 ≠ 0 | 5 (반복이 아님) |
| `aabaabaab` | 6 | 3 | 9 % 3 = 0 | **3** (`aab`) |

`abcab`처럼 나누어떨어지지 않는 경우 `shortest_prefix_covering`(= `n − failure[n−1]`, 여기서는 3)은 "접두사 `abc`를 겹쳐서 이어 붙이면 `abcab`가 부분 문자열로 나온다"는 광고 문제의 답입니다.

## 4. 구현

전체 코드는 [solution.py](solution.py)에 있습니다.

```python
def failure_function(pattern):
    failure = [0] * len(pattern)
    k = 0                                  # 지금까지 맞춘 접두사의 길이
    for i in range(1, len(pattern)):
        while k > 0 and pattern[i] != pattern[k]:
            k = failure[k - 1]             # 불일치: 더 짧은 접두사로 후퇴
        if pattern[i] == pattern[k]:
            k += 1
        failure[i] = k
    return failure

def kmp_search(text, pattern):
    if not pattern:
        return []
    failure = failure_function(pattern)
    positions = []
    k = 0
    for i, ch in enumerate(text):
        while k > 0 and ch != pattern[k]:
            k = failure[k - 1]
        if ch == pattern[k]:
            k += 1
        if k == len(pattern):
            positions.append(i - k + 1)    # 0 부터
            k = failure[k - 1]             # 겹치는 다음 등장을 위해 후퇴
    return positions
```

- `count_occurrences(text, pattern)`: 등장 횟수.
- `smallest_period(s)`: 가장 짧은 반복 단위의 길이(반복이 아니면 `len(s)`).
- `shortest_prefix_covering(s)`: `n − failure[n−1]`.
- 직접 실행하면 두 줄(본문, 패턴)을 받아 **등장 횟수**와 **시작 위치(1부터)**를 출력합니다. 공백이 들어 있어도 줄 단위로 읽습니다.

## 5. 복잡도와 입력 크기 가이드

- **시간 O(n + m)**: 실패 함수 `O(m)` + 검색 `O(n)`. **공간 O(m)**. ([복잡도 치트시트](../../../docs/complexity-cheatsheet.md))
- 이 환경에서 측정한 값입니다(세 번 중 최소).

| 작업 | 크기 | 시간 |
|---|---|---|
| `kmp_search` (2글자 알파벳 무작위 본문, 길이 20 패턴) | n = 10⁶ | 0.098초 |
| `rabin_karp` (같은 입력) | n = 10⁶ | 0.25초 |
| `str.find`를 반복해서 모든 위치 찾기 | n = 10⁶ | 0.0067초 |
| `failure_function` | m = 10⁶ | 0.093초 |
| `kmp_search` (`"a" * 10⁶`에서 `"a" * 5·10⁵`) | n = 10⁶ | 0.19초 |

- **파이썬 내장 `str.find`, `in`, `str.count`는 C로 구현되어 위 입력에서 KMP보다 약 15배 빠릅니다.** 단순 검색이면 내장을 쓰세요. KMP가 필요한 때는 **실패 함수 자체**가 답인 문제(주기, 테두리, 접두사-접미사 일치)입니다.
- `n, m ≤ 10⁶`이어도 `O(n + m)`이라 문제없습니다. 순진한 방법은 최악에 `O(nm)`이라 `n = 10⁶`, `m = 5·10⁵` 같은 입력(위 표의 마지막 줄)에서는 불가능합니다.

## 6. 자주 하는 실수

- **`failure[k]`와 `failure[k − 1]`**: `k`는 "맞춘 길이"라서 마지막으로 맞춘 글자의 인덱스는 `k − 1`입니다. 후퇴는 `failure[k − 1]`.
- **전체 일치 후 후퇴를 빠뜨림**: `k == m`이 되면 `k = failure[m − 1]`로 줄이지 않으면 `pattern[k]`가 범위를 벗어나거나 겹치는 등장을 놓칩니다.
- **`if`로 후퇴**: 후퇴는 여러 번 일어날 수 있으니 `while`이어야 합니다. `if`로 쓰면 `AAAAB`처럼 연달아 여러 번 물러나야 하는 패턴에서 실패 함수가 `[0, 1, 2, 3, 0]`이 아니라 `[0, 1, 2, 3, 2]`로 틀리게 나옵니다.
- **0부터 vs 1부터**: 내부는 0부터, 문제 출력은 보통 1부터입니다(`main()`이 `+ 1`).
- **빈 패턴**: `pattern[0]` 접근에서 오류가 납니다. 먼저 걸러냅니다.
- **줄 읽기**: 공백이 포함된 입력에는 `input().split()`이 아니라 줄 전체를 읽고 끝의 `\n`만 지웁니다(`rstrip("\n")`). `strip()`은 앞뒤 공백까지 지워서 틀립니다.
- **반복 판정에서 나누어떨어짐 확인 누락**: `abcab`는 `n − failure = 3`이지만 반복이 아닙니다.
- **재귀로 구현**: 길이 10⁶이면 재귀 깊이가 문제입니다. 반복문으로 씁니다.

## 7. 변형과 응용

- **원형 문자열 비교**: 본문을 두 번 이어 붙인 뒤 검색합니다 (회전해서 같은 문자열인지 등).
- **가장 긴 반복 부분 문자열**: 각 접미사에 대해 실패 함수를 구해 최댓값을 취합니다 (`O(n²)`).
- **회문 만들기**: `s + '#' + reverse(s)`의 실패 함수로 가장 긴 회문 접두사를 구합니다.
- **여러 패턴을 동시에**: [아호-코라식](../../../lv3-advanced/05-strings-advanced/aho-corasick/)이 KMP를 트라이 위에 올린 것입니다.
- **다른 선형 시간 도구**: [Z 알고리즘](../../../lv3-advanced/05-strings-advanced/z-algorithm/)은 접두사 일치 길이를 직접 구해 같은 문제를 다른 방식으로 풉니다.
- **해시로 풀기**: 부분 문자열 비교를 해시로 `O(1)`에. → [라빈-카프](../rabin-karp/)
