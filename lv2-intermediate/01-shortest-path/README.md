# 최단 경로 (Shortest Path)

그래프에서 한 정점에서 다른 정점까지(또는 모든 정점까지)의 가장 짧은 경로를 구하는 알고리즘들입니다. **간선 가중치의 성질**과 **출발점이 하나인지 모든 쌍인지**로 알고리즘을 고릅니다.

## 한눈에 비교

| 알고리즘 | 구하는 것 | 간선 가중치 | 시간 복잡도 |
|---|---|---|---|
| [BFS](../../lv1-elementary/05-graph-basics/bfs/) | 한 점 → 모든 점 | 모두 같음 (가중치 없음) | O(V+E) |
| [0-1 BFS](zero-one-bfs/) | 한 점 → 모든 점 | 0 또는 1 | O(V+E) |
| [다익스트라](dijkstra/) | 한 점 → 모든 점 | 0 이상 | O((V+E) log V) |
| [벨만-포드](bellman-ford/) | 한 점 → 모든 점 | 음수 가능 (음수 사이클 감지 가능) | O(VE) |
| [플로이드-워셜](floyd-warshall/) | 모든 점 쌍 | 음수 가능 (음수 사이클이 없을 때) | O(V³) |

## 고르는 순서

1. 가중치가 없다 (또는 모두 같다) → **BFS**
2. 가중치가 0 또는 1뿐이다 → **0-1 BFS**
3. 음수 가중치가 없다 → **다익스트라**
4. 음수 가중치가 있다 → **벨만-포드** (모든 쌍이 필요하고 정점 수가 수백 이하라면 플로이드-워셜)
5. 모든 정점 쌍의 최단 거리가 필요하고 정점 수가 수백 이하다 → **플로이드-워셜**
