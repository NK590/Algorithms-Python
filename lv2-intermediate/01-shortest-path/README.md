# 최단 경로 (Shortest Path)

그래프에서 한 정점에서 다른 정점까지(또는 모든 정점까지)의 가장 짧은 경로를 구하는 알고리즘들입니다. **간선 가중치의 성질**과 **출발점이 하나인지 모든 쌍인지**로 알고리즘을 고릅니다.

## 한눈에 비교

| 알고리즘 | 구하는 것 | 간선 가중치 | 시간 복잡도 |
|---|---|---|---|
| [BFS](../../lv1-elementary/05-graph-basics/bfs/) | 한 점 → 모든 점 | 모두 같음 (가중치 없음) | O(V+E) |
| [0-1 BFS](zero-one-bfs/) | 한 점 → 모든 점 | 0 또는 1 | O(V+E) |
| [다익스트라](dijkstra/) | 한 점 → 모든 점 | 0 이상 | O((V+E) log V) |
| [벨만-포드](bellman-ford/) | 한 점 → 모든 점 | 음수 가능 (음수 사이클 감지 가능) | O(VE) |
| [플로이드-워셜](floyd-warshall/) | 모든 점 쌍 | 음수 가능 (음수 사이클이 없을 때) | O(V³) |

## 고르는 순서

1. 가중치가 없다 (또는 모두 같다) → **BFS**
2. 가중치가 0 또는 1뿐이다 → **0-1 BFS**
3. 음수 가중치가 없다 → **다익스트라**
4. 음수 가중치가 있다 → **벨만-포드** (모든 쌍이 필요하고 정점 수가 수백 이하라면 플로이드-워셜)
5. 모든 정점 쌍의 최단 거리가 필요하고 정점 수가 수백 이하다 → **플로이드-워셜**

DAG(사이클 없는 방향 그래프)라면 음수 간선이 있어도 [위상 정렬](../02-graph-algorithms/topological-sort/) 순서로 한 번 훑는 O(V+E)가 가장 빠릅니다.

## 이 저장소의 구현에서 입력 형식

| 알고리즘 | 그래프 표현 | 반환 |
|---|---|---|
| [다익스트라](dijkstra/) | 인접 리스트 `graph[u] = [(v, w), …]` | `dist` (경로 복원은 `prev`) |
| [0-1 BFS](zero-one-bfs/) | 인접 리스트 `graph[u] = [(v, w), …]`, `w ∈ {0, 1}` | `dist` |
| [벨만-포드](bellman-ford/) | **간선 목록** `[(u, v, w), …]`와 정점 수 | `(dist, 음수 사이클 여부)` |
| [플로이드-워셜](floyd-warshall/) | **간선 목록**과 정점 수 | `n × n` 거리 행렬 |

간선을 모두 훑는 알고리즘(벨만-포드, 플로이드-워셜)은 간선 목록이, 이웃을 따라가는 알고리즘(다익스트라, 0-1 BFS)은 인접 리스트가 자연스럽습니다.

## 크기 가이드 (CPython 기준 대략)

| 알고리즘 | 안전한 크기 |
|---|---|
| BFS / 0-1 BFS / 다익스트라 | V, E ≈ 10⁵ (10⁶은 PyPy 권장) |
| 벨만-포드 | V·E ≈ 10⁷ 이하 (V = 500, E = 6,000이 대표적) |
| 플로이드-워셜 | V ≤ 300 안팎 |

## 읽는 순서

1. [BFS](../../lv1-elementary/05-graph-basics/bfs/) → [다익스트라](dijkstra/): "가까운 곳부터"의 일반화
2. [0-1 BFS](zero-one-bfs/): 다익스트라의 특수한 경우를 덱으로
3. [벨만-포드](bellman-ford/): 음수 간선과 음수 사이클
4. [플로이드-워셜](floyd-warshall/): 모든 쌍, DP로 보기
