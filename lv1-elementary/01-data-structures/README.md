# 기본 자료구조 (Data Structures)

스택, 큐, 덱, 연결 리스트, 해시 테이블, 우선순위 큐, 집합·딕셔너리처럼 거의 모든 문제에서 쓰이는 자료구조를 다룹니다. 알고리즘은 "어떤 순서로 꺼내 쓸 것인가"가 핵심이고, 자료구조 선택이 곧 그 순서를 정합니다.

## 한눈에 비교

| 자료구조 | 꺼내는 순서 | 핵심 연산 시간 | 파이썬에서는 |
|---|---|---|---|
| [스택](stack/) | 나중에 넣은 것부터 (LIFO) | push·pop O(1) | `list.append`, `list.pop()` |
| [큐](queue/) | 먼저 넣은 것부터 (FIFO) | enqueue·dequeue O(1) | `collections.deque` |
| [덱](deque/) | 양쪽 끝 모두 | 양끝 push·pop O(1) | `collections.deque` |
| [연결 리스트](linked-list/) | 순서대로 (링크를 따라) | 삽입·삭제 O(1), 탐색 O(n) | 직접 구현 (`list`, `deque`가 대신) |
| [해시 테이블](hash-table/) | 키로 바로 찾기 | 찾기·넣기 평균 O(1) | `dict`, `set` |
| [우선순위 큐](priority-queue/) | 가장 작은(큰) 것부터 | push·pop O(log n) | `heapq` |
| [집합과 딕셔너리 활용](set-and-dict/) | (해시 테이블의 실전 사용법) | 평균 O(1) | `set`, `dict`, `Counter`, `defaultdict` |

## 무엇을 쓸까

| 상황 | 선택 |
|---|---|
| 가장 최근 것부터 처리, 짝 맞추기, 되돌리기, DFS | **스택** |
| 들어온 순서대로 처리, BFS | **큐** (`deque`) |
| 양쪽 끝에서 넣고 빼기, 슬라이딩 윈도우, 0-1 BFS | **덱** |
| "이미 본 값인가", 빈도, 중복 제거, 키로 찾기 | **해시** (`set`/`dict`) |
| 가장 작은(큰) 값을 반복해서 꺼내기, 다익스트라 | **우선순위 큐** (`heapq`) |
| 번호(인덱스)로 읽고 쓰기 | **배열** (`list`) |
| 중간 삽입·삭제가 핵심이고 위치를 이미 알고 있다 | 연결 리스트 (PS에서는 드물다) |

**피해야 할 것**: 큐를 리스트의 `pop(0)`으로 만들기(O(n)), `x in list`를 반복하기(O(n)).

## 읽는 순서

1. [스택](stack/) → [큐](queue/) → [덱](deque/): 꺼내는 순서가 다른 세 가지
2. [해시 테이블](hash-table/) → [집합과 딕셔너리 활용](set-and-dict/): 빠르게 찾기
3. [우선순위 큐](priority-queue/): 가장 작은 것 꺼내기 (이후 [힙 정렬](../02-sorting/heap-sort/), [다익스트라](../../lv2-intermediate/01-shortest-path/dijkstra/)의 도구)
4. [연결 리스트](linked-list/): 링크를 다루는 감각 (트리·그래프의 바탕)
