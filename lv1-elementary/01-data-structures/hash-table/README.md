## 개요 (기존 주석에서 옮김)

- 임의의 데이터를 입력받아 고정된 길이의 데이터를 출력하는 해시 함수(Hash)를 이용한 자료 구조
- 적절한 해시 함수를 사용할 시 입력이 다른데 출력이 동일한 해시 충돌을 최소화시킬 수 있고,
- 이를 이용하여 인덱스에 해시 값을 사용하여 별도의 정렬 과정이 필요없이 입출력을 빠르게 받을 수 있는
- 자료 구조를 만들 수 있음
- Python에서는 Dictionary 자료형이 이 해시 테이블의 개념을 이용
- 이러한 해싱 개념은 후에 다양한 알고리즘에 응용됨
