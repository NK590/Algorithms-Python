# Stack (스택)

> **한 줄 요약**: 가장 나중에 넣은 것을 가장 먼저 꺼내는(LIFO, Last-In First-Out) 자료구조. 접시를 쌓고 맨 위부터 집는 모양이다.

## 1. 언제 쓰나 (문제 신호)

- "가장 **최근**의 것부터 처리", "**되돌리기**(undo)", "짝을 맞추는" 문제: 괄호, 태그, 수식
- 수식 계산(후위 표기식), 문자열 뒤집기, 방문한 곳을 기억했다 돌아오는 [DFS](../../05-graph-basics/dfs/)
- 재귀를 반복문으로 바꿀 때 (호출 스택을 직접 관리)
- "왼쪽/오른쪽에서 처음으로 자기보다 큰 값을 찾는" 문제 → 단조 스택 ([모노톤 스택](../../../lv2-intermediate/08-search-techniques/monotonic-stack/))

## 2. 핵심 아이디어

연산은 두 개뿐입니다. **push**(맨 위에 넣기)와 **pop**(맨 위에서 꺼내기). 중간 원소에는 접근하지 않습니다. 파이썬에서는 `list`의 `append`와 `pop()`이 곧 스택이고, 둘 다 O(1)입니다.

**괄호 짝 맞추기**가 대표 문제입니다. 여는 괄호는 쌓고, 닫는 괄호를 만나면 **가장 최근에 열린 괄호**(맨 위)와 짝이 맞는지 확인하며 꺼냅니다. 끝에 스택이 비어 있어야 올바른 괄호입니다.

**후위 표기식 계산**: 피연산자는 쌓고, 연산자를 만나면 위에서 두 개를 꺼내 계산해 결과를 다시 쌓습니다. 먼저 꺼낸 것이 **오른쪽** 피연산자입니다.

### 무엇을 저장하고 어떻게 움직이나

스택의 맨 위에는 가장 최근에 넣고 아직 처리하지 않은 원소가 있습니다. 괄호 검사에서는 닫히지 않은 여는 괄호, 후위식 계산에서는 계산이 끝난 부분 식의 값, 재귀 대체에서는 돌아와서 해야 할 작업을 저장합니다.

### 왜 이 방법이 맞는가

닫는 괄호는 가장 가까운 미해결 여는 괄호와 짝을 이뤄야 하므로 마지막 원소부터 꺼내는 LIFO가 맞습니다. 후위식에서는 연산자 앞에 완성된 두 피연산자가 스택에 쌓여 있으며, 꺼내는 순서를 뒤집으면 뺄셈·나눗셈의 의미가 달라집니다.

### 작은 예제로 검산하기

후위식 `8 3 -`에서 먼저 꺼내는 3은 오른쪽 피연산자이고 다음 8은 왼쪽입니다. 계산 결과 5를 다시 넣습니다. `([)]`는 괄호 수가 같아도 맨 위 종류가 맞지 않아 실패합니다.

## 3. 손으로 따라가기

**`([{}])`가 올바른 괄호인지**:

| 읽은 글자 | 하는 일 | 스택 (오른쪽이 맨 위) |
|---|---|---|
| `(` | 쌓는다 | `(` |
| `[` | 쌓는다 | `( [` |
| `{` | 쌓는다 | `( [ {` |
| `}` | 맨 위 `{`와 짝 → 꺼낸다 | `( [` |
| `]` | 맨 위 `[`와 짝 → 꺼낸다 | `(` |
| `)` | 맨 위 `(`와 짝 → 꺼낸다 | (비었음) |

끝났을 때 스택이 비어 있으므로 **올바른 괄호**입니다. `([)]`는 `)`를 만났을 때 맨 위가 `[`라서 짝이 맞지 않아 **틀린** 괄호입니다. (개수는 맞아도 순서가 틀립니다)

**후위 표기식** `3 4 + 2 *` = (3 + 4) × 2:

| 읽은 토큰 | 하는 일 | 스택 |
|---|---|---|
| `3` | 쌓는다 | `3` |
| `4` | 쌓는다 | `3 4` |
| `+` | 4, 3을 꺼내 `3 + 4 = 7`을 쌓는다 | `7` |
| `2` | 쌓는다 | `7 2` |
| `*` | 2, 7을 꺼내 `7 * 2 = 14`를 쌓는다 | `14` |

## 4. 구현

전체 코드는 [solution.py](solution.py)에 있습니다.

```python
def is_balanced(text):
    pair = {")": "(", "]": "[", "}": "{"}
    stack = []
    for ch in text:
        if ch in "([{":
            stack.append(ch)
        elif ch in pair:
            if not stack or stack.pop() != pair[ch]:     # 비었거나 짝이 다르면 틀렸다
                return False
    return not stack                                       # 여는 괄호가 남아 있으면 틀렸다
```

`Stack` 클래스(`push`, `pop`, `peek`, `is_empty`)와 `evaluate_postfix`, `reverse_with_stack`도 있습니다. 직접 실행하면 `T`와 괄호 문자열 T줄을 받아 `YES`/`NO`를 출력합니다.

## 5. 복잡도와 입력 크기 가이드

- `push`, `pop`, `peek`는 모두 **O(1)**, 공간은 쌓인 원소 수 O(n)입니다.
- 길이 n의 문자열을 한 번 훑으며 처리하므로 괄호·후위 표기식은 O(n)입니다. n = 10^6도 문제없습니다.
- 파이썬 `list.pop()`(끝에서)은 O(1)이지만 `pop(0)`(앞에서)은 O(n)입니다. 스택은 항상 **끝**에서만 다루세요.

## 6. 자주 하는 실수

- **빈 스택에서 `pop`/`peek`**: `IndexError`. 닫는 괄호가 먼저 나오는 입력(`)(`)을 항상 시험하세요.
- **끝에 스택이 비었는지 확인하지 않기**: `((`처럼 여는 괄호가 남는 경우를 놓칩니다.
- **괄호 종류만 세기**: `([)]`는 `(`와 `)`, `[`와 `]`의 개수가 같지만 올바르지 않습니다. 순서(최근 것과 짝)를 봐야 합니다.
- **피연산자 순서**: 먼저 꺼낸 것이 **오른쪽** 피연산자입니다. 뺄셈·나눗셈에서 뒤바뀌면 틀립니다.
- **재귀 깊이 제한**: 스택으로 DFS를 반복문으로 바꾸면 해결됩니다. ([DFS](../../05-graph-basics/dfs/))

## 7. 변형과 응용

- **단조 스택**: 값이 한 방향으로만 증가하도록 유지하는 스택 → [모노톤 스택](../../../lv2-intermediate/08-search-techniques/monotonic-stack/)
- **스택으로 큐 만들기 / 큐로 스택 만들기**: [큐](../queue/)의 `TwoStackQueue`
- **중위 표기식 → 후위 표기식 변환**(연산자 우선순위): 스택에 연산자를 쌓고 우선순위가 낮은 연산자를 만나면 꺼냅니다.
- **히스토그램에서 가장 큰 직사각형** 같은 고급 응용
