## 개요 (기존 주석에서 옮김)

- LIFO(Last-In First-Out, 후입선출) 특성을 가지는 자료 구조
- 메모리에 데이터가 들어오면서 먼저 들어온 데이터들이 점점 '아래로' 쌓이는 구조로,
- 데이터를 꺼낼 때 제일 마지막에 넣은 데이터부터 순서대로 꺼낼 수 있음
- 가장 마지막에 입력받은 데이터 위주로 처리할 때 유용하지만, 예전에 받았던 데이터를 꺼낼 때 불리
- Python에서는 리스트로 간단히 구현 가능
