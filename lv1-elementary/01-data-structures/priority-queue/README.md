# Priority Queue (우선순위 큐)와 힙

> **한 줄 요약**: 들어온 순서가 아니라 **우선순위가 가장 높은(가장 작은) 값**을 먼저 꺼내는 큐. **힙**이라는 배열 기반 트리로 O(log n)에 구현한다.

## 1. 언제 쓰나 (문제 신호)

- "**가장 작은(큰) 것을 반복해서** 꺼낸다", "가장 가까운 것부터", "비용이 가장 작은 것부터"
- [다익스트라](../../../lv2-intermediate/01-shortest-path/dijkstra/), [프림](../../../lv2-intermediate/02-graph-algorithms/prim/)처럼 "지금까지 중 최소"를 계속 고르는 그리디 알고리즘
- **상위 k개**(k번째로 큰 값), **중앙값 유지**, **K개의 정렬된 리스트 합치기**
- 정렬은 한 번에 끝나지만, 우선순위 큐는 **값이 계속 들어오고 나가는** 상황에 맞습니다.

## 2. 핵심 아이디어

**힙**은 완전 이진 트리를 배열에 담은 것입니다. 0번부터 시작하면 `i`번의 부모는 `(i−1)//2`, 자식은 `2i+1`, `2i+2`입니다. **최소 힙**의 성질은 "모든 부모 ≤ 자식"이라서 **루트(`a[0]`)가 항상 최솟값**입니다.

- **push**: 맨 뒤에 넣고, 부모보다 작으면 자리를 바꾸며 **위로 올립니다.** 높이만큼, O(log n).
- **pop**: 루트를 꺼내고, 맨 뒤 원소를 루트로 옮긴 뒤 두 자식 중 작은 쪽과 바꾸며 **아래로 내립니다.** O(log n).
- **힙 만들기**: 마지막 부모부터 루트까지 거꾸로 내려 보내면 **O(n)** 입니다. n번 push하는 것(O(n log n))보다 빠릅니다.

파이썬의 `heapq`는 **최소 힙**만 제공합니다. 최대 힙은 값에 `-`를 붙여 넣고 꺼낼 때 다시 붙입니다. 튜플 `(우선순위, 값)`을 넣으면 앞 원소 기준으로 정렬됩니다.

**중앙값 유지**: 작은 절반은 최대 힙, 큰 절반은 최소 힙에 두고 크기 차이를 1 이하로 유지하면 중앙값은 한쪽 힙의 루트입니다.

### 무엇을 저장하고 어떻게 움직이나

일반 큐는 넣은 순서, 우선순위 큐는 가장 작은·큰 우선순위부터 꺼냅니다. 힙은 부모와 자식의 우선순위 관계만 유지하며 전체 배열을 정렬해 두지는 않습니다. 같은 우선순위에서 어떤 항목을 먼저 처리할지도 필요하면 보조 키로 명시합니다.

### 왜 이 방법이 맞는가

삽입은 새 원소를 부모와 비교하며 올리고, 추출은 마지막 원소를 루트로 옮긴 뒤 더 좋은 자식과 비교하며 내립니다. 각 단계에서 바뀐 한 경로 밖의 힙 성질은 보존됩니다. 배열 길이에 비해 높이가 로그여서 연산은 O(log n)입니다.

### 작은 예제로 검산하기

작업 `(3,A),(1,B),(2,C)`를 최소 힙에 넣으면 B, C, A 순으로 꺼냅니다. 우선순위가 같은 튜플에 서로 비교할 수 없는 객체가 뒤따르면 오류가 나므로 삽입 번호를 보조 키로 사용할 수 있습니다. 임의 항목 수정은 별도 설계가 필요합니다.

## 3. 손으로 따라가기

최소 힙에 `5, 3, 8, 1`을 넣고 두 번 꺼냅니다. (배열 표현)

| 연산 | 하는 일 | 배열 |
|---|---|---|
| push 5 | 빈 힙 | `[5]` |
| push 3 | 맨 뒤에 넣고 부모(5)보다 작아 교환 | `[3, 5]` |
| push 8 | 부모(3)보다 커서 그대로 | `[3, 5, 8]` |
| push 1 | 맨 뒤(인덱스 3), 부모(5)와 교환, 부모(3)와 교환 | `[1, 3, 8, 5]` |
| pop → **1** | 루트 1을 빼고 맨 뒤 5를 루트에. 자식 3, 8 중 작은 3과 교환 | `[3, 5, 8]` |
| pop → **3** | 루트 3을 빼고 맨 뒤 8을 루트에. 자식 5와 비교해 8 > 5 이므로 교환 | `[5, 8]` |

꺼낸 순서 `1, 3`은 항상 오름차순입니다.

**중앙값 유지** (`5, 1, 3, 8, 2`를 차례로 넣으며): 5 → 중앙값 5, 1 → `[1, 5]`의 작은 쪽 가운데 1, 3 → `[1, 3, 5]`의 가운데 3, 8 → `[1, 3, 5, 8]`의 작은 쪽 가운데 3, 2 → `[1, 2, 3, 5, 8]`의 가운데 3.

## 4. 구현

전체 코드는 [solution.py](solution.py)에 있습니다.

```python
def push(self, value):
    self._a.append(value)
    i = len(self._a) - 1
    while i > 0 and self._a[i] < self._a[(i - 1) // 2]:   # 부모보다 작으면 올린다
        parent = (i - 1) // 2
        self._a[i], self._a[parent] = self._a[parent], self._a[i]
        i = parent
```

`MinHeap`(`push`, `pop`, `peek`, 리스트로 힙 만들기), `heap_sorted`, `kth_largest`(크기 k인 힙만 유지), `merge_sorted_lists`(K개 리스트 합치기), `RunningMedian`(두 힙으로 중앙값)이 있습니다. 직접 실행하면 `N`과 N개의 연산을 받아, 양수는 넣고 0이면 가장 작은 값을 꺼내 출력합니다. (비면 0)

실전에서는 `heapq`를 씁니다.

```python
import heapq
heap = []
heapq.heappush(heap, (cost, node))     # (우선순위, 값)
cost, node = heapq.heappop(heap)       # 가장 작은 우선순위
```

## 5. 복잡도와 입력 크기 가이드

- `push`, `pop` **O(log n)**, `peek` O(1), 리스트에서 힙 만들기 O(n), 공간 O(n)입니다.
- n = 10^5~10^6번의 push/pop은 `heapq`로 충분합니다. ([복잡도 치트시트](../../../docs/complexity-cheatsheet.md))
- 힙으로 `kth_largest`는 O(n log k), K개 리스트 합치기는 O(N log K)입니다.

## 6. 자주 하는 실수

- **최대 힙을 `heapq`에 그대로**: `heapq`는 최소 힙입니다. 값에 `-`를 붙여 넣으세요.
- **임의의 항목 삭제/수정을 기대**: 힙은 루트만 빠르게 꺼냅니다. 값을 바꾸려면 새 항목을 넣고 꺼낼 때 낡은 항목을 건너뛰는 방식(lazy deletion)을 씁니다. ([다익스트라](../../../lv2-intermediate/01-shortest-path/dijkstra/))
- **비교할 수 없는 값을 튜플 뒤에 넣기**: `(우선순위, 객체)`에서 우선순위가 같으면 객체를 비교하려다 에러가 납니다. 중간에 순번을 끼우세요.
- **빈 힙에서 pop**: `IndexError`. `while heap:`로 확인하세요.
- **힙을 정렬된 리스트로 착각**: `heap[1]`은 두 번째로 작은 값이 아닙니다. 루트만 최솟값이 보장됩니다.

## 7. 변형과 응용
