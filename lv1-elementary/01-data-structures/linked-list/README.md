# Linked List (연결 리스트)

> **한 줄 요약**: 노드마다 "다음 노드를 가리키는 링크"를 가진 자료구조. 중간에 끼워 넣고 지우는 것은 링크만 바꾸면 되지만, i번째를 찾으려면 처음부터 따라가야 한다.

## 1. 언제 쓰나 (문제 신호)

- **중간 삽입·삭제가 매우 잦고**, 위치를 이미 알고 있을 때 (배열은 뒤를 모두 밀어야 한다)
- "연결 리스트를 뒤집어라", "가운데 노드", "사이클이 있는가", "정렬된 두 리스트 합치기" 같은 **포인터 조작 문제** (면접·코딩 테스트에서 자주 나온다)
- 커서를 움직이며 편집하는 에디터 문제는 연결 리스트나 **스택 두 개**로 풀립니다.

**PS에서 직접 연결 리스트를 쓰는 일은 드뭅니다.** 파이썬의 `list`와 `deque`가 대부분을 해결해 주기 때문입니다. 대신 연결 리스트에서 배우는 **링크를 다루는 감각**이 [트리](../../05-graph-basics/tree/), [그래프](../../05-graph-basics/graph/)의 바탕입니다.

## 2. 핵심 아이디어

`Node(value, next)`가 줄줄이 이어집니다. `head`가 첫 노드를 가리키고, 마지막 노드의 `next`는 `None`입니다.

| 연산 | 시간 | 이유 |
|---|---|---|
| 맨 앞에 삽입 | O(1) | 새 노드의 `next`를 `head`로, `head`를 새 노드로 |
| 이미 찾은 노드 뒤에 삽입 | O(1) | 링크 두 개만 바꾼다 |
| 값 찾기 / i번째 접근 | **O(n)** | 처음부터 따라가야 한다 |
| 지우기 | O(n) (찾는 데) + O(1) | 앞 노드의 링크를 한 칸 건너뛰게 바꾼다 |
| 맨 뒤에 삽입 | O(n) | 끝을 찾아야 한다 (꼬리 포인터가 있으면 O(1)) |

**뒤집기**: 노드를 하나씩 따라가며 `next`가 가리키는 방향을 반대로 바꿉니다. `previous`, `node` 두 포인터로 충분합니다.

**토끼와 거북이**(플로이드): 한 칸씩 가는 `slow`와 두 칸씩 가는 `fast`를 함께 보냅니다. 끝(`None`)에 닿으면 사이클이 없고, **둘이 만나면 사이클**이 있습니다. 같은 방법으로 `fast`가 끝에 닿을 때 `slow`가 **가운데**에 있습니다. 추가 메모리 O(1)로 해결됩니다.

## 3. 손으로 따라가기

**뒤집기** `1 → 2 → 3`:

| 단계 | `previous` | `node` | 하는 일 | 링크 상태 |
|---|---|---|---|---|
| 시작 | None | 1 | | `1→2→3` |
| 1 | 1 | 2 | `1.next = None` | `1→None`, `2→3` |
| 2 | 2 | 3 | `2.next = 1` | `2→1→None`, `3` |
| 3 | 3 | None | `3.next = 2` | `3→2→1→None` |
| 끝 | | | `head = previous` (3) | `3 → 2 → 1` |

**가운데 찾기** `1 → 2 → 3 → 4 → 5`: `slow`는 1칸씩, `fast`는 2칸씩. `(slow, fast) = (1, 1) → (2, 3) → (3, 5)`. `fast`가 마지막이라 멈추고 `slow`는 3 = 가운데입니다. 개수가 짝수면 뒤쪽 가운데입니다.

## 4. 구현

전체 코드는 [solution.py](solution.py)에 있습니다.

```python
class Node:
    __slots__ = ("value", "next")
    def __init__(self, value, next=None):
        self.value, self.next = value, next

def reverse(head):
    previous, node = None, head
    while node is not None:
        node.next, previous, node = previous, node, node.next   # 오른쪽을 모두 계산한 뒤 한꺼번에 대입
    return previous
```

`LinkedList` 클래스는 `prepend`, `append`, `find`, `insert_after`, `remove`, `reverse`, `middle`, `to_list`를 제공하고, 별도로 `has_cycle`(토끼와 거북이)과 `merge_sorted`(정렬된 두 리스트 합치기)가 있습니다. 직접 실행하면 N개의 정수를 받아 뒤집어 출력합니다.

## 5. 복잡도와 입력 크기 가이드

- 앞쪽 삽입·삭제는 O(1), 탐색·뒤쪽 삽입은 O(n)입니다. 같은 연산이 `list`에서는 앞쪽 삽입이 O(n), 인덱스 접근은 O(1)로 반대입니다.
- 뒤집기·가운데 찾기·사이클 판별은 모두 한 번 훑는 **O(n)**, 추가 메모리 O(1)입니다.
- 파이썬 객체 하나하나가 노드라서 메모리를 많이 쓰고 느립니다. 큰 N(10^6)을 연결 리스트로 직접 구현하는 것은 피하세요. ([복잡도 치트시트](../../../docs/complexity-cheatsheet.md))

## 6. 자주 하는 실수

- **링크를 바꾸는 순서**: 삽입할 때 `node.next`를 덮어쓰기 전에 원래 다음 노드를 새 노드에 연결하지 않으면 뒤쪽이 사라집니다. 뒤집을 때도 다음 노드를 미리 저장해야 합니다.
- **`head`를 지우는 경우**: 맨 앞 노드는 앞 노드가 없어서 별도 처리가 필요합니다(`head = node.next`).
- **`None` 접근**: `fast.next.next`는 `fast`와 `fast.next`가 모두 `None`이 아닐 때만 안전합니다. 반복 조건을 `while fast and fast.next`로 쓰세요.
- **사이클이 있는 리스트를 끝까지 순회**: 무한 반복합니다. `has_cycle`로 먼저 확인합니다.
- **크기 갱신 누락**: 크기를 따로 세는 구현에서 삽입·삭제마다 갱신해야 합니다.

## 7. 변형과 응용

- **이중 연결 리스트**: `prev` 링크도 가져서 지우기가 O(1) (노드를 알 때). `deque`와 LRU 캐시의 바탕
- **원형 연결 리스트**: 마지막이 처음을 가리킴. 요세푸스 문제
- **더미 노드(sentinel)**: 맨 앞을 가리키는 가짜 노드를 두면 `head` 예외 처리가 사라집니다.
- **커서 편집기**: 커서 왼쪽/오른쪽을 [스택](../stack/) 두 개로 관리 (BOJ 에디터)
