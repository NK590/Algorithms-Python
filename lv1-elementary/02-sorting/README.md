# 정렬 (Sorting)

원소를 정해진 순서로 늘어놓는 알고리즘들입니다. 실전에서는 파이썬 내장 `sorted()` / `list.sort()`를 쓰면 되지만, 정렬 알고리즘은 시간 복잡도 분석, 분할 정복, 힙 같은 핵심 개념을 익히기에 좋은 재료입니다.

## 한눈에 비교

| 알고리즘 | 최선 | 평균 | 최악 | 추가 메모리 | 안정 정렬 | 특징 |
|---|---|---|---|---|---|---|
| [버블 정렬](bubble-sort/) | O(n)† | O(n²) | O(n²) | O(1) | O | 가장 단순하지만 느려서 실전에서는 거의 쓰지 않음 |
| [선택 정렬](selection-sort/) | O(n²) | O(n²) | O(n²) | O(1) | X | 교환 횟수가 적음 |
| [삽입 정렬](insertion-sort/) | O(n) | O(n²) | O(n²) | O(1) | O | n이 작거나 거의 정렬된 입력에서 빠름 |
| [병합 정렬](merge-sort/) | O(n log n) | O(n log n) | O(n log n) | O(n) | O | 입력과 무관하게 성능이 일정한 분할 정복의 대표 |
| [퀵 정렬](quick-sort/) | O(n log n) | O(n log n) | O(n²) | O(log n)‡ | X | 평균적으로 가장 빠른 편, 기준값 선택에 민감 |
| [힙 정렬](heap-sort/) | O(n log n) | O(n log n) | O(n log n) | O(1) | X | 최악에도 O(n log n)을 보장하지만 캐시 효율은 낮음 |

† 한 번도 교환이 없으면 멈추는 조기 종료를 넣었을 때의 값입니다.
‡ 제자리(in-place) 구현의 재귀 호출 스택 기준입니다. 이 저장소의 `Quick_Sort`, `Quick_Sort_2`는 새 리스트를 만들기 때문에 O(n) 메모리를 씁니다.

표의 안정성은 표준 구현 기준입니다. 이 저장소의 [병합 정렬](merge-sort/)은 알려진 이슈가 있어 그대로는 안정 정렬이 아닙니다.
