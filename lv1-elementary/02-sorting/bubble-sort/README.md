# Bubble Sort (버블 정렬)

> **상태: `migrated`** — 기존 `solution.py` 상단 주석의 설명을 그대로 옮긴 초안입니다. [문서 템플릿](../../../docs/TEMPLATE/README.md)에 맞춰 다시 쓸 예정입니다.

## 개요 (기존 주석에서 옮김)

- 인접한 두 수를 비교해 나가면서 정렬해 나가는 알고리즘.
- 두 수를 비교해서 앞 수가 뒤 수에 비해 큰 경우 둘의 위치를 바꿔가면서 큰 수를 뒤로 밀어냄
- 시간복잡도는 O(n^2)로 비교적 느린 편
