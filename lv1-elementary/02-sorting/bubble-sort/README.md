# Bubble Sort (버블 정렬)

> **한 줄 요약**: 이웃한 두 원소를 비교해 순서가 틀리면 바꾸는 일을 반복해서, 한 바퀴마다 가장 큰 값을 맨 뒤로 보내는 정렬.

## 1. 언제 쓰나 (문제 신호)

실전에서 정렬이 필요하면 파이썬 내장 `sorted()` / `list.sort()`를 씁니다. 버블 정렬을 직접 짜는 경우는 다음과 같습니다.

- **정렬 과정 자체를 묻는 문제**: "버블 정렬을 했을 때 **교환이 몇 번** 일어나는가", "k번째 바퀴가 끝났을 때의 배열은?"
- N이 아주 작아서(대략 N ≤ 1000) 구현 속도가 더 중요한 경우
- 정렬 알고리즘의 가장 단순한 예로서, 불변식과 시간 복잡도 분석을 연습하고 싶을 때

N이 10^4을 넘으면 O(N²)은 파이썬에서 시간 초과입니다. 교환 횟수를 묻는 문제의 N이 크다면 [병합 정렬](../merge-sort/)로 역전 수를 세는 문제입니다. ([7. 변형과 응용](#7-변형과-응용))

## 2. 핵심 아이디어

배열의 앞에서부터 이웃한 두 원소 `arr[j]`, `arr[j+1]`을 비교해서 앞이 더 크면 서로 바꿉니다. 큰 값이 거품처럼 뒤로 떠오른다고 해서 버블 정렬이라고 부릅니다.

- 한 바퀴를 돌면 **남은 구간에서 가장 큰 값이 맨 뒤에 자리 잡습니다.** 큰 값을 만나면 계속 들고 가서 뒤로 보내기 때문입니다.
- 그래서 `i`번째 바퀴가 끝나면 뒤쪽 `i`개는 최종 위치에 있습니다. 다음 바퀴는 그 앞쪽만 훑으면 됩니다. (불변식)
- 한 바퀴를 돌면서 **한 번도 바꾸지 않았다면** 모든 이웃 쌍이 순서대로라는 뜻이므로 이미 정렬된 상태입니다. 여기서 멈추면 정렬된 입력에서는 O(n)입니다.

**교환 횟수 = 역전의 수.** `i < j`이면서 `arr[i] > arr[j]`인 쌍을 역전이라고 합니다. 이웃한 두 원소를 바꾸면 그 두 원소 사이의 순서만 달라지므로, 역전이 정확히 하나 줄어듭니다. 정렬이 끝나면 역전이 0이므로, 교환 횟수는 처음 배열이 가진 역전의 수와 같습니다.

## 3. 손으로 따라가기

`[5, 2, 4, 6, 1, 3]`을 정렬합니다. 한 바퀴를 돌 때 `arr[0..end]` 구간을 비교합니다.

| 바퀴 | 비교 구간 | 교환 횟수 | 바퀴가 끝난 배열 (확정된 값은 오른쪽 끝) |
|---|---|---|---|
| 1 | `arr[0..5]` | 4 (5↔2, 5↔4, 6↔1, 6↔3) | `[2, 4, 5, 1, 3, 6]` |
| 2 | `arr[0..4]` | 2 (5↔1, 5↔3) | `[2, 4, 1, 3, 5, 6]` |
| 3 | `arr[0..3]` | 2 (4↔1, 4↔3) | `[2, 1, 3, 4, 5, 6]` |
| 4 | `arr[0..2]` | 1 (2↔1) | `[1, 2, 3, 4, 5, 6]` |
| 5 | `arr[0..1]` | 0 → **조기 종료** | `[1, 2, 3, 4, 5, 6]` |

교환 횟수의 합은 4+2+2+1 = **9**이고, 처음 배열 `[5, 2, 4, 6, 1, 3]`의 역전도 9쌍입니다. (5>2, 5>4, 5>1, 5>3, 2>1, 4>1, 4>3, 6>1, 6>3) 4바퀴에서 이미 정렬이 끝났지만, 정렬이 끝난 것을 확인하려고 5바퀴째가 필요합니다.

## 4. 구현

전체 코드는 [solution.py](solution.py)에 있습니다.

```python
def bubble_sort(arr):
    swaps = 0
    for end in range(len(arr) - 1, 0, -1):       # arr[end+1:] 은 이미 제자리를 찾은 값들
        swapped = False
        for j in range(end):
            if arr[j] > arr[j + 1]:              # 같을 때는 바꾸지 않아야 안정 정렬
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
                swaps += 1
                swapped = True
        if not swapped:                          # 한 번도 안 바꿨다면 이미 정렬됨
            break
    return swaps
```

- 입력 리스트를 **제자리에서** 정렬합니다. 반환값은 교환 횟수입니다.
- 직접 실행하면 `N`과 N개의 정수(한 줄에 하나)를 입력받아 정렬한 결과를 출력합니다.

## 5. 복잡도와 입력 크기 가이드

- **시간**: 비교는 최대 (n−1) + (n−2) + … + 1 = n(n−1)/2번이라 최악과 평균이 O(n²)입니다. 이미 정렬되어 있으면 한 바퀴(n−1번 비교)로 끝나서 O(n)입니다.
- **공간**: 추가 메모리 없이 제자리에서 바꾸므로 O(1)입니다.
- **안정 정렬**: 같은 값은 서로 바꾸지 않으므로 원래 순서가 유지됩니다.
- N이 10^3이면 약 5×10^5번 비교라 충분하고, 10^4이면 약 5×10^7번이라 CPython에서는 부담스럽고, 10^5부터는 불가능합니다. ([복잡도 치트시트](../../../docs/complexity-cheatsheet.md))

## 6. 자주 하는 실수

- **`>=`로 비교하기**: 같은 값끼리도 바꾸게 되어 불필요한 교환이 생기고, 같은 값의 순서가 뒤집혀 안정 정렬이 깨집니다. 교환 횟수도 역전 수와 달라집니다.
- **안쪽 반복 범위 실수**: `j`는 `end - 1`까지만 가야 `arr[j + 1]`이 `end`를 넘지 않습니다. `range(len(arr))`로 잡으면 마지막에 `IndexError`가 납니다. 반대로 매 바퀴 `range(len(arr) - 1)`로 고정하면 답은 맞지만 이미 확정된 뒤쪽을 불필요하게 다시 비교합니다.
- **조기 종료를 빼먹기**: 답은 맞지만 정렬된 입력에서도 O(n²)이 됩니다.
- **큰 N에 쓰기**: 교환 횟수를 구하는 문제도 N이 크면 시간 초과입니다. 아래 변형을 보세요.

## 7. 변형과 응용

- **교환 횟수 세기 → 역전 수.** 버블 정렬이 몇 번 교환하는지는 **직접 정렬하지 않고 역전 수를 세어서** 구할 수 있습니다. [병합 정렬](../merge-sort/)의 합치는 단계에서 O(n log n)에 셀 수 있습니다. N이 50만인 문제가 이 유형입니다.
- **칵테일 정렬(양방향 버블 정렬)**: 한 바퀴는 앞에서 뒤로, 다음 바퀴는 뒤에서 앞으로 훑습니다. 작은 값이 앞쪽으로 가는 속도가 느린 버블 정렬의 약점을 줄입니다.
- 정렬 알고리즘 사이의 비교는 [정렬 그룹 개요](../README.md)를 보세요.
