# Prime Factorization (소인수분해)

> **한 줄 요약**: 2부터 `d × d ≤ n`인 동안 나눠떨어지면 계속 나누고, 끝에 남는 1보다 큰 수는 그 자체가 소수다. 10^12 이하의 수 하나는 약 0.1초 안에 분해된다.

## 1. 언제 쓰나 (문제 신호)

- "소인수분해하라", "**소인수들을** 출력하라"
- **약수의 개수·합**이 필요할 때 (소인수의 지수에서 공식으로)
- 제곱수인지, 서로 다른 소인수가 몇 개인지, 어떤 소수로 몇 번 나눠지는지(예: `n!`의 끝 0의 개수는 5의 지수)
- 수 하나를 분해: O(√n) 시도 분해. **여러 수**를 분해해야 하면 먼저 [체](../sieve-of-eratosthenes/)로 가장 작은 소인수 표를 만든다.

## 2. 핵심 아이디어

모든 자연수는 소수의 곱으로 **유일하게** 나타납니다(산술의 기본 정리). 작은 수부터 나눠서 소인수를 하나씩 떼어 냅니다.

1. `d = 2`부터 시작해 `n`이 `d`로 나눠떨어지는 동안 계속 나누고 `d`를 기록한다.
2. 더 나눌 수 없으면 `d`를 1 늘린다.
3. `d × d > n`이 되면 멈춘다.
4. 이때 `n`이 1보다 크면 그 `n`이 마지막 소인수다.

**왜 `√n`에서 멈춰도 되는가**: 지금의 `n`이 합성수라면 `n = p × q`에서 `p ≤ q`이므로 `p ≤ √n`입니다. 그런데 `d`가 `√n`을 넘도록 `n`의 약수를 하나도 못 찾았다면 `n`은 합성수일 수 없고 소수입니다. 또한 `d`가 합성수인 경우는 이미 그 소인수로 다 나눠서 `n`이 `d`로 나눠떨어지지 않으니 소수만 걸러집니다.

**약수의 개수와 합**: `n = p₁^e₁ × p₂^e₂ × …`일 때

- 약수의 개수 = `(e₁ + 1)(e₂ + 1)…`  (각 소인수를 0~e번 쓰는 경우의 수)
- 약수의 합 = `(1 + p₁ + … + p₁^e₁)(1 + p₂ + … + p₂^e₂)…`

## 3. 손으로 따라가기

`n = 360`:

| 단계 | d | n | 나눠떨어지나 | 기록 |
|---|---|---|---|---|
| 1 | 2 | 360 | O | 2, n = 180 |
| 2 | 2 | 180 | O | 2, n = 90 |
| 3 | 2 | 90 | O | 2, n = 45 |
| 4 | 2 | 45 | X | d = 3 |
| 5 | 3 | 45 | O | 3, n = 15 |
| 6 | 3 | 15 | O | 3, n = 5 |
| 7 | 3 | 5 | X | d = 4 |
| 8 | 4 | 5 | `4 × 4 = 16 > 5` → 멈춤 | `n = 5 > 1`이므로 5 기록 |

결과: `[2, 2, 2, 3, 3, 5]`, 즉 `360 = 2³ × 3² × 5`.

- 약수의 개수 = `(3+1)(2+1)(1+1) = 24`
- 약수의 합 = `(1+2+4+8)(1+3+9)(1+5) = 15 × 13 × 6 = 1170`

(두 값 모두 [테스트](test_solution.py)가 1~1499의 모든 수에서 직접 약수를 나열한 값과 비교합니다.)

`n = 84`는 `d = 2`로 `84 → 42 → 21`, `d = 3`으로 `21 → 7`, 이어서 `4 × 4 = 16 > 7`이라 멈추고 남은 `7`을 기록해 `[2, 2, 3, 7]`입니다.

## 4. 구현

전체 코드는 [solution.py](solution.py)에 있습니다.

```python
def factorize(n):
    factors = []
    d = 2
    while d * d <= n:           # 남은 n 이 합성수라면 √n 이하의 약수가 있다
        while n % d == 0:
            factors.append(d)
            n //= d
        d += 1
    if n > 1:
        factors.append(n)       # 남은 1 보다 큰 수는 소수
    return factors
```

- `prime_exponents(n)`: `{소인수: 지수}`. 예: `360 → {2: 3, 3: 2, 5: 1}`
- `count_divisors(n)`, `sum_of_divisors(n)`: 위 공식 그대로.
- `factorize_with_spf(n, spf)`: [체](../sieve-of-eratosthenes/)의 `smallest_prime_factor_table`로 만든 표로 `n`을 O(log n)에 분해합니다. 수가 많을 때 씁니다.
- 직접 실행하면 `N`을 받아 소인수를 오름차순으로 한 줄에 하나씩 출력합니다. (`N = 1`이면 아무것도 출력하지 않습니다.)

`d`를 2, 3, 5, 7, 9, …처럼 홀수만 돌려도 되지만(2를 먼저 처리), 성능은 두 배쯤만 달라져서 이 폴더는 단순한 형태를 택했습니다.

## 5. 복잡도와 입력 크기 가이드

- **시간 O(√n)**, 공간 O(1) (소인수 목록 제외). 시도 횟수는 최악에 `√n`이고, 마지막에 남는 큰 소수가 최악의 입력입니다.
- 이 환경에서 측정한 값입니다. ([복잡도 치트시트](../../../docs/complexity-cheatsheet.md))

| 입력 | 결과 | 시간 |
|---|---|---|
| 999,999,937 (약 10^9의 소수) | 소수 하나 | 약 0.002초 |
| 999,999,999,989 (약 10^12의 소수) | 소수 하나 | 약 0.09초 |
| 10^18 근처의 소수 | | √n = 10^9번 시도하므로 약 90초로 추정 (측정 안 함). 시간 초과 |

- 그러므로 **수 하나가 10^12 이하**면 이 방법으로 충분합니다. 10^18 근처의 수를 분해해야 하면 [밀러-라빈](../../../lv4-expert/01-number-theory/miller-rabin/)과 폴라드 로 같은 다른 알고리즘이 필요합니다.
- **분해할 수가 많고 모두 10^7 이하**면 [체](../sieve-of-eratosthenes/)의 `spf` 표를 한 번 만들고 각각 O(log n)에 분해합니다.

## 6. 자주 하는 실수

- **끝의 `n > 1` 처리 누락**: `14 → [2]`처럼 큰 소인수(7)가 사라집니다. 반드시 마지막에 확인하세요.
- **`d * d <= n`에서 n이 변하는 것을 놓침**: 원래의 `n`이 아니라 **나눈 뒤 남은** `n`으로 비교해야 일찍 멈춥니다. 위 코드는 `n //= d`로 이미 그렇게 됩니다.
- **`range(2, n)`로 모두 돌기**: 소수 `n`이 10^9면 10^9번 돕니다. `d * d <= n`을 쓰세요.
- **`d`가 합성수일 때 걱정**: 4, 6, 9 같은 수는 나눠떨어지지 않으니 따로 걸러낼 필요가 없습니다. (작은 소인수로 이미 다 나눈 뒤입니다.)
- **`int(n ** 0.5)`**: 큰 수에서 부동소수점 오차가 생길 수 있어서 `math.isqrt`나 `d * d <= n` 비교가 안전합니다.
- **1의 소인수분해**: 빈 목록이 정답입니다. 문제에서 1을 입력으로 허용하는지 확인하세요.

## 7. 변형과 응용

- **약수의 개수·합**: 위 공식. 1~n 전체에는 [약수 체](../divisor-sieve/)가 더 효율적입니다.
- **오일러 피 함수**: `φ(n) = n × ∏(1 − 1/p)`. 서로 다른 소인수만 알면 됩니다. → [오일러 피 함수](../../../lv2-intermediate/06-number-theory/euler-phi/)
- **`n!`의 소인수 지수**: `n!`에서 소수 `p`의 지수는 `⌊n/p⌋ + ⌊n/p²⌋ + ⌊n/p³⌋ + …` (예: 끝자리 0의 개수는 5의 지수)
- **큰 수의 분해**: 폴라드 로 같은 알고리즘은 상위 레벨 주제입니다. ([밀러-라빈](../../../lv4-expert/01-number-theory/miller-rabin/))
