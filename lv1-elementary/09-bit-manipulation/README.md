# 비트 연산 (Bit Manipulation)

정수를 **비트의 모음**으로 보고 다루는 연산자(`& | ^ ~ << >>`)와, 이를 **작은 집합의 표현**으로 쓰는 비트마스크를 다룹니다.

## 한눈에 비교

| 개념 | 하는 일 | 대표 도구 | 시간 |
|---|---|---|---|
| [비트 연산자](bitwise-operators/) | 비트 읽기/켜기/끄기, 켜진 비트 세기, XOR 성질 | `x & (x−1)`, `x & −x`, `x ^ x = 0` | O(1) |
| [비트마스크](bitmask/) | 정수 하나로 집합을 표현, 모든 부분집합 순회 | `mask \| (1 << i)`, `range(1 << n)`, submask 열거 | 집합 연산 O(1), 순회 O(2ⁿ) |

## 언제 비트를 쓸까

| 문제 상황 | 선택 |
|---|---|
| 이진수에서 1의 개수, 2의 거듭제곱 판별 | [비트 연산자](bitwise-operators/) |
| 같은 수가 두 번씩 나올 때 홀로 남은 수 | XOR ([비트 연산자](bitwise-operators/)) |
| 원소 20개 이하 집합의 **모든 부분집합** | [비트마스크](bitmask/) |
| 방문한 곳/쓴 문자를 집합으로 상태에 기억 | [비트마스크](bitmask/) → 이후 [비트마스크 DP](../../lv2-intermediate/04-dynamic-programming/bitmask-dp/) |
| 원소가 20개를 훨씬 넘음 | 비트마스크 전체 순회는 불가 → [중간에서 만나기](../../lv3-advanced/06-query-techniques/meet-in-the-middle/), DP 등 |

## 파이썬에서의 주의

- 정수 크기에 제한이 없어 `1 << 100`도 되지만, 음수는 2의 보수처럼 동작합니다(`~x == −x − 1`). 고정 폭이 필요하면 `& ((1 << w) − 1)`로 마스크하세요.
- `x & 1 == 0`은 파이썬에서 `(x & 1) == 0`이지만 C/C++에서는 아닙니다. 괄호를 습관으로 쓰세요.
