# Bitmask (비트마스킹)

> **한 줄 요약**: 원소가 n개인 작은 집합을 **정수 하나**로 표현한다. i번째 비트가 1이면 i가 집합에 있다. 합집합·교집합이 `|`, `&` 한 번이고, 모든 부분집합은 `0 … 2ⁿ−1`을 도는 것으로 끝난다.

## 1. 언제 쓰나 (문제 신호)

- 원소가 **20개 안팎**인 집합의 모든 부분집합을 확인한다 (2²⁰ ≈ 100만)
- 집합 연산(합집합, 교집합, 포함 여부)이 많고 속도가 중요하다
- "**이미 쓴 것**"을 상태로 기억해야 한다 (알파벳, 방문한 도시, 고른 물건)
- 모든 `k`개 조합을 한 번씩 보고 싶다
- 그다음 단계인 [비트마스크 DP](../../../lv2-intermediate/04-dynamic-programming/bitmask-dp/)의 상태(어디까지 방문했는가)를 만드는 도구이기도 합니다.

## 2. 핵심 아이디어

집합 `S ⊆ {0, 1, …, n−1}`을 `mask = Σ 2ⁱ (i ∈ S)`로 바꿉니다. 이진수의 각 자리가 "있다/없다"입니다. 예: `{0, 2, 3}` ↔ `1101₂ = 13`.

| 집합 연산 | 비트 연산 |
|---|---|
| i 추가 | `mask \| (1 << i)` |
| i 제거 | `mask & ~(1 << i)` |
| i가 있는가 | `mask >> i & 1` |
| i 뒤집기(토글) | `mask ^ (1 << i)` |
| 합집합 / 교집합 / 차집합 | `a \| b` / `a & b` / `a & ~b` |
| 대칭차(한쪽에만 있는 것) | `a ^ b` |
| 원소의 수 | 켜진 비트 수 (`size`) |
| 전체 집합(0..n−1) | `(1 << n) − 1` |
| 여집합 | `mask ^ ((1 << n) − 1)` (`~mask`는 음수가 되므로 쓰지 않는다) |
| 공집합 | `0` |

### 모든 부분집합 보기

`mask`를 `0`부터 `2ⁿ − 1`까지 돌리면 모든 부분집합이 정확히 한 번씩 나옵니다. 각 `mask`에서 `mask >> i & 1`로 i번째 원소가 들어갔는지 확인하면 됩니다. 재귀 백트래킹의 "넣는다/안 넣는다"를 반복문으로 바꾼 것입니다. ([백트래킹](../../07-algorithm-paradigms/backtracking/)의 `all_subsets`)

### 어떤 집합의 부분집합만 보기 (submask 열거)

`sub = (sub − 1) & mask`를 반복하면 `mask`의 부분집합을 큰 것부터 모두 방문합니다. `sub − 1`은 가장 낮은 켜진 비트를 끄고 그 아래를 모두 켜는데, `& mask`로 `mask` 밖의 비트를 지우면 바로 다음으로 작은 부분집합이 됩니다. 모든 `mask`의 부분집합을 합치면 총 `3ⁿ`개입니다. (각 원소가 "mask에 없음 / mask에 있고 sub에 없음 / 둘 다에 있음" 세 상태)

### 정확히 k개가 켜진 마스크 (고스퍼의 해킹)

`n`비트 중 `k`개가 켜진 마스크를 오름차순으로 만들어 줍니다. 조합 `C(n, k)`개를 반복문으로 순회할 때 씁니다. 다음 값은 가장 낮은 연속한 1 묶음의 맨 위 1을 한 칸 올리고, 나머지 1들을 맨 아래로 내려서 만듭니다.

## 3. 손으로 따라가기

**3개 원소의 모든 부분집합** (`n = 3`):

| mask | 이진수 | 집합 |
|---|---|---|
| 0 | `000` | {} |
| 1 | `001` | {0} |
| 2 | `010` | {1} |
| 3 | `011` | {0, 1} |
| 4 | `100` | {2} |
| 5 | `101` | {0, 2} |
| 6 | `110` | {1, 2} |
| 7 | `111` | {0, 1, 2} |

**submask 열거** `mask = 1011₂`:

```
1011 → (1011−1)&1011 = 1010 → 1001 → 1000 → 0011 → 0010 → 0001 → 0000
```

여덟 개(= 2³, 켜진 비트가 3개)가 큰 것부터 나옵니다.

**4비트 중 2개가 켜진 마스크** (`masks_with_k_bits(4, 2)`): `0011, 0101, 0110, 1001, 1010, 1100` = 6개 = C(4, 2).

## 4. 구현

전체 코드는 [solution.py](solution.py)에 있습니다.

```python
def submasks(mask):                    # mask 의 모든 부분집합 (큰 것부터)
    result, sub = [], mask
    while True:
        result.append(sub)
        if sub == 0:
            break
        sub = (sub - 1) & mask
    return result

def count_subsets_with_sum(numbers, target):     # 비어 있지 않은 부분집합 중 합이 target
    n = len(numbers)
    count = 0
    for mask in range(1, 1 << n):                # 공집합(mask = 0)은 제외
        total = sum(numbers[i] for i in range(n) if mask >> i & 1)
        if total == target:
            count += 1
    return count
```

- `from_elements`, `to_elements`, `add`, `remove`, `contains`, `toggle`, `size`, `full_mask`, `complement`: 집합 연산.
- `masks_with_k_bits(n, k)`: 고스퍼의 해킹으로 정확히 k개가 켜진 마스크.
- `min_team_difference(synergy)`: n명을 n/2명씩 두 팀으로 나눠 능력치 차이를 최소화. 0번 사람이 속한 팀을 고정해 대칭인 절반을 건너뜁니다.
- `process_commands(commands)`: `add/remove/check/toggle/all/empty` 명령을 원소 1~20의 집합에 적용. 직접 실행하면 `M`과 M개의 명령을 받아 `check`의 결과를 출력합니다.

## 5. 복잡도와 입력 크기 가이드

- 집합 연산 하나는 **O(1)**(정수 하나의 비트 연산)입니다.
- 모든 부분집합을 도는 것은 **O(2ⁿ)** (× 각 부분집합을 처리하는 비용). 이 환경에서 측정한 값입니다. ([복잡도 치트시트](../../../docs/complexity-cheatsheet.md))

| 작업 | 시간 |
|---|---|
| `range(1, 2²⁰)` 반복만 | 0.06초 |
| 숫자 16개의 부분집합 합 세기 (`count_subsets_with_sum`, 마스크 65,535개 × 16비트) | 0.05초 |
| `masks_with_k_bits(20, 10)` (184,756개) | 0.03초 |

- n ≤ 20이 일반적입니다. 처리 비용이 크면 n ≈ 16~18이 안전합니다. 그보다 크면 [중간에서 만나기](../../../lv3-advanced/06-query-techniques/meet-in-the-middle/)로 2ⁿ을 2·2^(n/2)로 줄입니다.
- 마스크 하나가 정수 하나이므로 메모리가 작습니다. 길이 2ⁿ짜리 배열(`dp[mask]`)은 n ≤ 22 정도까지입니다.

## 6. 자주 하는 실수

- **여집합에 `~mask` 사용**: 파이썬에서 `~mask`는 음수입니다. `mask ^ full_mask(n)`을 쓰세요.
- **`mask >> i & 1`의 괄호**: 파이썬에서는 `(mask >> i) & 1`과 같게 읽히지만, 다른 언어에서는 아닐 수 있어서 습관적으로 괄호를 쓰는 편이 안전합니다.
- **0부터냐 1부터냐**: 원소가 1~20이면 `1 << x`로 비트 0은 비워 두거나 `1 << (x−1)`로 옮겨야 합니다. 일관되게 한쪽만 쓰세요. (`process_commands`의 `all`은 비트 0을 비워 둡니다)
- **공집합 처리**: `mask`를 `0`부터 돌면 공집합이 포함됩니다. 합이 0인 부분집합을 세는 문제(`S = 0`)에서 공집합이 답에 들어가지 않는지 확인하세요.
- **중복 원소로 마스크 만들기**: `mask |= 1 << k`는 중복에 안전하지만 `^=`는 아닙니다. 집합을 만들 때는 `|=`.
- **`1 << n`을 너무 큰 n으로**: n = 30이면 10억 개의 마스크라 반복이 불가능합니다. 제약(n ≤ 20)을 먼저 확인하세요.
- **부분집합 열거를 매 마스크마다 O(n)으로**: 합 같은 값은 `lowest_set_bit`을 이용해 이전 마스크에서 증분 계산하면 O(2ⁿ)로 줄일 수 있습니다.

## 7. 변형과 응용

- **비트마스크 DP**: `dp[mask]` = 방문한 집합이 `mask`일 때의 최솟값. 외판원 순회가 대표 문제. → [비트마스크 DP](../../../lv2-intermediate/04-dynamic-programming/bitmask-dp/)
- **격자 위의 방문 집합**: 지나온 알파벳을 `mask`에 모으며 DFS (백준 1987 알파벳). → [백트래킹](../../07-algorithm-paradigms/backtracking/)
- **모든 k개 선택**: `masks_with_k_bits`로 조합을 반복문으로 순회 (스타트와 링크, 가르침)
- **큰 비트셋**: 값의 범위가 10⁵~10⁶이면 파이썬 정수를 비트셋처럼 써서 `|`, `&` 한 번으로 집합 연산을 합니다. 가끔 `set`보다 빠르고 메모리가 작습니다.
