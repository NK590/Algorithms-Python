# 연습문제 — 격자 탐색

쉬운 것부터 어려운 순서로 정리했습니다. **문제 지문은 옮기지 않고** 링크와 "배울 점"만 적었습니다. 난이도(solved.ac 티어)는 시간이 지나며 바뀔 수 있어서 표에 적지 않았으니 각 링크에서 확인하세요.

| # | 문제 | 유형 | 배울 점 |
|---|---|---|---|
| 1 | [백준 1012 유기농 배추](https://www.acmicpc.net/problem/1012) | 덩어리 세기 | 배추가 인접한 칸들의 덩어리 수를 센다. 테스트 케이스마다 격자를 새로 만든다 (`count_regions`) |
| 2 | [백준 2667 단지번호붙이기](https://www.acmicpc.net/problem/2667) | 덩어리 크기 | 덩어리의 수와 각 크기를 오름차순으로 출력한다 (`region_sizes`) |
| 3 | [백준 2178 미로 탐색](https://www.acmicpc.net/problem/2178) | 최단 거리 | (1,1)에서 (N,M)까지 지나는 최소 칸 수. [solution.py](solution.py)의 `main()`이 그대로 풀이다. 입력은 공백 없는 0/1 줄이다 |
| 4 | [백준 4963 섬의 개수](https://www.acmicpc.net/problem/4963) | 8방향 | 대각선도 인접으로 본다. `DIRECTIONS`에 4개를 더하고 입력이 `0 0`으로 끝나는 형식을 처리한다 |
| 5 | [백준 7576 토마토](https://www.acmicpc.net/problem/7576) | 다중 시작점 BFS | 익은 토마토를 모두 큐에 넣고 시작해 모든 칸이 익는 날 수를 구한다. 안 익는 칸이 남으면 -1이다 |

## 풀이 메모

- 3번은 입력이 `"101111"`처럼 공백 없이 붙어 있어서 `list(map(int, line.strip()))`로 읽습니다.
- 5번은 입력 순서가 `가로(열) 세로(행)`라서 행/열을 헷갈리기 쉽습니다. 문제 입력 형식을 확인하세요.
