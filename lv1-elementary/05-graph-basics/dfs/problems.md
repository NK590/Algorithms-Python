# 연습문제 — DFS

쉬운 것부터 어려운 순서로 정리했습니다. **문제 지문은 옮기지 않고** 링크와 "배울 점"만 적었습니다. 난이도(solved.ac 티어)는 시간이 지나며 바뀔 수 있어서 표에 적지 않았으니 각 링크에서 확인하세요.

| # | 문제 | 유형 | 배울 점 |
|---|---|---|---|
| 1 | [백준 2606 바이러스](https://www.acmicpc.net/problem/2606) | 도달 가능 | 1번에서 갈 수 있는 정점의 수. `reachable`이 그대로 풀이다 |
| 2 | [백준 1260 DFS와 BFS](https://www.acmicpc.net/problem/1260) | 방문 순서 | 작은 번호 이웃부터 방문하는 DFS 순서와 BFS 순서를 출력한다. [solution.py](solution.py)의 `main()`이 DFS 부분을 처리한다 |
| 3 | [백준 24479 알고리즘 수업 - 깊이 우선 탐색 1](https://www.acmicpc.net/problem/24479) | 방문 순번 | 각 정점이 몇 번째로 방문되는지 출력한다. 재귀 깊이가 문제이니 스택 버전으로 푼다 |
| 4 | [백준 11724 연결 요소의 개수](https://www.acmicpc.net/problem/11724) | 연결 요소 | 방문하지 않은 정점마다 DFS를 새로 시작해 횟수를 센다 |
| 5 | [백준 1012 유기농 배추](https://www.acmicpc.net/problem/1012) | 격자 DFS | 칸을 정점으로 보고 인접한 배추 덩어리의 수를 센다. [격자 탐색](../grid-search/)으로 이어진다 |

## 풀이 메모

- 3, 4번은 정점이 10만 개라서 재귀 DFS는 `RecursionError`가 날 수 있습니다. `dfs_iterative`를 쓰세요.
- 5번은 테스트 케이스가 여러 개이니 케이스마다 방문 배열을 새로 만드세요.
