# 그래프 기초 (Graph Basics)

그래프와 트리를 **코드로 담는 방법**과, 그 위에서 **정점을 훑는 기본 탐색**(DFS, BFS)을 다룹니다. 최단 경로, 위상 정렬, 최소 신장 트리 같은 이후의 그래프 알고리즘은 모두 이 개념들 위에 쌓입니다.

## 한눈에 비교

| 개념 | 하는 일 | 핵심 도구 | 시간 |
|---|---|---|---|
| [그래프](graph/) | 정점과 간선을 코드로 담기 | 인접 리스트 / 인접 행렬 / 간선 목록 | O(V+E) |
| [트리](tree/) | 사이클 없는 연결 그래프, 루트와 부모 | BFS 순서로 부모·깊이·서브트리 | O(V) |
| [DFS](dfs/) | 깊이 우선으로 갈 수 있는 곳 탐색 | 재귀 / 스택 | O(V+E) |
| [BFS](bfs/) | 가까운 곳부터 탐색, 최단 거리 | 큐(`deque`) | O(V+E) |
| [트리 순회](tree-traversal/) | 이진 트리를 전위·중위·후위로 방문 | 재귀, 순회 결과로 복원 | O(n) |
| [격자 탐색](grid-search/) | 칸을 정점으로 보고 DFS/BFS | 방향 배열 | O(행×열) |
| [연결 요소](connected-components/) | 연결된 덩어리 세기, 사이클 판별 | 방문하지 않은 정점마다 탐색 | O(V+E) |

## DFS와 BFS 중 무엇을 쓸까

| 상황 | 선택 |
|---|---|
| 최단 거리 / 최소 이동 횟수 (가중치가 모두 같을 때) | **BFS** |
| 갈 수 있는가, 연결된 덩어리 세기 | 둘 다 가능 (보통 DFS가 짧다) |
| 모든 경로를 끝까지 따라가야 함 (백트래킹, 사이클, 위상 정렬, 서브트리) | **DFS** |
| 단계별로 퍼지는 현상 (불, 토마토) | **BFS** (다중 시작점) |
| 정점이 아주 많고 경로가 깊다 | 스택 DFS 또는 BFS (재귀 DFS는 깊이 제한) |

두 방법의 차이는 **다음에 방문할 정점을 꺼내는 규칙**입니다. 스택(나중에 넣은 것)이면 DFS, 큐(먼저 넣은 것)이면 BFS입니다.

## 읽는 순서

1. [그래프](graph/) → [트리](tree/): 표현 방법
2. [DFS](dfs/) → [BFS](bfs/): 기본 탐색
3. [격자 탐색](grid-search/), [연결 요소](connected-components/): 응용
4. [트리 순회](tree-traversal/): 이진 트리 전용
