# 재귀 (Recursion)

함수가 **자기 자신을 더 작은 입력으로 호출**해 문제를 푸는 방식을 연습합니다. 재귀는 하노이 같은 분할 정복, DFS, 백트래킹, 메모이제이션 DP의 공통 뼈대입니다.

## 개념

| 개념 | 하는 일 | 시간 |
|---|---|---|
| [재귀 기초](../../lv0-basics/06-recursion/recursion-basics/) (Lv0) | 기저 조건, 호출 스택, 팩토리얼·피보나치·거듭제곱 | |
| [하노이의 탑](tower-of-hanoi/) | 같은 모양의 더 작은 문제 둘 + 한 번의 이동으로 쪼개기, 점화식 풀기 | O(2ⁿ) |

## 재귀로 풀기 위한 세 질문

1. **언제 멈추는가?** (기저 조건: 가장 작은 입력의 답을 직접 안다)
2. **어떻게 작아지는가?** (n → n−1, 길이 절반, 한 칸 이동 등)
3. **작은 문제의 답으로 큰 문제의 답을 어떻게 만드는가?** (하노이: 앞 답 + 한 번 이동 + 뒤 답)

세 질문에 말로 답할 수 있으면 코드는 짧아집니다. "작은 문제를 호출하면 맞게 동작한다고 **믿는** 것"이 재귀의 핵심입니다.

## 재귀를 쓸 때 주의할 점

- **깊이 제한**: 파이썬의 기본 재귀 한도는 1000입니다. 깊이가 그 이상이면 `sys.setrecursionlimit`을 올리거나 [스택](../01-data-structures/stack/)으로 바꿔 쓰세요. (예: 깊이 10⁵의 DFS)
- **호출 횟수**: 하노이는 깊이는 n인데 호출이 2ⁿ번입니다. 같은 인자를 반복해서 호출하면 [메모이제이션](../07-algorithm-paradigms/dynamic-programming/)으로 한 번씩만 계산합니다.
- **전체를 만들지 않기**: "k번째만" 필요한 문제는 전체를 만들지 않고 목표 위치로만 내려갑니다. ([하노이](tower-of-hanoi/)의 `hanoi_kth_move`)
