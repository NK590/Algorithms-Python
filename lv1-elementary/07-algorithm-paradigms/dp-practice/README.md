# DP Practice (1차원·2차원 DP 연습)

> **한 줄 요약**: DP는 **상태를 어떻게 잡느냐**가 전부다. 연속합·LIS·집 털기·계단·격자 경로·삼각형, 일곱 가지 대표 문제의 상태와 점화식을 한 표로 익힌다.

## 1. 언제 쓰나 (문제 신호)

| 문제의 표현 | 상태 `dp` | 점화식의 뼈대 |
|---|---|---|
| 연속된 구간의 합이 최대 | `dp[i]` = i에서 **끝나는** 구간 합의 최댓값 | `max(a[i], dp[i−1] + a[i])` |
| 가장 긴 증가하는 부분 수열 | `dp[i]` = i를 **마지막으로** 하는 LIS 길이 | `max(dp[j] + 1) (j < i, a[j] < a[i])` |
| 이웃은 못 고르는 집 털기 | `dp[i]` = 앞의 i채 중 **고려한** 최대 | `max(dp[i−1], dp[i−2] + a[i])` |
| 연속 세 계단은 못 밟기 | `dp[i][k]` = i를 **연속 k번째**(k = 1, 2)로 밟은 최대 | k=1: `(i−2번째의 두 상태 중 최대) + s[i]` / k=2: `(i−1번째를 k=1로 밟은 값) + s[i]` |
| 오른쪽·아래로만 가는 최소 비용 | `dp[r][c]` = (r,c)까지의 최소 합 | `min(위, 왼쪽) + g[r][c]` |
| 삼각형 위에서 아래로 최대 합 | `dp[r][c]` = (r,c)에서 **시작하는** 최대 합 | `t[r][c] + max(아래, 오른쪽 아래)` |
| 장애물 있는 격자의 경로 수 | `dp[r][c]` = (r,c)까지 가는 경로 수 | `dp[r−1][c] + dp[r][c−1]` (장애물이면 0) |

[다이나믹 프로그래밍](../dynamic-programming/)의 4단계(상태 정의·점화식·초기값·계산 순서)를 이 일곱 문제에 적용합니다.

## 2. 핵심 아이디어

"마지막(또는 처음) 선택이 무엇이었는가"로 경우를 나눠 점화식을 세웁니다.

- **구간에서 끝나기 / 시작하기**: "i를 포함하는 가장 좋은 구간"을 상태로 하면 "앞을 이어 붙일지 새로 시작할지" 두 가지뿐입니다. 연속합이 그렇습니다. 앞의 합이 음수면 버리는 것이 이득입니다.
- **마지막으로 끝나기**: LIS는 "i에서 끝나는" 수열만 따로 세어야 다음에 어떤 수를 이을 수 있는지 판단할 수 있습니다. 전체 LIS는 `dp` 중 **최댓값**입니다 (마지막 원소가 어디일지 모르므로).
- **고려한 범위**: 집 털기는 `dp[i]`가 "i번째를 반드시 턴다"가 아니라 "앞의 i채에서 **어떻게든** 고른 최대"입니다. 그래서 `dp[i−1]`(i번째를 건너뜀)과 `dp[i−2] + a[i]`(i번째를 털고 이웃은 건너뜀) 두 경우로 끝납니다.
- **상태에 이력을 넣기**: "연속 세 계단 금지"는 직전까지의 연속 횟수를 모르면 다음 선택을 정할 수 없습니다. 그래서 상태를 `dp[i][k]`로 늘립니다. **다음 선택에 필요한 정보는 상태에 들어가야 한다**가 상태 설계의 기준입니다.
- **격자 DP**: 오른쪽·아래로만 간다면 `(r,c)`에는 위나 왼쪽에서만 올 수 있어서, 행과 열을 순서대로 보면 계산 순서가 자연스럽게 정해집니다.

**삼각형은 거꾸로**: 위에서 아래로 계산하면 마지막 줄의 최댓값을 한 번 더 구해야 합니다. 아래에서 위로 올라오면 `dp`가 "여기서 시작해 맨 아래까지 가는 최대 합"이 되어, 맨 위의 값 하나가 답입니다.

## 3. 손으로 따라가기

**연속합** `[−2, 1, −3, 4, −1, 2, 1, −5, 4]`

| x | −2 | 1 | −3 | 4 | −1 | 2 | 1 | −5 | 4 |
|---|---|---|---|---|---|---|---|---|---|
| current(= dp) | −2 | 1 | −2 | 4 | 3 | 5 | 6 | 1 | 5 |
| best | −2 | 1 | 1 | 4 | 4 | 5 | 6 | 6 | 6 |

답 **6** (`[4, −1, 2, 1]`).

**LIS** `[10, 20, 10, 30, 20, 50]`: `dp = [1, 2, 1, 3, 2, 4]`. 최댓값 **4**. `prev`를 따라가면 수열 `[10, 20, 30, 50]`을 복원합니다.

**집 털기** `[2, 7, 9, 3, 1]`: `dp[0..5] = [0, 2, 7, 11, 11, 12]` → **12** (2 + 9 + 1).

**격자 최소 경로** `[[1,3,1],[1,5,1],[4,2,1]]`

```
dp = [[1, 4, 5],
      [2, 7, 6],
      [6, 8, 7]]
```

답 **7** (`1 → 3 → 1 → 1 → 1`).

**경로의 수** `[[0,0,0],[0,1,0],[0,0,0]]` (가운데가 장애물)

```
dp = [[1, 1, 1],
      [1, 0, 1],
      [1, 1, 2]]
```

답 **2**.

**삼각형** `[[7],[3,8],[8,1,0],[2,7,4,4],[4,5,2,6,5]]`: 아래에서부터 `[4,5,2,6,5]` → `[7,12,10,10]` → `[20,13,10]` → `[23,21]` → `[30]`. 답 **30**.

**계단** `[10, 20, 15, 25, 10, 20]`: 최적은 `10 + 20 + 25 + 20 = 75` (0번, 1번, 3번, 5번을 밟음).

## 4. 구현

전체 코드는 [solution.py](solution.py)에 있습니다.

```python
def max_subarray_sum(numbers):              # 연속합 (카데인)
    best = current = numbers[0]
    for x in numbers[1:]:
        current = max(x, current + x)       # 앞을 이을까, 새로 시작할까
        best = max(best, current)
    return best

def lis_length(numbers):                    # O(n²)
    if not numbers:
        return 0
    dp = [1] * len(numbers)
    for i in range(len(numbers)):
        for j in range(i):
            if numbers[j] < numbers[i] and dp[j] + 1 > dp[i]:
                dp[i] = dp[j] + 1
    return max(dp)                          # 마지막 원소가 어디일지 모르므로 최댓값

def min_path_sum(grid):                     # 격자 최소 경로
    ...
    dp[r][c] = min(dp[r - 1][c], dp[r][c - 1]) + grid[r][c]
```

- `lis_sequence`: `prev[i]`에 "i 앞에 어떤 원소를 이었는지"를 기록해 수열 자체를 복원합니다.
- `rob_houses`: 직전 두 값만 필요해서 변수 두 개로 줄였습니다(공간 O(1)).
- `stairs_max_score`: `dp[i][0]` = 연속 1번째로 밟음, `dp[i][1]` = 연속 2번째. 연속 세 번째가 되는 전이는 아예 만들지 않습니다.
- `triangle_max_path`, `count_paths`, `min_path_sum`: 격자·삼각형 DP.
- 직접 실행하면 `N`과 N개의 수를 받아 연속합의 최댓값을 출력합니다.

## 5. 복잡도와 입력 크기 가이드

| 문제 | 시간 | 공간 |
|---|---|---|
| 연속합, 집 털기, 계단 | O(n) | O(1)~O(n) |
| LIS (이 구현) | O(n²) | O(n) |
| 격자·삼각형 | O(행 × 열) | O(행 × 열) |

- LIS의 O(n²)은 n ≤ 3,000~5,000이 한계입니다. n이 10⁵면 [LIS O(n log n)](../../../lv2-intermediate/04-dynamic-programming/lis/)이 필요합니다. ([복잡도 치트시트](../../../docs/complexity-cheatsheet.md))
- 격자가 1,000×1,000이면 10⁶ 칸이라 파이썬으로 충분합니다.

## 6. 자주 하는 실수

- **연속합에서 모두 음수**: `best`를 0으로 시작하면 틀립니다(`[−3, −1, −2]`의 답은 −1). 첫 원소로 시작하세요. (이 폴더의 테스트가 확인합니다)
- **LIS에서 `dp`의 의미**: `dp[n−1]`이 아니라 **`max(dp)`**가 답입니다. 같은 값이 연속되면(`[5, 5, 5]`) 증가가 아니므로 `<`를 써야 합니다(`<=` 아님).
- **집 털기 경계**: 집이 0채, 1채일 때 `dp[i−2]`가 없습니다. 변수 두 개를 0으로 시작하면 자연스럽게 처리됩니다.
- **계단에서 첫 계단**: 시작점(0번째 계단 앞의 땅)에서 1칸 또는 2칸 올라올 수 있으므로, 두 번째 계단은 첫 계단을 거치지 않고 바로 밟을 수 있습니다. 마지막 계단은 반드시 밟아야 합니다.
- **격자 첫 행·첫 열**: `dp[r−1][c]`나 `dp[r][c−1]`가 범위를 벗어납니다. 첫 행·열을 따로 처리하거나 가장자리를 0/무한대로 채우세요.
- **시작이 장애물**: `dp[0][0] = 1`로 두기 전에 시작 칸이 막혔는지 확인하세요. (끝 칸이 막힌 경우는 `dp`가 자연스럽게 0입니다.)
- **삼각형을 위에서 계산**: 가능하지만 마지막 줄에서 최댓값을 한 번 더 구해야 합니다. 아래에서 올라오는 편이 간단합니다.
- **`dp`를 `[[0] * m] * n`으로 생성**: 모든 행이 같은 리스트를 가리킵니다. `[[0] * m for _ in range(n)]`로 만드세요. ([2차원 배열](../../../lv0-basics/01-data-structures/two-dimensional-array/))

## 7. 변형과 응용

- **LIS O(n log n)**: 이분 탐색으로 줄입니다. → [LIS](../../../lv2-intermediate/04-dynamic-programming/lis/)
- **LCS, 편집 거리**: 두 문자열을 2차원 `dp[i][j]`로. → [LCS](../../../lv2-intermediate/04-dynamic-programming/lcs/)
- **배낭 문제**: 상태가 "몇 번째 물건까지, 무게 얼마까지". → [배낭 문제](../../../lv2-intermediate/04-dynamic-programming/knapsack/)
- **구간 DP**: `dp[l][r]` = 구간 `[l, r]`의 답. → [구간 DP](../../../lv2-intermediate/04-dynamic-programming/interval-dp/)
- **연속합의 변형**: 원형 배열, 하나 지우기, 길이 제한 등. 상태를 하나 늘려서 푼다.
